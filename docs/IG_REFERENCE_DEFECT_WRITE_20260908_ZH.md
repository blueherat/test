# IG写入中的参考往返误差与相减控制

2026-09-08。用户要求将FSG的信息搬运taste用于AG/IG，不能把“条件写进噪声”本身当作创新。当前候选不使用PFR修正，不以强弱模型达成一致作为质量目标。

## 为什么先检查数值往返

令S为强场、G=W+1.78(S−W)为原生IG场。目标是短程使用G，将有效纠错写回当前状态，随后只用S生成。给定噪声时间t=1、H=.125，定义Euler前向 `F_G(z)=z−HG(z,t)`，近似返回 `R(y)=y+HS(y,t−H)`。

朴素写入T_G=R∘F_G，即使G=S也不一定为恒等；参考往返T_S=R∘F_S带有数值误差。此前CFG撤条件实验的纯null往返出现大量纹理或不完整主体，不能将这项误差当作条件写入本身。

候选固定为 `B_G(z)=z+[T_G(z)−T_S(z)]`。G=S时，两项完全相等，写入为零。用原始G写入后再用S返回，与先前合成参考2S−G不同；也不等于既有strong-flow共轭未来gap方法。相减操作本身是一般数值误差控制思路，不宣称其单独具有新颖性。

## 局部误差说明

假设所选参考前向F_S在局部可逆，准确逆为R*，近似返回R=R*+E。则准确离散搬运为A=R*∘F_G，且R*∘F_S=z，所以

`B_G−A = E(F_G(z))−E(F_S(z))`。

若E在这两个查询之间Lipschitz，误差有界为 `L_E H ||G−S||`；朴素返回的误差为E(F_G)，没有这种随guidance差消失的性质。这里的准确逆是所选离散参考前向的逆，不自动等于连续ODE逆或正确终点分布。该推导不证明FID改善、全局收敛或一般非线性坐标不变性。

它给出一个具体预期：当AG/IG差较小时，公共往返误差可能比有效写入更大；减去它可以恢复对纠错信号的响应。是否因此提高实际质量仍需生成实验。

## 本轮假设的边界与下一步判别

AG原文把强弱差解释为学习分布比值的梯度所产生的纠正，强调两个模型在相近位置有不同程度的欠拟合：https://arxiv.org/html/2406.02507v3 。因此，把CFG的条件/无条件两支机械替换为强/弱两支、追求S=W，不自动产生质量目标；两个模型可能在错误处一致。

当前写入的目标是让强采样器保留有用的guided纠错，不能用弱模型接管或节省弱头计算替换此目标。RAEv2原生IG已经在同一次前向中得到强弱预测（https://raev2.github.io/），本轮104/106 Full调用比原生100还多，不具有预设的提速优势。

相减写入在H较小时仍有 `B_G(z)−z = −H(G−S) + O(H²)`，假设场在当前局部及时间上光滑、guidance幅度有界。因此，零guidance恒等是必要数值控制，不是新机制证明；若质量改善，需要区分当前guidance脉冲、有限时段的状态响应与额外计算的贡献。只比raw更好而不胜过普通Full/原生IG，不足以保留为主方法。即便1K越过基准，也需同预算和独立确认后才扩大结论。

“撤去guidance后仍获益”是研究检验，不强制所有纠错必须在t=1的两轮内完成。当前固定高噪写入失败，只否定该具体配方；但也不应在没有新机制证据时扫描H/K救结果。
