# SiT-XL PFR：补足共同强度网格的上侧范围

触发依据为[已完成的十二点结果](OFFICIAL_SIT_PFR_SYMMETRIC_RESULTS_20260909_ZH.md)：普通 IG、time-only PFR、完整 projected PFR 的最低值均位于 scale=1.75 的上界。尚未夹住最优点，不能冻结这一点就宣称已胜过充分调优基线。

在产生任何新增质量结果前固定六臂：ordinary2.0、time2.0、projected2.0、ordinary2.5、time2.5、projected2.5。三个家族共享相同的两个新增强度，其余设置完全沿用原协议：同一官方 SiT-XL/2 joint depth-8 EMA，同一 MSE VAE、FP32 网络 / FP64 状态、TF32 关闭、B4、原 1K 探索银行。普通 Euler115；PFR Euler100+50 prefix8，h=1/32，noise-time>.5 激活。

直接复用已验证并锁定源码的普通 IG 与 PFR 采样函数，不重写动力学。新包装器只累计完整网络调用，PFR 的额外调用由复用函数返回。每卡先对三种方法各复现四张 scale=1.75 历史图像；共三组各16张、48个图像输出，必须逐像素相等。分片、合并、输入与源码身份及实际调用数继续核验。四卡共同完成同一臂后再进入下一臂。

六臂全部保留，完成后与旧十二点统一形成十八点表；新增六点分别从原始特征独立复算 FID，旧十二点复用已通过的数值核验。绘制共同范围的 FID/IS 曲线，报告每个家族是否已出现内部最小值。若最低点仍落在2.5上界，应明确调优仍不完整，不以外推拟合值或网格截断声称最优。

本次仍是探索，没有改变输入银行，也没有新增方法。随后只有在配置冻结后，新的独立噪声实验才能提供确认；不能把旧5K重新标为新配置的确认，也不能以1K改善不到固定百分比直接排除较大样本验证。原生 SDE＋CFG＋IG 是另一个明确标注计算与解码器差异的强基线，不能与本次 Euler 表混作同成本比较。
