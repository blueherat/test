## 方向一：原生 Base 的多速率基线

源码 [`DiTwDDTHeadIG.forward`](../external/RAEv2/src/stage2/models/DDT.py) 的实际结构为 28 层 encoder 加 2 层 Full decoder，Base 在第 8 层取出表征。原生 Base 可在第 8 层后直接执行自己的读出，免除剩余 encoder 和 Full decoder。读出并非一个裸线性层：`SiLU(t+h8)` 之后仍有 `DDTFinalLayer` 的 RMSNorm、adaLN shift/scale 和 1440→1024 线性层。完整调用已有 Base 输出，宏步完整查询时可以复用它；这不等于微步 Base 免费，也不能把不同调用都记为一个等价 NFE。

以递增时间 \(\tau=1-t\)，保留原生 BF16 IG 算术及最后转 FP32 的顺序，定义

\[
 V(z,\tau)=\frac{G_{\rm native}(z,t)-z}{d(t)},\qquad
 b(z,\tau)=\frac{B_{\rm native}(z,t)-z}{d(t)},\qquad
 R=V-b,\quad d(t)=\max(t,.05).
\]

数学上的 \(V=b+R\) 是精确分拆，不增加 guidance 增益。在实数算术下窗口内 \(R=1.78(F-B)/d\)；实际实现应从真实 native 输出作差，不能用 FP32 重排冒充位级一致。Base-only 需要独立与完整 forward 的 Base 分支检查 parity，并沿用当前 native TF32 设置；旧审计的精度配置不能直接继承。

原 IG 在 \(t=.1\) 有硬窗口，分母在 \(.05\) 有折点。宏步及差分应按这些已存在事件分段，不跨事件引用平滑误差展开，也不为了效果移动事件。末端是否查询 \(t=0\) 及 floor 的连续区间必须明写；原 Euler 最后一段直接跨到零，换积分器后不能暗中更改所求场。

**冻结残差为什么只有一阶。** 宏步从 \(y_n\) 出发，记 \(r_n=R(y_n,\tau_n)\)，高精度求解

\[
 w'=b(w,\tau)+r_n,\qquad w(\tau_n)=y_n.
\]

对平滑区间作 Taylor 展开，记 \(D_VR=\partial_\tau R+J_RV\)：

\[
 w^*=y_n+HV_n+\tfrac12H^2(\partial_\tau b+J_bV)_n+O(H^3),
\]

\[
 y(\tau_n+H)-w^*=\tfrac12H^2D_VR_n+O(H^3).
\]

所以 gap 范数小并非正确条件；常量残差可很大却容易积分。反之幅值 \(\varepsilon\) 的 \(\sin\omega\tau\) 残差，其主误差常数随 \(\varepsilon\omega\) 增长。这个局部误差机制与 SISC 2022 的分析一致，不能宣称首次发现。

**一个可审查的二阶补偿。** 在预测端点查询 \(r^*=R(w^*,\tau_n+H)\)，令

\[
 y_{n+1}=w^*+\tfrac H2(r^*-r_n).
\]

因为 \(r^*-r_n=HD_VR_n+O(H^2)\)，上述缺项消掉。若便宜微积分用 Heun、微步长 \(h\)，局部误差为 \(O(H^3+Hh^2)\)。系数 \(1/2\) 来自阶条件，无需拟合。下一宏步若复用 \(r^*\)，它在预测状态而非已修正状态，误差为 \(O(H^2)\)，需要作为带缓存状态的方法分析稳定性，不能称为精确 FSAL。它只是说明可行耦合的推导例子；正式基线也可直接采用已发表的二阶 MRI 系数。

CPU 标量 \(V=-y,b=-.3y\) 实验中，宏步数 160→320 的观测收敛阶：冻结残差 1.00177，端点补偿 2.00291，复用预测端点版本 2.00004。它验证此例的阶数，不是一般稳定性证明，更不是 RAEv2 结果。

**成本门槛。** 若完整查询单次耗时为 \(C_F\)，Base-only 为 \(C_B\)，K 个宏步、每宏步 m 个 Heun 微步的粗成本为

\[
 (K+1)C_F+(2mK-q)C_B+C_{\rm extra},
\]

其中 \(q\) 只能数实际可复用且输入完全相同的 Base 查询；\(C_{\rm extra}\) 包含张量运算、缓存和同步。相对于 mK 次完整 Euler 查询，忽略边界开销时至少需要 \(1+2mC_B/C_F<m\)。例如 m=2 要求 \(C_B/C_F<.25\) 才可能胜过同细网格 Euler；“只有八层”本身不能证明满足。时间差异还受 BF16 kernel、读出、B8 和共享 GPU 影响。这个方向的创新性弱，但成本门槛清楚，适合先判伪。

## 方向二：只学习完整场的快速变化

固定 Base 主干与整段原生读出，在最终线性层的实际输入特征 \(u_8\) 上加极小增量 \(A_\phi u_8\)，从而得到便宜场 \(b_\phi\)。昂贵残差定义为 \(R_\phi=V-b_\phi\)，完整场没有被蒸馏掉。希望把难以粗步积分的变化交给廉价场，留下较慢残差。

在**同一实际完整模型轨迹**的相邻状态上定义

\[
 \mathcal L_{\rm var}(\phi)=\sum_i\Delta\tau_i\left\|
 \frac{(V_{i+1}-V_i)-(b_{\phi,i+1}-b_{\phi,i})}{\Delta\tau_i}
 \right\|^2.
\]

权重 \(\Delta\tau_i\) 是时间积分的求积权重，非手动时间增益；非均匀 shifted 网格不能无解释地用 step index 差分。若原生特征给出的增量在 clean prediction 空间，转换到 velocity 后的 \(1/d(t)\) 也必须包含在差分中。不得跨硬事件拟合导数。BF16 输出相减会产生约为量化误差除以 \(\Delta\tau\) 的噪声，需记录真实 native 输出，不能拿 FP32 模型的平滑性替代。

rank8 的 1440→1024 两因子增量为 19,712 参数，rank16 为 39,424 参数；这比训练整个 readout 小。两个因子同时学习并非凸回归。若要求单一线性最小二乘，可固定一个由既定、无标签特征构造的投影，只训练另一因子，使用明确的最小范数解处理不可识别常数；投影构造、秩与数值截断都必须先固定，不许比较多个秩挑 FID。当前没有实际选择或训练这些版本。

其区别必须通过**同特征、同参数、同数据、同求解器、同成本**的 value-fit 对照建立；少训练参数不等于少训练成本。完整 teacher 轨迹生成、特征缓存和拟合均单列，避免藏进“training-free calibration”。有计算优势还需大于固定成本的摊销点 \(N_{\rm break}=C_{\rm train}/(C_{\rm baseline}-C_{\rm candidate})\)。

**同一参数的正机制例。** 令 \(V(\tau)=M+\varepsilon\sin\omega\tau\)，限制 \(b_\phi=\phi(1+\sin\omega\tau)\)。在一完整周期上，值拟合最优 \(\phi=(2M+\varepsilon)/3\)，导数拟合最优 \(\phi=\varepsilon\)。取 \(M=100,\varepsilon=1,\omega=20\)，前者值 MSE 为 3267、残差导数 MSE 为 871200；后者值 MSE 更差为 9801，但残差恒等于 99，导数误差为零。若便宜流精确积分，后者冻结残差就精确。这说明目标差异有实质，并不意味着真实模型具有该结构。

**必须面对的反例：完美 teacher loss 仍可失稳。** 考虑完整场 \(V=2\tau\)，teacher 为 \(y=\tau^2\)，定义

\[
 b=2\tau+L(y-\tau^2),\qquad R=-L(y-\tau^2).
\]

在整条 teacher 上 \(R\equiv0,D_VR\equiv0\)，任何轨迹差分损失都是零；完整场对状态的 Jacobian 也为零。但便宜场的横向 Jacobian 为 L，残差为 −L，二者靠同时求值抵消。冻结残差后，Heun 从零出发第一微步即产生 \(-Lh^3/2\) 的误差，便宜流随即放大偏离轨迹的误差。CPU 取 L=20、宏步 H=1、32 个 Heun 微步，完整 Heun 的解析终点为 1，便宜预测为 −78566.18，上述端点补偿后为 707105.64。端点校正没有救回失稳。

因此，\(D_VR\) 小不能代替横向耦合稳定性条件；即便它在整条真实轨迹上精确为零，也未控制 \(J_b,J_R\) 或实际微步偏离。二阶方法消掉第一残差导数缺项后，剩余误差还涉及更高材料导数与耦合项；不能把只拟合第一差分称为二阶方法的最优目标。已有 SISC 2022 理论要求代理误差及其导数的相应界；我们的狭窄候选贡献只能是特定训练目标与可验证稳定性结构，而非多保真分拆或导数重要性本身。当前检索没有证明该训练目标全新。

## 未执行的机制审计草案与停止条件（用户拒绝后作废）

以下是拒绝前提出的最小机制检验，未执行：先用固定 8 条轨迹做成本及误差诊断；最多再用预先保留的另 8 条轨迹核验。相同 class/noise、B8、实际 native BF16 场，首批与留出身份先记入 manifest；不根据结果换类、换 seed 或挑子集。不先采 1K，也不测 FID 选微步倍率。

1. 原生 Base-only 在真实输入上与完整分支 parity；分别交错计时 Full、Base-only 和缓存/校正操作，使用 CUDA event 与端到端时间。报告实际调用数、B8、warmup、显存和共享 GPU 限制。若唯一预定微步方案连乐观成本不等式都不满足，立即停止。
2. 沿相同 actual rollout 存储原生 V、B、实际时刻和状态身份，计算分段 \(\Delta R/\Delta\tau\) 与 \(\Delta V/\Delta\tau\)。统计积分加权误差，而不是只给平均 gap 范数。事件附近独立列出，不能靠剔除难点改善结论。该检查只作为否定门槛，不能认证质量。
3. 在同一批轨迹的预定宏区间，实际跑 cheap 微步与完整细步参考，检查预测缺陷及端点补偿是否符合阶数；在**候选自己走到的状态**查询完整 residual，核对缓存误差与横向放大。这样直接检验反例暴露的耦合问题；不以 teacher 上良好相关性代替。
4. 只有成本与稳定性都成立，才决定是否值得极小 adapter。若训练版不能在留出上同时改善实际积分缺陷并保持成本优势，停止；导数 loss 或值 MSE 单独改善不够。真正的质量试验随后单独冻结协议，比较相同端到端预算的官方 Euler、适用的高阶 solver 与原生多速率基线。所有校准、训练及 teacher 成本另列，不把多采样、挑样或调度增益混入。

## 不把初始耦合包装成分布提升

若每个 \(Z_i\sim\mathcal N(0,I)\) 的边缘保持不变，且 \(X_i=G(Z_i,c_i)\) 的固定生成映射逐样本独立作用，则各 \(X_i\) 的边缘分布也不变。因而总体 Inception 均值、covariance 与总体 FID 不变；成组相关性可能改变有限样本 FID 的偏差/方差和画廊多样性。一次插件 FID 下降不能作为用户要求的分布质量改善。对已有 cohort 相互作用场，此逐样本映射前提不成立，更不能用同一结论为改噪声协议开脱；那将是另一个算法。
