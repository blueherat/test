# Base 的分布错误不是统一的额外扩散

2026-09-08。四组1000张采样、两套官方评价和原始数组分析全部完成，进程均退出0。**在固定1000类别、每类两份独立噪声上，Base的平均类内总方差比Full低1.6500%，空间平均特征的类内方差却高9.5392%；空间残差的类内方差低8.0162%。** 两份噪声的跨副本内积还检测到条件均值偏移。这些结果不支持把Base直接建模为Full叠加独立零均值Gaussian噪声。

这不是新guidance的成功，不否定AG的一般兼容欠拟合解释，也没有证明上述分量对应何种视觉错误。终点统计不等于同噪声时刻的score密度；有限Euler、模型近似和表示坐标均属于结论边界。

## 类内宽度与均值偏移

两份独立噪声给出每类 `.5||X1−X2||²`，对1000类等权。Pool是每通道256个空间位置的平均。空间残差是去掉该空间均值的正交分量，因而全latent方差迹严格分解为 `256×pooled迹 + spatial残差迹`。

| 表示 | Full类内协方差迹 | Base类内协方差迹 | Base/Full |
|---|---:|---:|---:|
| 全latent | 192508.866215 | 189332.514600 | .983500 |
| pooled 1024维 | 272.699265 | 298.712591 | 1.095392 |
| 去空间均值残差 | 122697.854274 | 112862.091229 | .919838 |
| 固定64维pooled投影 | 16.862838 | 18.518479 | 1.098183 |

Base−Full的类内迹差：全latent −3176.351615，pooled +26.013326；2000次类别配对bootstrap的2.5%/97.5%分位数分别为[−3953.629916,−2434.689248]、[23.153543,28.803766]。这些描述固定类别集合的重采样波动，不能作为独立训练或整个类别总体的保证。只有358/1000个类对呈现全latent正差，pooled则731/1000为正。

条件均值偏移的平方范数通过跨独立噪声副本的强弱位移内积估计，避免把同副本随机差异直接平方。全latent估计2744.509948，pooled估计9.692375；相应bootstrap区间为[2598.235625,2898.388660]、[9.216309,10.190911]。保留原始有符号逐类内积，没有截零。它衡量条件均值变化，不判断其语义正确与否。

固定64维协方差差谱含22个负特征值；全部谱保留。有限高维估计存在随机负特征值，因此主要结论基于预定迹差与均值量，不把每个负方向当作可部署投影。

第一seed相对真实validation1000图的统计也已完成：全latent总方差Full254666.270216、Base251276.491146、真实262279.125947；pooled方差Full505.093022、Base530.713022、真实495.365423。真实bank每类恰一图，类别权重一致，但没有真实类内方差估计，不能用总体量冒充它。

## 复核、成本与下一步

原始数据SHA、请求/源码身份、样本配对及第一seedFull像素均通过。独立CPU计算不导入原分析函数，逐个重读全部1000个类对，使用`var(ddof=1)`和平方范数差重建类内迹及均值偏移；关键标量最大差5.68e−14，7.68秒。主总体统计13.46秒，主类内统计14.18秒。官方FID尚未另做独立feature-Gram数值重算，按官方实现报告。

四组采样与保存分别811.70、797.57、795.28、807.51秒；每组100000次完整模型样本调用（两头均计算），约53.5 GPU分钟，总墙钟因启动时间不同而不同。没有用此未优化的Base读取声称速度优势。全部FP32终点latents、uint8图及feature缓存保留。

下一步的机制问题收窄为：**原生IG如何同时影响过大的pooled类内变化与不足的空间残差变化，以及哪些影响对应实际质量？** 本轮不能直接推出按分量调gain或做终点方差匹配；这些与仓库旧subspace/moment路线邻近，必须先核对旧实验，防止把统计分解重命名为新方法。内部条件直接外推失败的裁决保持不变，PFR未混入，论文未写。
