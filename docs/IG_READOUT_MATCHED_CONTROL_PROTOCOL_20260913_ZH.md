# 原结构读出的等训练控制

冻结时点：MLP Context已在SiT-S/2 ImageNet-100独立5K达到37.2343 FID，原IG40.2817，ADG39.5775，66步原IG40.2734。Raw/LN/LN+stats的独立1K没有支持归一化统计解释。此时仍有关键混杂：原IG头使用旧训练配置，MLP使用3000步真实数据训练。不能把整套配置的收益直接归因于MLP。

只增加一个新控制：原depth4 AdaLN+Linear弱头从官方零初始化重新训练，保持原结构和原始条件输入；不沿用旧弱头参数。真实数据、每步clean/类别/噪声/时间、batch32、3000步AdamW(lr3e-4,wd1e-4)、EMA0.995、固定最终EMA都与保留MLP完全相同。先共享32批用于MLP的固定逐通道统计估计，原头不改变自己的归一化方式；实际更新从第33批开始。主干冻结，监督只有真实velocity，不使用strong预测或生成数据。

同循环复做Raw MLP用于验证训练数据/配置重放，要求最终EMA逐tensor等于已保留的Context；这个重复不是新候选，也不重新生成它的质量样本。两种结构本身的归一化与参数化仍不同，所以该控制检验的是整套读出结构/输入处理与训练配置的区别，不能进一步唯一归因于非线性。

只生成新原结构头的1000图，复用上一轮归一化实验的种子2026121341和逐样本噪声/标签，与已经保存的Raw、原IG、ADG比较。三个输入文件分别校验SHA一致，不变更原五臂协议和原输出目录。本检验是看到之前结果后的补充控制，不将其当成新的独立确认。新增生成1000图，引用比较3000图。

所有采样原64步Heun/128 full、0额外prefix，在同一次共享主干中替换旧弱头；IG强度与窗口沿用原设置。保存全部样本、调用与权重/源码/输入hash，并从缓存特征FP64复算FID。完整训练MSE仅记录，不用它判断指导质量。原结构新头与旧头参数量相同；另做同GPU、batch8、三次完整采样和解码计时，不宣称精确零开销。

固定判定：如果新原结构头与Raw的FID相差不超过0.5，或比Raw更低，则训练配置足以解释大部分收益，不能归因于MLP结构。如果Raw比等训练原结构头仍低至少1且IS至少其90%，则支持保留整套读出结构/输入处理为研究因素。中间区间视为未分清。无论结果如何，不扫学习率、步数、初始化或引导系数，也不自动将这个控制提升为新方法。
