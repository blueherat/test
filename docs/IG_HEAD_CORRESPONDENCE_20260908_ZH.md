# 强弱头空间对应关系：固定前提检验

2026-09-08。本轮考虑把信息放进强弱预测之间的空间对应关系：若原生gap混有同一结构的错位，先对应再比较是否有意义。此处只检验离散token错位是否足够大，没有部署新guidance，也不以gap降低证明质量。

## 与已有工作的边界

S-CFG（CVPR2024）已经研究全局CFG强度带来的空间不一致，用注意力划分语义区域并分配区域强度：https://arxiv.org/abs/2404.05384 。本轮阅读其摘要以核对这一边界，未声称完整阅读正文。当前问题是同状态Full/Base clean预测的token对应，不是区域gain；但“空间对齐”及最优匹配本身不具有自动的新颖性。最初CVF PDF获取失败403，后通过arXiv摘要核对，不把失败请求算作全文阅读。

## 固定检验

使用已有8条原生IG FP32轨迹的索引0/47/73/87，Full/Base输出为1024×16×16。32次B1 Full前向，关闭TF32；每个缓存状态及其原生一步后继都通过字节SHA复现。输出完整保存，匹配计算与模型采样分开。

对256个位置的1024维向量作不受空间距离限制的最小平方代价一对一指派。恒等置换始终可行，因此最优值给出本类任意位置置换最多能去掉多少平方gap，而不是所有连续变形或插值的上界。第二个固定检验仅用偶数通道求对应，在奇数通道测量变化；这不是独立数据或独立语义标注。

恒等输入、已知31位置循环置换均精确恢复。CPU重读全部32份输出并核对哈希；不调用另一个独立指派求解器，不夸称跨实现最优性验证。
