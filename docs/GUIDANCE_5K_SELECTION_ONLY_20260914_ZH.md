# 5K 扫参执行修订：跳过当前点，取消独立验证

用户指示：“不用跑w = 2了，直接跑后面的吧，然后独立5k验证其实也不用”。

- 停止当时正在生成的第4层 MLP、w=2 粗扫点，记作用户取消，保留部分批次，不计算部分 FID，不标记为数值失败。其他头与 SG 的系数范围仍按此前 1–2 执行。
- 后续继续第8层 MLP。所有保留的粗扫点与细扫点仍使用 5000 张；步长分别为 0.2 和 0.05。
- 细扫仍按两个端点完整 5K FID 的均值选择前三个相邻区间。取消的点不能充当区间端点。
- 取消头实验和 SG 的独立新种子 5K 确认阶段。原先已生成的调参结果继续用于选参；已经准备的独立噪声输入保留，但不生成对应图像。
- SG 保留此前安排的两种 NFE 成本对照，改在同一个调参 5K 输入组上生成；不重新生成最优 SG 或 IG 基线。它们是计算成本对照，不是独立验证。
- 最终报告明确展示“已测系数中最低调参 FID”，不将同组选择后的最低值声称为独立验证收益。

原冻结请求、采样实现及批次摘要不修改。执行修订通过 selection_only.py、独立 execution_manifest.json 与 skipped.json 记录；新细扫请求绑定这些修订来源。完整像素、缓存特征与原有运行检查保留，省略部分调参终点数组的策略沿用原方案。
