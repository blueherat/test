# 回到 guidance 信息写入 latent：两轮5K后的方向回顾

2026-09-07。用户明确指出：“fix point是把guidance信息放入latent里……不动点是解释这个的。”本回顾在当前两条空间协方差5K与独立审计完成后形成。3%目标仍未达到。

## 本次两轮研究留下什么

时间求积：原FID6.94977；guidance-only6.94955、Full-only6.95027、完整二阶6.96546。只改变原指导场的时间求积，没有实质收益。这没有检验PFR的核心，因为PFR改变的是校准里的反事实参考，不是沿已访问轨迹更精确地积分。旧PFR材料已有更高阶积分不能复制其收益的证据，本轮起点应更充分尊重这一事实。

空间协方差：完整K为6.90614，对角K为6.92158。完整K对official改善0.6278%，而旧方向方差已改善0.5641%；新增结构只额外减少0.00443 FID。残差似然显著改善，没有转成足够大的生成收益。公式证明了怎样拟合所选统计目标，未建立把有用guidance写进latent的机制。用户指出的方向偏移成立，结束该分支。

两轮代码、配置、样本与特征、正负结果和数值核验均保留。当前5K bank已反复用于探索，不能把微小获胜点称作独立确认。

## 重新读 FSG 后应保留的核心

原文：[Towards a Golden Classifier-Free Guidance Path via Foresight Fixed Point Iterations](https://proceedings.neurips.cc/paper_files/paper/2025/file/b56d827a2b8433517e722e0272c7f464-Paper-Conference.pdf)。本轮反复核对§3、附录A.1–A.5/B/C，并补读§4的机制消融。

1. **改变当前状态，使后续生成能够使用guidance信息。** 长区间条件去噪构造较明确的原型，逆向参考过程把原型信息带回当前latent。固定点组织了这种写入与反馈，而不是质量的先验定义。
2. **写入与读取是不同角色。** 附录式13–14、16–17把CFG/CFG++精确重写为latent校准和使用已缓存无条件预测的推进。式14/17中的预测在校准前位置评估；Algorithm2/3也保留最后一次校准前的reference。不能把它随手换成校准后重新评估reference并仍称作同一算法。
3. **较长视野服务于信息的形成。** 论文以未来条件原型、早期语义形成与有限预算为线索设计较长区间和少数迭代。借鉴的是这一因果顺序，不是认为任何长区间、收缩或更小预测差都能提高质量。

附录B的匹配/不匹配prompt实验支持条件信息与latent已有内容相容的直觉。附录A.5的平均随机方向收缩是辅助证据；不代替信息语义、全方向稳定性或FID。理论边界应被准确记录，同时不能让审查边界取代对核心机制的正面思考。

## PFR给出的更直接起点

[反事实残差记录](PFR_COUNTERFACTUAL_RESIDUAL_THEORY_ZH.md)中，ordinary IG与PFR可分别写为

    B = W(p)+β[S(p)-W(p)]，
    PFR = W(p)+β[S(p)-W(q)]。

当前弱头的推进参照保留，校准里的负参考改由反事实query读取。这是“先写入一个提案，再观察参考如何响应”的结构。它并不要求新query的弱预测更准：SiT中恰有弱预测MSE变差而生成变好的证据。任何新解释都应能容纳这一反常事实。

RAEv2的Full/Base在同一条件下训练，Base还存在能力差距。因此，要求Base读出Full的全部内容，可能又变成迫使弱模型追赶强模型。写入机制首先要明确**谁负责后续读取**，不能由强弱差的代数形式自动决定。

## 一个待检验候选：由实际读取者决定写入方向

讨论中最初用W作为一般读取者说明公式。对RAEv2，更值得先考察的是以Full作为读取者，以原生IG已经给出的增量作为消息：

    F_t = Full(z_t,t)， G_t = native_IG(z_t,t)， M_t = stopgrad(G_t-F_t)。

这样不要求Base追上Full。消息来自已有生成收益的原IG，而不来自新拟合的误差代理；但这仍不保证每个局部消息都能改善终点分布。

原Euler可以在实数算术下精确拆成

    z_s = z_t -(t-s)(z_t-F_t)/t + q M_t， q=(t-s)/t。

即Full推进，加一次写入δ_IG=qM_t。该等式用于机制解释，重排浮点运算未必逐位相同；后续实现仍须保留原生算术控制。

若R_t为冻结参数的读取者，希望在同样的latent扰动预算r_t=||δ_IG||内，使读取变化尽量沿消息M_t，则局部问题是

    maximize_δ M_t^T J_R δ， subject to ||δ|| <= r_t。

由Cauchy–Schwarz得到δ*=r_t J_R^T M_t / ||J_R^T M_t||。这只需一个向量的反向乘积，不需拟合协方差或求整个Jacobian。若J_R^T M_t=0，则这个一阶目标无法区分写入方向；不能凭空声称获得改进。

在光滑连续模型的一阶近似下，该方向对既定消息的读取增量不低于同预算的原始写入。它既不是强弱共同移动的固定点，也没有证明FID改善。这是局部写入效率的候选机制；实际原生BF16模型仍需要有限扰动验证，不能把连续近似的梯度当作真实量化函数的精确导数。

## 成败要检验“写入以后”

- **当步是否读到：** 对相同原生状态和相同写入大小，实际模型是否产生预期的消息方向响应。冻结本次消息，避免目标随改写一起漂移。
- **后续是否留存：** 写入之后暂时撤去额外guidance，让Full独自推进，比较有/无写入以及原生写入的配对轨迹。观察信息是否仍在，而不是只让当步输出贴近某个目标。
- **能否改善生成：** 留存不是质量定理。只有前述机制与真实有限更新相容，才值得冻结候选进行完整配对5K，并计入模型反向传播成本。不得用读取损失或留存量替代FID，也不得将本讨论称作已验证新方法。
