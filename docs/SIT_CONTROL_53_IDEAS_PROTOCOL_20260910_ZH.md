# 控制输出五十三项的配对1K实验协议

本轮在冻结ImageNet100小SiT上实现五十个控制输出假设，再加三个重点方案。每项使用4个CFG增量强度和3个结构参数，共12组；636组候选、73组对照，合计709组，每组1000张。所有配置都实际采样评价，不按代理输出提前淘汰。没有自动5K确认、额外大诊断或新增模型训练。

## 输出与采样

时间由噪声0到图像latent终点1。主ODE为Heun64；CFG场为 $v_c+a(v_c-v_u)$，$t<0.75$ 启用。四个强度为0.5、1.25、2、2.75。每项三个结构参数、输出、理由和区别见[完整目录](FSG_CONTROL_50_IDEAS_20260910_ZH.md)，三项精确命题见[重点推导](FSG_CONTROL_THREE_PRIORITY_IDEAS_20260910_ZH.md)。

默认优化未来为8步Heun完整到1；滚动项目按自己的实际移动终点计算。第52项另查询16步未来作验收。默认事件第8、24步；积分、微分、信赖半径、递推辨识、误差漏斗、滚动规划和触发/接管项目使用第8、16、24、32、40步。每个batch的事件上下文与历史独立，跨配置不共享更新状态。

默认输入空间是当前条件/null gap和一个固定随机方向的二维正交空间。有限差分步长为 $0.001\max(\|x\|,\sqrt{4096})$；半径为 $(4/64)a\|v_c-v_u\|$。明确扫描半径的项目再乘各自结构参数。第20项切向写入后重投影，第43项把维度扫为2/4/8；第37、49项最多两次基本更新并限制最终加速候选在两倍基础半径内；第44项分别约束两次计划输入。一般候选经实际非线性目标下降验收；各特殊控制器使用目录中明示的实际接受条件。

SDE项目在前8步使用ODE，之后进入Euler–Maruyama尾部：漂移 $2v-x/t$、扩散平方 $2(1-t)/t$。未来SDE同样从正时间事件开始，使用8步、固定共享布朗探针。实际主采样的布朗噪声与未来探针分别由输入内容哈希派生；重跑、断点恢复和候选比较不重新选择随机数。原生SDE及SDE语义直接控制使用同一主采样器。

## 对照与语义资产

73组对照为：强条件模型1组，局部注意力IG回归锚1组，原生CFG12组，APG15组，原生SDE4组，FSG短算子8组，16步完整终点根8组，离散SMC8组，16步ODE语义直接控制8组，8步SDE语义直接控制8组。

CFG原生扫描增量0.25到3、步长0.25；APG扫描强度1、1.5、2、2.5、3与历史系数−0.75、−0.5、−0.25。其余主要对照使用相同四档强度，各两个结构参数。FSG短时距0.0625/0.125；完整根半径倍率0.5/1；SMC增益0.1/0.2、衰减5；语义直接控制阈值0.5/0.8。均为当前模型和采样器下的明确适配。

额外语义资产为已有冻结ConvNeXt-Tiny ImageNet1K V1及已有类别manifest。完整1000类目标概率与所选100类softmax分布分开定义，后者用于分布一致性/教师方法。连续VAE解码映射到[0,1]后采用官方预处理。模型在工作进程准备期加载和预热；内部解码/分类全计入采样时间，并保存实际处理图数。主FID使用原生uint8输出，不以优化分类分数筛图。

比较同时匹配ODE/SDE和是否使用外部分类读出。每个方向报告本轮12组最低FID、对匹配对照的差和实际成本；所有完整曲线写入CSV。对照也分别调参，没有强制相同计算预算；不能把额外资产或更多计算带来的收益算作免费的改善。不同bank上的旧FID只作为背景。

## 输入、评价和成本

输入种子202610100，连续CUDA generator按B8生成1000个独立noise；标签种子202610101，100类各10个、固定打乱。全部709组共用该新bank；不复用旧20项或七方法的调参noise。四张GPU按全局batch索引共同完成每个配置，B8、每组125个batch，不同时跑四个不同实验。

沿用固定ADM ImageNet100 validation n5000参考、固定Inception图及特征缓存。FID是本轮选优指标；已有提取器同时产生sFID/IS，原始记录保留。没有额外后验分类器评价或自动扩大样本量。1K最小值仅作为筛选结果，不给统计显著性或独立确认结论。

每批保留输入身份、请求/配置哈希、完整latent、原生uint8图像、实际Full/prefix调用和采样/解码时间。额外decoder/classifier图数与响应、不可行、拒绝等控制统计一并保存。第52项保存两个位置粗细分数与接受掩码；第53项保存九个实际损失/范数、选中索引和是否达到下降要求，评价时逐批完整检查。

## 预检、冻结与无人值守队列

CPU检查覆盖159个结构参数设置在全部事件的历史逻辑、53条完整测试轨迹、RLS与独立加权批量最小二乘一致性、不同控制方向及不可行情形的二维QP、重点命题的独立数值检查。真实网络四卡预检覆盖636个候选参数点及8个新SDE语义对照；53项各一条B8完整生成，另有6条对照完整生成。逐项检查ODE/SDE零引导极限、禁用校准退化及IG/CFG/APG历史首批逐元素回归。探针、插值embedding和接管过程必须恢复标签、hooks和全局数值设置。

预检通过后冻结目录、实现、数值检查、文档生成源、管线、协议、推理文档、旧调用依赖、模型和语义资产、输入bank及预检记录。正式运行使用每批原子文件与提交哈希，已提交结果在恢复时保留，不重新采样；数值失败保留部分输出与失败原因并继续其他配置，实现错误停止队列。

队列首先等待旧七方法根状态同时满足 phase=complete、no_further_sampling_queued=true、total_arms=140且不存在stage字段；还必须确认其pasted_screen_1k为140/140及最终审计通过。旧七方法自身仍等待旧20项完整结束，因此形成20项→七方法→本轮53项的严格串行依赖。本轮等待期不创建CUDA模型。停止标记在等待期也有效；正式采样的停止标记在当前配置提交后正常退出。

运行完成核验709组全部覆盖和元数据，并对每个family的最佳有效配置复核原始batch与聚合文件哈希、实际成本及缓存特征FP64 FID/sFID；不重新生成图像。完成后状态明确标记没有后续采样，不把筛选结束自动等同于研究目标达成。
