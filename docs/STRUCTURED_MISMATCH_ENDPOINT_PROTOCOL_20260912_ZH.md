# 共同误差的简单卷积与加性残差：固定端点检验

保留 $S=(1-a)P+aE+\delta_S$、$W=(1-b)P+bK_\tau E+\delta_W$，其中 $K_\tau$ 为原生 latent 坐标上的中心各向同性高斯卷积。只检验一个简单核的必要分布关系；不将有限特征拟合、任意加性残差或负结果解释成完整密度识别。

使用 guidance_distribution_20260912 已有 Strong/Weak/Null 各1000个端点，不生成新图像。每模型前500个拟合、后500个留出；Strong/参考保留已有同噪声配对。真实P按相同类别抽取训练／验证 latent，二者图像池不交叉。SiT使用已有SD-VAE后验样本乘0.18215；RAE使用已有原生DINO latent。此处P是对应真实latent目标，不是Inception空间高斯假定。

固定随机种子2026121371，16个单位Rademacher线性投影，每个取0.5、1、2三个频率。频率用真实训练投影的标准差换算到原生坐标；同一换算用于所有来源。每个复特征同时保留图像边缘与乘以固定类别正负号的联合特征。前8个投影拟合，后8个投影只留出；拟合与测试都用一个全局参数组，不拟合逐类别系数。联合特征只提供必要关系，不足以保证条件分布正确。

拟合关系为

$$\phi_W=\frac{g_\tau}{\kappa}\phi_S+
\left[1-b-\left(\frac1\kappa-b\right)g_\tau\right]\phi_P,
\quad g_\tau(\omega)=e^{-\tau\|\omega\|^2/2},\quad \kappa=a/b.$$

严格模型仅拟合κ；卷积模型拟合κ、b、τ。范围κ∈[0.02,0.98]、b∈[0.02,1]、τ≥0；τ上界为真实训练投影方差中位数的4倍。仅用三个固定起点求同一最小二乘目标，以降低优化失败风险，不根据FID选择。记录全部收敛状态和边界命中；边界解不能写成可靠混合比例。严格模型对b不识别。

在留出500样本上分别报告已有投影、新投影的复矩残差均方；300次配对样本重采样给描述性变化范围。类别平衡、固定类别和稀少的每类样本使其不是严格置信区间。训练拟合含有限样本噪声，不承诺无偏参数估计。加性残差不另拟合灵活函数：无法解释的留出差异直接保留。没有把它训练成新的引导门控、预测头或部署模型。

该检验只回答“一个简单卷积是否跨样本、跨投影解释更多差异”。不推导生成改善；无论结果如何，不自动启动大队列或增加推理网络。以原始请求、文件哈希、投影矩阵、真实样本索引和脚本哈希保存复核材料。
