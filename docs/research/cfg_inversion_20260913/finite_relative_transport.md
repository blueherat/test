# 有限条件相对运输：反演做什么、何时重复有益

2026-09-13。结论是：**这条路线有明确的数学对象，也存在有限区间反演优于任意已搜索标量 CFG 的受限成功模型；值得检验的是有限运输误差的抵消，而不是可逆性或固定点变小。** 三腿基本构造已有 W2SD / Z-Sampling 前例，仓库亦已研究其局部极限。这里收窄理论条件，不包装成新算法；未运行 GPU、图像采样或质量评估。

## 1. 反演究竟做什么

固定物理区间 \([t,s]\)，\(s=t+h\)。令 \(U,C:\mathcal X_t\to\mathcal X_s\) 为参考与前向模型的确定性精确流，假设在相关区域光滑、可逆且所有中间轨迹存在。这里 C 表示所选择的前向分支，未强制其 CFG 系数为 1；U 也未强制为 null。

\[
R=U^{-1}C,\qquad G_n=UR^n=(CU^{-1})^nU.
\]

R 每次返回同一时间 t，重新查询当前状态，不添加独立噪声。它将 C 的未来输出换算成 U 的起点：\(U(Rx)=C(x)\)。重复时目标亦随当前起点更新，\(U(R^{j+1}x)=C(R^jx)\)；**并非始终重建第一次的固定目标 C(x)**。

|n|化简后的实际操作|净时间变化|
|---:|---|---|
|0|U|t→s|
|1|C|t→s|
|2|C→U 反演→C|t→s→t→s|
|3|C→U 反演→C→U 反演→C|t→s→t→s→t→s|

n≥1 只需 n 条 C 正向腿和 n−1 条 U 逆向腿；不应真的执行代数抵消的第一对 U / U⁻¹。n=2 是第一次产生额外效果的 packet，只有一次反演。n 是算法外推次数；逆腿内部为达到指定精度使用的子步数或隐式求解迭代数，是另一个变量。

## 2. 准确的分布目标和不变量

令 μ 是本次实际进入区间的分布，\(\nu_n=(G_n)_\#\mu\)，并定义未来层映射 \(A=CU^{-1}\)。则

\[
\nu_0=U_\#\mu,\quad\nu_1=C_\#\mu,\quad\nu_n=A_\#\nu_{n-1}.
\]

如果有密度，严格变换公式为

\[
q_n(y)=q_{n-1}(A^{-1}y)|\det DA^{-1}(y)|.
\]

这定义了一个明确的分布族，**一般不是** \(q_n\propto q_0^{1-n}q_1^n\)，也不是同一条件提供了 n 份独立证据。反例：U(x)=a x、C(x)=b x、μ=N(0,1)，实际方差为 \(a^2(b/a)^{2n}\)；密度幂倾斜若可归一化，方差却为 \([(1-n)/a^2+n/b^2]^{-1}\)。a=1,b=.8,n=2 时分别为 .4096 与 .470588。

在 t=0 两个理想模型共享起始高斯时，一次 C 可以准确得到条件分布；这不推出 n>1 仍准确。内部 t 时，真实 conditional 流只保证把自己的 \(p_t(\cdot|c)\) 送到 \(p_s(\cdot|c)\)；已有 guidance 的实际 μ 未必等于这个输入。因此不能直接把每一个 C#μ 称为真实条件边缘。

能严格保持的对象只有带条件的陈述：

- 总概率质量始终为 1，这是任何合法 pushforward 都有的性质，并非质量保证。
- 若未来可观察量 I 满足对相关所有 x 都有 I(Cx)=I(Ux)，则 I(Ay)=I(y)，从而 I(G_n x)=I(Ux)。共同语义、背景或范数必须满足这条具体条件，不能凭名字指定为不变量。
- 可逆性保证有限次操作仍可恢复输入；它不保证欧氏体积、熵、类内方差或感知细节不变。

若密度熵及积分存在，逐次输出熵变化为

\[
H(\nu_n)-H(\nu_{n-1})
=\mathbb E_{Y\sim\nu_{n-1}}\log|\det DA(Y)|.
\]

这可诊断体积变化，但 det=1 仍允许一方向收缩、另一方向膨胀；熵也不是 FID 或语义质量。不能用一个 logdet 门限直接宣布最优停止。

## 3. 与局部 CFG 的差异从哪里开始

固定整数 n，采用准确的同区间子流：

\[
G_n=\Phi_{n v_C-(n-1)v_U}^{s\leftarrow t}+O(h^3).
\]

原因是化简后的 \(C U^{-1}C\cdots U^{-1}C\) 为回文对称复合；BCH 的二阶项抵消。对非自治场增广时间坐标，前后腿分别推进 h 与 −h，同样成立。此处 h→0 时 n 固定；不能把它外推至 n 随 1/h 增长。

R 自己可以含二阶输运项，但**完整 G_n 的领先独立差异不能写成该二阶项**。可交换线性场中与相应标量 guidance 精确等价，不只是小 h 近似。仓库已证明这些边界：[局部流与强度重标定](../../LIFTING_MODIFIED_FLOW_AND_SCALE_20260909_ZH.md)、[可交换高斯流](../../AG_FSG_COMMUTING_FLOW_IDENTITY_20260908_ZH.md)。

三种分支口径：

|前向 C|逆向参考 U|首阶等效场|
|---|---|---|
|普通 conditional|同模型 null|v_u+n(v_c−v_u)|
|高 CFG，权重 w|普通 conditional|v_u+[1+n(w−1)](v_c−v_u)|
|同条件强模型|同条件弱模型|v_weak+n(v_strong−v_weak)|

所以用户原构造 n=2 时，应对照总权重 2w−1 的 CFG；不能仅因超过原 w 的结果就归因有限反演。有限区间可带来局部线性组合没有的高阶作用，符号和质量方向则不由回文结构决定。

## 4. 最有利且可证伪的误差假设

先固定同任务、同输入耦合的理想区间映射 F。假设两模型的有限映射有一致 C¹ 展开：

\[
C_\epsilon=F+\epsilon a+O(\epsilon^2),\qquad
U_\epsilon=F+\epsilon b+O(\epsilon^2).
\]

直接展开逆映射得到

\[
C_\epsilon U_\epsilon^{-1}C_\epsilon
=F+\epsilon(2a-b)+O(\epsilon^2).
\]

不要求底层向量场交换。若 b≈2a，则一次反演把首阶共同误差抵消。对同一输入测度的配对均方映射误差，首阶严格改善条件是

\[
\|b\|^2-4\langle a,b\rangle+3\|a\|^2<0.
\]

记 r=||b||/||a||、cosθ=⟨a,b⟩/(||a||||b||)，则要求 \(r^2-4r\cos\theta+3<0\)。仅“弱模型更差”不够：r=2 时需 cosθ>7/8。若 b=κa，要求 1<κ<3；κ=2 首阶抵消，κ>3 则过度修正。

**这条首阶抵消不是 inverse 独有。** 若两模型速度本身相对同一真实场具有小误差，普通线性外推也能首阶抵消。因此真正的有限反演机会，需要更强的端点误差结构。

设 E_α 是某个同一光滑误差向量场生成的一参数可逆流：\(E_\alpha E_\beta=E_{\alpha+\beta}\)。若

\[
C=F E_\epsilon,\qquad U=F E_{\kappa\epsilon},\quad\kappa>1,
\]

则没有小 ε 截断，严格有

\[
\boxed{G_n=F E_{[\kappa-n(\kappa-1)]\epsilon}.}
\]

κ=2 时 G₂=F，抵消整个有限误差流。它利用的是两个模型从相同源坐标出发的共同误差规律；既不要求 U/C 接近固定点，也不把更高 CFG 自动视为更准确的教师。

## 5. 一个真实非空的受限成功模型

预先指定目标矩阵和误差生成元：

\[
F=\exp\!\begin{pmatrix}.7&0\\0&-.4\end{pmatrix},\qquad
V=\begin{pmatrix}.1&.4\\.4&-.1\end{pmatrix},
\quad C=F e^{\epsilon V},\quad U=F e^{2\epsilon V}.
\]

它们有实矩阵对数，可作为同一区间长度 1 上自治线性 ODE 的精确映射。输入 N(0,I₂)，目标 N(0,FFᵀ)，所以质量距离可准确用 Gaussian W₂²计算。三腿严格 C U⁻¹ C=F。普通标量 CFG 的映射族为

\[
\exp\{\log U+w(\log C-\log U)\}.
\]

因有限矩阵不交换，这个族通常不能复现 F。CPU 在 w∈[−10,10] 的密集网格定位所有检出的局部最小值，再分别连续优化；ε=1 时结果如下（最终数值见配套 JSON）：

|方法|目标 Gaussian W₂²|
|---|---:|
|C 本身|.497443|
|普通 CFG w=2|.0106602|
|该区间内数值调优 CFG，w≈1.920824|.00843977|
|精确三腿反演|数值零，映射误差 <10⁻¹²|

这不是全体实数 w 的最优性证明，也未比较任意时变 CFG 或更复杂的强基线。它证明的是一个有限、可复算的机会：**已指定目标和共同有限误差后，反演能准确消掉标量场外推留下的高阶误差。**

trace(V)=0，所以 det U=det C=det F；成功并不依赖体积收缩。该例属于一般可逆线性生成流，不声称是标准线性插值 Gaussian FM 的理想条件／边缘场。它也不能代替真实模型生成质量证据。

## 6. 反例与原则性停止边界

第一，若 C 已经准确，将它当成仍有同方向偏差的模型会过度修正。仓库已有比简单高斯缩放更强的相容反例：真实 conditional 为 N(m,1)，null 为两个对称类的混合；完整区间一次 U⁻¹C 再由 U 输出准确得到条件分布，继续迭代却压缩方差、逃向尾部，尽管 endpoint gap 下降。[精确条件搬运反例](../../FSG_EXACT_GAUSSIAN_TRANSPORT_20260908_ZH.md)。

第二，即使两模型都可逆、U 更差、cycle 误差为零，若误差方向不同，一次外推也可增大目标误差。上述 r/θ 条件给出了明确失败区域。仅比较各自 FM MSE 或说弱 checkpoint 较早，无法保证有限映射误差方向满足条件。

第三，给定任意 U,C，可以把任意某个 Gₙ 声称为未知目标 F；仅凭这两个算子无法识别真实 F、κ 或最优 n。没有无监督万能 stopping rule。熵、gap、cycle norm 都不能填补这项不可识别性。

因此最小原则方案是：**先固定 n=2 的一次真实反演，以同任务共同偏差外推为明确假设；不以反复收敛为目标。** 在 κ 已有独立依据时，可考虑最接近 \(\kappa/(\kappa-1)\) 的整数 n；未知时不能把该公式伪装成自动调参依据。同条件多个训练 checkpoint 的有限映射差是否近共线、随成熟度按稳定规律缩减，可以支持这一假设，但仍需独立 checkpoint 或目标数据检验外推是否有效。

有限映射的逐样本误差还要求共同源耦合：随机取真实图像 X、独立高斯构造 x_t，再把 X 当成该确定性 ODE 的唯一终点，通常不成立。两种相同输出分布的模型也可能选不同可逆耦合，不能将其相对位移全部叫质量误差。

## 7. 逆哪个模型最有理论依据

用户原路线可直接定义为：高 CFG 正向→普通 conditional 真实反演→高 CFG 正向。这选择“同条件生成能力”为逆向坐标系，放大高 CFG 相对普通 conditional 的有限运输；操作明确，但高 CFG 与 conditional 可能偏好不同分布，不能自动套用共同真实 F 的误差抵消定理。

同条件强／弱 checkpoint 更接近“两个模型逼近同一个目标 F”的理论前提，因此误差外推的解释更自然；这仍是选择模型对的假设，需要验证，不能仅按能力排行榜选择。null 逆腿最直接表达条件与无条件的对比，但这首先是目标差异，不是弱模型误差，连续反复更容易重复施加已有条件偏置。选择同一 C 作逆腿则退化为恒等，适合作为数值核查。

实用上应先回答哪个具体缺陷希望抵消：条件不足、同任务模型欠拟合，还是局部求解误差。相应理论目标不同；若只是降低离散误差，提高普通采样器精度就是相关直接对照。准确 inverse 的意义，是让有限误差抵消对象得以实现；逆向数值误差 δ 会经末次 C 的 Lipschitz 常数放大至至多 L_C δ，不应与方法效果混在一起。

## 8. 与最近原始文献的边界

[W2SD，Algorithm 1、Theorem 1、Appendix E.2](https://arxiv.org/html/2502.00473v3) 已采用强前、弱逆、强前，并允许 guidance 或模型差异。其局部 score 差解释依赖逆近似，附录单列误差项；将弱→强解释为强→理想仍需误差方向假设。因此这里的 n=2 算子不是新颖点，有限端点误差假设及何时优于标量 CFG 才是应检验的具体问题。

[FSG，Algorithm 1 与 Theorem 1](https://arxiv.org/html/2510.21512v1) 在部分时刻执行前瞻 guided 前向、null 逆向的多轮校准，再接 CFG++ 和普通推进。它的收缩理论控制预测 gap，不是上述指定目标 F 的误差定理，实用完整算子也不等于只做 Gₙ。作者代码的时钟、分支和发布实现近似已在[先前审计](fsg_w2sd_prior_art.md)逐项核对，无须重新扩展对照家族。

目前能支持的最强主张：已有反射形式中，**准确实现的有限相对运输有可能抵消同任务模型共享的有限偏差，并产生标量 CFG 不具备的高阶收益。** 真实模型是否具有这个误差结构，以及额外反演成本能否换来质量提升，仍需小规模真实反演后以独立图像质量结果决定；数学可逆性与小 cycle 不作质量标准。
