# 已经满足类别的图片，再施加该类别，何时近似不变？

2026-09-13。仅理论研究，无 GPU、采样器改动或新增实验。继承[已有 CFG 不变量报告](../../CFG_INVARIANTS_RESEARCH_20260913_ZH.md)中的硬事件幂等和后验关系，**不再提出 posterior gating**。本稿只考察一个 image→image 的真实反演算子及其重复行为。

核心结论：**可以要求一个有范围的近似保持性质：在整个所选反演区间内，类别仍然明确且其后验对状态近似平坦的图片，追加该类别应只带来很小改变。** 终点“已经是猫”不够；无新随机噪声也不够。完全准确的模型在较深的跨分支反演后仍可能持续改变一张已属于该类的图片。下面给出严格条件和一个标准 Gaussian FM 精确反例。

## 1. 固定真实 image-level 操作

在 latent 图像坐标上，令

\[
T_\tau(x)=\Phi_c^{1\leftarrow\tau}\!\left(\Phi_u^{\tau\leftarrow1}(x)\right),\qquad
x_{k+1}=T_\tau(x_k).
\]

每轮从当前图片 x 出发，用同一个模型的 null 场真正反演到 τ，再用普通 conditional 场沿同一物理区间生成回 1。没有新抽高斯噪声，每条腿随当前状态和正确时间重新查询。

这是跨分支反演，不能用同场逆流的代数恒等式保证 identity。当前 x 的所有信息可以仍藏在其逆坐标中，但 conditional 与 null 用不同解码规则；信息可恢复不代表换分支后仍输出同一实例。若使用相同 c 反演再用 c 正向，才是另一种同场重建检查。

讨论限于存在唯一流、相关逆向轨迹可达的区域。若映射到硬支撑分布的终点存在奇异边界，下列公式理解为在类内正密度区域的极限，不要求跨越边界的全空间光滑可逆性。

## 2. 一个严格的条件保持界

设 \(z_r=\Phi_u^{r\leftarrow1}(x)\)，即 x 的 null 逆轨迹；定义 \(g=v_c-v_u\)。对复合函数 \(\Phi_c^{1\leftarrow r}(z_r)\) 求导，得到

\[
\boxed{
T_\tau(x)-x
=\int_\tau^1 D_z\Phi_c^{1\leftarrow r}(z_r)\,g(z_r,r)\,dr.
}
\tag{1}
\]

因此，若相关 conditional 后续流的 Jacobian 范数不超过 M(r)，则

\[
\|T_\tau(x)-x\|\le
\int_\tau^1 M(r)\|g(z_r,r)\|dr.
\tag{2}
\]

这既保留整个有限区间，又明确了判定位置：gap 必须沿 **null 逆轨迹**评价，并考虑它经 conditional 后续动力学的放大。只看输入图或一个噪声层的 gap 不够。式(1)也允许方向抵消，所以这个上界是充分条件，不是必要条件。

在线性 Gaussian FM \(Z_r=rX+(1-r)\epsilon\) 中，如果 conditional/null 真正来自同一联合分布，Gaussian 微分恒等式给出

\[
v_c-v_u=\frac{1-r}{r}\nabla_z\log q_r(z),\qquad
q_r(z)=P(c\mid Z_r=z),\quad0<r<1.
\tag{3}
\]

FM 的概率路径与条件速度框架见 [Flow Matching for Generative Modeling](https://arxiv.org/abs/2210.02747)；式(1–3)为本稿对所指定路径的直接推导。它们不适用于任意错误网络，也不把 score 和 velocity 的端点行为混为一谈。

如果沿整段逆轨迹有 \(\|\nabla\log q_r\|\le b(r)\)，那么

\[
\|T_\tau(x)-x\|\le
\int_\tau^1 M(r)\frac{1-r}{r}b(r)dr.
\tag{4}
\]

这是所需的非代数退化条件：**不同分支可以在别处有正常类别作用，但对当前一族图片及这段区间，已有类别信息近似冗余。** 它不要求将所有输入的 gap 消零。

仅 q≈1 不推出梯度小。例如合法光滑函数 \(q_\eta(z)=1-\eta+\frac\eta2\sin(z/\eta^2)\) 很接近 1，梯度却可达 1/(2η)。另一个明确充分条件是 q≥1−η，并且两类 score 对比 B 有界：对补事件 \(\bar c\)，

\[
\nabla\log q=(1-q)(s_c-s_{\bar c}),\qquad
\|\nabla\log q\|\le\eta B.
\]

低噪声时 B 可能发散，需检验 η 的衰减能否补偿；不能只看分类器报了 99%。

若正向改为固定有限权重 w 的 CFG，\(v_w=v_u+w g\)，同一推导把式(1)中的 g 换为 wg、后续 Jacobian 换为 CFG 流的 Jacobian。因此已有类别确实冗余时，有限 CFG 也应近似不改；但权重及后续放大都进入误差界，不能对任意大 w 作一致保证。这是 image-level 的条件保持命题，没有给 gap 增加新的门控规则。

## 3. 低噪声下何时接近复制

若 x 附近真实 marginal 与 conditional 密度正、足够光滑，score 及必要导数有界，且终点流的极限正规，那么当 δ=1−τ→0：

\[
\boxed{T_\tau(x)-x
=\tfrac12\delta^2\nabla\log P(c\mid X=x)+o(\delta^2).}
\tag{5}
\]

理由是 null 逆轨迹 \(z_r=x+O(1-r)\)、后续 Jacobian 为 I+O(1-r)，而式(3)的前因子约为 1−r。于是整个 image-level 变化是二阶小量；这不等于沿轨迹的 clean 预测保持不变。

如果标签在 x 的邻域内确定，且与其他类支撑有正间隔，终点 posterior 局部为常数 1，一阶系数消失。远处其他类通过 Gaussian 尾部混入的量还可指数小，但这需要类别间隔和密度正则性；不能直接套在类别边界或多义图片上。

这里有一个重要测量边界：τ 越接近 1，几乎任何连续的两场往返都会越来越接近 identity。**仅缩短区间得到漂亮保真图不构成模型更强的证据。** 对正则相容 FM，式(5)还能提供特定二阶尺度；普通错误模型可能已有 O(δ) 的终点分支差，但错误模型也可以恰好满足同样边界，因此这仍不是充分质量标准。

## 4. 完全准确模型仍持续漂移：硬标签的精确反例

取真实数据 \(X\sim N(0,1)\)，类别 \(c=\{X>0\}\)。对任意 x>0，clean posterior 都严格等于 1；条件数据是正半正态。噪声 \(\epsilon\sim N(0,1)\) 独立，采用标准 Gaussian FM 插值。

记 \(a_\tau=\sqrt{\tau^2+(1-\tau)^2}\)。null 边缘为 N(0,aτ²)，其精确逆轨迹为 zτ=aτx。设 \(W=Z_\tau/a_\tau\)，则 W 与 X 都标准正态，相关系数 ρ=τ/aτ。由一维流保持分位数，

\[
T_\tau(x)=F_{c,1}^{-1}\!\left(F_{c,\tau}(a_\tau x)\right).
\]

而对于任何 τ<1、x>0，

\[
F_{c,\tau}(a_\tau x)-F_{c,1}(x)
=2P(W>x,X\le0)>0.
\]

故 **Tτ(x)>x**：每轮都向类内尾部移动。它不是错误模型、离散误差或新噪声导致的现象，整个反演／生成都是精确且确定性的。

尤其 τ=0 时，记 Φ 为标准正态 CDF，Q=1−Φ，有

\[
T_0(x)=\Phi^{-1}\!\left(\frac{1+\Phi(x)}2\right),\qquad
Q(T_0^k(x))=2^{-k}Q(x).
\]

于是重复轮数无限增加会向正无穷漂移。事实上任何固定 τ<1 都没有有限正固定点：Tτ 连续且严格大于恒等，若其单调迭代有有限极限，就与无固定点矛盾。

这个例子直接排除了“图已经属于 c，所以任意 null 反演后再加 c 都必须保持”的主张。终点的硬条件在反演后的噪声层重新变得不确定；即使反演没有丢弃信息，两种分支所选择的跨层对应关系也不同。

## 5. 同一反例也给出非空的近保持区域

沿 null 逆轨迹，后验恰好是

\[
q_\tau(a_\tau x)=\Phi\!\left(\frac{\tau x}{1-\tau}\right).
\]

令 b=τ/(1−τ)。上节的 CDF 差的一半为

\[
I_\tau(x)=\int_x^\infty\phi(w)\Phi(-bw)dw
\le Q(x)\Phi(-bx).
\]

固定正 margin 0<m≤x≤M，在 τ 足够接近 1 时，由中值定理有

\[
0<T_\tau(x)-x
\le\frac{Q(m)}{\phi(M+1)}\Phi(-bm)
\le\frac{Q(m)}{\phi(M+1)}
\frac{e^{-b^2m^2/2}}{bm\sqrt{2\pi}}.
\tag{6}
\]

这里已先选择 τ 使 Tτ(x)≤M+1；这是 CDF 一致收敛带来的局部条件。式(6)说明：**同一个正确模型，深反演时持续改变实例，浅反演且类别 margin 足够大时可极接近复制。** 两种现象并不冲突。

当 x 与 (1−τ)/τ 同阶、靠近类别边界时，后验可能仍明显低于 1，上述指数保持不再统一成立。任何跨模型比较都必须固定物理区间，并说明图像位于哪种类别确定性范围。

## 6. 五轮稳定能推出什么

若在预先固定的图像区域 Ω 内有 \(\|T_\tau(x)-x\|\le d\)，并且前 K 轮仍留在 Ω，则

\[
\|T_\tau^k(x)-x\|\le kd,\qquad k\le K.
\]

若初始点离 Ω 的边界大于 Kd，可通过归纳保证这些轮次不离开区域。这里不需要把 T 做成收缩映射，也没有要求迭代走向某个吸引子。保留原图的目标是对原始 x 的误差小，不能只看相邻两轮越来越接近。

半正态反例中，固定 τ 的无限轮仍会漂移，但固定 K、远离边界且 τ 近 1 时，可以满足极小的 K 轮误差。这正是必须区分“5 轮近复制”和“全局幂等”的原因。

## 7. 错误模型也稳定，怎样解释原观察

如果一个模型完全忽略类别，\(\widehat v_c=\widehat v_u\)，跨分支往返也会精确 identity；它可能生成很差。两个分支共享同样错误也可以近稳定。稳定性因此至多说明当前操作的条件冗余和两分支相容性，不能单独给生成先验排序。

一个非平凡的条件保持命题应同时保留两端：对所选区间里确已明确的类别，重复操作尽量保留实例；对尚未满足或仍不确定的类别，模型依然能够做相应改变。否则将所有条件作用归零也能满足保留部分。即使两端均成立，也还没有证明纹理、覆盖率或新图 FID 更好。

与用户最初 image+“完全不变”接口的联系必须准确：原生编辑器接收完整图片和保留指令，任务本身要求复制。这里的 Tτ 是一个 **受类别冗余条件限制的代理操作**，不是那个 API 的严格复现；它只在式(4)/(6)所说明的范围内有近 identity 的依据。它也没有理由成为用于所有真实图像、所有 τ 的统一惩罚项。

可保留的新问题是：在明确固定的反演深度下，真实图片中哪些实例的类别沿逆轨迹始终确定；这些实例在跨分支重复后出现的额外漂移，是否超过理想条件变化和数值／codec误差所能解释的范围？这直接承接“重复无新增要求应保留”的观察，且不会重新退回普通 posterior gating、未来信息外推或 Richardson 叙事。

与其他代理交叉审查后的边界：同条件独立 reference 反演再由待测模型解码，是另一种更接近保留任务的构造；其可信性依赖 reference 与被测模型共享同一任务和规范概率路径，也有共同错误抵消的问题。它不应与本文 null→conditional 的操作混成一个 identity 标准。
