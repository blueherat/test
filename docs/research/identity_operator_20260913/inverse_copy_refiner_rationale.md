# 反演复制配对修复器：有界继续的理由与反方

日期：2026-09-13。本轮只审查并明确候选，没有新增 toy、GPU 运行或修改 sampler。

**决定：继续一个小型学习验证。** 使用 500 张训练缓存真实图，按原图 source ID 分成 400 fit、100 holdout；固定 S800、W400，同类别普通 conditional 的短程反演—重建构造两种退化，学习轻量 latent residual 修复器，同时训练真实图 identity。部署先只应用一次，五轮作为稳定性观察。它是有真实监督的修复假说，尚无独立生成质量收益，也尚未确立新颖性。

## 1. 与用户原始不变性问题的关系

原始 no-op 指令要求保留任意输入，包括输入本来具有的伪影；本候选另加了“真实数据图应为固定点、模型扰动邻域应修复回真实图”的生成建模假说。因此它保留了不变性主线，但不是声称“保持不变”天然意味着修复坏图。

这里真实 x 是外部监督。构造人工退化 C(x)→x 不再要求提供一个正确的 oracle 反演；即使冻结教师有误差，这个配对任务仍定义清楚。关键未解问题变为：C 产生的变化是不是实际生成伪影的一种有用近似。

## 2. 冻结的唯一配对构造

物理时间统一为 0 噪声、1 数据。令 S、W 分别为 S800、W400 的 EMA、同类别普通 conditional 速度场。记其精确流为 ΦS、ΦW：

\[
b_\tau(x,c)=\Phi_S^{\tau\leftarrow1}(x;c),\qquad
C_\tau(x,c)=\Phi_W^{1\leftarrow\tau}(b_\tau(x,c);c),
\quad \tau\in\{.75,.5\}.
\]

先沿 S 从 1 反演到 .5，保存 .75 和 .5 两个状态；W 再分别从它们走回 1。每次在当前状态和物理时间重新查询模型。统一 Heun 网格 h=1/64：

- S 反演 1→.5：32 步、64 次单分支查询。
- W 生成 .5→1：32 步、64 次查询。
- W 生成 .75→1：16 步、32 次查询。

总计 160 次单分支查询/真实图，得到两对 Cτ(x)→x。没有 fresh Gaussian 加噪；若缓存需要 VAE posterior 采样，真实 latent 应在配对准备时只采一次并冻结。所有来自同一原图的 τ、标签和 identity 样本属于同一数据分区。

这两个 τ 是一次预先确定的范围选择，不根据最终生成质量调参。它们的用途是保持输入接近图像域、降低离线成本、提供不同退化程度；不能据此断言差场只改变伪影。

P 只接收待修复 latent，不接收 τ、原始 x、反演 code 或教师模型 ID。教师和 VAE 冻结，部署时不运行反演或逐图拟合。

## 3. 为什么不采用“高 CFG copy→真实图”的单一配对

固定可逆 C 的纯平方配对回归，若达到逐点零误差，则在训练输入支撑上学习的是 C⁻¹。真实目标 x 不会消除此代数关系。

例如完整区间取 C=GD∘GS⁻¹，其中 GD 是 S 的高 CFG 生成、GS 是普通 conditional：

\[
P=C^{-1}=G_S\circ G_D^{-1}
\quad\Longrightarrow\quad
P(G_D(z))=G_S(z).
\]

它是在学习撤销 guidance；输出可能改变，但不能把结果叫成独立的伪影修复机制。若完整区间采用 C=GW∘GS⁻¹，纯配对最优逆是 GS∘GW⁻¹，作用于强生成输出则成为已经讨论过的相对映射外推。小学生只是把该映射摊销，并不使它成为新原理。

当前采用同类别普通 conditional 的强弱短程 copy，不把 high/low CFG 差别作为退化标签，降低“训练目标就是去指导”的问题。但对每一个固定 τ，仍然有

\[
C_\tau^{-1}
=\Phi_S^{1\leftarrow\tau}\circ\Phi_W^{\tau\leftarrow1}.
\]

因此本候选必须同时保留真实 identity、混合两个 τ，并在实际生成分布上验证。**混合 τ 只使学生不再被一个唯一显式逆映射强制指定；它不保证消除逆映射捷径，学生仍可能从图像识别 τ，或学习两种相近逆映射的平均。**

## 4. 学到的东西是什么：监督修复，而不是幂等即质量

采用 Pφ(y)=y+Rφ(y) 的轻量残差形式，可将最后一层初始化为零。核心目标为

\[
L_{\rm pair}=\mathbb E_{x,\tau}\|P_\phi(C_\tau(x))-x\|^2,\qquad
L_{\rm real}=\mathbb E_x\|P_\phi(x)-x\|^2.
\]

先检验这两项。少量幂等项只作为后续迭代正则或消融，不能替代外部真实目标，也不能用最终相邻轮变化小作为成功标准。

忽略幂等项、设 clean 分支权重 π、两种退化权重 rk，令真实密度为 p、qk=Ck#p。无限容量的平方回归最优解为

\[
P^*(y)=
\frac{\pi p(y)y+(1-\pi)\sum_k r_k q_k(y)C_k^{-1}(y)}
{\pi p(y)+(1-\pi)\sum_k r_k q_k(y)}.
\]

这揭示了可行机制：模型根据输入更像真实图还是人工退化，在保留与修复之间折中。它是条件均值学习的解释，不是额外实现建议；若训练退化与真实生成错误不重合，解释不会自动迁移到 CFG/APG 输出。

也存在明确冲突：若 C 只把一张合法真实图变成另一张合法真实图，identity 要保留 C(x)，配对却要求回到 x；二者不能同时严格满足。例如各向同性高斯数据上的非平凡旋转就是这种反例，平方回归折中可以收缩方差。对于处处正密度的数据分布，要求 P(x)=x 几乎处处还会与非平凡修复产生全局冲突，因此只能谈近似保留高概率真实数据，不能宣称无条件精确流形投影。

若理想数据局部是光滑流形 M，且 P 在 M 上恒等，那么其雅可比必须保留切向方向；若同时幂等，固定点处有 DP²=DP。修复小扰动 e 则要求 DP·e 较小。故真正可能有质量收益的是去除离开真实数据邻域的错误，同时保留合法变化；checkpoint 间差异并不天然具有这种性质。

## 5. 与 IGN、SIGN 的准确关系

| 项目 | 已有方法 | 本候选 |
|---|---|---|
| 真实数据固定点 | IGN 直接训练 f(x)≈x | 相同思想，不是新内容 |
| 重复输出幂等 | IGN/SIGN 都训练或检验 f(f(u))≈f(u) | 相同思想，作为弱正则和 R1–R5 观察 |
| 约束非数据输入 | IGN 加 tightness；SIGN 用 flow consistency、分布匹配及可选回归/去噪项 | 用真实图锚定的跨 checkpoint 短程 copy 配对 |
| 教师用法 | SIGN 的 flow loss 比较同教师 PF-ODE 相邻状态上的学生输出 | 两个冻结模型构造图像域终点→真实图的局部配对 |
| 部署目标 | 学习从源分布到数据的幂等生成器，可单步/递归生成 | 只修复现有生成 latent，不承担从高斯生成 |

IGN 明确需要比 identity＋幂等更多的约束；其论文也讨论模糊及坍缩。[IGN §2](https://arxiv.org/html/2311.01462v1)

SIGN Eq.8–9、Appendix A 将教师 PF-ODE 与幂等学习连接起来，并包含配对回归等可选项；其递归 Algorithm 2 不加新噪声，另一个采样算法才注入噪声。[SIGN §3](https://arxiv.org/html/2509.21470v1#S3)

因此当前方案与 SIGN/IGN 及普通监督修复有直接近例，不能把“加小网络＋identity loss＋循环”宣称新方法。可能需要研究的具体差别只有：这种无新噪声的真实图 cross-copy 退化，是否比普通训练邻域更能迁移到已有生成器的实际错误；现在尚未证明。

## 6. 胜负标准与陈述边界

先冻结 P，对既有 CFG/APG 生成 latent 各应用一次，另保存 P 的 R0–R5。相同输入和样本顺序用于配对比较；不根据这些测试输出回调 P、配对 τ 或修复强度。

有用的正结果必须同时包含：未见真实图的内容保留、未见配对的修复，以及独立生成图上的质量或明确伪影改善。只降低 paired MSE、只使第五轮稳定，均不够。评估应面对已有充分调参 baseline，并核查收益是否仅等同更低 guidance、细节模糊或多样性缩减。

这不是用离线重建风险作为禁止实际生成验证的门槛；真实生成迁移本来就是此次小试要回答的核心问题。若训练配对改善而生成图无收益，应结论为“人工退化可逆学会了，但未获得生成修复证据”，而不是继续从循环残差推出质量。

本次继续的理由是：外部真实 x 明确限定了固定点和修复目标，配对构造可控且可摊销，能实际检验不变性与修复的结合。尚不可证明的包括：P 是真实数据投影、P 越稳定生成越好、P 保留 CFG 的全部有益变化，以及本构造超过 SIGN/IGN 的既有思想。

后续仅增加一个等权双向配对消融，推导、端点退化及旋转收缩反例见 [symmetric copy 数学审查](symmetric_copy_refiner_audit.md)；不改变原单侧方案，也不把对称化直接称为密度恢复。
