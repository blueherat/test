# 最后一轮建设方审查：合法不变量存在，新的反演修复机制尚未建立

2026-09-13。已读既有 copy、公共逆、数据锚、curl / APG 与 weighted projection 记录；本轮只有文献与数学审查，没有 GPU、代码改动、参数扫描或新增 toy。**裁决：结束本分支，不启动新实验。** 原因是本轮最强可成立的修复法已经落入已有保守场蒸馏；不是宣称有限模型永远不能从一致性监督获益。

## 1. 三轮推进后唯一值得认真保留的候选

最初的“共同 Gaussian prior 上同步耦合”必须区分两个操作。固定类别 c，若 Q_c#ν=ν，则终端 G_c∘Q_c 的输出边缘与 G_c 完全相同，population 分布指标不变。但这**不能**推出分别改变 conditional/null 的时间依赖速度代表元后，再混合 CFG 也没有作用；后者的混合一般不保持相同边缘。这是建设方接受反方纠正后的重要收窄。

最后保留审查的单一候选是：**先按每条分支自身边缘，提取其等价的梯度速度，再做 CFG。** 它保持的是分支概率流所代表的分布，而非未经指定耦合的逐像素身份。其完整理想定义如下。

令 b∈{u,c}，ρ_b,t 为冻结分支 v_b 从同一 Gaussian prior 正向 ODE 得到的实际边缘。在 L²(ρ_b,t) 中，对光滑梯度场的闭包作正交投影：

\[
\bar v_b=P_{\rho_b}v_b
=\arg\min_{h\in\overline{\{\nabla\phi\}}}
\mathbb E_{\rho_b}\|h-v_b\|^2,
\qquad
\bar v_w=(1-w)\bar v_u+w\bar v_c.
\]

边界条件、有限二阶矩、弱导数及连续性方程唯一性满足时，r_b=v_b−bar v_b 满足 div(ρ_b r_b)=0，所以每条分支投影前后的整个边缘路径相同。给它再加任意相同意义的无散 r，投影结果不变：Pρ(v+r)=Pρv。这是非空洞的 **CFG 对分支内部密度保持自由度不敏感** 的规范。

ρ 无需显式密度公式：可以在各自正向轨迹的样本上拟合标量势 φ_b，最小化 E||∇φ_b−v_b||²。推理用两条势梯度混合。这需要离线训练、输入梯度和有限近似误差；逆腿不承担任何必要角色，反演次数为 **0**，没有逐图反复自回环。强行加一个逆腿不会增强该投影定理。

若进一步假设两条实际边缘就是同一个真实联合分布所规定的 canonical Gaussian-FM 路径，则规范 Bayes 速度本身为梯度场。此时投影恢复对应 Bayes 代表元，消除纯 gauge 误差后，混合得到规范 CFG 场。**恢复规范 CFG 场不是证明它采样真实 P(X|c)，也不保证它优于调优 APG。** 在一般近似网络中，branch marginal 本身可能错，投影会保留这些错误。

## 2. 为什么这比“删掉旋度”强，但不是本轮新发现

固定 t，令两分支 score 为 s_u、s_c，分支附加量满足 div(p_u r_u)=div(p_c r_c)=0。若瞬时密度 π_w∝p_u^(1−w)p_c^w 可归一化，则

\[
\frac{\mathrm{div}\{\pi_w[(1-w)r_u+w r_c]\}}{\pi_w}
=w(1-w)(r_u-r_c)^\top(s_c-s_u).
\]

因此 branch 内无害的运动可以在 CFG 中干扰密度。**π_w 只是此局部诊断指定的密度，不是现行 CFG 实际边缘的通用表达。** 如果只按 π_w 投影混合场或 gap，删掉的恰是相对于 π_w 无散的部分，不会消除原有的 π_w 连续性残差；需要区分 branch-wise 投影与混合后投影。

这个交叉项、连续时间可解反例和真正离散类别混合的例子已经写在[2026-09-11 仓库报告](../../FSG_RELEASE_CURL_AND_APG_REVIEW_20260911_ZH.md:184)。其中离散例取 p_u=½N(m,I)+½N(−m,I)，p_c=N(m,I)，r_u=0、r_c=A(x−m)，并非用任意两个 Gaussian 冒充同一分类联合分布。故本轮不再运行相同 toy，不将该现象标为新发现。

修复对象也有直接文献近例。Thornton 等 AISTATS 2025 的 **Eq.(7)** 已给出 E_pt||∇u−v||² 的保守投影损失，**Eq.(8) 后**明确讨论原向量场与投影场具有相同边缘；随后用 pretrained score 蒸馏能量模型并用于 composition / SMC。把相同投影分别套到 CFG 两条分支，在当前论证下是该工具的应用，还不是新的修复原则。[原文 §3.2 / Appendix A.1](https://arxiv.org/html/2502.12786v1#S3.SS2)、[正式论文](https://proceedings.mlr.press/v258/thornton25a.html)。

更早的 QCSBM 已使用 Jacobian 反对称正则；Horvat–Pfister 已分析不改变分布的 gauge 自由度。因此“score 应保守”“两分支各自规范化”都不能只因换成 FM / CFG 用语就认定新颖。[ICML 2023](https://proceedings.mlr.press/v202/chao23a.html)、[ICLR 2024](https://arxiv.org/abs/2402.03845)。

## 3. 径向势与反演锚点没有补上缺口

在固定 t、星形区域、固定锚 a 下，令

\[
\psi_a(x)=\int_0^1 g(a+s(x-a))^\top(x-a)\,ds.
\]

其梯度为

\[
\nabla\psi_a(x)=g(x)+\int_0^1s[J_g^\top-J_g](a+s(x-a))(x-a)\,ds.
\]

理想 Gaussian FM 的 g=((1−t)/t)∇log p(c|x_t) 确实满足闭合空间路径积分为零；固定锚的精确构造会保持所有梯度 g 不变。这比要求 guided 图片自身不动合法，也不等同于自逆恒等。但它不等于上述加权正交投影。

一个明确反例：真实 gap g*=0，测试密度 N(0,diag(100,1))，近似 gap g(x,y)=(y,0)。原平方风险为 1；锚在 0 的径向势是 xy/2，梯度为 (y/2,x/2)，风险变成 **25.25**。变得保守反而放大误差。真正 L² 加权投影在这个线性例中的对称系数为 1/101，与直接取 Jacobian 对称部分不同。

若锚来自本张图片的反演 a=a(x)，stop-gradient 只是在各次查询中人为忽略 da/dx，并不使拼起来的 guidance 成为同一个全局势的梯度。最直接的反例是每次取 a=x：自动微分把 a 当常数时给出 g(x)，但真实标量 ψ_{a(x)}(x) 恒为 0。若保留完整链式法则，即使原 g=∇φ，仍得到 ∇[φ(x)−φ(a(x))]=g(x)−Da(x)^T g(a(x))，一般也不再保持正确的原 g。

因此，反演锚不能同时免费提供全局保守性、正确场不变与加权最优误差这三项性质。增加积分节点或更精细逆解只改善所选构造的数值精度，不解决错误投影目标。

## 4. 与原始 no-op 图像动机及真实数据的诚实边界

完整源图 s 与 no-op 指令同时作为两条分支条件时，类别 c 冗余，理想目标是 δ_s、gap 为零。这是合法复制规范。但给纯 class-only SiT 添加源图接口和复制多任务训练，是一个新训练任务；不能把训练端点在生成时不可得的问题藏起来。有限网络可能因此受益，原有理论没有给出向无源图采样迁移的保证，也没有确立区别于已有图像条件编辑 / 一致性正则的新机制。[既有完整论证](cfg_copy_invariant_after_refiner.md)。

真实训练数据当然可以提供外部锚，本轮并不禁止使用。问题是，真实路径的最小分布修复又得到 P_p(v*−v) 的加权梯度残差，这已经是仓库[可观测误差 guidance](../../RAEV2_OBSERVABLE_ERROR_GUIDANCE_20260906_ZH.md)的理论与有限实现对象。该旧实现的有限结果不能否定所有一致性方法，但也不能把重新使用同一目标称作新的误差信息。

三轮结论依次是：**第一轮**，终端保 prior 的耦合变换不改边缘质量，但此结论不覆盖“先改分支 gauge、再混合”；**第二轮**，CFG 的 gauge 干扰使 branch-wise 规范化成为真机制，但该干扰已在仓库推导；**第三轮**，可实现的严谨修复就是已有能量/势函数蒸馏，反演锚没有形成额外可证明的质量机制。

**最终 no-go 是本轮研究决策，不是不可行定理。** 当前没有一个同时满足“实质新机制、与原始图像身份动机有明确连接、优于强基线的独立依据”的新增候选。保留上述边界与文献归属，停止本分支；不再以修改 inverse 模型、回环次数或势函数参数来延长实验。
