# 保留原图时，CFG 究竟可以要求什么不变

2026-09-13；有界理论结论，未运行 GPU、未修改冻结代码。已阅读此前 copy、公共反演、数据编码及修复器笔记；当前四个 terminal refiner 未见生成质量收益，不继续外推该方向。

**最强可保留命题：完整源图和明确 no-op 条件已经固定输出时，增加冗余类别/描述的 CFG 不应改变复制结果。这个命题针对图像条件的复制任务；目前没有理由把它直接施加到没有源图的普通 class CFG。**

### 1. 两个分支必须面对同一个复制任务

令 s 为完整源图表示，k=0 为明确的不修改操作，c 为附加类别/描述。规定目标 Y=s，则

\[
p(Y\mid s,k=0,c)=p(Y\mid s,k=0)=\delta_s.
\]

Gaussian FM 使用 Zt=tY+(1−t)ε。在 0<t<1，两条理想速度满足

\[
v^*(z,t\mid s,0,c)=v^*(z,t\mid s,0)
=\frac{s-z}{1-t},\qquad \Delta_{\rm noop}^*=0.
\]

因此用 vα=v0+α(vc−v0) 生成，理想复制结果与 α 无关。**两分支都保留 s 和 no-op，只移除 c。** 若 null 分支连源图或 no-op 一起丢掉，它们已对应不同任务，上式不成立。

源图独立于正在生成的 noisy target，一直可以访问；目标内部存在噪声不等于源图信息被替换。FLUX.1 Kontext 的源图 token 与目标 token 分开、以图像和指令条件训练 flow，提供这种接口的先例；原文没有替我们保证严格 no-op 已被学会。[Kontext §3](https://arxiv.org/html/2506.15742v2#S3)

### 2. 什么可检验，什么又会变成自证

合法检验对象是**实际学习到的两个不同条件查询**：它们是否在 no-op 数据上产生相同速度、是否在不同 α 下仍复制同一个 s，以及输出反馈五轮后是否保持最初图片。每轮只读取上一轮图片，固定协议与模型，不调用被测生成器自己的反演来保证成功。

不能把解析桥 (s−z)/(1−t) 硬写进算法，再用其必然复制证明模型强；桥的终点还是奇异极限。也不能将“直接复制”判为 no-op 任务作弊，但它单独不能证明生成能力；需另有小幅明确编辑来区分“能遵守保留范围”和“所有输入都原样返回”。

精确性还取决于表示：若只保留非单射 H(s)，c 可能补回丢失信息，不再必然冗余。最干净的白盒规范是在同一完整 latent 表示上定义源图和复制目标；像素误差另外计入 codec 限制。

### 3. 为什么现有反演实验不能替代它

自己的精确逆给 GαGα⁻¹=I，任何错误但可逆模型都能通过。普通 conditional 的逆与 guided 生成组成 GαGc⁻¹，则本来就改变了终点目标；在精确场下也可漂移，不能把非零位移默认标为 no-op 违例。

公共第三方逆消除了前一种代数恒等，却留下参考坐标偏好；当前 R700、另一个训练 run 及 XL 的敏感性已经说明不能把它当作原图保持任务的统一真值。这里不再提出另一个 inverse 组合。

### 4. 能否训练一个有用的 zero-op 正则？

可以，但仅适用于拥有上述图像条件接口的模型：以 (s,k=0,Y=s) 训练复制，对 c 做 dropout 而保留 s,k；在真实复制目标之外，用

\[
L_{\rm redundant}=\mathbb E\|
v_\theta(z,t\mid s,0,c)-v_\theta(z,t\mid s,0)\|^2
\]

约束冗余条件。必须同时保留真实复制监督和非零编辑任务，否则“两条分支共同出错”或“一律复制”也会满足该一致性。

**它不能不加条件地迁移到普通 SiT。** 训练时已知真实端点 x，不代表从噪声生成时可访问 x；把训练端点作为推理输入会改变任务。在没有 source 的 class CFG 中，理想内部时间差场一般为

\[
v_c^*(z,t)-v_u^*(z,t)
=\frac{1-t}{t}\nabla_z\log p(c\mid Z_t=z),
\quad 0<t<1,
\]

通常非零。直接把它压成 Δnoop=0 会消除合法条件信息。共享参数上的复制多任务训练是否改善普通生成，是另一个需要实证的问题，不能从上述不变量推出。

### 5. 不建议把下一步换成每类 α 校准

固定 ER 时，D(ER#Pc,ν) 与 α 无关；把它加到逐图重建损失上，并不能去掉 α 的参考偏好。真正的耦合界还包含 Lip(Gα) 及 prior 误差，但当前高维量未获认证，上界也不保证模型排序。多个参考的重建损失一致同样不等于无偏。

若改用 Eα=Gα⁻¹，重建项恒为零；剩余聚合 prior 与 Jacobian 的约束实质上回到正常流的密度/似然学习。它可以合法研究，但不是发现了新的复制不变量，也不应包装成此次主线的进展。

**结论：当前可严谨研究的是“源图条件复制中，冗余 guidance 不应改变图像身份”；若坚持只用现有冻结 class-only SiT，目前尚未得到既非自反恒等、又无参考偏差的图像 no-op 约束。要将其变成可验证的生成改进，需要额外、可检验的真实数据锚，或真正学会源图条件；现阶段不启动新的校准或修复实验。**
