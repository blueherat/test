# 把原图复制迁移到 FM：公共反演需要什么外部锚

日期：2026-09-13。独立数学审查；未运行 GPU、未新增采样方法。此文接续 [先前的操作定义](inversion.md)，补充同一训练目标的唯一性，以及重建误差何时能连接生成分布。公共参考反演本身不是新方法。

**可保留的操作是：冻结一个独立的、同类别的公共编码器，每轮重新编码上一轮图片，再由待测模型重建。其理想 oracle 有真实图片 fixed point；普通 checkpoint 参考则只提供有偏的近似。自反回环或多轮稳定本身不能给模型质量排序。**

## 1. 最接近原始现象的一个操作

固定类别 c、数据表示、反演规则及参考 R。记生成映射 Gθ,c 和公共编码器 Eref,c：

\[
T_{\theta\mid\mathrm{ref},c}(x)=G_{\theta,c}(E_{\mathrm{ref},c}(x)),\qquad
x_{r+1}=T_{\theta\mid\mathrm{ref},c}(x_r).
\]

协议必须明确：

- 每轮输入的是上一轮输出 xr；重新执行同一个 Eref，而不是始终反演 x0 或复用最初噪声。
- 不添加独立的新高斯噪声；类别不变；参考不随被测模型、图片或轮次重新拟合。
- 被测 strong/weak 都使用第三方参考，不能把参考自身的零误差作为排名依据。
- 同时保存每一轮相对原图和相对上一轮的误差。只看第五轮、或只看相邻轮变化，都会漏掉第一轮塌缩后稳定的反例。

这里把反演用作“读入图片”的接口，并未把回环位移当 guidance 方向。它比原生图像条件编辑器多了一个人工公共编码假设；不能声称两种任务已完全等价。

## 2. 同训练目标能否固定一个非任意的 oracle？

令真实联合分布为 P(X,C)，噪声 ε 独立且服从 ν=N(0,I)，固定 Gaussian FM 构造

\[
Z_t=tX+(1-t)\epsilon,\qquad
v_c^*(z,t)=\mathbb E[X-\epsilon\mid Z_t=z,C=c].
\]

回归的平方损失有正交分解：

\[
\mathcal L(v)=\mathcal L(v^*)+
\mathbb E\|v(Z_t,t,C)-v_C^*(Z_t,t)\|^2.
\]

因此，同一个数据分布、噪声—数据耦合、时间权重和回归目标，指定唯一的 L2 Bayes 最优速度，唯一性在训练测度下几乎处处成立。**不是“指定中间密度就唯一确定速度”**；相同密度路径允许保持分布的额外旋转等速度。固定回归目标才排除这些额外分量作为另一个精确最优解。FM 原文 Eq.8、Theorem 2 给出对应的条件速度聚合及目标等价关系，§4 明确讨论同一密度路径的向量场不唯一。[Flow Matching 原文](https://arxiv.org/html/2210.02747v2)

进一步假设速度足够正则、相关轨迹上 ODE 唯一且端点流可逆，定义

\[
G_c^*=\Phi_{v_c^*}^{1\leftarrow0},\qquad
E_c^*=(G_c^*)^{-1}.
\]

那么真实样本 x 在该表示下满足

\[
G_c^*(E_c^*(x))=x.
\]

这给出了合理的“正确模型应该复制原图”标准。它不要求近似模型与其自己的逆抵消，因为 E* 是被测模型之外的固定对象。

边界条件不能省略：若数据是有限原子或奇异流形分布，不能默认一个全局光滑微分同胚在有限时间把连续高斯变成该分布。可在具有合适密度和流正则性的设定中陈述，或使用明确的平滑数据目标/内部时间截断。截断对应平滑状态，不可直接改名为原始像素的精确重建。

## 3. 正向定理：oracle 公共逆使重建成为分布误差的上界

固定 c，省略下标。若 G* 将 ν 推到真实 P，且 E* 是其逆，那么

\[
\begin{aligned}
R_\theta^2
&=\mathbb E_{X\sim P}\|G_\theta(E^*(X))-X\|^2\\
&=\mathbb E_{Z\sim\nu}\|G_\theta(Z)-G^*(Z)\|^2.
\end{aligned}
\]

同一个 Z 给出模型与真实分布之间的合法耦合，因此

\[
W_2^2((G_\theta)_\#\nu,P)\le R_\theta^2.
\]

这是推导，不是现行 CFG 的质量定理。它说明：**在外部公共逆正确这一前提下，小的逐图重建误差确实足以控制生成分布误差。** 它不保证重建误差给所有模型正确排序；另一种正确的潜空间耦合可以生成完全正确的分布却有较大的 Rθ。该定理也只需一轮；多轮的作用是展示误差是否累积、进入周期或吸引域。

普通 guidance 所得到的 Gθ 可以代入同一上界，但它是否接近指定的 P 仍需验证。尤其不能要求 conditional 与 unconditional 使用不同目标却逐图不动。

## 4. 现实参考的偏差，以及排除 autoencoder 合谋的必要附加项

实际只有近似参考 Gr，Eref=Gr⁻¹。在光滑小误差设定

\[
G_\theta=F+\varepsilon a_\theta+O(\varepsilon^2),\quad
G_r=F+\varepsilon a_r+O(\varepsilon^2)
\]

下，

\[
G_\theta(G_r^{-1}(x))-x
=\varepsilon(a_\theta-a_r)(F^{-1}(x))+O(\varepsilon^2).
\]

所以共享错误会抵消。不同训练种子可减少参数共享，但不能排除相同数据或架构造成的系统误差。第三方参考避免结构性的自反零误差；第二个独立参考可显示排名敏感性，仍不能自动制造 oracle。

对于任何固定编码器 E，额外检验聚合编码分布 E#P 与真正采样 prior ν 的相容性，可以补上逻辑缺口。若

\[
G(E(X))=X\quad P\text{-a.s.},\qquad E_\#P=\nu,
\]

则

\[
G_\#\nu=(G\circ E)_\#P=P.
\]

若只有近似成立，且 G 是 L-Lipschitz、分布有有限二阶矩，则由三角不等式及重建耦合得到

\[
W_2(G_\#\nu,P)
\le L\,W_2(\nu,E_\#P)
+\bigl(\mathbb E\|G(E(X))-X\|^2\bigr)^{1/2}.
\]

这是本文给出的直接推导；其“重建 + 聚合编码匹配 prior”的结构与 Wasserstein Auto-Encoder 相同。WAE 原文以编码数据分布匹配 prior 的正则项连接重建与生成。[Wasserstein Auto-Encoders](https://arxiv.org/abs/1711.01558)

高维 latent 的均值、方差或噪声范数匹配，不等于完整分布匹配。实际有限样本检验和可能很大的 Lipschitz 常数会使此上界难以数值认证。它说明缺的证据是什么，不是宣告现有参考已通过。

## 5. 必须保留的反例

| 误用 | 反例 | 合法解释 |
|---|---|---|
| 自己反演、自己生成，误差小所以模型好 | 任意错误可逆 G 都有 GG⁻¹=I；零速度场也成立 | 数值可逆性 |
| 只要两个模型终点分布正确，公共逆就应复制 | GB=GA∘Q，Q 是高斯保测度旋转；两者同分布，GBGA⁻¹ 却改变图片 | 公共耦合比边缘分布正确要求更强 |
| 独立参考一定给真值 | Gr=Gθ=H，H 都错时仍精确复制 | 独立训练不是正确性的数学保证 |
| 独立训练 autoencoder 就解决合谋 | 任意可逆 E 配 G=E⁻¹ 都能复制；若 E#P≠ν，从 ν 生成仍错 | 需要聚合编码 prior 相容或其他外部监督 |
| 再加一次跨模型闭环可去参考偏差 | 完整组合中的 G⁻¹G 会抵消 | 闭环不能替代单向逐图重建 |
| 多轮稳定就意味着保留原图 | T(x)=x常量，第一轮毁图后永远稳定 | 必须每轮比较最初图片 |
| null 反演再同类生成也是保持同条件 | 两场对应不同目标，oracle 也可持续漂移 | 它是条件转换，不是一般 copy |

最后一行有精确例子：X~N(0,1)，c 为 X>0。从数据端完整 null 反演后进行理想 conditional 生成，

\[
T(x)=\Phi^{-1}\bigl((1+\Phi(x))/2\bigr),\qquad x>0.
\]

每轮尾概率减半，T(x)>x，所有模型和求解器都可以完全正确。这直接否定“已经满足类别，所以 null→conditional 必须复制”。

即使限定同 canonical FM 目标，有限模型的训练风险排序也不自动给逐条轨迹误差排序；小 L2 平均风险不保证低概率区域或偏移后轨迹上的均匀误差控制。不能用这层唯一性绕过参考验证。

## 6. 对当前 SiT 的表示约定

以上 x 首先是 FM 的数据表示。当前 SiT 在 VAE latent 中运行：

- 潜变量回灌 z[r+1]=Gθ(Eref(z[r]))，每轮只解码展示，是 latent copy 实验。
- 像素回灌 x[r+1]=Dvae(Gθ(Eref(Evae(x[r])))) 每轮重新编码图片，额外包含 VAE 重建漂移。应同时保留反复 Dvae∘Evae 的 codec 对照。
- 每轮重新采样 VAE posterior 会引入新的随机量；确定性协议需明确编码规则。但使用 posterior mean 又可能与训练时 posterior sample 的数据分布不同，不能声称其 prior 已自动匹配。

所以即使 FM 在 latent 上完全恒等，也不推出真实像素是整条 codec 链的精确 fixed point。若要求逐像素复制，需要无损输入通道；若只要求可见内容不变，应事先定义容许的误差。

## 7. 最终裁决

当前最值得保留的不是新的反演 guidance，而是一个有明确预期目标的公共编码重建协议。理论上，同 canonical FM 回归目标能够指定非任意 oracle；oracle 公共逆下，逐图重建还有明确的 Wasserstein 上界。现实 checkpoint 只能近似这个外部锚，因此先研究一至多轮重建、参考偏差和 codec 误差，不能把当前测量直接升级成生成质量排序。

原生图像条件 no-op 的目标更直接：给定完整原图与不修改指令，目标输出分布为 δx。内部目标噪声并不妨碍这一任务，只要完整源图仍可访问。普通 class-only SiT 没有这一接口；公共反演是一个可检查的替代编码约定，而不是悄悄声称模型本来就懂“复制”。
