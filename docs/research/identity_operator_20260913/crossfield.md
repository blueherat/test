# 重复零编辑、重建与幂等性：直接相关文献和跨领域反例

日期：2026-09-13。本文为交叉领域研究子任务，文献事实、我们的推论和待验证假设分别标明。未运行 GPU 实验。

## 1. 最重要的判断

用户的原操作最好先命名为 **重复零编辑（repeated no-op / identity-instruction editing）**：每轮输入上一轮的完整图片，给出固定的保留指令，通过同一个图像编辑接口输出图片。它的任务目标是保留输入；不能把任何“图像进去、图像出来”的随机过程都视为这个任务。

“更强模型更稳定”有两种不同解释：（a）更强的图像条件保留和指令遵循能力；（b）更好的无条件或类别条件生成先验。当前观察首先支持检验（a），不能直接推出（b）。一个编辑系统可以通过复制通道取得完美零编辑成绩；一个生成分布正确的重采样器可以持续改变实例。两者都不是悖论。

主实验中的对象应当是接口算子或转移核，而不是笼统的模型：

\[
x_{r+1}\sim K_{M,a}(\cdot\mid x_r,p_{\rm keep},h_r),
\]

其中 \(a\) 包括尺寸、源图保真选项、编码解码、采样和 API 版本；\(h_r\) 是历史。若要研究“输出作为唯一新输入”的链，应清空历史，使 \(h_r=\varnothing\)。沿用整段会话会允许系统继续访问原图，形成不同实验。

## 2. 真正接近用户操作的原始文献

### A. Why Do DiT Editors Drift? Plug-and-Play Low Frequency Alignment in VAE Latent Space，2026-05 预印本

这是本次检索中**操作最直接匹配**的论文。其 §3 定义零编辑违约 \(T_{\rm noop}(x)-x\)，实验连续运行 10 轮保留指令；比较完整像素循环、绕过中间 VAE 的 DiT 循环及 VAE 单独循环，模型包括 FLUX.2、SD3-UE、Qwen Image 2.0、Seedream 4.0。附录 F.7 报告黑盒调用固定 seed=42。作者在所测设置中发现 DiT 的低频漂移占主导，并用低频统计对齐缓解。这是预印本实证，不是适用于所有编辑器的定理。[原文及附录](https://arxiv.org/html/2605.08250v1)

可借鉴：直接 no-op 接口、逐轮原图距离、组件拆分。不可照搬：把有限架构上的低频归因推广到所有模型；把低频对齐后的保留优势直接称为生成能力提升。固定种子只固定随机控制；它本身不会创造保留源图的任务。

### B. REED-VAE，2025

§5.5 明确研究**反演—同提示词再生成—再反演**：NTI 用 source prompt 反演图像，再以同一 prompt 生成，没有编辑意图。作者对比普通 VAE 和 REED-VAE；示例在约 5–10 轮已出现明显差异，附录展示 25 轮。它还单独测试 VAE 重复编码解码。因此，这确实是已有的无编辑迭代重建研究，远比独立加噪更贴近原问题。[原文 §5.5 及附录 B.3](https://arxiv.org/html/2504.18989v1)

与 A 的差异不是简单的“哪篇正确”：A 测现代图像指令编辑器和低频漂移，B 测特定 VAE、NTI 与重建流程。架构、图像接口、反演误差和频段不同；应把“VAE 主导还是生成器主导”当作需要组件对照回答的经验问题。反演后的噪声坐标是由当前图片求得，不能等同新抽高斯噪声。

### C. The Drift Kernel，CVPR 2026：相关，但方法学需要反驳

论文用 SD1.5、SD2.1、SDXL、InstructPix2Pix 测 no-op/copy prompt；正文设置为 15 DDIM 步、guidance 5、strength .3、seed 42，并扫描 strength。其主张 decoder Jacobian 导致漂移约随 \(\sigma^2\) 变化。论文报告聚合拟合 \(R^2=.97\)，同时单模型仅 .10–.26。[官方原文 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Ram_The_Drift_Kernel_Why_Diffusion_Models_Change_Even_When_Told_CVPR_2026_paper.pdf)

我们的批评：

- 普通 SD 的 img2img 文本条件不自动具有“照做编辑指令”的语义；若输入实例仅经有损加噪保留，用户对旧实验的反对同样适用。不能因为论文用了 no-op 一词就接受其 identity 解释。
- 正文从正向加噪跳到 decoder 输入 \(\mu+\epsilon\)、\(\epsilon\sim N(0,\sigma^2I)\)。实际去噪后残差的均值和协方差取决于完整流程；API strength 也不等于 decoder 残差的标准差。
- 一般局部表达应包括残差均值及 \(\operatorname{tr}(J\Sigma J^T)\)，不能未经证明把 \(\Sigma\) 换成 strength 平方乘单位阵。Jacobian 在哪个 latent 点计算也会随条件改变。
- 聚合拟合不能替代单模型预测验证；平方像素误差不是充分的感知距离。

所以它能作为待复现的扰动敏感性研究，不能证明“扩散模型在保留任务下原则上不能保持图片”，也不能反驳用户的意见。

## 3. 幂等生成和编解码：接近的数学结构，不是同一质量命题

### Idempotent Generative Network，2023/2024

IGN 同时要求真实数据自重建 \(f(x)=x\)、生成输出幂等 \(f(f(z))=f(z)\)，并加入约束固定点集合的 tightness 目标。论文自己解释：前两个目标允许全空间恒等映射，所以不能只优化幂等损失；其理论依赖理想优化条件，实验也讨论模式坍缩和模糊。[原文 §2 及 §6](https://arxiv.org/html/2311.01462v1)

启发是“真实数据应为固定点”可以成为**受数据约束的训练设计**。它不是“预训练扩散模型的一步去噪后验均值应当是投影”的证明，更不能把当前内部探针残差自动当作质量判据。

### Encoder–Decoder Manifold Alignment for Idempotent Generation，2026-06 预印本

该文对 \(T=D\circ E\) 加入 \(E(D(E(x)))\approx E(x)\) 的潜变量一致性约束，并测试 VAE/生成/编辑。附录 Proposition 1 证明：若 \(T\) 已经是投影则幂等；Proposition 2 证明上述潜变量等式足以推出输出幂等。它不证明反方向：任意幂等映射不必是最优数据流形投影。[原文及 Appendix B](https://arxiv.org/html/2606.22304v1)

这对仓库中的 VAE 主线可能比立即改 CFG 更直接。但“潜变量循环更一致”与“语义更正确”仍须分别评估。

### Idempotent Learned Image Compression with Right-Inverse，NeurIPS 2023

该文把重复压缩稳定性作为独立性质，指出全变换可逆是充分条件而非必要条件，并用 right-inverse 构造幂等图像压缩。[会议原文入口](https://proceedings.neurips.cc/paper_files/paper/2023/hash/2a25d9d873e9ae6d242c62e36f89ee3a-Abstract-Conference.html)

可以直接看到两个量为何不同：令 \(T=D\circ E\)，若有效码上 \(E\circ D=I\)，则 \(T^2=T\)；但 \(T(x)\) 第一次丢失了多少信息并没有由这个等式决定。粗量化可第一次损伤严重，此后完全不再变化。

### Code Drift，2024/ICASSP 2025；LILAC，2026-08 预印本

Code Drift 实测神经音频编解码器在反复编码时漂移，部分系统约三次就明显退化，且可通过微调改善幂等性。[原文](https://arxiv.org/abs/2410.11025) LILAC 则用结构设计保证有效 token 序列的解码再编码完全一致，并独立评估听感质量。[原文](https://arxiv.org/html/2608.05727v1)

跨领域价值：**稳定性与单次质量是不同坐标轴**；结构性的幂等保证可以不依赖训练是否已达到高质量。因此原观察很适合提出保留能力指标，但不足以排列生成先验强弱。

## 4. 其他领域提供的反例和边界

### 传输链与信息瓶颈

Griffiths 与 Kalish 的 Bayesian iterated learning 理论指出，在相应采样假设下，代际链的平稳分布可由学习者先验决定。[2007 原文](https://onlinelibrary.wiley.com/doi/10.1080/15326900701326576) 这说明链的终点可以揭示先验偏好，但“最终稳定”不是“原始信息忠实传递”。

Patterns 的 Autonomous language-image generation loops（2025 在线 / 2026 卷期）用 SDXL↔LLaVA 的图像—文字循环，发现长期趋向有限的通用主题。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12827715/) Image Regeneration（2024）也通过 GPT4V 将参考图片转成文本来评估 T2I 重建。[原文](https://arxiv.org/html/2411.09449v1) 两者都引入文本瓶颈；不能当作完整图像条件的零编辑实验。长期主题稳定甚至可以来自实例信息丢失。

### 感知—失真权衡的适用边界

Blau–Michaeli 讨论不适定恢复中的感知质量和失真约束。[原文](https://arxiv.org/abs/1711.06077) 对本问题的启发是不能用 FID 代替原图保留。**但是当完整原图已经作为条件、任务只是返回它时，并没有必须接受该信息损失的理由**；不能引用恢复任务的权衡来为 zero-edit 失败免责。

### Cycle consistency 可以被隐藏信息满足

CycleGAN, a Master of Steganography 展示网络能在难以察觉的高频信号中藏入原图信息，使反向映射满足循环恢复。[研究者原文](https://arxiv.org/abs/1712.02950) 因而 \(B(A(x))\approx x\) 不保证中间结果语义正确；循环损失也不能替代每一步的忠实度。另一方面，无编辑任务下明确允许复制完整输入，本身并不是作弊；只有把复制成功解释成强生成能力时才发生推理越界。

## 5. 建议的操作定义和最小对照

| 名称 | 每轮操作 | 正确的零假设 | 能回答的问题 |
|---|---|---|---|
| 重复零编辑 | 完整上一轮图片 + 固定保留指令 → 原生编辑接口 | 输出应接近当前输入，并长期接近初始图 | 图像条件保留和指令遵循 |
| 迭代反演重建 | 从当前图求源噪声/轨迹 → 原条件解码 | 同一逆映射与正映射应恢复对应输入 | 数值、反演、codec 及坐标一致性 |
| 重复 codec | 当前图片编码→解码 | 理想 codec 首次投影后不再损伤 | 编解码闭合和累积误差 |
| 有损再采样 | 当前图加独立噪声→按类别去噪 | 一般不应要求逐图 identity | 混合、先验漂移和分布动力学 |

对第一个任务，建议：固定模型版本、分辨率和源图保真选项；每轮新请求只传上一轮图片，保持同一提示词；同时报告固定种子链和独立随机链，多条独立链用于估计随机性。不能把固定种子视为必须条件，也不能把新随机种子本身叫作“给了模型新语义信息”——决定性的区别是原图信息是否仍作为完整条件存在。

每轮至少分开记录：（1）相邻轮变化；（2）对初始图的累积变化；（3）主体、文字、布局、颜色等任务保留；（4）视觉质量。再做“每次都从初始图重做一次”的单步分支，区分一次编辑本身的随机性与递推输入造成的误差累积。白盒追加 codec-only、latent-only、full-pixel 三组，不把它们混为一种测试。无须先跑大规模 FID 调参。

## 6. 与理论代理、反演代理辩论：原主张、反例与修正

| 原主张 | 对方提出的反例或质疑 | 修正后的条件 |
|---|---|---|
| 有未加噪源图条件，所以精确像素保留必然可实现 | 源图虽然以完整文件传入，内部编码器可能非单射；不同原图共享条件码时无法逐一精确恢复 | 区分任务目标与模型可达性。零编辑忠实度评价仍合理，但精确像素不变的理论保证需要可恢复源信息或复制通道；用 codec 对照衡量特定实现的损失，不宣称任意架构都能零误差 |
| 要禁止复制，才能真实评价用户的保留要求 | 用户就是要求不变，复制是合法且最优的任务解 | 零编辑任务允许复制；另外报告是否调用生成路径，并用正常编辑任务评估生成能力。不能把合法任务解重新定义为作弊 |
| 新种子带来新噪声，所以一定不应要求一样 | 若完整源图仍作为独立条件，最优保留算子可以对种子完全不敏感 | 真正关键是破坏是否丢掉源信息，以及任务是否有保留义务。加噪作为生成工作变量不等于删除源条件；旧 SiT 操作恰好把被破坏的状态当作唯一实例通道 |
| 重复编辑损伤主要是 VAE；或者主要是 DiT | REED-VAE 与 VAE-LFA 的实验观察并不相同 | 只对相应模型、反演接口、频段和数据作归因；运行 codec-only、latent-only、full-pixel 对照后再谈主导因素 |
| 稳定性约束必然改善 CFG/IG | reference 自循环误差可偏爱 reference guidance；常数映射、复制和完美可逆劣质生成器分别满足不同一致性条件 | 将编辑保真作为具体能力，用非零编辑成功率和外部视觉质量防止退化；新图生成收益必须另外验证 |

这里的“完整图像条件”是指接口仍接收未被外部破坏的原图，而非断言内部视觉编码器无损。普通类别 SiT 连这个图像条件接口也没有；因此不能拿它的高噪声再采样漂移解释原实验。

辩论后的行动共识：

1. 最优先复现原生图像条件编辑器的零编辑接口。反演代理指出 InstructPix2Pix 的未加噪 source latent 是独立条件通道；本仓库类别 SiT 不具有该接口。仅保持类别标签没有保留原实例的义务。
2. 反演—重建适合作为可控代理，但完美可逆的差模型也可能零误差。FlowEdit 一类速度差在源目标相同条件下也可能构造性归零；这验证算法性质，不能评估模型先验。
3. 理论代理反驳“用 reference reconstruction 误差优化 guidance 就能提高生成”：若目标是 \(\|D_g(E_{ref}(x))-x\|\)，reference 本身的 guidance 可能构造上占优，copy bypass 也可能最优。必须有独立非零编辑成功率、已知破坏恢复或外部质量证据。
4. 因此最可信的 CFG/IG 连接是**编辑任务中的零编辑校准和非请求变化控制**，且同时验证正常编辑能力。想回到 class-only SiT 的新图生成，需另证稳定性测量与独立质量的关系；不能先把它当质量代理损失再大规模调参。

当前尚未解决的问题不是哪个 guidance 公式更漂亮，而是：选定一个保留完整实例信息且任务目标明确的算子后，是否存在排除了复制、codec、反演误差及随机性之后，仍能预测外部质量的残差信号。这是可证伪的新研究问题，现有文献尚不替我们给出肯定答案。
