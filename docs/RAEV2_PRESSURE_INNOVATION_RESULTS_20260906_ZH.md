# 最后第2轮结果：协方差压力与对称创新不进入训练

**本轮完成，结论为否决当前机制的训练入口。** 全部100个固定时刻的已有teacher缓存，不能支持把残差能量全部解释为原生IG仍缺失的方差；独立Gaussian反例进一步表明，即使Full预测精确、创新严格保持均值，补入posterior variance仍可能重复补偿IG已经修好的方差。本轮没有训练、GPU模型调用、生成样本或RAE FID结果，不构成“FID改善5%”的证据。

这是用户所限最后最多五轮中的**第2轮**；原压力与对称创新属于同一机制族。独立复核、解析计算和数据归档均属于本轮核验，不另计轮次。依据是事先写定的[协议](RAEV2_PRESSURE_INNOVATION_PROTOCOL_20260906_ZH.md)和[机制审查](RAEV2_REMAINING_MECHANISM_REVIEW_20260906_ZH.md)，没有按结果挑时刻、类别、gain或窗口。

## 理论成立的范围

对固定类别和固定原生一步，令Y是teacher状态经过原生IG Euler后的状态，W是与它共享X、ε的下一真实bridge状态，R=W−Y，辅助插值Uτ=Y+τR。若初始条件均值m₀(Y)=E[R|Y]确为0，在密度正则、相关矩可积、分部积分边界项消失等条件下，初始物质加速度满足

    a₀(y)=−h₀(y)⁻¹ div(h₀(y) E[RRᵀ|Y=y]),
    E[a(Y)·a₀(Y)]=E[Rᵀ J_a(Y) R].

因此可以考虑最小化二阶Stein人口目标

    ½ E||a(Y)||² − E[Rᵀ J_a(Y)R].

若R=βe，且固定测试函数族及参数导数界、e的四阶矩对β一致受控，零输出附近的二阶标签参数梯度方差有O(β⁴)上界；直接速度标签则可以是O(β²)。这提供有条件的统计动机，并不保证实际CNN的方差更小、风险更低或FID更好。若边界正则性或固定函数族条件不成立，这个比较也不能照搬。

有限IG不自动具有m₀=0。此时同一个Stein目标识别的是raw二阶通量a_raw，而真实物质加速度还包含均值项的修正；辅助流也需要一阶位移m₀。仅使用自然Taylor系数½作Y+a_raw(Y)/2，会遗漏这些项。若a_raw精确且上述积分条件成立，其**有限更新**必须满足

    E[||Y+a_raw/2||²−||Y||²]/D
      = E||R||²/D + E||a_raw||²/(4D) ≥ E||R||²/D.

而目标的精确总体恒等式为

    d₂−e₂ = 2 E[Y·R]/D,
    d₂ = E[||W||²−||Y||²]/D,    e₂ = E||R||²/D.

m₀=0蕴含d₂=e₂≥0。经验缓存只是对这些量的描述性估计，不能把一次样本中的不等式直接当作总体m₀=0的统计拒绝。反过来，即使经验cross接近0，也只检验了一个必要矩条件，不能认证完整条件均值为0。

## 对称创新的独立反例

为精确保留有限G的均值，可以另定义独立符号ζ∈{−1,+1}，R*=ζβ(X−F)，W*=Y+R*。条件于原输入Z，它对任何有限Full预测F都保持均值Y，创新协方差为

    β² {Cov(X|Z)+(M−F)(M−F)ᵀ},    M=E[X|Z].

这定义了一个新的目标kernel，未证明它等于原p_s或代表IG还未补偿的误差。固定反例取X、ε独立N(0,1)，t=½到s=0，Z=(X+ε)/2，精确Full F=M=Z，原生IG G=√2Z。此时Y=G已经服从目标N(0,1)。因为Z与X−Z联合Gaussian且协方差为0，R*=ζ(X−Z)独立于Y，方差为½，于是W*服从N(0,3/2)。

在恒等decoder的一维Gaussian例子中，FID从0变为

    (√(3/2)−1)² = 0.050510257216821901802715925294108608034052519343314.

该数值由独立50位Decimal计算确认，见[解析结果](data/raev2_pressure_innovation_20260906/gaussian_counterexample.json)。它否定“正确posterior variance加均值保持就普遍改善质量”的保证，不意味着实际RAEv2必然处于该Gaussian情形；它也不是RAE图像FID实验。当前缓存没有保存Full F，不能用R_G替代R_F去估计这个变体的实际创新协方差。

## 成本、裁决与保留内容

本轮原缓存审查墙钟0.3594359511秒、CPU累计3.464768558秒；独立复核墙钟0.2169781059秒、CPU累计0.361914926秒。两者均从函数入口计至summary写入前，均为0 GPU、0主模型、0辅助模型、0解码、0训练、0新样本、0 FID调用；文档与打包I/O不在这两个计时区间内。

复用缓存不是宣称历史生产免费。原validate阶段记录墙钟115.9858161989秒、CPU149.333333311秒；主模型1300次/10400条样本，候选辅助模型2000次/50000条，控制辅助模型1200次/30000条，含尾batch补齐。它是第1轮已计入的历史阶段，没有在本轮重新执行；原始[生产summary](data/raev2_pressure_innovation_20260906/producer_summary.json)和[请求](data/raev2_pressure_innovation_20260906/producer_request.json)保留在数据包中，相关训练/数据准备链见[配对桥pilot记录](RAEV2_PAIRED_BRIDGE_PILOT_RESULTS_20260906_ZH.md)。不能把上述CPU审查成本当成完整候选方法的训练或部署成本。

**不分配新的训练预算。** 理由是压力入口的零条件均值前提未得到支持，实际IG剩余协方差没有识别，对称创新又存在严格的重复补偿反例。此外，无限制函数族的有限样本Stein目标可能通过“样本点场值小而Jacobian大”趋向无界；尚无自然、受控且有新表示依据的有限函数族来闭合学习问题。添加经验正则、扩大CNN、换窗口或重训旧矩校准器均不由当前证据推出。

保留的贡献是协方差压力的二阶弱形式、带条件的方差阶数比较，以及区分“posterior uncertainty”与“IG仍未修复的分布误差”的必要性。本轮裁决不宣称所有压力方法失败，不将teacher矩诊断冒充rollout质量保证，也不宣称达到用户的5%目标。
