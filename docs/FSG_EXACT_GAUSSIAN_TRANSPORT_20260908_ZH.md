# 精确条件搬运与固定点逼近的区别

用户约束：继续方法研究，不写论文。这里是方法设计的反例检查，不是新方法
或ICLR贡献声明，也不声称解释了RAEv2的失败。

重新阅读FSG原文§3.1、附录A.5/B/C：
https://arxiv.org/html/2510.21512v1 。其附录B用条件生成后无条件反演构造
近似匹配latent，附录C要求收缩与有界性。本例不满足这些全局假设，因此
不构成对其条件定理的反驳；它检验将经验直觉扩展为通用设计准则是否成立。

## 可精确求解的模型

目标类 P_c=N(m,1)，无条件 P_u=.5N(-m,1)+.5N(m,1)，m>0。
初始z~N(0,1)，标准正态CDF为Phi，混合CDF为M。精确单调解码为

    C(z)=m+z, U(z)=M^{-1}(Phi(z)).

一维从同一连续先验出发的精确概率流输运均保持顺序，因此端点由这些
分位数映射给出。没有神经网络估计或ODE离散误差。
取完整端点区间的条件前向/无条件逆向校准

    T=U^{-1} C, T(z)=Phi^{-1}(M(m+z)).

这是条件scale=1的理想完整区间版本，不等于仓库内使用合成IG参考与
异步Euler时钟的实现，也不声称复现FSG的实际质量实验。

一次搬运后 U(T(z))=C(z)，所以精确产生条件分布。另一方面

    M(m+z)=.5 Phi(z)+.5 Phi(z+2m)>Phi(z),

故所有有限z都满足T(z)>z，且C(z)>U(z)：在这个初始时刻不存在有限的
端点相等点。T连续，单调增加的迭代若有有限极限就必须有固定点，因此
T^k(z)趋于正无穷。全局收缩假设不成立。

右尾满足 T(z)-z~log(2)/z，C(z)-U(z)~log(2)/z。
因此端点差趋于零可以伴随latent与解码位置逃向尾部，不能推出正确分布。
这个推导并不排除其他时间、分布或实际模型具有有用的近似golden path。

## 确定性数值核验

8192个正态中点分位数，固定m=.5/2/4，报告迭代0/1/2/4/8/16/32/64。
所有m均第一次达到数值零W2，之后报告节点上的W2严格增大而gap严格下降。
平方W2是对真实条件分布分位数积分的中点求积，不是图像FID。

| m=2，迭代次数 | 条件目标平方W2 | 端点gap MSE | 解码标准差 |
|---|---:|---:|---:|
| 0 | 5.646499 | 5.646499 | 2.236014 |
| 1 | <1e-20 | .826192 | .999920 |
| 2 | .826192 | .238728 | .606633 |
| 8 | 8.071692 | .049310 | .305162 |
| 64 | 83.85554 | .005609 | .107476 |

采样点上的平均局部导数平方始终<1，但没有有限固定点；这具体说明局部
平均收缩统计不能替代全局收缩、自映射与有界性检查。T导数由
T'(z)=p_u(C(z))/phi(T(z))精确计算。
稳定log-CDF实现避免尾部概率舍入为1；U(T(z))=C(z)最大误差<2e-12。
另用独立SciPy标量Brent求根验证U，并加倍m=2的积分节点核验代表性W2。

## 对下一步方法的约束

不能以“消除条件/无条件gap”或“更多迭代更接近固定点”单独确定校准目标。
一次U^{-1}C是正确的条件分布搬运；重复它却对已经搬运过的分布再次施加
同一偏置。因此后续候选需要解释它在当前分布上还缺什么条件信息，以及
为何不会继续压缩类内变化。单纯寻找更快的gap收敛器没有获得支持。

U^{-1}C本身也不是新算法：完整条件生成再反演不带来已证明的计算优势。
本例提供的是设计约束，尚未提供可部署的有限区间方法。不得把该toy反例
当作实际RAEv2迁移机制或生成方法成功，不推进论文。
