# 递归再生成响应用于 CFG／IG：十项假设、每项二十组

2026-09-13。用户明确授权打磨约十个 idea，每个预留二十组参数，并放入一个 tmux 开始运行；随后明确要求至少五轮完整回灌，每一轮单独执行、评价及保存，不能只看第五轮。本协议最终落实为小 SiT 的 **200 个候选配置 + 59 个对照，每个配置第0轮初始生成＋第1–5轮完整回灌，每轮1,000张配对图像**。共1,554个配置轮次，最多1,554,000张主输出。模型、真实数据训练、已有 checkpoint 和历史实验不改动。内部再生成探针不算这五轮完整回灌。

研究问题是：再生成中的方向响应、偏移及强弱差分持续性，能否作为有用的 guidance 控制信号。小 SiT 没有自然语言恒等编辑接口，因此本轮研究的是 **latent 上固定噪声时刻的再加噪与去噪代理操作**，不是复现商业图像编辑模型的完整像素复制链。重建稳定性不被当作真实图像质量标签。此前直接优化自重建固定点及配对一致性失败的记录保留；本轮具体区别见[设计审查](RECURSIVE_GUIDANCE_DESIGN_REVIEW_20260913_ZH.md)。

## 模型、主采样及两条主线

- strong：仓库已有 ImageNet-100 SiT-S/2，800K EMA，velocity 参数化，SD-VAE；100 类条件保持原接口。
- CFG：`S+α(S-U)`，其中 U 是同一个完整模型的 null 条件输出，不使用弱头辅助 CFG。
- IG：`S+α(S-W)`，候选全部使用已确认的 depth4 MLP 弱读出，来源为原真实数据训练的最终 EMA。原 depth4 头作为独立普通 IG 控制；strong 主干不变。
- 主采样为 FP32、既有 runtime 的 TF32 设置、64 步 Heun。CFG 的额外 α 在左端时间 `<.75` 开启；IG 在 `<.25` 使用峰值的 `6/7`，`.25≤t<.5` 使用峰值，之后关闭。两个 Heun 子阶段共用左端窗口，不能第二阶段提前关停。
- 额外 α=0 恢复 strong。CFG 的常规 scale 是 `1+α`；不能把两者混写。强度数值不跨 CFG／IG 直接比较。

## 再生成算子与固定实现

### 完整输出回灌：逐轮执行0、1、2、3、4、5

第0轮从共享标准高斯噪声运行完整采样，得到每个配置自己的最终latent `x^(0)`。第r轮（r=1..5）读取该配置的上一轮实际输出，构造

`z_.25^(r)=.25*x^(r-1)+.75*ε_r`，

然后完整运行原全局网格从`.25`到`1`的采样后缀。64/96/128步配置分别执行48/72/96个后缀Heun接受步，不将48步后缀称作新增64步。原CFG/IG的全局时间窗口、强度、tau设置和弱头均保持不变；每轮重新初始化探针状态、动量与控制历史。所有配置共用同一轮ε_r及标签，但各自拥有自己的父latent，禁止把其他配置输出或第0轮重复作为后续起点。

这是一次有较强加噪的条件再生成，`.25`使既有IG窗口仍包含实际引导区间；它不是无损恒等编辑，也不要求精确模型逐图不动。采用latent反馈是为了把VAE重复编码误差与guidance机制分开；解码图像用于查看和质量评价，RGB不会被重新编码进下一轮。

**每一轮都先完成1K采样、单独计算FID/sFID/IS、保存图像与latent，再进入下一轮**。每轮记录相对第0轮及上一轮的像素/latent差异，生成固定样本预览和逐轮联系表。全部图像像素保留在原始NPZ分片中，每轮另存固定前16图预览与跨轮对比；不挑选最好看样本。评估所需拼接图像只临时生成，提取特征和记录SHA后释放，避免永久保存第二份百万级图像数据。raw分片、最终latent、特征、指标与身份记录保留用于恢复和复核。

初始4个锚点配置先运行完整六轮，此后十个idea从中间强度与τ=.8的设置开始交错运行，并逐步插入剩余对照。最终200点候选及59点对照不变。每轮最佳FID可以用于标注探索性排序，但跨轮曲线必须跟踪同一固定配置，不能把不同轮次不同参数的最佳值拼成一条方法曲线。

### 采样内部的小规模再生成探针

时间约定 `z=tX+(1-t)ε`。当前 clean 估计 `m=z+(1-t)S`；固定探针时刻 `τ=max(t_left,τ_setting)`。定义

`T_j(x;ξ) = y+(1-τ)F_j(y,τ), y=τx+(1-τ)ξ`。

通常使用 `T̄_j=(T_j(+ξ)+T_j(-ξ))/2`。这只是两次反向噪声探针平均，不等于精确期望。强弱分支和中心差分共享同一 ξ；第9项分别读取两份噪声的 gap；第10项在第二轮仍使用相同的反向噪声对。它不是精确 ODE 反演，精确 posterior mean 的正常收缩也不被命名为模型错误。

从第8步（左端 t=.125）开始，每8个已接受步骤更新一次探针：CFG 在8/16/24/32/40步更新，IG 在8/16/24步更新。读出的标量或方向在下个更新前冻结，两次 Heun 查询不更新历史；当前 velocity gap 仍在每次查询重新计算。中心差分的无量纲步长固定 `h=.1`，在 clean 方向 `d=(1-t)(S-R)` 上查询 `m±h d`。

普通方向、投影和范数变换在当前 velocity gap 上应用；不直接把历史 clean 位移相加到速度。第4项存储正余弦加权、截范数后的共同漂移与当时 gap 范数之比，每次应用按当前 gap 范数缩放，并重新删除其沿当前 gap 的分量。第2/7项若输运向量范数≤1e-12，保留当前方向。其余分母下限1e-12，cos限制[-1,1]；非有限探针或状态直接判为该配置数值失败，不静默回退到基线。

## 五十九个对照

- strong：1组。
- 原弱头普通 IG、MLP普通 IG：各6组，峰值`.2,.4,.6,.8,1,1.2`。
- MLP-ADG：5组，沿用仓库原论文公式。
- 普通 CFG：7组，峰值`.25,.5,.75,1.25,1.75,2.25,2.75`。
- 既有 APG 适配：5强度×2动量系数`-.5,-.25`，共10组。
- 既有 CFG-Ctrl 适配：5强度，switching gain=.2、decay=5，沿用`U+(1+α)modified_gap`和已接受步历史。属于已发表方法对照。
- 普通 CFG、MLP-IG 的96/128步：各2组，共4组，峰值分别1.25/.8。
- 第2/3/4/7项在中间强度、τ=.65/.8：8组等幅度方向对照。计算完全相同探针，仅将修改方向换回原gap方向、保持修改后的范数；用于识别方向贡献。
- 第3/4/7项在中间强度、τ=.8：3组反号修正对照，更新仍限制在2倍原gap范数内。
- CFG和MLP-IG在τ=.5/.9：4组只读取探针而不修改的控制，预期像素和latent与同参数普通方法一致。

59组控制均在新bank重新生成，不拼接旧FID。CFG与IG分别对比同源基线；IG还明确比较同MLP弱头基线，避免把已知读出收益归到本轮算子。有效强度下降型候选必须和较低固定强度比较，方向型候选须看等幅度控制。高NFE对照是计算预算参考，不保证逐项精确等时。
