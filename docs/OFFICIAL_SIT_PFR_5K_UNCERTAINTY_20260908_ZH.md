# 配对 5K FID 的局部采样波动检查

此补充在 5K 尚未完成、尚无 FID 时固定。主指标、样本、参数和独立
FID 审计均不变；不增加模型推理。主审计完成后才运行
`experiments/analyze_official_sit_pfr_5k_influence.py`。

目的：如果两组 FID 接近，避免仅根据差值正负就宣告可靠收益。
输出配对的一阶波动估计，不将其解释为经过校准的置信区间或 p 值。
参考统计量固定，不估计参考数据自身的不确定性。

设生成特征均值、无偏样本协方差为 m、C，参考为 r、R。
FID 对均值的梯度为 2(m-r)，对协方差的梯度为

`A = I - R^(1/2) [R^(1/2) C R^(1/2)]^(-1/2) R^(1/2)`。

对权重总和为 1、协方差保持固定修正 n/(n-1) 的加权矩函数，
样本 i 的影响值为

`I_i = 2(m-r)^T(x_i-m) + n/(n-1)*(x_i-m)^T A (x_i-m) - tr(A C)`。

两组共享样本索引、标签和初始噪声，先取影响值之差 D_i。
标签固定为 1000 类、每类 5 张，因此使用类内方差：

`SE^2 = sum_c (n_c/n)^2 * sample_variance(D_i | c) / n_c`。

这种设计不把固定类间差异当成随机抽样波动。两组分别估计方差再
相加会丢掉共同噪声产生的协方差。

公式使用正定矩阵的平方根微分。相关既有理论见
[Rippl、Munk、Sturm 的 Gaussian Wasserstein 极限分布研究](https://arxiv.org/abs/1507.04090)。
这不是新理论；文中的 Gaussian/渐近结论不能直接充当本次高维
Inception 特征、每类仅 5 个样本的有限样本保证。
这里只作局部 delta 近似，也不校正有限样本 FID 偏差。
遇到非正定协方差将停止该补充，不加 ridge 改变指标。

数值核验包括独立加权 FID 中心差分与解析方向导数的一致性，以及
类内常数影响值的方差为零。此检查验证计算，不验证近似的统计覆盖率。
所有结果均须与主审计的 FID 一致；不根据该分析修改、挑选或校正图像。

数值自检已完成（会话 60674，exit 0）：两档权重扰动 1e-3、5e-4，
中心差分与解析导数的绝对误差分别约 3.63e-9、8.71e-10；
零差值、类内常数两项方差核验通过。
