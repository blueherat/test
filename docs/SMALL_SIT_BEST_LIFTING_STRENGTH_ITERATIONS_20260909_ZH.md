# 历史 SiT 工作点：前半程强度与 lifting 次数

用户补充：后半程可为0，前半程强度丰富一些，迭代次数比较两种。
沿用 SMALL_SIT_BEST_CONFIG_LIFTING_20260909_ZH.md 的历史配对bank、
模型、精度、Dopri5主推进、Heun辅助流、4细步最大block、.25/.5边界。
前半程固定三套 alpha：(.6,.7)、(.7,.8)、(.8,.9)，后半程统一0。
每套 m=1、2；历史(.6,.7),m=1已在单独队列中，只复用，不重复。

对同一活动block，在当前状态重算 L=(Phi_W)^(-1)Phi_S，顺序执行m次
z <- z+(alpha/m)*(L(z)-z)，然后一次Strong主推进。不重复主推进，
两次不是复用同一个L(z)，而是在第一次写入后的状态重新评估。
分摊系数令小步一阶总引导匹配alpha；有限步下结果不必相同。
这不是同时间固定点求解，也不能在没有对照时称作收敛性提高。

新增五组各1K，等待历史一次版本完成再运行，四卡协同一组、组间顺序。
前段强度和次数均是同一历史bank上的探索变量，有选择偏差。
每图m=1辅助100 Full+100 prefix；m=2辅助200 Full+200 prefix；
主Dopri5调用随轨迹而变，必须记录实际调用和耗时。仅新lifting，
