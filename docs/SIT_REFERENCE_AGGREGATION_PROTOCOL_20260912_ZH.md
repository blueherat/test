# 固定教师的 IG 学生状态聚合：冻结协议

固定第五轮浅层参考蒸馏的最终 EMA 为两个读出的共同起点。上一轮新1K中，浅层蒸馏66.8875，原IG68.2781，已有自身数据参考66.1928，ADG66.7650；未达晋级门槛。这次只检验参考回归的状态分布变化，不修改CFG候选，不搜索深度、宽度、损失权重或guidance强度。

教师仍为已有独立5K有效的 native 四层弱前缀 W_T，强模型 S 冻结。指导场 G_phi=S+a(S-W_phi)。训练数据依赖参考，因为改变 W_phi 会改变 G_phi 的轨迹。沿学生轨迹的标准稳定性界使用教师场的 Lipschitz 常数和学生状态上的参考回归误差；它不保证 FID。数据聚合来自已有模仿学习思想，不能作为新算法定理。

新增两组配对轨迹：1000条教师引导、1000条上一轮浅层学生引导。两组使用完全相同的初始噪声、类别、取样步；各自状态上查询同一个固定教师 W_T。前800条各类8条训练，后200条各类2条验证，每条收集4个predictor状态；32个有效引导步在训练中每类每步恰好出现一次。两个策略都只运行至t=.5，按既有Heun64及IG强度.8、前.25乘6/7取值。

训练两头：teachercontinuation使用上一轮教师轨迹3200个训练状态与新增教师轨迹3200状态；studentaggregation使用相同旧3200状态与新增学生轨迹3200状态。每个batch在合并后的6400状态上均匀有放回抽样，因此旧／新各占1/2是在期望意义上成立，非每batch严格各16。两头使用相同批次索引流、EMA初值、优化器重置与3000个额外训练步，B32，AdamW1e-4、betas(.9,.999)、wd0、clip1、EMA.995；最终EMA，不以验证挑checkpoint。两个读出均301840参数、共享第四层，推理每图128次full和0次prefix。

共同验证集为新增学生轨迹的800个保留状态，报告初始／最终教师MSE与误差/强弱gap能量比。训练时不使用该集合，也不据此调参。这只评估上一轮学生访问的状态，不能称新学生自身分布已经收敛到固定点。只做一轮聚合。

新配对1K共六组：继续训练、学生状态聚合、原浅层蒸馏、原IG、既有自身数据参考、ADG。质量种子2026121224，类别种子+1，每类10图；数据种子2026121223，训练种子2026121225。预检零引导逐元素回strong、既有四种基准逐元素复现、共享hook恢复、速度通道正确、独立弱前缀部署未加载、强模型状态不变；核验源码/输入/权重指纹。所有质量batch覆盖及缓存FP64 FID/sFID复算完成后才判定。

工程质量晋级：两个新候选任一比全部四个旧对照FID至少低.5，可取其中FID最低者晋级；不得因此声称数据聚合机制成立。若晋级，以固定权重、独立种子2026121226的新5K同时评估全部六组，候选须比全部旧对照低至少1% FID才称确认。数据聚合的增量证据单独要求学生状态聚合比继续教师训练1K低至少.5，且如执行5K则低至少1%；仍然只有一个训练种子，不宣称统计显著。记录sFID、IS、失败率及实际GPU秒，不将相同NFE说成零时间开销。

若无候选晋级，不自动再聚合、增加步数或重启旧大队列。独立弱教师仅用于离线数据生成，既有旧STOP标记保持。
