# 在短程流终点合成guidance

前述三个额外往返写回版本都没有超过已有IG1K。本版改变引导的作用对象：从同状态的瞬时预测差，改为强弱分支各自演化一段后的latent差；不反向积分，不追加写回后再走一次同区间。

对原100步网格每4步组成的区间[t,s]，从同一个z分别按Full/Base Euler流生成zF、zB，直接推进到s：

    z_s = zF + .78*(zF−zB).

每个区间继续guidance1.78，并无全程撤除guidance或仅初始写入。遇到原生活动区间边界截断macro block；最后非活动步按Full直接生成。4步是本次固定方法设置，不扫block大小。单步情形显式采用原native速度合成，防止代数重排舍入；较长区间的非线性路径差是候选作用，不预先保证改善。

首步强弱来自同次Full模型输出。后续强轨迹用完整模型，弱轨迹用原生Base前缀。99个活动步分为24个4步区间加1个3步区间，另一个非活动步：每图100次完整forward、74次Base前缀。Base前缀与完整读取的既有实现parity直接复用；这一新版没有旧整图smoke可以复用，不伪造逐像素复现声明。实际每batch计数与数值有限性在线检查。

seed202609413、B4、FP32状态/BF16+TF32、shift8不变。四卡只协同生成这个方法1000张，每batch保存图像/全局标签/噪声与请求SHA，可恢复；合并后只评价新方法，复用原生IG基线FID38.264239。

直觉：给浅层与深层一个短区间，让它们各自形成的结构差参与引导，而非每一步都把两者重置到同一个输入。它从用户“未来状态原型”的思路出发，但取消逆向写回。不是PFR未来瞬时gap修正，也不宣称已完成新颖性检索或理论贡献。先用最终质量裁决；不做机制检测前置，不写论文。
