# RAEv2：原生IG与20K MLP的独立5K比较

用户在20K训练与400图复测结束后明确要求“做两者的5k采样比较”。此次授权直接启动两臂5K；此前未通过自动扩展门槛的记录保持原样，不据此阻止此次明确请求。

只比较两个已测设置：原生IG额外alpha=.78（官方scale1.78），以及20K Context MLP额外alpha=.39（scale1.39）。它们分别是此前各自两档中的最低FID设置。该选择来自旧400图，因此本轮换全新噪声，不复用旧质量样本。两者系数不同，本轮比较具体采样配置，不能仅将差异归因于更换读出结构或延长训练。不增加同系数消融、其他系数或训练。

每臂5000张、每类5张，全部1000类；新种子2026091421。两臂共享同一个初始noise bank和同一个标签顺序，单图单路径。仅准备实际使用的第一噪声，不生成备用第二路径。冻结此前20K最终EMA、原RAEv2 checkpoint及解码器，继续Euler100、shift8、IG活动时间[.1,1]，batch16（最后一批8，两臂一致），bf16 autocast沿用原运行时。每图100次完整主干调用、0额外prefix；MLP复用编码器第8层特征，每个活动步执行一次新读出，原生弱头仍随主干计算。

在新质量采样前，用原400噪声各重放4张原生alpha=.78与20K MLP alpha=.39，要求latent和像素逐位一致（此复现仍用原batch4）。正式5K两臂都用batch16；不声称不同批量的浮点轨迹逐位相同。核对实际30个Transformer block调用次数与MLP调用次数、图像/标签/噪声身份、样本覆盖及有限数值。

GPU1–3分片采样，本轮不用GPU0。采样完成后用空闲GPU2对两个完整5000图文件依次提取评价特征，均使用原nanogen-evals、imagenet_256_fid_stats和相同CUDA FP32评价配置（batch64）。此次评价在相同设备配置内比较；与旧400图CPU评价以及不同样本数的绝对FID不交叉比较。保存Inception特征、FID、IS和评价请求。用同一批特征的FP64对称协方差公式独立复算FID；这是算术核验，不是独立特征提取或独立生成重复。

另在同一GPU、batch16上对两臂完整采样及解码各预热1次，再交错测量3次，报告中位耗时。相同主干调用数不表述成完全零成本。全量输出保留，不选图；展示固定顺序前4张。两臂均须完成，不依据中途指标停止其中一臂，不扩展队列。5000图提供更充分的配对比较，但单一生成bank和单一训练种子不证明普适性或理论机制。
