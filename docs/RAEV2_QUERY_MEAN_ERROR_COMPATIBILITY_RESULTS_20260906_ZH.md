# Query 均值弱分支：配对误差方向为正，但风险修复成分很小

日期：2026-09-06。**全部 10 个固定 teacher 时刻的平均 `C_W=E[(X−F)·(F−W)]/D` 为正。** 这个新结构响应包含指向 Full 剩余 clean 预测误差的成分，但规模很小；它没有证明误差共线、采样纠偏或 FID 改善。本轮没有选择 guidance 系数、窗口、层号或启动 1K。

这一步来自 [SWG 的兼容误差问题](RAEV2_GUIDANCE_READING_SWG_20260906_ZH.md)与 [CPC 对信息对比的区分](RAEV2_GUIDANCE_READING_LINEAR_CPC_20260906_ZH.md)，接续[已完成的 160 条结构诊断](RAEV2_DECODER_QUERY_MEAN_RESULTS_20260906_ZH.md)。协议在新交叉量计算前[单独冻结](RAEV2_QUERY_MEAN_ERROR_COMPATIBILITY_PROTOCOL_20260906_ZH.md)；此前已经看过这些历史状态的方向大小，不把本轮说成未见数据验证。

## 恒等式与固定样本

令 `Δ=F−W`、`m=E[X|z,t,y]`，则

`C=E[(X−F)·Δ]/D=E[(m−F)·Δ]/D`，`Q=E||Δ||²/D`。

不可约 posterior noise 对 C 的总体期望贡献为零。对任意共同标量 a：

`R(F+aΔ)−R(F)=−2aC+a²Q`，`R(W)−R(F)=2C+Q`。

正 C 是“弱支同向放大强支条件均值误差”的必要方向证据，不证明完整误差共线。有限样本 C 的正负也不能直接当总体符号。这里的 R/C/Q 都按 `D=262144` 个坐标平均；实际坐标相关，不以名义维数扩大有效样本量。

保留此前所有 10 个 teacher snapshot、每时刻 8 个 ID，共 **80 条、8 个相关真实图像/类别**；同一图像在所有时刻复用同一原始噪声。不使用 rollout 与原 X 的人为配对作 posterior witness。clean bank 为 `heldout_clean_c_current_fp32/clean_rank00.npz`，按 id/label/source_row 三项唯一联结；实际 latent 存储为 FP16，本轮目标是这份量化 bank。

全部 teacher 状态与 `(1−t)X+tε` 的原 CPU FP32 算术逐位一致，最大差为 0。重新计算的 80 条 FP32 `F−W` / `F−B` 与上一轮保存向量全部逐位一致，单独 Full/Base/Weak norm 的差也均为 0。没有另加一次原生 reference forward；上一轮完整原生 parity 已通过，此轮保留的是差向量和 norm 复现边界。

## 数值、调用与成本

主统计先将 F/B/W 与 X 升格到 FP64，再计算差和风险。W、Base 两个风险恒等式的最大绝对残差分别为 `2.733e−16` / `1.458e−16`。作为上一轮 parity 对象的 FP32 差另行核对：W 差相对 FP64 差的舍入最大为 0，Base 为 `2.98023224e−8`；没有将这项数值差混入机制解释。

实际 10 个共享 encoder（280 个 encoder blocks）、20 个 Full decoder blocks、20 个弱 decoder blocks、20 次 Full readout（含弱支）和 10 次 Base readout 均与逐阶段 hook 记录一致。没有新的原生 reference、训练、图像 decoder、噪声、采样轨迹或 FID。

CPU prepare wall **11.08383 s**、CPU **12.62786 s**；单 GPU run 从 imports 后至 summary 前 wall **19.09595 s**、CPU **21.67050 s**。run 中输入哈希为 10.49289 s、模型加载为 5.24353 s；共享 encoder 0.72237 s、原 Full 准备/decoder/读出与 Base 合计 0.10210 s、额外弱 decoder/读出 0.09038 s、风险统计 0.82195 s。传输、bridge 检验、parity、I/O 和最终哈希均在完整成本记录中。

这些是机制研究成本；小规模同步计时、加载、hook 和首批初始化不能当部署吞吐，亦没有据此作同成本 FID 结论。prepare/self-test、上一轮实验、论文阅读及独立复核的成本分别保留，不把没有统一计时的研究总投入补成一个数。
