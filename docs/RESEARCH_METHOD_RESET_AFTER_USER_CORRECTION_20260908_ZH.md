# 用户纠正后的方法重审：不启动新变体

用户明确否决把尚未在RAEv2站住的方法转去蒸馏。蒸馏脚本只准备未执行，不可自动续跑。本轮重读用户附件、AG §§3–4和FSG §3，并查看固定前8样本，不生成新图，不训练。

## 需要撤回的推理跳跃

AG要求退化相容。强弱两个预测不同、时间响应相关、拟合风险降低，都不足以确定差值包含需要纠正的错误。AG原文还区分随机训练差异和足够大的系统性退化，不能把任意构造的弱参考当作质量条件。来源 https://arxiv.org/html/2406.02507v3 。

FSG针对给定条件下的生成路径相容，并保留迭代/引导。把该设计迁移到强弱容量差，需要解释为什么弱分支可以表达要保留的内容；不能仅要求它复制Full的全部输出。原文 https://arxiv.org/html/2510.21512v1 。

已有Full/Base终点统计不是同时间score几何，不能直接据此选取“坏方向”。全局载体约0.31%的同bank结果也没有证明结构信息被搬运。换载体位置、时间差分或参考头的代码可实现性不是研究依据。

## 固定样本的实际变化

图 experiments/results/terminal_defect_20260908/research_reset/fixed_first8.png，列为native、teacher PFR、global anchor、temporal curvature，行是全局索引0..7，非择优样本。原始像素文件与hash见manifest。

在这些例子中，teacher PFR与global anchor大体保留主体与构图，局部外观有变化。temporal curvature常大幅改变视野和主体尺度：索引0由持鱼人物场景变为鱼的近景；索引1变为鱼身局部；索引5变为纹理特写；索引6不再保留潜水者场景；索引7变为鸡头特写。不能从8张图推出全部1K比例，更不能证明裁剪变化是FID恶化的唯一原因。但这使“修正细节而不动内容”的预设失去依据，与其IS上升/FID恶化的数值现象同时保留。

下一项方法必须说明自己要修复的具体错误、保留的实例内容，以及操作如何区分两者。仅“限制变化/保构图”同样不够，因为它可能只是阻止任何有效干预。此次阅读还发现attention布局干预、跨层复用和内部外推已有广泛相邻工作，不能把换到attention空间就称作创新。

当前没有成熟到足以启动的新方法。这是停止盲目小变体的执行纠正，不是研究成功或归档结题。暂不启动蒸馏、差分扫描或注意力搬运试验；继续围绕RAEv2质量突破思考。新方法成立后仍按用户要求只采新方法、四卡协同、复用已有基线，不写论文。
