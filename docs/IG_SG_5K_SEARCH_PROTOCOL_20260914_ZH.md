# IG + SG：所有外推系数直接5K，再独立5K比较

用户要求RAEv2后训练头完成后，将SiT、JiT、RAEv2上原版SG与log-scoreSG全部扩展到5K，并明确“1k明显不合适，直接用5k”。本轮粗扫和局部细化中的每个系数都直接生成5K，1K结果只保留作历史诊断，不参与候选淘汰。

沿用此前三个冻结IG设置；RAEv2为原生第8层IG、w=1.78。新训练的RAEv2头另有独立实验。统一SG外推定义：v_out=v_IG+(w_SG-1)*(v_strong-v_reference)。代码omega=w_SG-1；旧omega=1对应w_SG=2。IG系数、时间窗口、模型与求解器保持原设置。原版SG时间偏移.01朝更噪方向；log-score使用同时间对称扰动，kappa=.2。只扫描外推强度。

粗网格omega=[.25,.5,1,2]，即w_SG=[1.25,1.5,2,3]。每模型IG-only加两种SG各4点，共9组，每组5K。根据本轮5K FID，各SG在最佳正外推点的两侧加相邻中点，各5K；下边界扩至omega=.125，上边界扩至3。合并粗扫与细化选择该方法的最佳正外推系数，FID相同取较小系数。IG-only单独保留；若正外推最优仍差于IG，报告无增量收益。

调参统一使用seed2026091441完整5K bank。SiT的100类各50张，JiT／RAEv2的1000类各5张，同模型全部配置共享噪声与类别。此bank在本轮首次生成输出；不复用旧1K生成样本。原已准备的1K输入保留作历史文件，不作为当前采样输入。

锁定系数后，使用全新seed2026091452的独立5K。每模型5组：标准步数IG、最佳原版SG、最佳log-scoreSG、原版SG成本对照、log-score成本对照。全部15组、75K全新最终样本均完成。粗扫27组135K、细化12组60K、最终15组75K，合计计划270K新图；数值失败候选整组记为无效。

SiT Heun64的实际NFE为128/255/382，对照Heun128=256、Heun191=382；JiT和RAEv2 Euler100为100/199/300，对照Euler199、Euler300。SiT原版SG对照多一次前向，其余完全一致。所有正外推系数保持相同NFE。原版SG使用发布版velocity外推；log-score平滑不等同于密度高斯卷积后的精确score。

SiT沿用ADM ImageNet100参考；JiT／RAEv2沿用Nanogen ImageNet256参考。调参5K与最终5K严格区分，最终bank不参与选参。每批保存全部像素、终点、输入身份、NFE与实际耗时，验证覆盖、配对与实际block计数。保存特征并用FP64复核FID，不将同一特征的算术重算称为独立评价器。展示固定ID，不筛图。

本方案在任何SG生成请求冻结前修订。最初的1K粗筛方案及随后提出的前三名5K复核均未在此新目录启动生成；现直接执行每个系数5K。数值检查失败的调参系数保留异常身份，整组无效，不报部分FID；最终5K失败则停止调查，不据最终bank改选参数。有限网格最优不声称全局连续最优，单一最终bank不能自动保证细小差异具有统计显著性。
