# OU方向是否主要是仿射协方差响应：探索性检验

动机：SiT-v/x都有OU额外FID收益，但RAE没有。检验“RAE证书主要反映高斯
协方差而非非线性形状”这一可能解释；不训练、不提出新的采样修正。
先检查已有posterior-mean closure反例，该路线不重启。

令x,y独立标准高斯，u=(x+y)/sqrt(2)，v=(x-y)/sqrt(2)，c=sqrt(2)-1。
对OU strong degree1证书场D定义

    R=D(u)+cD(v)-D(x)-cD(y).

四个点各自都是标准高斯，任意仿射D(z)=Az+b都满足R=0；随机FP64仿射矩阵
检验最大误差8.88e-16。高斯分布的精确score/velocity及其该证书均为仿射，
故本检验可排除纯仿射解释，但非零也可能来自模型误差，不能自动解读成真实
数据的高阶形状。报告 E||R||² / E||D(x)-D(y)||²，这是特定差分响应比，
不是正交分解下的“非线性能量占比”。

固定24组四点（labels0..23），u_data=.05/.1/.2，h=1/32，seed202609422。
各时刻把同一标准化坐标映射到相应raw latent，再分别计算当前/未来Full。
SiT-v800 FP32；RAE官方100080 EMA先BF16，再同输入FP32复核。
模型latent维度不同、类别ID不对应相同语义；这些是高斯坐标probe，不是
原生生成轨迹或配对真实图像，不能宣称严格跨模型因果对照。

| data time | SiT-v FP32 | RAE BF16 | RAE FP32 |
|---|---:|---:|---:|
| .05 | .104713 | .804590 | .799753 |
| .10 | .083922 | .886218 | .881453 |
| .20 | .096872 | .842086 | .826591 |

结果与动机中的简单解释相反：本探针下RAE显示更强的非仿射响应。FP32后
模式保留，不能归因于BF16差分噪声。FP32仍开启TF32矩阵乘，不称FP64 oracle。
模型计算时间SiT .961秒、RAE BF16 4.911秒、FP32 6.835秒（加载不计）。

裁决：没有证据把RAE失效简单归因于“OU只捕获仿射协方差”；不据此新增
协方差消去采样器，也不把较强非线性本身称为失败原因。该probe反驳一种
机制候选，没有获得FID改善或新方法。论文保持暂停。
