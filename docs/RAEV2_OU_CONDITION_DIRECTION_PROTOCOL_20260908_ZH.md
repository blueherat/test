# RAEv2 OU条件分解：固定生成质量检验

上一轮几何probe不能给出质量符号。本轮不以余弦筛选，固定三个方向进入配对
1K：D_c、D_u、D_c-D_u。后者为同一Full的时间×条件差分；理想自洽密度下
有条件后验分数的跨尺度解释，真实网络不保证满足该身份，更不保证质量。

保留native IG1.78、Euler100官方shift8、BF16/TF32、seed202609413连续B4，
labels0..999各一张。沿已完成canonical PFR定义rho=1,h=min(1/32,t-.5)，
t>.5时间修订，查询不做空间前移。仅在t>.75用所选方向投影raw修订并恢复
raw范数，其余第一半程保持raw时间修订。不是历史rho=.05结果的完整复现。
没有按生成结果选rho/窗口；三组本身将提供相同协议下的完整条件OU基准。

三组都在早段执行相同的条件未来OU、空标签当前和空标签未来OU三次额外
Full查询，丢弃不使用的输出，以匹配实际调用。保留原Full/Base普通场。
每样本100+3*N(t>.75) Full及N(t>.5) prefix；实际N由官方grid记录。
预计三组采样合计约2.2 GPU小时，加载与评估另计。无训练。

各组先ordinary8重现既有native像素，再方法8检查prefix/full一致、有限输出
及调用数，通过后才1000张。记录源码、模型、noise/labels/pixel hash；官方FID
之后独立特征Gram复核。比较三组与已有native100，不能只比较新方向与差基准
就称成功。探索1K不替代独立5K；不按该bank做强度或时间搜索。论文保持暂停。
