# RAEv2 初始校准：半径与方向交叉干预

冻结于事件拆分、32样本噪声壳层测量之后。当前1K FID：无校准38.264239，
仅初始48.659778，完整48.972310，仅后期38.144204。RAE初始两次校准后平方
范数移动1.815个原高斯标准差；此处检验径向改变是否造成该退化。

令z0为原始噪声，z1为原初始两次async校准后的状态，r0=||z0||、r1=||z1||。
两组固定1K：
- radial：使用(r1/r0)z0，只保留新半径、原方向；
- angular：使用(r0/r1)z1，只保留新方向、原半径。
只在第一个事件的两次迭代全部结束后干预，不逐次归一化。后两个事件执行全部
原计算但丢弃结果，和已完成early_only严格同预算：每样本110次完整前向。
后续使用原生100步IG；seed202609413/B4/模型/decoder/shift8/BF16/IG1.78均不变。

8张none必须逐像素等于原ordinary100；8张full必须逐像素等于已完成early_only。
然后目标分支8张检查有限性、计数、输入hash，以及angular范数保持、radial方向保持，
再运行1K并使用原官方评价器。FP64累计范数、FP32缩放，记录约束最大误差。
不按图像或FID调参，预计两个1K采样合计0.49 GPU小时，加载/评价另计。

若radial单独重现退化且angular接近原生，支持径向因素；若angular仍差且radial
接近原生，反对径向主因；其余情况检查交互。FID不作线性贡献百分比分解。
任意正面1K都不是独立验证或新方法。固定半径的噪声优化已有DSG/Oracle Noise等
先例；保留半径也不保证均匀角分布，不能声称完整高斯先验保持。

## 解释上的守恒边界

令固定条件c的后续生成器为F_c，原噪声分布mu=N(0,I)。若初始变换T_c满足
(T_c)#mu=mu，则(F_c composed with T_c)#mu=(F_c)#mu。对固定随机采样核也
同理。因此只修改初始噪声且严格保留每个条件的完整先验，不可能改变真实的
条件输出分布；有限bank重排或偶然指标变化不能当作总体质量收益。
该结论是推前测度的基本恒等式，不是新理论。它不否定有意改变角分布的噪声优化，
也不意味着保留半径的本次angular组保持了完整高斯。

## 完成结果：径向主因假说被否定

| arm | 1K FID | IS |
|---|---:|---:|
| none 原生 | 38.264239 | 59.077 |
| full 仅初始完整校准 | 48.659778 | 71.155 |
| radial 仅新半径 | 38.260656 | 59.167 |
| angular 仅新方向 | 48.703479 | 71.240 |

两组新增采样分别882.142秒和873.324秒，累计1755.466秒（.4876 GPU小时），
不含加载/smoke/FID。全1K的radial方向约束最大误差2.54812e-8，angular半径
约束最大相对误差2.98684e-8。独立审计已完成，全部配对输入、已复制源码、模型、
评价器、像素hash、事件和调用数通过。独立feature-Gram FID最大重算差约2.5e-5。
CSV：`experiments/results/terminal_defect_20260908/raev2_initial_radius_direction.csv`。

本协议内，半径偏移不能解释主要退化：单独半径变化几乎保留原生FID，恢复原始
半径也没有去除退化及IS上升。停止将噪声壳层偏移作为这次失败的主要机制，
不开展归一化修复的5K或参数搜索。这个结果不是所有噪声约束方法无效的结论。
角方向改变量保留了失败，但尚未识别其中是条件均值、各向异性响应、语义变化
还是其他成分；不得直接称作过度语义对齐或模式坍缩。此结论也不能替代原PFR
自己的跨模型因果证据。下一步应回到具体场方向与原PFR的关系，避免继续扩展
只解释时钟校准失败、却未推进核心方法的控制树。
