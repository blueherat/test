# FSG / CFG-Ctrl 图像机制检查：预先固定协议

使用现有 ImageNet-100 SiT-S/2 800K checkpoint、原 VAE、256px 解码和 Heun64。
时间由噪声0到图像1；普通 CFG 写作 vc+a(vc-vu)，故论文常见权重 w=1+a。
除明确的后缀切换外，附加 guidance 在 t≥0.75 归零，此后仍使用条件模型。
NULL 为训练时的空类别100；类别读出映射回完整 ImageNet-1K 标签。

## 要分辨的命题

1. 一次 FSG 更新更接近修改前的条件未来，是否有别于仅让修改后的两条未来一致。
2. FSG 前向反演是否表现为隐式逆流响应，是否提供同长度局部 CFG 无法复现的方向变化。
3. 更小的局部 gap 或未来一致性误差，是否能预测撤除全部条件后的目标保持。
4. 公共 CFG-Ctrl 的历史是否提供瞬时非线性抑制之外的收益。

## 参数和样本

固定两档 CFG：a=1.25 为现有1K网格最佳原生CFG；a=2.75为较强干预。
主 CTRL 使用现有1K最佳的 a=2.75、K=0.2、λ=5，同时保留 K=0.1 旧结果与新瞬时对照。
参数选择来自既有数据，须视为机制探索，不声称独立验证。
FSG 使用已固定的 SiT 算子适配：每4步一次、H=0.125、前向Euler引导和NULL反向Euler；
位移裁剪半径为 (4/64)a||g||。这是有限区间前向反演适配，不是完整复现原文全部CFG++采样流程。
同时检查同场往返、扣除同场误差、把FSG实际位移长度仅沿g施加、等260次full调用的Heun加密。

机制集为全新连续CUDA B8噪声，seed=202612111；100类各2张，共200张，标签seed=202612112。
9条轨迹在 t=1/8,1/4,3/8,1/2,5/8,3/4 各做纯NULL和纯条件后缀；同时保存原引导终点。
每张后缀图片均保存；ResNet18与ConvNeXt-Tiny都只后验读取同一份uint8像素，均不参与优化。
类别top1、目标概率仅衡量类别对齐，FID衡量固定样本分布；不计算单图FID。

## 同状态干预

固定机制集前64个样本，两档CFG的 t=1/8,3/8,5/8 状态。
冻结 C(x) 和引导终点为两个不同质量的目标，分别记录
Ewrite=RMS[U(x+δ)-C(x)]、Eagree=RMS[U(x+δ)-C(x+δ)]、局部gap和双方类别读出。
候选包括不动、同半径g、FSG、同场往返，以及局部gap/未来一致性/冻结原始条件未来/冻结引导未来四个目标。
后四个目标共用由g、FSG位移、两条种子固定随机方向构成的4维正交子空间，中心差分ε=0.001max(||x||,64)。
每个目标各有同半径负梯度方向与有半径限制的Gauss–Newton更新；后者以16步未来在0、半步、全步中选择。
正式轨迹保持既有TF32设置以精确复用基线；有限差分、同状态干预的整个比较与拟合内部未来统一关闭矩阵TF32，避免量化误差主导微小扰动。
这些诊断使用同一模型权重、同一捕获状态和同一时间网格的FP32流；与原TF32轨迹读数分开记录。
所有结果使用主采样器剩余64网格重新验证；接受时的粗目标下降不等同于细目标下降。
前32样本额外检查完整NULL反演的未裁剪与裁剪oracle；该昂贵oracle不视为实用方法。

## Jacobian 检查

前32样本、相同两档CFG和三个时刻；H=2/64,4/64,8/64,16/64。
参考变换为8小步Heun的带guidance前向，再用8小步NULL反演；以16小步作数值分辨率检查。
比较实际Euler FSG、扣除同场往返误差、同长度g和精细流反演。
同时报告实际半径裁剪后的FSG与同长度CFG，以及TF32原生Euler位移对FP32诊断位移的偏差。
直接测定沿每条位移方向的 J_U δ（中心差分ε和2ε），以及非线性 U(x+δ)-U(x)。
目标变化是局部区间 Cw_H(x)-U_H(x)，不偷换为完整条件终点差。
报告目标相对误差、线性化余项、差分分辨率、方向夹角与 H→0 的 (1+a)Hg 极限。
短区间极限另用 H=1/1024 和1/256检查，不以质量结果选择区间。
不宣称算法显式估计了完整4096×4096 Jacobian；逆流的有限操作与局部线性化分开评价。

## 配对1K评估与复核

新增12条完整轨迹对照和20条后缀配置，每条1000张；4条已提交基线复用前须通过B8逐位latent回放和实际调用数检查。
1K输入逐字节复制既有100类各10张的bank，因而所有比较配对；全部配置和源文件在新FID之前冻结。
后缀为5种前缀方法在 t=1/4,1/2,3/4 转NULL，以及在 t=1/2 转纯条件。
四种拟合目标各做一次t=3/8更新，继续同一CFG；记录其额外完整未来计算。
FID使用同一ADM Inception图和5000张ImageNet-100验证集统计；记录sFID/IS、完整及prefix调用、实际采样解码秒数。
完整保留所有结果，机制主张依据配对对照；本轮不根据新FID挑参数，不自动扩为5K。
验证包括真NULL、标签恢复、原CFG/FSG/CTRL逐位回放、NULL后缀离散半群、零修正、同范数对照与有限差分分辨率。
报告将明确短区间精确恒等式、实际算子近似和图像质量证据三者各自的适用范围。
