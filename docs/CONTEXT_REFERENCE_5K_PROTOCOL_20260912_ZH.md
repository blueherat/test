# 上下文参考的独立5K与成本对照

冻结时点：六臂独立1K全部结束，Context FID 61.9471、原IG 64.8090、ADG 63.8138；尚未生成本协议5K样本。该读出最初是Local筛选的对照；这是一条已披露选择过程的确认实验，不把MLP读出本身声称为新方法。

只用SiT-S/2固定强模型、原depth4弱读出和旧3000步最终Context EMA。后者只在真实训练数据上监督velocity，增加304,528个参数；不更新模型、EMA、强度、窗口、损失或训练过程。

新噪声种子2026121331，每臂5000图，每类50图；同一first噪声与标签逐样本配对。second文件为继承的数据接口保留，采样不使用。不以这些样本做训练或选择超参数。

四臂：Context、原IG、ADG均64步Heun/128次完整主干；另加原IG 66步Heun/132次完整主干。原IG增加3.125%主干查询，旨在覆盖前次Context约2.33%实测额外开销，实际墙钟是否覆盖须重新计时确认。66步仍使用相同物理时间上的固定窗口和分段强度，因此离散窗口落点略有变化，结果作为更高计算预算的强对照，不把差异唯一归因于截断误差。所有臂每个RHS一次共享主干、零次额外prefix，无独立弱网络前向。

固定保留标准：Context FID比三个对照均低至少1，IS至少原IG的90%。这是继续研究的效应大小门槛，非显著性检验。若任一条件失败，不搜索新强度、步数或checkpoint。即使通过，也只确认该具体参考读出的收益；跨模型、新颖性与加性误差的因果解释仍须独立证据。

时间测量在空闲同一GPU、相同batch8上轮换四臂，先预热，再三次完整采样与解码，记录逐次秒数、中位数和实际主干调用。不用不同GPU的质量采样速度宣称零开销。预算对照若实测仍便宜于Context，则如实报告成本未完全覆盖，不事后调整候选或假装等墙钟。

使用原ADM FID/IS评估与固定真实参考，保存全部图像、标签、初始噪声校验、源码/权重/协议hash。由缓存的Inception特征FP64复算FID，明确不是独立特征提取器验证；核验每臂5000图完整、相同输入与无额外路径。四臂全部报告，固定前四张不筛选。
