# JiT读出的独立5K与接近同预算CFG参考

冻结依据：此前JiT-B/16固定1K中，MLP FID53.6491、旧IG56.1130、ADG56.1578、等训练原结构58.1444。MLP通过预设迁移门槛；官方Heun50 CFG参考38.5081，但需198次完整前向。需要验证IG收益是否在独立样本上保持，并检验其与接近同计算预算的CFG之间的实际差距。小MLP和冻结读出本身仍不构成新原则。

本轮不重新训练。保留3000步最终EMA、真实图像训练、depth4、所有模型权重及像素量化。四臂各5000张全新噪声，每类5张；numpy seed2026121391，batch4，全组初始噪声和标签配对。原1K不合并入本轮FID。

三个IG相关臂直接调用冻结1K的采样函数。CFG只改变官方采样步数为25：前24步各两个RHS，最后一步一个RHS，每个RHS条件/无条件各一次，共98次完整前向。两种求解器不相同；这是一项接近同主干查询预算的实用基准，不用于归因某个求解器改动。逐步时间网格及CFG区间离散落点也随步数改变。实际单卡耗时另测，不以98与100的次数接近宣称延迟严格相等。

固定确认门槛：MLP FID比原IG和ADG均低至少1，IS至少原IG的90%，才视为独立5K保持了IG收益。单独报告相对CFG25的FID、IS与实际耗时；即使IG确认通过，若CFG25更好，也不能把读出收益写成已优于CFG的同预算核心方法。等训练原结构已在原1K完成，此次不重复它、不将旧1K结果称为5K控制。

预检要求三个保留IG相关臂调用原函数，原强/弱与旧IG完整轨迹仍一致；新CFG25必须与官方Denoiser的完整25步轨迹逐项相同。保存每批完整调用、12个block调用、读出调用，确保每步只执行同一主干一次或CFG规定的两次。比较程序可同时加载小头以切换臂，但每次前向只计算选中读出。训练与正式采样不新增独立弱前缀。

全部图像、像素前状态、噪声、标签、源码、模型、读出、评价统计和特征提取权重保存SHA。沿用nanogen imagenet_256_fid_stats，在同一缓存特征上用FP64对称协方差形式复算FID，明确不属于独立特征提取器验证。全部4臂20000图都报告，固定首四张展示；原始请求与旧协议保持不变。失败不追加训练、层数、强度、窗口或步数网格。
