# 为什么只判别最终外推图片就足够定义训练目标

这是当前二分类实现的解释，不是实验有效性的证明。2026-09-15。

冻结强场 \(S\)，弱头为 \(W_\phi\)。真正接受评价的生成器是整个采样映射

\[
X_\phi=\operatorname{Dec}\left(T_{S+a(t)(S-W_\phi)}(\epsilon,c)\right),
\qquad R_\phi=\mathcal L(X_\phi\mid c).
\]

因此可以直接定义 \(R_\phi\) 与真实图片分布 \(P\) 的二分类对抗问题。无需先确定弱模型单独采样的分布 \(Q_\phi\)，也不需要知道强、弱密度及其误差是否共线。实际只改变既有浅头，强模型、采样器和推理调用数量不变。

这里“合适的弱分布”本来就应当相对于冻结强模型、时间窗口和采样器定义，而不是一个预先唯一确定的平滑分布。在a(t)>0的区间，如果不限制弱场容量，任意期望采样场U都可写成W=((1+a)S-U)/a。当前实现的实质约束来自固定浅层表征、既有小头的函数族以及后半程冻结的采样映射。端点对抗目标只要求实际生成分布合适，不会唯一识别某个弱分布。50K初始化提供一个具体起点，不能将小步更新本身当作唯一性或泛化保证。

## 判别器在辨认什么

等量、同类别先验的真假样本下，不受限二分类器的理想解为

\[
D^*(x,c)=\frac{p(x\mid c)}{p(x\mid c)+r_\phi(x\mid c)}.
\]

这个比值只涉及真实分布与**实际外推端点分布**，不涉及独立强模型或弱模型端点。标准minimax生成目标代入此解后是条件JS散度加常数；实际代码采用非饱和的 \(-\log D(X_\phi,c)\)，更新弱头时固定当前D，不对“最优D随phi的变化”求导。因此不能把代码的每一步直接称为精确JS梯度下降。[GAN原论文](https://arxiv.org/abs/1406.2661)

当前D前面有固定Inception表征 \(F\)。上述理想密度比及匹配结论严格作用于 \((F(X),c)\) 的分布。仅匹配这个有限表征不足以证明完整图片分布相等；判别器的有限容量、R1和有限训练也使它不等于理想密度比。使用固定预训练表征作为判别输入已有先例，但这里不是复现其完整多尺度结构。[Projected GAN](https://arxiv.org/abs/2111.01007)

## 后半程关闭guidance反而明确了问题

暂在latent空间讨论，假设冻结强场的连续后半程 \(B=T^S_{\tau\to1}\) 可逆。将前半程受弱头影响的实际采样映射记作 \(A_\phi\)。那么端点为

\[
R^z_\phi=B_\#(A_\phi)_\#\mathcal N(0,I).
\]

若希望端点latent分布等于 \(P^z\)，理想中间目标是

\[
\boxed{\mu^*_\tau=(B^{-1})_\#P^z,}
\]

即把真实端点通过**实际冻结后半程的逆映射**拉回去。这个分布一般不等于对真实图片直接加噪的 \(P^z_\tau\)：模型后半程有误差时，进入它的分布必须补偿该误差。最终图片的对抗反馈可以隐式寻找合适的 \(A_\phi\)，不用显式计算 \(B^{-1}\)，也不用把任何前向加噪分布当作唯一正确中间目标。

这是对时间窗口设置的解释，不是新加的loss或算法。实际64步Heun不假设全局可逆；VAE解码也非一一映射，图片D只约束解码后的分布。因此上述拉回公式是连续、latent可逆理想化下的解释，不能直接当作离散图片空间的唯一性定理。

这也给出了与原去噪训练的一个具体区别：旧弱头在真实样本的前向插值状态上回归x/v或组合场，而部署时读取的是强弱共同产生的采样轨迹状态。两者的状态分布可以不同；即使回归损失很小，也不能据此保证组合采样器的最终分布正确。当前训练每次沿实际组合轨迹求梯度，并只由最终图像反馈定义目标。这是选择端点目标的理由，尚未证明它就是当前实验中主要的误差来源。

## 为什么反传必须经过后半程

令D给最终图片的梯度为 \(g_X\)。弱头的梯度含有

\[
\nabla_\phi L
=\mathbb E\big[(\partial_\phi A_\phi)^\top
  (\partial_z B)^\top(\partial_z\operatorname{Dec})^\top g_X\big].
\]

虽然后半程不再调用弱头，\(\partial_z B\) 仍决定早期修改如何影响最终图片。冻结强模型只是不更新其参数，并不意味着截断对其输入的梯度。代码用逐步重算完成完整离散采样器的一阶反传，已经核对其前向与原采样器一致。

## 应如何解释结果

若实际5K改善，首先支持的是“现有浅头还有通过最终图片反馈改善外推结果的空间”。它不自动证明弱模型是强模型的高斯平滑版、不证明误差共线，也不证明单独弱采样质量变差或变好。弱分布的含义可以随后再研究；当前优先完成真实模型训练、连通系数扫描和两组5K验证。

还有一个需要保留的区别：弱头参与ODE后会隐式诱导一个采样分布，但仅用最终对抗损失，不保证它在每个时间点仍是同一个干净分布前向加噪后的精确score/flow回归解。因此本实现的严格依据是可微采样映射及端点分布的对抗学习；不能直接沿用“每个t都精确增强强弱log密度比”的结论。原来的分布或误差假设可以作为后续可证伪解释，但不是此次训练的必需前提。
