# 小SiT：浅层可预测分歧的固定质量检验

2026-09-09。用户要求继续思考其他办法，并对具体候选直接运行FID。本轮是一个新的、小成本、可证伪的弱参考构造，不是论文成果或固定点理论。

## 问题和候选

原生速度为S、W，D=S−W。普通IG使用S+αD。浅层输出头之前的条件特征记作H；同一次完整主干计算即可取得。用固定仿射函数族预测D：C(H)≈D，然后取R=D−C(H)。它等价于以W+C(H)作为新的弱参考，强头始终不变。

这检验“原生gap中，浅层廉价读出已能预测的部分是否值得继续放大”。C只接受H，不接受S、D或深层特征。训练目标仍是原模型的D，因此本质上包含对强预测的弱读出拟合。它不引入外部信息；不能把有限读出的残差称为Shannon信息增量、真实条件期望创新或纯深度因果效应。移除的成分也不预先认定为有害。

对已有训练cache的131072个token，逐坐标标准化H，附加截距，求FP64岭回归；目标是velocity gap。目标函数是平均每token的平方误差，加`λ||B||²`，λ=0.001，截距不正则化。标准差下限1e-6。没有学习率、训练步数、模型宽度或λ扫描。全局一组系数，不按时间/类别单独选择。cache来自8192幅训练图，每图16patch；另1024幅不重叠图的16384个token只用于报告误差。完全复用既有真实图加噪cache及其哈希，不新增质量数据参与拟合，不使用Inception或FID优化系数。

## 三个新配置

1. `residual_raw`：S+αR。
2. `residual_norm`：S+αR̂，其中R̂=||D||R/||R||；范数为每幅完整latent的L2范数。
3. `parallel_norm`：S+α[〈R̂,D〉/||D||²]D。

R或D范数数值小于1e-12时回退D，计入诊断；不按正负截断投影系数。第三组逐状态保留第二组在原生D方向上的分量，删除其正交改变。它不是第二组整条轨迹上的因果分解，因为两者随后进入不同状态；但在同一个状态上恒等式严格成立。若只有raw改善，不能排除引导减弱；若norm不优于parallel，未建立新方向的增量价值。所有新组若不能优于原生IG则停止该构造，不围绕结果继续调λ或归一化。

固定普通IG已有完整1K配对基线。三组各1000图，沿用ImageNet-100 SiT-S/2 v800、原depth4 velocity head、同一噪声与类别、B8、FP32/TF32、MSE VAE、Dopri5(rtol=.001,atol=1e-6)。时间从噪声0到数据1，网格(0,.125,.25,.375,.5,1)，α=(.6,.6,.7,.7,0)。线性读出仅在α非零时使用。原始噪声bank已被多轮探索复用，不是独立确认。

## 实现和质量检查

准备前冻结此协议、实现、全部依赖、原模型、训练cache及其来源。拟合后再次冻结线性系数及采样请求。所有batch保存noise/label/request身份、完整latent、像素、调用次数、时间和有限性。先运行真实模型预检：原生pair/单支、捕获特征线性读出、禁用新读出时的原生IG首批latent、零α、norm/parallel几何恒等式、GPU回归与独立NumPy矩阵乘法比较。正式1K仅在全部rank预检通过后启动。

每组记录所有活动RHS的残差长度比、C长度比、R与D夹角、规范化残差的正交能量比例以及回退计数；包含求解器拒绝的试探查询。Full/prefix次数、拟合成本和采样/解码成本分别报告。旧基线耗时不是同一时刻重跑的吞吐比较；固定同状态预热计时作为补充。

使用冻结ADM图提取FID/sFID/IS；另以相同缓存特征上的独立FP64公式核算FID/sFID。检查完整125个batch的覆盖和哈希，固定展示最前8张，不挑图。数值失败保留并报告；实现错误停止队列。只有明确质量信号才考虑后续独立样本，不因回归风险下降就宣称成功。

## 与已有工作的关系

内置弱头及输出外推已有IG/AG；训练弱读出也不构成新颖性。近期[Residualized Temporal Sparse Autoencoders](https://arxiv.org/abs/2605.27813)摘要已覆盖移除可线性预测的时间特征，用于解释和定性干预；本轮不能把“残差化”本身称为新方法。[SSG](https://arxiv.org/html/2607.29122v1)已有冻结主干并训练内部弱读出，目标和数据构造不同，但明确限制新颖性叙述。本轮的实际价值取决于上述固定FID和方向对照。

旧[深度×查询DiD实验](DEPTH_INFORMATION_DIFFERENCE_IN_DIFFERENCES_IG_ZH.md)已经说明：满足代数不变性、消除某种公共项，不自动改善质量。本轮不重新使用它的跨时间查询；此处使用同状态的受限读出回归，并将失败可能性保留为正式判据。
