# CFG 不变量实验执行

状态更新：首轮已全部完成，见 [结果汇总](CFG_INVARIANTS_RESULTS_20260913_ZH.md)。实际完成 13+3 个真实图像配置、6400 张正式图像，以及下列全部已知分布／诊断／算子检查。

用户已授权尝试上一轮全部 idea。本轮将生成方法、概率诊断与算子检查分别落实，避免把任何一致性读数自动解释为质量提升。沿用现有 SiT-S ImageNet100 模型和数据；旧实验队列保持原状态。

| 思想 | 本轮实际实验 | 主要读数 |
|---|---|---|
| 共同预测分量保持 | 原 CFG、作者 CTRL、将 CTRL proposal 投影回 gap、幅度对照 | 共同分量改变、配对图像、小样本生成指标 |
| 等证据层内分布保持 | 两种已知联合分布的精确 Gaussian FM、多种反馈与同样本数真实目标基准 | 层内分布偏移、目标分布误差、证据收益 |
| 同一终点目标跨噪声相容 | 标准 CFG 与真正终点倾斜后的精确 noisy 场 | 终点目标误差、数值步长误差 |
| 反馈势相容 | norm、时间、证据反馈，以及作用量配平对照 | 旋度、额外指导量、分布收益；真实图像后验估计标明代理 |
| Bayes 一阶／二阶相容性 | 真实 validation 图像与配对标签加噪，5 个噪声层、独立随机探针和打乱标签对照 | 相对于真实联合数据的弱残差、预测误差、按图置信区间 |
| 参数化与历史一致 | 真实模型 gap 序列中转换 epsilon／clean 单位；正确运输历史与直接复用数值比较 | 还原后的控制输出误差 |
| 同一流的剩余终点保持 | SiT 实际轨迹在 5 个时间点分别重新完成剩余采样，同网格／细网格／改变未来指导三对照 | 重算终点、普通 clean 预测和数值误差；每个时间点保存图片 |
| 固定集合投影幂等 | 同一真实 gap 上固定允许集合，独立应用投影 5 次 | 每次相对前一次和第一次的变化 |
| 硬条件幂等／软似然重复计数 | 已知分布的硬条件与软重加权 | 分布差异，不将整个 CFG 强制幂等 |
| 指定密度保持 | Gaussian 旋转与径向控制的解析／采样对照 | 参考密度变化与总质量的区别 |

首轮为可运行性和机制筛查，暂不将全部方向展开为 20 组参数搜索。真实图像生成采用配对初始噪声和标签；最终报告将以实际完成的样本量、步数、参数、运行成本和不确定性为准。以上 5 个时间点是采样轨迹检查，不是加入新噪声后要求图片不变的回灌。
