# RAEv2 guidance：全图方向之外的空间相关残差

2026-09-07。时间求积机制的完整5K已结束，结果近零或阴性，归档提交 `10a5f43`。本轮只检验一个新假设：现有全图 Full/Base 分歧方向的随机校准，是否遗漏了可用于生成的位置间相关性。旧方向方差实验的5K为6.91057，对原6.94977仅改善0.564%，本轮不将其称为已验证的显著收益。

## 从有限步反向分布到待检验的机制

对线性桥 z_t=(1-t)X+tε，已知同一桥中的 X 和 z_t 时，下一个状态满足 z_s=(s/t)z_t+qX，q=(t-s)/t。若固定使用原生 guided clean G_t 作为均值，则高斯反向核以 Euler 均值为中心，协方差可以近似 q² E[(X-G_t)(X-G_t)^T|z_t,c]。

这里 G_t 并非真实条件均值。上式是固定均值高斯似然下的二阶残差，而不是无偏后验协方差；它包含均值偏差。似然改善不推出 FID 改善，这正是必须继续做完整生成对照的原因。

已有方法用固定条件标量 m(z_t,t,c) 和全图单位方向 u_g=normalize(Full-Base)：

    Σ₀ = m S₀²， S₀ = I+(sqrt(κ)-1)u_g u_g^T。

κ和m全部沿用已保存校准。本轮不重新选择它们。该协方差只有一个全图相关方向；其余方向共享方差。

## 严格嵌套的空间扩展

对16×16个位置，各自沿1024维通道的 Full/Base 差归一化，得到256个支撑互不重叠的列，组成 U，U^T U=I。全图方向在该空间内：u_g=Uw，其中w为各位置差值范数除以全图范数。

还需保持不变量：新方法在u_g上的方差仍为mκ。直接在白化后的整个256维空间拟合矩阵，可能再次改变这一已校准方向，模糊机制归因。故只在全图方向的正交补中拟合。

用将第一坐标e₀映射到w的Householder反射H(w)，定义V=UH(w)[:,1:]。则V有255个正交单位列，且V^T u_g=0。反射的定义固定，不用FID选择坐标系；对角控制指这个固定正交补坐标系中的对角矩阵，不等同于原始256个位置各自独立。

已有模型的白化在V空间中恰好是恒等，因此白化残差的有效坐标为：

    r = V^T S₀^(-1)(X-G)/sqrt(m) = V^T(X-G)/sqrt(m)。

用64K训练行拟合一个固定正定矩阵K，然后定义

    S_K = I+V(K^(1/2)-I)V^T，
    ξ_new = S₀ S_K ξ = S₀ξ+V(K^(1/2)-I)V^Tξ， ξ~N(0,I)，
    z_s = Euler_native + q sqrt(m) ξ_new。

因为两个修正空间正交，此处S₀与S_K交换。相应协方差为m[I+(κ-1)u_g u_g^T+V(K-I)V^T]，u_g的特征值严格保留为mκ，总迹为m(d-256+κ+trK)。K=I时严格返回旧全图方向模型；新方法只改变剩余空间结构。

## 可直接求解的拟合与机制对照

固定G、m、S₀、U后，相对旧模型的单行完整维度高斯NLL差为

    Δℓ(K;r) = 1/2 [logdet K + r^T K^(-1)r - r^T r]。

训练经验风险的唯一正定最优解为未中心化二阶矩 K=mean_train(rr^T)。不减残差均值，因为采样均值仍固定为G；不增加ridge、特征选择、时间窗口或强度网格。若经验矩阵不正定，本次假设停止，不靠调正则救回。

一个预定机制控制是 K_diag=diag(mean_train(r²))。完整K含32640个自由参数，对角控制含255个。二者都嵌套K=I。用原8K验证行分别检查full相对旧global、full相对diag的NLL差，要求两项均值加两倍1000类聚类SE小于零，才进入生成。该验证集已用于历史研究，不能称作未接触的独立验证集；SE是描述性诊断。

记录K谱、迹、条件数及残差均值贡献，检查可能的偏差膨胀。这里的统计不选择模型参数，也不充当FID代理。
