# 固定特征的加权线性参考拟合

前一轮全读出2048步SGD未改善任何目标的heldout风险，因此不据此判断标签机制。
本轮冻结原Base读出中的RMSNorm和AdaLN，只拟合最终linear及bias。特征phi取该
linear实际输入（按BF16 forward的有效精度转换），与时间权重w=1/max(t,.05)^2。
真实目标X和教师目标F共用同一Gram矩阵G=sum w phi phi^T（附常数1列）。
分别求解Theta=G^+ sum w phi target^T。这是规定线性类的全局加权最小二乘解，
不是整个非线性读出的最优；两解之差精确等于对F−X用同一G的拟合。

train5000真实图像每张取一次新噪声/时间，CUDA seed202609421，B16，官方shift8
logit-normal时间、10%空标签。同一已核验bank；validation仍1000、seed202609420。
没有多轮训练或checkpoint挑选。FP64累计Gram/交叉矩；对称eigh，特征值阈值
eps64*max(token_count,feature_dim)*lambda_max，只作数值秩判定，无ridge搜索。
记录秩、条件数、方程残差、原始/拟合训练风险及heldout风险、参数和输入来源。

部署仍BF16，因此同时报告FP64解和BF16量化系数的训练风险，不能用实数域最优
冒充BF16最优。保持原模型不变，只保存两个独立读出；不进行质量采样。
预计小于.25 GPU小时；固定5000图像、单噪声/时间，成本实测。

## 完成结果

1441维设计矩阵满秩，条件数1283.28，正规方程相对残差约3.6e-15。
真实标签/教师标签的训练风险分别从 .478319/.069537 降到
.470790/.067128；BF16量化系数风险为 .470793/.067130。
但1000个独立验证样本上，真实标签风险原Base为 .477276，数据拟合为
.484877，教师拟合为 .479392；教师目标风险也都未超过原Base。
拟合43.91秒、含验证50.62秒（约 .0141 GPU小时，加载与文件哈希除外）。
参数有限、原模型非线性参数未改、原Base验证逐行一致均经独立审计。
本轮未保存Gram/交叉矩，故方程残差是训练程序记录，未独立重构。

结论：有限单噪声训练集上的精确线性拟合收益未泛化；不能把本次失败归因于
SGD未收敛，也不能据此否定所有参考标签方法。此处MSE只检验拟合干预是否实现，
不作为PFR质量的必要条件或充分条件。没有启动这些读出的FID采样。
结果见 experiments/results/terminal_defect_20260908/raev2_linear_reference_*.csv。
