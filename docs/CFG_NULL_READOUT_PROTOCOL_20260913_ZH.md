# 纯CFG的无条件读出：固定真实生成检验

研究假设：有限的共享末层读出可能给null预测引入特有的近似误差，而CFG以负系数使用这项误差。固定条件分支及全部主干，用真实无条件FM数据重新拟合null读出，可能改善指导质量。它不假定全部误差共线，也不宣称降低null训练MSE必然改善采样；判断只用固定生成对照。

这项实验受SiT的IG读出实际收益和[Unconditional Priors Matter](https://arxiv.org/html/2503.20240v2)启发。该文主要研究微调模型并用另一个模型替换无条件预测，不能直接证明这里的单主干读出问题；本实验不加载另一个主干。仓库旧null头续训/teacher试验已失败，本次是新的结构和等训练控制，不复活蒸馏。MLP本身不是新贡献。

固定SiT-S/2、ImageNet-100与原checkpoint。null特征来自同一模型完整12层，条件强模型和原末层始终冻结。三个null头共享完全相同的真实clean、噪声、时间和训练步：MLP从零输出初始化；原AdaLN结构从官方零初始化；原AdaLN结构从预训练原末层继续训练。保持原结构本身的归一化。新增训练均3000步，batch32，AdamW(lr3e-4,wd1e-4)，EMA0.995，最终EMA固定；种子2026121351，32个训练批估计MLP固定逐通道统计，之后开始参数更新。时间uniform[.01,.99]；训练只输入null类别100，监督真实velocity，不使用teacher或合成数据。

MLP宽度384，和IG候选相同的token、condition与固定8维位置输入，输出尺寸匹配原末层。原模型未用于velocity的额外输出通道不计入loss，保持采样接口并忽略它们；不对这些通道构造额外监督。所有生成都只替换null调用的末层，条件调用恢复原末层。CFG仍需原条件末层，因此新增null参数不能像IG那样仅按两弱头参数差计数。

七臂固定400图，种子2026121361，每类4图，同噪声/标签：MLP、原结构从零训练、原结构续训、原CFG、半强度原CFG、ADG、APG。MLP及原结构训练头的CFG额外系数均1.25，半强度0.625，ADG1.25。APG使用仓库既有cfg_apg_07配置：强度2、momentum -0.5、cap=2倍gap范数、去除沿clean预测的投影；它是已有强对照，不是新候选。沿用其Heun两个stage共用历史、提交第一stage历史的实现，并逐项核验。

统一64步Heun，CFG在left_time<0.75启用，每图224次full、0prefix、一条路径；窗口以每步left_time决定两stage是否启用。不在末段重开guidance，不调时间网格。第二噪声文件只保留数据接口，不用于采样。

固定推进标准：MLP FID比全部六个控制均低至少2，IS至少原CFG的90%，才进入全新1K确认。原结构两个训练头是控制，不自动事后升级成新方法。失败则停止本构造，不补扫头宽、深度、训练时长或引导系数。零引导须精确退回原条件模型；交换null末层后条件输出须保持相同；所有基线的公式和实际调用数须核验。

同GPU、同batch轮换七臂，预热后各三次完整采样与解码计时，报告新增参数与NFE，不能只用参数量宣称等成本。全部图像、输入、请求、权重和源码保存hash；缓存Inception特征FP64复算FID，不冒充独立特征提取器验证。首四张固定展示，七组全部报告。

文献取舍：[Terminal-Fitted Repair](https://arxiv.org/html/2607.07665v1)给出高guidance、小噪声末段的零额外NFE修复，但其作者也限制了普适质量结论。当前协议已在末段关闭CFG，不为套用该机制而改变评估任务或重新打开末段。优先检验读出问题并保留失败证据。
