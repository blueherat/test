# AG与FSG的联系：latent中的隐含来源条件

本笔记沿用户最新明确的方向：保留guidance；从AG相对密度支持的解释出发，寻找可与FSG条件校准联系的信息载体。撤引导、decoder及真实像素重建支线暂停。以下是条件解释与可核验恒等式，不是已经有效或已证新颖的采样方法。

## 从来源条件构造联系

固定类别c和噪声层t，假设pS、pW为合法密度，score为sS、sW。引入一个人为来源变量H：H=S时采自pS，H=W时采自pW。设来源先验a∈(0,1)，则其混合边缘为

    m=a pS+(1−a)pW， ρ(z)=P(H=S|z)=a pS(z)/m(z)。

ρ是latent承载的相对来源证据。它不是外部质量标注，也不证明pS更接近真实数据；质量含义仍依赖AG关于弱模型放大类似错误的解释。构造m始终合法，与此前假设Full是固定比例Base污染的线性去污染不同。

Bayes和混合score恒等式给出

    ∇log[ρ/(1−ρ)] = sS−sW，
    sm = ρ sS+(1−ρ)sW，
    ∇logρ = sS−sm = (1−ρ)(sS−sW)。

因此原生AG的score形式

    sAG=sS+γ(sS−sW)

可以写成

    sAG=sS+[γ/(1−ρ)](sS−sm)。

这是一种以H=S为条件、m为无条件边缘的自适应CFG解释。AG强调log odds；对来源条件采用固定额外CFG强度强调log posterior，两者差一个状态相关因子，不能直接说是同一种固定强度算法。

这里的a是人为构造的先验；自适应等价式对任何a都给相同AG。若将γ/(1−ρ)换成常数来提出新采样器，a便会影响算法，那是新增设计选择，不能藏成理论唯一答案。a=.5只是一种对称约定。ρ<1时，两种局部方向的零点相同；没有凭空创造能逃离所有坏驻点的方向。

## 与FSG直觉的对应及边界

FSG用条件/无条件续生成的一致性表达校准目标。借这个构造，AG也有了明确的隐含条件和对应无条件参考：希望latent更支持强来源、减少弱模型相对过度支持的区域。持续guidance仍然参与校准和生成，不要求撤掉它。

但这只建立解释层的联系：sS≈sm是同一噪声层的局部量，不能推出两条完整续生成相同；高ρ也不能保证真实质量，且未必存在ρ接近1的区域。特别是直接把强弱输出相等当作来源证据已充分，是错误的。研究实现需决定校准的是当前来源证据还是后续证据，并证实对生成质量的作用。

此前 `SEMIGROUP_CONSISTENT_GUIDANCE_THEORY_ZH.md` 已有端点密度比的后验条件矩和Bellman修正，其实际模型失败仍然有效。本笔记不将该未来价值函数改名重做；也不调用旧的未通过审计的神经密度比估计器。标准Bayes恒等式、混合score和密度引导本身不宣称新颖。

## 精确密度核验

固定双峰strong=.5N(−2,.35²)+.5N(2,.35²)，weak使用同峰但标准差1.2。四个共同Gaussian平滑噪声标准差0/.5/1/3、三个来源先验.2/.5/.8，x∈[−8,8]的32001点；γ=.78。12组检验混合score、后验score、AG自适应CFG等价式；用中心差分独立核对logρ的导数。

CPU执行22601退出0。代数恒等式最大误差小于8e−15，中心差分最大绝对误差5.60e−8（采用带相对项的容差）。无神经模型、训练、采样或质量评价。

一个明确反例：无额外平滑、a=.5时，双峰中点sS=sW=0，但ρ仅1.1163e−6。来源证据极低，局部强弱差却为零。这只证明零gap不是高来源后验的充分条件；两种梯度在此都为零，也不把单个对称驻点当成总体采样失败证据。
