# 分区控制的局部代数边界

本页是标准正交最小二乘的应用，不认领公式创新，也不提供终点质量保证。
它使当前候选机制可计算、可反证。

固定访问状态 (z,t)，两个速度预测为 v_x、v_e，Bayes 条件速度为 u。
记 Δ=v_x−v_e，P 为一个正交投影，Q=I−P；P 可以依赖状态，但不能依赖
当前未知 clean target。令 A=||PΔ||²，B=||QΔ||²，二者严格正。

不加 [0,1] 约束时，两部分的最优 gate 分别为

    r_P = <P(u−v_e),PΔ>/A,
    r_Q = <Q(u−v_e),QΔ>/B。

每部分目标都是以其最优值为中心的二次函数。共享标量的最优值为

    r_* = (A r_P + B r_Q)/(A+B)，

共享标量相对两个独立标量的点态最小风险差恰为

    AB/(A+B) * (r_P−r_Q)²。

证明：利用 P、Q 正交把平方误差拆成两项；完成平方后，将 r_* 代入
`A(r−r_P)²+B(r−r_Q)²` 即得。若两个分区均无有效 head disagreement，
或两者最优 gate 相等，则分别控制不产生收益。

真实实验将 gate 限制在 [0,1]。仅当两个无约束最优值均在区间内时，上式
也是 constrained risk gap；否则需要分别求解 clipped 二次问题，不能把
clipped gate 直接代入上式宣称恒等。分区控制的可行类仍包含所有共享 gate，
因此其最优局部风险不会更高。这一性质已有数值测试。

普通 flow 配对目标 Y=X−ε 满足 E[Y|z,t]=u。对任何只依赖 (z,t) 的
候选预测 f，`E||f−Y||²=||f−u||²+E||Y−u||²`，所以可通过配对监督
学习分区 gate，而不需要 Bayes oracle。有限样本、函数容量、优化失败和
rollout 分布偏移均不由这个 population 恒等式解决。

需要从数据进一步回答的不是“多一个参数是否降低 MSE”，而是：

- 可估计分区是否让最优 gate 的分歧比随机分区更稳定、可学习；
- pointwise gain 能否迁移到完整生成分布；
- head bottleneck 消失或数据不再线性低秩时，收益是否消失；
- 是否超越已有动态混合、空间 gate、几何 guidance 的效果与成本。

在这些问题未被回答前，这个代数分析不足以构成论文主贡献。

## 不应漏掉的控制类

标量 gate 的可行速度是一条线段。逐坐标 gate 的可行速度是以两预测为对角
顶点的轴对齐盒；PCA 两 gate 则是沿两个正交方向的矩形，两者一般互不包含。
因此“PCA 两 gate 比标量好”本身不证明数据几何是必要条件。

令 c=(v_x+v_e)/2，R=||v_x−v_e||/2。坐标盒和两个正交 gate 的矩形都包含在
闭球 B(c,R) 中。对任意对称矩阵 0≼M≼I，速度 v_e+M(v_x−v_e) 也在该球中，
因为 `||MΔ||²≤<MΔ,Δ>`。反之，该球是此类矩阵作用在固定 Δ 上的可行集。
对目标 u 的球内最小平方误差解是 u 到该球的欧氏投影。

球 oracle 在本轮 toy 接近真实分布，但它直接读取 Bayes 速度；两头在端点
附近的误差放大还可能使球半径很大。这不是一个已得到的可用方法，也不能
据其结果把 PCA 分区认定为最优控制类。当前应区分控制类的表达能力与其在
有限样本、固定参数预算下是否容易学习。
