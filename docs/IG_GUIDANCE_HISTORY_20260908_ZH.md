# IG历史对强弱读取的配对影响

本轮检验一个信息载体候选：是否应维持不接收IG的对照轨迹作为弱参考。不是PFR未来查询，不要求强弱一致，也不宣称双轨迹本身新颖。原有有限写入实验已否定“RAEv2普遍擦除guidance”作为前提，见 `RAEV2_FINITE_GUIDANCE_RETENTION_20260907_ZH.md`。

## 固定对照及可复核执行

复用endpoint_adjoint_response_v1全部8条FP32原生IG轨迹，同初始噪声、同类别另生成100步Full-only轨迹。固定索引0/47/73/87读取双方Full与Base，100步shift8、B1、FP32、关闭TF32。每个选中IG状态及其一步原生IG后继均逐字节匹配旧缓存；每条Full轨迹从已核对哈希的相同初始噪声开始。未以零guidance Full终点冒充原生IG终点复现。

记两种历史状态为zG、zF。记录gG=S(zG)−W(zG)、gF=S(zF)−W(zF)、ΔS=S(zG)−S(zF)、ΔW=W(zG)−W(zF)，全部为clean预测；精确关系gG−gF=ΔS−ΔW。额外保存状态差。这里只改变过去是否施加IG；因而包含此前全部非线性轨迹响应，不等同单步偏导或独立语义干预。

GPU执行13293退出0，832次B1 Full前向，采样及向量保存25.650087秒；加载、哈希及CPU审计额外，无训练、反传、解码或FID。独立CPU执行51632退出0，32个向量快照文件哈希及全部Gram重算通过，向量恒等最大绝对舍入差4.7684e−7，索引0历史响应严格为零。checkpoint SHA在模型加载前核对。

## 这改变了什么决定

“弱参考读取写入历史会耗尽指导信号”在这些配对样本上没有能量证据。直接使用另一条历史的弱预测会同时更换参考的当前状态，混入比原生gap更大的历史响应；不能将其直接称为恢复条件信息或纯质量纠错。当前不启动这种跨状态guidance的1K/5K，也不从三个时刻挑窗口。

这并不证明历史响应有害：没有图像、类内多样性或质量读数；两条轨迹可改变构图和实例。保留后续必须解决的问题是如何识别可迁移的有效纠错，而非仅因一个载体能保存历史就把它接入采样。已有单步参考响应与读取反馈方案的5K负结果仍然有效，不换名重启。
