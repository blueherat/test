# 共同污染假设的真实终点分布数据协议

沿用用户指定的纯CFG与单次共享主干IG两条主线。上一轮36臂全部未通过；本轮不恢复旧队列，不训练蒸馏模型。

先收集SiT-S/2与RAEv2各1000个配对初始噪声、均匀类别的三个真实生成源。Strong全程采用原条件场。Weak仅在原IG窗口采用原内部弱场，窗口外采用Strong。Null仅在原CFG窗口采用null条件场，窗口外采用Strong。这一定义与有限窗口的概率流推导一致，不把Weak/Null终点说成全程弱／无条件模型的分布。

SiT使用原Heun64、IG窗口前半程、CFG窗口前四分之三；RAE使用原Euler100 shift8、IG噪声时间[.1,1]及全程CFG窗口。数据种子2026121291。每源使用同一个初始噪声及类别；每臂1000个独立样本，无筛选。离线Weak路径可用原弱前缀节省成本，这不是部署时增加第二模型的许可。完整／前缀调用和采样解码时间分别记录。

首500个源样本用于估计唯一全局去污染比例，后500个用于检验；不以最后生成FID选择该比例。参考目标为相同官方Inception特征统计所规定的一、二阶矩。因参考只提供矩，这只能检验分布混合的必要关系，不能识别全部真实密度。拟合采用固定二次核的均值嵌入，目标尺度由参考二阶矩固定，不搜索核宽度、特征子集或类别。配对源估计应排除同一seed的核对角偏置，分别报告CFG与IG的比例及留出剩余误差。

该数据协议没有提前规定一个未知比值处的截断采样方法。若比例估计或正性条件不支持减法，则记录其失败，不把clamp后经验公式继续称为精确去污染。后续真实生成方法及控制必须在结果可见前单独冻结。两模型从本轮数据阶段同时进入。
