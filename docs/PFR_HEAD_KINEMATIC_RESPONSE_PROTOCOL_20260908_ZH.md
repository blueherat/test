# 共享时间响应的显式状态项核验

固定重复上一轮32条无干预轨迹及四个时刻，保留全部原始响应统计。
新增A=beta*(1/t-1/r)*z，P_W=dW-A，P_F=dF-A。
在t,r>.5、velocity=(z-D)/t下，它是clean参数化的代数分解；
对直接velocity输出的SiT，D=z-tv定义等价隐式clean预测。
用传给模型的实际FP32时间计算系数，所有分解与归约FP64。

报告A与P_W能量相对dW能量、P_W/P_F余弦，以及分别将dW/dF
正交于当前z后的余弦和剩余能量。正交投影会同时去掉真实径向预测，
不能将它叫作纯粹的去参数化或真实误差分离。A与P不正交，能量比不
是贡献百分比；大项相消尤其不能直接指导删除其中一项。

不改状态；终点必须复现已审计原生轨迹。每模型832 Full和32 prefix。
预计计算合计约.024 GPU小时，加载另计。无解码、训练或质量搜索。
旧小SiT的Gaussian/score分量单独采样均已失败，不能重试这个删除方案。
论文暂停。本轮只判定上一轮共识是否在去掉当前状态方向后仍存在。

RAE最后时刻A能量比为1.716而预测项为2.273，二者相消后才得到原响应。
直接查看预测项余弦会从原始.670升至.851，不能据此认定预测项更可信；
添加或扣除共享向量本身就会改变余弦。正交后的.657给出另一个几何视角，
同样不是概率真实性或生成质量的判据。

结论约束：显式径向参数化并未解释跨模型共识差距；弱头也不是唯一
响应来源。下一步不再围绕径向缩放、强弱投影或删除代数分量做质量试验。
核心未解问题是共享的非径向时间响应何时对应有益分布改变；当前统计
没有识别其相对于目标分布的方向，因而不构成新方法。论文继续暂停。
