# 强弱头时间响应：固定原生轨迹诊断

目的：检验当前官方SiT/RAE的raw PFR是否主要来自弱头独有时间响应。
不将强头当作真值，不将响应分歧直接命名为模型误差。

复用IG方向探针的模型、精度、32个初始噪声(seed202609431)、标签和原生轨迹。
SiT在t=1,.9,.75,.55；RAE使用最近原生网格点1,.900212,.747405,.544503。
每次在同一状态计算Full/Base在t和r=max(.5,t-1/32)的velocity。
定义dW=beta*(W(t)-W(r))、dF=beta*(F(t)-F(r))。
恒等式dF-dW=beta*((F-W)(t)-(F-W)(r))用于接口数值核验。
这只是确定函数的代数，不是误差修正或生成质量的保证。

报告每时刻pooled cosine、Full/weak能量比、差分/weak能量比、
逐样本投影可解释能量比例。差分与共享分量不保证正交。
四时刻全部报告；不据诊断筛时间窗、强度或直接启动质量搜索。
终点必须逐bit复现已有无干预轨迹，否则停止解释。

每模型832次batch4 Full、32次prefix parity；不解码、不写回探针。
预计总采样探针约0.03 GPU小时，加载另计。论文暂停。

RAE的共识比SiT弱，但仍有约45%–86%的weak响应能量可由单一Full响应方向
逐样本解释；不能说RAE响应全是弱头独有噪声。两种模型均有显著共享响应，
“存在强弱共识”本身不能区分质量成败。也不能以它为真实模型误差的估计。

额外解释边界：在clean参数化下
v(t)-v(r)=(1/t-1/r)z-D(t)/t+D(r)/r，
两个头共享显式状态项。因此高共识可能包含共同参数化项，并不自动认证
真实概率路径的弯曲。前述统计没有把这一项的能量单独拆开，也没有证明
共享方向有益。四时刻不是整段积分，后几个时刻跨模型有小网格差异。
