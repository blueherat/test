# Lifting 与普通 IG 的跨模型宽强度曲线

用户于 2026-09-09 重新授权 lifting 扫参，要求同时扩大 lifting 强度和普通 IG scale，并在扫参期间独立思考其他方法。随后用户指出 4 太大；最终共同网格为 **α＝0、0.25、0.5、1、1.5、2**，不运行 α＝4。PFR 扩展保持停止。

现有 lifting 自身承担 guidance：每段先计算 L＝(ΦW)⁻¹ΦS，写入 z←z＋α(t)(L(z)−z)，随后沿 Strong 推进该段；不额外叠加普通 IG。分别扫描两个方法的强度，普通 IG 为 F＋γ(t)(F−B)，以 γ(t)＝α(t) 配对，即峰值 IG scale＝1＋α。它们是两条曲线，不是把同一引导重复叠加的二维搜索。

辅助 Strong 正流、Base 逆流都沿每段原细网格用 Heun，最多四个细步，单次有限写入；数值逆流不宣称精确离散逆。固定 m＝1，不同时改变窗口、horizon 或迭代次数。

小 SiT 两条新曲线采用相同分段重启时刻，隔离重启本身的影响。lifting α=.7 恢复旧 (.6,.7,0) 实现；旧未按 lifting block 重启的最佳普通 IG 单独保留为强基准，不能冒称同一个离散实现。时间坐标与绝对 FID 不在模型间直接比较。

每个新配置生成配对 1000 张，四张 GPU 合作一个配置，配置依次运行。α=0 两法按构造共享同一个 Strong 结果。已有同模型、同 bank、同窗口／步数／精度的点核验后复用，保留中间强度；其他窗口、m=2 或步数不同的点另列，不能作为同曲线点。所有完整旧图像只在小批入口复现，不重跑整组旧基线。输入整体哈希、checkpoint／源码／协议哈希、每批索引、图像与耗时均保存。

入口验证包括四卡各一批的旧像素复现、同时间 Full/Base 独立接口相等、α=0 两法终点相同、实际 Full／prefix 调用计数和时间方向。小 SiT 在旧 lifting α=.7 上复现，JiT 在旧 IG/lifting α=.3 上复现，RAEv2 在旧 lifting α=.5 和普通 IG α=.78 上复现，XL 在旧普通 IG Euler115 α=.35 上复现；XL lifting 为首次迁移，不能宣称它已有旧质量验证。实现错误先修复，不把入口测试通过写成生成成功。

输出完整 FID／IS 曲线、逐强度差值、相对各自最好点的差距、实测 GPU 时间和 Full／prefix 调用量；辅助诊断记录固定前16张（小 SiT 32张）的写入幅度及全部终点幅度。数值非有限或求解器失败明确列出，不从图表里删掉，也不偷偷缩小 α 或改变 sampler 后继续计为原配置。

本轮是已经看过的 1K 探索 bank，强度间不是独立复现。区分：(1) 同强度下是否持续改善；(2) 是否优于调参后的普通 IG 最低点；(3) 方法自身是否有宽阔的好性能区间。平坦但一直较差不能称为稳定收益。额外计算尚未排除；稳定收益也不单独证明机制或新意。若有值得确认的区间，需冻结配置，在新的配对 bank 上验证并补实际计算可比的强对照，再讨论论文主张。
