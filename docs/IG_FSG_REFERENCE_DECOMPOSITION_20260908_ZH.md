# IG 时钟校准的参考场分解

此处是研究实现的精确代数核对，不是新颖性或质量定理，不推进论文写作。

当前G=S+gamma(S−W)，合成参考R=2S−G。给定同一个输入z，q=z+hG(z,t)，
令带撇号的场都在(q,t+H)查询（RAE噪声时间则是t−H），有精确等式：

    A = q − h(2S'−G')
      = [q − hG'] + 2h(G'−S').

方括号就是同场往返，后一项是未来位置的两倍IG增量。因此当前IG的两场校准
并非只能从条件信息固定点解释：它也完全等于同场数值往返加未来guidance。
这不意味着多事件完整轨迹的FID可加，因为每次写回会改变后续查询。

更一般地，固定G和S，可取a≠1，R_a=(aS−G)/(a−1)，仍有G=R_a+a(S−R_a)。
其校准等于同场往返加h*a/(a−1)*(G'−S')。当前a=2；原始weak对应a=1+gamma
（gamma为零处须单独处理）。仅保持普通guided场相同并不固定校准算子。
这说明将一个IG表达式改写为CFG形式不能自动继承条件/无条件的语义解释。

随机FP64张量检查a=1.6/1.7/2以及直接R=2S−G分解通过，容差1e-14。
本等式不说明哪一个a好，也不授权扫描a。SiT同场IG结果接近原组的事实，只能
说明在那组1K中增加未来IG没有显示明显必要性。RAE事件拆分仍在运行，尚不能
判定RAE退化来自同场部分、未来IG部分或它们的轨迹交互。

训练侧的核对：RAE的clean输出通过(xt−clean)/max(t,t_eps)换算后按速度误差
训练，Full/Base损失相加，Base取共享第8层特征且未detach。SiT后训练头冻结
骨干。监督输出记号不同不等于目标对象不同；时间采样/权重、模型表示和训练
耦合仍不同。仅重训RAE的读出头不能单独识别骨干联合优化历史的因果作用。
