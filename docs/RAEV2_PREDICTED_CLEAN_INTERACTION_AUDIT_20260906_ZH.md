# RAEv2 predicted-clean 四格特征交互审计

本轮对两组既有完整 5K bank 做 CPU 分析。稳定结果是：历史项 H 在训练原图误差轴上的留出投影均为负；当前 head 的解码特征响应随历史状态明显转向。但交互项 I 的六组误差轴投影区间全部跨零，且 I 本来包含 −C，不能把其与 C 的反相关当成新的纠错机制。**未产生 guidance 候选、当前新 FID 或真实一步后缀因果结果。**

机器数据与完整 SHA：[predicted_clean_interaction_audit.json](data/raev2_guidance_restart_20260906/predicted_clean_interaction_audit.json)。独立 CPU 脚本：[analyze_raev2_predicted_clean_interaction.py](../experiments/analyze_raev2_predicted_clean_interaction.py)。不修改模型或已有实验数据。

**冻结定义与统计单位。** 使用 seed `20260801/20260802`，每组全部 5000 张、1000 类、每类 5 张，沿用原 800 训练类和 200 留出类划分。先对四格原始 2048 维 Inception 特征逐类取五张的平均，再做以下全部统计；因此协方差迹是**类别均值之间的经验协方差迹**，不是 5000 张图的 pooled 协方差，也不是类内多样性。缓存 FP32 提升到 FP64，未白化、换特征或做 2048 维 FID 特征分解。

令 $Y_{a|b}$ 为历史分支 b 的中间状态上，head a 的 predicted-clean 输出经过官方 decoder、clamp、uint8 转换和 Inception 后的类别均值。定义

\[
X=Y_{F|F},\quad H=Y_{F|IG}-X,\quad C=Y_{IG|F}-X,\quad I=Y_{IG|IG}-Y_{F|IG}-C,\quad T=H+C+I.
\]

**I 含 −C 的陷阱与事后恒等核对。** $I=C'-C$，其中 $C'=Y_{IG|IG}-Y_{F|IG}$。即使 C′ 与 C 正交且等范数，也有 $\cos(C'-C,C)=-1/\sqrt2$；因此约 −0.71 的数值本身不能证明系统主动抵消、饱和或修复 C。为防止这种误读，在冻结分析完成后，从原 CSV 的范数和 dot product 对全部 seed×time×split 恢复 C′。这是**事后、全组的代数恒等核对，不作为新假说检验**，没有再选时刻或特征。

**均值与协方差迹的完整代数。** 对类别向量 V 定义 $M(V)=\|\bar V\|^2$、$K(V,W)=\mathrm{tr}\widehat{\mathrm{Cov}}(V,W)$（ddof=1）。对 V∈{H,C,I} 保留所有自身项和两两交叉项：

\[
M(T)=\sum_V M(V)+2\sum_{V<W}\bar V^\top\bar W,\qquad K(T,T)=\sum_VK(V,V)+2\sum_{V<W}K(V,W).
\]

同时完整记录 $K(X+T,X+T)-K(X,X)=2\sum_VK(X,V)+K(T,T)$，以及以原图均值为参照的平方均值误差变化 $2\sum_Ve^\top\bar V+M(T)$。没有删除响应项、把交叉项归给某一个可独立干预的原因，或把 covariance trace 当作完整 covariance distance。留出数值为：
