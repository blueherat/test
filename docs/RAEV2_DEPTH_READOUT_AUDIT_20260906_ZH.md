# RAEv2 深度 × 读出交叉审计

日期：2026-09-06。**冻结交叉读出没有形成可直接使用的弱参考；不继续做范数匹配补救，也不进入 1K。** 四角交互远大于原生 gap，分解出的 depth/readout 两项巨大且近乎反向，说明当前原生读出不能作为跨深度可互换、近似可加的测量工具。这是机制否定，不是已测 FID 失败。

本次实际运行复用[法向审计](RAEV2_NORMAL_CURVATURE_AUDIT_20260906_ZH.md)首 8 类、10 个时刻的 teacher/原生 IG rollout 状态，共 160 个样本—时刻—域条目、20 个 B8 状态批。冻结官方 DINOv3-L K7、EMA step 100080；原状态来自官方 shifted Euler 100 步、shift 8、IG 1.78、区间 `[0.1,1]`。没有重采样轨迹，没有训练、clean-target MSE、解码或 FID。

**四个可观察对象。** 一次完整 encoder forward 保存 $h_8,h_{28}$，同一时刻嵌入保持不变。Base 读出 $R_B$ 是 `SiLU(t_emb+h) → base_final_layer`；Full 读出 $R_F(h;x)$ 包含 `s_projector`、从原始 noisy input $x$ 出发的 `x_embedder`、两层 DDT decoder 及 `final_layer`。因此这里的“读出”不是仅最后一个线性层。

| 输出 | 表征 / 读出 | 训练分布关系 |
|---|---|---|
| $Y_{8B}$ | $R_B(h_8)$ | 原生 Base |
| $Y_{28F}$ | $R_F(h_{28};x)$ | 原生 Full |
| $Y_{8F}$ | $R_F(h_8;x)$ | 冻结 Full 读出接收未经训练的浅层表征 |
| $Y_{28B}$ | $R_B(h_{28})$ | 冻结 Base 读出接收未经训练的深层表征 |

记原生 $g=Y_{28F}-Y_{8B}$，采用对称的二因素代数分解：

\[
D=\tfrac12[(Y_{28F}-Y_{8F})+(Y_{28B}-Y_{8B})],
\]
\[
R=\tfrac12[(Y_{28F}-Y_{28B})+(Y_{8F}-Y_{8B})],\quad D+R=g,
\]
\[
I=Y_{28F}-Y_{8F}-Y_{28B}+Y_{8B}.
\]

$I$ 衡量两条路径的非加性；这些恒等式不是误差或生成质量定理。特别是原生 gap 可以借助任意交叉角作这种分解，不能因 $D,R$ 较大就把它们解释成真实模型中的两个独立误差源。

**原生精确复现。** 保持官方运算顺序，分别比较 $Y_{28F},Y_{8B}$ 与额外独立 `model.forward`，并比较 FP32 提升后的值与原 BF16 保存输出。20 批 × 4 项，即 **80 项完整 B8 张量比较全部 bitwise 相等**。BF16 autocast/TF32 开启、参数和状态 FP32；诊断在输出提升为 FP32 后以 FP64计算。$D+R-g$ 的最大范数为 **0.000e+00**，零 gap 条目为 **0**。这些检查排除了原生算术或配对被改变，却不证明交叉角在训练分布内。

所有域、时刻均值中，交互范数为原生 gap 的 **12.73–30.81 倍**；depth/readout 两项平均约为 gap 的 **8.29/8.28 倍**，相互余弦总体均值 **-0.99070**。交叉 $Y_{8F}$ 的输出范数时间均值为原生 Full 的 **2.17–5.47 倍**。为避免把均值范围误写成所有样本范围：逐样本交互比实际为 9.64–35.18，$Y_{8F}$/Full 为 1.98–7.66。逐时刻及各域完整数字保存在[机器归档](data/raev2_guidance_restart_20260906/depth_readout_audit.json)。

这组结果不支持“直接把浅层特征送入冻结 Full 读出，就能消除独立 head 混杂并得到校准 weak predictor”。大量抵消和交互来自未经训练的交叉角，不能当成原生 IG 质量收益的解释。将这些大方向缩放至原 gap 范数也不能修复其训练分布与语义校准问题，因此本次停止该直接构造。没有据此否定重新训练／独立校准的共享读出，但它们尚未被本实验验证。

**与旧实验的区别。** [Common adapter／head-swap 账本](RAEV2_SELF_GUIDANCE_RESEARCH_LEDGER_ZH.md)中，common adapter 在已算完的 Full/Base 上共同加残差，严格保持原 contrast，不共享读出；checkpoint head-swap 交换 Flow/LPL 模型的整个 Full 或 contrast，也不交叉隐藏深度与读出。本次首次直接计算同一冻结模型的这四角。Routing reference 则保持原生完整深度表征和 Full 读出，只扰动 decoder attention，属于另一种干预；其旧 1K 因目标修订中止，不能归入本次质量失败。

**成本与边界。** 实际执行 20 次共享 encoder pass，并另有 20 次完整原生 verification forward；计入 verification 后 Full/Base 读出各 60 次、encoder 样本评估 320 次。耗时 9.29 秒，峰值显存 3.59 GiB。这里的 pass 是 B8，Full 读出包含两层 decoder，不能把这些异构调用直接称为相同 NFE。它们是审计成本，没有候选生成速度或同成本 FID 结论。

只有 8 类、单噪声 bank，时间与两域条目高度相关；没有总体显著性或独立种子确认。裁决只针对当前冻结交叉读出的直接可用性，不证明“深度无关”“readout 是 IG 唯一机制”，也没有得到 FID 阴性结果或完成至少 5% 改善目标。
