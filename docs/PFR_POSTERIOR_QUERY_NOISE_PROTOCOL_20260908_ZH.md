# 后验耦合查询的真实模型重复性检查

固定复用上一项 IG 方向诊断的 32 个初始噪声、标签、100 步未修改轨迹，
采样 seed 202609431。分别使用官方 SiT/RAEv2 权重和前次精度配置。
在原生网格最接近 noise-time 1、.9、.75、.55 的四点查询，记录实际时刻。
未来时间固定 max(.5,t-1/32)，使用候选文档定义的 A、B、V_noise。

每个状态使用独立 query RNG（seed 202609433），重复 16 对 antithetic
噪声；查询不写回状态。每次得到 clean 残差后以 -scale/t 转为当前
velocity 坐标，便于与原始 PFR 对照。此符号只是候选弱参考替换的坐标
转换，尚未据此决定部署控制律，也不保证质量改善。

记录 16 个残差的 Gram 矩阵，计算均值能量 M、单对估计方差 V，以及
无偏的信号能量估计 M-V/16；允许信号估计为负，不裁零伪造信号。
报告单对查询信噪比 (M-V/16)/V，并比较前 8 对与后 8 对均值的余弦。
这些只衡量查询随机性，不分离系统性的后验近似偏差与模型预测误差。

每模型 800 次 B4 Full、1088 次 prefix，其中 32 次验证当前廉价 prefix
与联合头一致、32 次读取原始时间 PFR，其余 1024 次用于 16 对重复查询。
初始噪声及完整未干预端点哈希须逐位复现前次方向诊断，从而验证查询
没有改变 RNG 主流或轨迹。保留源码、权重与实际调用量。

无 decoder、Inception、训练或质量候选运行。预计两模型合计数分钟
GPU 计算，加载/哈希另计。先完成并解释该检查，再决定候选是否值得
质量试验；不按信噪比挑时间点并假称事先确定的完整方法。

## 完成结果

SiT会话66102、RAE会话17602均exit0。32条轨迹的初始噪声和完整端点
逐位复现前一诊断；当前prefix一致性全部通过。CPU从Gram非对角项
独立重算无偏信号能量、方差，逐行计数、源码哈希及半正定性检查通过。
计算SiT39.255秒、RAE72.625秒，合计.03108 GPU小时，加载/哈希另计。
