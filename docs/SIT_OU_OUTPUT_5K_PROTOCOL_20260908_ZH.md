# SiT-v/x OU方向收益的独立5K确认

1K共同协议下v/x的OU FID均降低约2.6，但sFID均上升。本轮在新的独立seed
202609423、5000张（ImageNet100均匀随机类别；原文误写每类50张，见勘误）上固定复核四组，完整报告FID/sFID/IS。
不根据结果选择模型、指标或改变算法。论文写作仍暂停；不声称已解决RAE问题。

完全复用sample_sit_ou_output_control.py，不改gamma=.35、Euler100、h=1/32、
OU首段t<.25、PFR t<.5、原强/弱checkpoint、FP32/TF32、连续RNG及B8。
time_only保留被丢弃的额外Full查询用于机制配对，每样本125 Full+50prefix。
因此不是相对最快time_only实现的等成本优化声明，也不是历史Heun最优结果复现。

四组在GPU0..3各自运行，每组native8/ordinary8逐像素核验、目标方法8张未来
prefix核验后才采样5K；完整样本的前8张必须与smoke逐像素相同。源wrapper
hash必须与已完成1K相同；源代码、命令、协议副本、输入与模型记录保存。
预计新增采样合计 .62 GPU小时，加载与ADM评估另计，无训练。

完成后检查四组输入hash、模型/head、实际调用数与样本数；从保留pool3和
spatial特征分别用独立FP64协方差平方根重算FID及sFID。首次1K是探索，此次
固定5K是该共同协议的一次独立确认，仍不等于多训练种子或跨数据集验证。
若出现指标冲突，按原样报告；不以挑选指标将负结果改写成成功。

## 标签说明勘误

完整输出审计发现原协议把实际沿用的torch.randint类别生成误写为严格每类
50张。实际5K四组均使用完全相同标签，各类30–68张；此前1K各类4–20张，
同样四组一致。两种样本量均覆盖100类。没有更改样本、重排或重新挑选种子。
原始运行目录的协议副本保留原文作为审计轨迹。此处是方案文字与所复用代码
不一致的记录错误，不得声称严格平衡类确认；配对比较保持成立。
