# 加性误差假设下的IG读出验证

最优分布加共同错误分布的主要结构继续保留。现在需要同时允许共同错误成分形状错配，以及各模型无法由这一结构解释的加性残差。在固定噪声时刻与条件下，写作

$$S=(1-a)P+aE+\delta_S,\qquad W=(1-b)P+bKE+\delta_W,\quad 0<a<b.$$

这里K保持质量与非负性，delta是积分为0的有符号密度残差，完整的S、W仍须是合法密度。如果“加性误差”指样本上加独立噪声，它已经对应卷积；如果指网络输出的偏差，则应另外写成向量场误差xi。冻结网络的xi通常是确定函数，不必零均值，也不必是一个概率密度的score。

令kappa=a/b，按原严格混合公式反演，准确得到

$$\frac{S-\kappa W}{1-\kappa}=P+D,\qquad D=\frac{a(I-K)E+\delta_S-\kappa\delta_W}{1-\kappa}.$$

这个式子保留了原假设，又明确了其偏离。K=I且delta_S=delta_W时，共同的绝对加性误差原样留下；只有delta_S=kappa delta_W时才抵消。一个模型独有的残差还可能被反演放大。允许任意残差会使模型失去可检验性，故不能靠增大未知模型解释所有结果。

在P>0、P+D>0处，精确反演对应gamma=kappa W/(S-kappa W)。若网络输出分别是各自score加xi，则

$$\widehat s_{\rm guide}-s_P=\nabla\log(1+D/P)+(1+\gamma)\xi_S-\gamma\xi_W.$$

实际常数IG的系数g与gamma不同时，还要加上(g-gamma)(hat_s_S-hat_s_W)。该固定噪声层恒等式不等于证明学习采样器的整个时间边缘满足同一混合模型。相对残差及其梯度才决定score稳定性，单独的小密度平均误差不足够。完整推导和此前负结果见[结构错配与加性误差分析](AG_IG_STRUCTURED_MISMATCH_20260912_ZH.md)。

本轮从这个问题出发核查了一条已有的具体读出改动：在SiT-S/2的ImageNet-100设置中，保持强模型、depth4表示与IG强度不动，用真实数据训练的MLP作为弱读出。它最初是Local读出的对照，Local在SiT和RAEv2均失败；Context在SiT出现收益，随后固定权重，在新1K和新5K分别确认。这不是对混合模型参数的识别实验。

直接替换原弱头后净增加2,688参数。同GPU三次完整采样与解码的中位耗时相对原IG增加0.29%，24条完整轨迹与原捕获实现逐项一致；可复用入口又精确复现冻结5K首批8张。故这是一次有实际生成收益、成本接近原IG的具体改动。数据、误差核验与限制见[5K报告](CONTEXT_REFERENCE_5K_RESULTS_20260912_ZH.md)，实现入口和逐次计时见[直接替换读出说明](CONTEXT_REFERENCE_DIRECT_READOUT_20260913_ZH.md)。

解释候选也做了可失败检验：新一组1K中，Raw FID63.7752，先LayerNorm为63.2511，补回均值与尺度为63.2910。去掉统计没有损害收益，补回也没有改善，因此“保留归一化统计解释当前收益”未获支持。Raw权重与旧读出逐tensor相同，避免把随机重训差别混入解释。[五臂结果与负判定](IG_READOUT_NORMALIZATION_RESULTS_20260912_ZH.md)保留完整记录，不做归一化参数搜索。

当前还不能区分原读出结构与训练过程对收益的贡献，也没有把网络误差xi独立识别出来。RAEv2原400图Context对照没有同样收益，纯CFG这轮没有新增可信改善。[SSG](https://arxiv.org/html/2607.29122v1)已经提出冻结中间adapter，[RevIN](https://github.com/ts-kim/RevIN)已有移除再恢复统计的原则，所以不能将MLP或统计恢复本身称为核心新意。长期研究目标仍然保留，现阶段得到的是可复核的SiT读出收益和一个被生成实验否定的具体解释。
