# 最后第2轮：协方差压力与对称创新的结构裁决

用户要求最多五轮后收束。第1轮配对桥的固定1K仍按原协议运行；本轮仅用已有缓存和固定解析反例，检验一个不同的学习入口，不新增GPU、训练、采样、gain或窗口。依据[独立机制审查](RAEV2_REMAINING_MECHANISM_REVIEW_20260906_ZH.md)及Flow Matching/Stochastic Interpolants的条件期望与弱形式。

## 候选与必须满足的前提

令Y为真实teacher状态的原生IG Euler输出，W为同X/ε配对的下一时刻真实bridge状态，R=W−Y。若m₀(Y)=E[R|Y]=0，则配对插值的初始加速度为

    a₀=−h₀⁻¹ div(h₀ E[RRᵀ|Y]).

分部积分给出E[a·a₀]=E[RᵀJ_aR]，可用二阶Stein目标拟合a₀，不直接回归含一阶随机残差的速度标签。在固定函数族、四阶矩和导数界对β一致等条件下，R=βe使二阶标签的参数梯度方差为O(β⁴)，直接速度标签则可为O(β²)；这不是所有网络/时刻的普遍方差排序。

自然的首项更新为Y+a₀(Y)/2，系数来自辅助时间积分，不是手调。但若有限IG下m₀≠0，上述目标学到的是raw momentum flux，漏掉均值漂移和mmᵀ项。即使该raw field拟合精确，也有

    E[||Y+a_raw/2||²−||Y||²]/D
      = E||R||²/D + E||a_raw||²/(4D) ≥ E||R||²/D.

真实目标则满足

    E[||W||²−||Y||²]/D − E||R||²/D = 2E[Y·R]/D.

因此不能把所有残差二阶矩都当成还缺失、必须额外补入的方差。

另一变体以独立符号ζ=±1，令R*=ζβ(X−F)、W*=Y+R*，F为原Full预测。它对任意有限F/G都精确保留条件均值Y；条件协方差是β²{Cov(X|Z)+(M−F)(M−F)ᵀ}。这给出了不同于原p_s校准的新kernel，不能因形式合理就声称质量必然提高：IG可能已补偿相同方差。详见下面固定反例。

## 预先固定的全缓存检查

使用 `paired_bridge_v1/validate/moments.npz` 与 `teacher_regression.csv`，覆盖全部100时刻、每时刻100条、总10000条；不选类别或时段。

- `target_sum/official_sum[:,1024:]` 与 `counts` 重建逐时全坐标平均的W²与Y²；同时保留1024个通道的原始二阶差。
- 四份teacher target_energy必须一致；逐行乘β²再按step_index平均，得到e²=E||R||²/D。
- 输出逐时d²=E(W²−Y²)/D、e²、cross_twice=d²−e²、它们的原始量及符号分布；总体只作等时刻均值，不用比值选择幅度。
- 前1024列输出平均channel residual的平方描述；每通道R²未存，不能伪造逐通道cross或条件covariance。
- 时间/类别异质且同图noise复用；这些是固定cohort描述，不作IID置信区间。R²来自已存FP32归约及β的单位转换，不声称重算了未保存原始R。

该检查可说明当前数据是否支持把全部R²当作缺失方差，不能从经验cross接近0认证总体m₀=0，也不能由teacher上的二阶矩判定实际rollout FID。若原压力的必要前提不获支持，则本轮不给它新训练预算；对称变体还必须有“实际IG仍缺多少covariance”的独立证据，不能用Full residual covariance直接代替。

## 固定解析反例

X、ε独立N(0,1)，t=1/2到s=0；Z=(X+ε)/2，精确Full F=M=Z。取G=√2 Z，则原生Euler Y=G已经是目标N(0,1)，一维Gaussian FID为0。

对称创新R*=ζ(X−F)独立于Y、方差1/2，因此W*=Y+R*~N(0,3/2)，一维Gaussian FID变为(√(3/2)−1)²>0。均值保持、精确Full和正确posterior variance同时成立，仍可能重复补偿已经被IG修好的方差。该反例否定普遍保证，不宣称实际RAEv2必然处于这个情形。

## 有限实现与决策边界

无限函数空间中的Stein人口目标有L²投影解释；有限训练点可被“样本点上场值小、Jacobian大”的函数利用，经验目标不自动有下界。不能未经约束就用更宽CNN或补训来处理。线性有限族可以闭合二次问题，但会回到已有moment/低秩方案的覆盖限制；本轮不因已有代码方便就再跑一个Gaussian校准器。

只生成小型CSV/JSON、解析结果、来源SHA和书面裁决，全部工作计入第2轮。两条变体属于同一机制族，不能拆成额外轮次。若被否决，保留二阶弱形式和统计阶数洞见，并转向其他有证据的机制；不得以改标签、改窗口或加经验正则延长本轮。
