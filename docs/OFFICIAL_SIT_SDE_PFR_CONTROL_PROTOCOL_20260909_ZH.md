# PFR 在原生 SDE＋CFG＋IG 下的固定预算检验

本协议在产生这两组新图像前固定。它回答：固定的 time-only PFR 收益是否能延续到作者提供的 SDE＋CFG＋IG 配置，并超过把同一计算量用于更多普通步数的对照。该实验是对已有候选的质量与适用边界检验；一个正结果本身不足以识别因果机制，一个负结果也不代表穷尽所有 PFR 参数。

## 固定两臂与比较

沿用官方 800EP SiT-XL/2 EMA、联合 depth-8 弱头、CFG1.35（noise-time ≤ .7）、IG1.4（全区间）、FP32 网络 / FP64 SDE 状态、TF32 关闭、B4。复用原生 SDE 基线的平衡 1K 初始噪声与标签，仍是探索数据。每组终点分别用 EMA 和 MSE VAE 解码，完整报告两者，不择优隐藏。

| 新臂 | 时间网格 | PFR | 完整前向/图 | 前缀/图 | block/图 |
|---|---|---|---:|---:|---:|
| ordinary281 | 作者线性网格，281 步 | 无 | 474 | 0 | 13272 |
| time250 | 作者线性网格，250 步 | time-only，固定原幅度 | 422 | 182 | 13272 |

同时复用已完成的原生 ordinary250：422 次完整前向，11816 block/图。主比较是 time250 与 ordinary281 的同 VAE FID/IS；ordinary250 用于区分相同步数下的改变与更多计算的收益。block 精确相同不代表硬件时间相同，分别记录噪声耦合准备、轨迹和各次解码时间。

PFR 在 t>.5 时计算 r=max(.5,t−1/32)，当前状态保持不变。每个已有条件/空标签分支分别取

`G = B(t) + 1.4 * (F(t) − B(t)) + 1.4 * (B(t) − B(r))`。

沿用原生 IG 的 FP64 混合次序，然后使用作者的 velocity-to-score、SDE 漂移与 CFG 混合。这是 time-only 响应的明确移植；没有空间射线、范数恢复或新参数搜索。选择 time-only 的原因是先前 XL 对称曲线的空间增量很小，而且固定状态时间查询不需要另行规定随机漂移下的空间射线。不能将结果称完整 projected PFR 的穷尽检验。

## 随机路径与实现核验

原生 250 网格的 249 个 FP64 标准 Gaussian 增量使用原先各 B4 批次的 seed 和逐次抽样形状，原样保留。281 网格的新时间点由独立、按批次命名的 Brownian bridge 补入；这构成共同 Brownian 路径在两个网格的取值，不把相同 seed 下不同步号误称相同物理时间的噪声。最后 .04→0 的一步仍按作者代码不加随机噪声。

CPU 预检通过：用标准基向量显式构造耦合线性算子，250→281 的标准化增量协方差与单位阵最大差 1.94e-14，终点 Brownian 增量最大差 1.01e-15；另外覆盖同网格、稠密网格和粗网格。含多个新点的同一旧区间按更新后的左端点逐个条件采样。此检查验证噪声分布，不验证图像质量。

实现复制作者原生 sampler 的运算次序，只改为显式读取标准增量，并在 IG 后、score/CFG 前加入上述响应。CPU 上 250/281 步与原作者函数在相同注入噪声下逐位相同，执行查询但令响应为零也逐位相同。正式运行前，每卡检查本卡首个 B4：原始 250 sampler、复制后的零响应、已保存旧终点与两个 VAE 图像一致；281 步用原函数局部噪声代理进行同噪声比较；两个实际未来查询与完整前向返回的 Base 一致。代理只用于验证，未修改磁盘作者源码或全局 torch 模块。

每批次原始 Gaussian 生成器终态哈希必须与旧 SDE250 记录一致。前四批次的新臂预检结果在正式采样首批逐位重现。实际完整/前缀输入数量计数、所有 1000 个索引覆盖一次、原始片段与合并像素一致，源码/模型/VAE/特征有来源哈希。两臂四组解码的 FID 用同一特征独立复算，不把该算术检查计作新样本确认。

四卡合作，每次仅运行一个臂，评估时所有采样进程等待。当前 Euler 上侧网格完成后再启动，避免干扰其时间测量。运行入口 `experiments/run_official_sit_sde_pfr_control_20260909.py`；核心实现和 CPU 检查分别为 `official_sit_sde_pfr_control_core_20260909.py`、`check_official_sit_sde_pfr_control_core_20260909.py`。

旧条件分量干预与语义留存检验未支持 PFR 特异补充类别信息，因此这里不预先赋予这一机制。即使结果为正，仍需排除 IG/CFG 参数重调、精度与覆盖率取舍等替代解释，并做新的独立样本确认，才能支持论文核心论断。
