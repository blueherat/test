# PFR 不再作为论文主线

2026-09-09，结合用户对理论与实验基础的质疑，当前决定是停止 PFR 的新增扩展，将它保留为指定配置上的经验结果。CFG／autoguidance／IG 的整体研究目标仍然 active，尚未达成。

理论上的缺口不是少一个无条件 FID 定理。现有公式确实刻画了弱头未来查询对向量场和终点的影响，但没有识别该操作消除的生成错误，也没有独立预测改善的符号、何时有效或何时失败。局部误差与终点质量可以反向的反例仅排除了“局部更准必然更好”，不能据此推出 PFR 的修正方向正确。早期均值／协方差分工在更宽强度范围中也不稳定。[历史推导](PFR_COUNTERFACTUAL_RESIDUAL_THEORY_ZH.md)与[后续完整网格](OFFICIAL_SIT_PFR_EXTENDED_RESULTS_20260909_ZH.md)应共同阅读。

实验上的缺口不是所有正结果消失。小 SiT 和旧 XL 指定低强度配置的 5K 改善保留；但当前 XL 共同六点网格的各自最低 FID-1K 是普通 IG 38.18548、time-only PFR 38.63782、完整 PFR 38.48965。普通 IG 最低点仍在上界，这不是充分调优或独立确认。RAEv2／JiT 的已测失败进一步限制可推广的主张；不能据此断言所有模型与配置下 PFR 无效。[辅助指标](OFFICIAL_SIT_XL_MULTIMETRIC_RESULTS_20260909_ZH.md)呈现识别率、精度与覆盖率的取舍，没有证实全面质量优势或特定错误修复机制。

继续扩大同一方法的样本数能够检验指定配置的效应，但不能单独补上上述机制与贡献缺口。因此目前不继续 PFR 调参、投影变体或 5K 扩展，也不把停止该路线或整理材料计为研究成功。

执行状态已落实：

- `official_sit_sde_pfr_control_20260909` 的普通 SDE281 已完成 1K 与两种 VAE 评价；评价器报告 EMA/MSE FID 为 38.19176／38.20863。当前未运行该队列的完整双臂分析，不能称整组实验验证通过。随后自动开始的 `time250` 已中止；四个 worker 日志各记录至少 32 张进度，没有完整 PFR 分片或质量结果。控制器与四个 worker 均已退出。
- `official_sit_xl_selected_5k_20260909` 仅准备了输入，未启动采样；状态已设为 `shelved`。两组原始目录均保留 `PFR_MAINLINE_STOP_20260909.json`，记录此前状态与本次停止原因。

后续方法研究需先提出一个具体的生成错误、解释新操作为何针对它，并给出能区分替代解释的失败预测，再开展昂贵生成实验。当前没有已经满足这些要求的新核心 idea 或可投稿论文。
