# CFG 反演研究：强基线与监督校准的搜索协议

目标是找到超过充分调参、计算量可比 baseline 的生成方法。达到目标需要独立图像实验；文献整理、算子恒等或局部监督误差下降本身不算完成。

已有强前—弱逆构造与 Z-Sampling、W2SD、FSG、仓库 lifting 重叠。首轮把反演作为可验证的候选修正来源，先判定它是否提供强度重标定、APG 和便宜割线之外的信号。

## 强基线复测

模型固定为 SiT-S/2 ImageNet100 EMA 800K checkpoint、原 SD-VAE 和 ADM 5K 验证参考。标准约定为噪声时间 0、数据时间 1，普通 CFG 为 `v_c + alpha * (v_c-v_u)`，在左端 `t < .75` 开启额外 guidance。Heun 两次查询使用同一个左端 schedule，控制器历史冻结到接受步后才更新。

首轮为新独立 balanced 1K 输入 bank，seed `2026091397`，每类 10 张，所有配置相同噪声及类别，batch16。配置在采样前固定：

| 方法 | 参数 | 步数 |
|---|---|---:|
| CFG | alpha=1 / 1.25 / 1.5 / 1.75 | Heun64 |
| APG 适配 | alpha=1.5 / 2 / 2.5 / 3，beta=-.5，原相对半径 cap 与 clean 正交投影 | Heun64 |
| 调优 CTRL 及强度对照 | alpha=1.25 / 2.75，lambda=5，K=.2 | Heun64 |
| 较高计算预算 APG | alpha=2 / 2.5，beta=-.5 | Heun96 |

特别更正：历史 `smc_high` 的 alpha 为 **2.75**，不是 1.25。历史 alpha2.75/lambda5/K.2 的 CTRL FID1K44.7256，APG44.5039；Sep13 默认 lambda=.05 的失败不能替代该对照。历史独立5K APG21.6517 优于普通 CFG22.5125，旧 secant/APG/rescale 为21.2281但约1.377倍 APG 成本。不同 bank、样本数下的绝对 FID 不直接横向排名。

结果目录：`/home/zhoushunyu/data/eqvae/experiments/cfg_transport_search_20260913/baseline_1k`。实现、配置、模型、输入和参考在 request 中记录身份；所有样本与五个采样时间点保留。FID、sFID、IS、饱和度、实际单分支调用数和采样/解码时间分别报告。评估时间与模型加载、预热不计为采样时间，另保留评估耗时。

本阶段属于基线搜索；后续从该 bank 选出的最佳点不当作独立确认。候选确认需要新的 balanced 5K 噪声 bank，在产生结果前冻结配置；届时同时重跑选定 CFG、APG、CTRL，以及按成本需要的加密 APG 和旧最佳组合。

## 算子探针

GPU0 使用先前保存的8个真实 SiT 状态，在 t=.25/.5/.75、h=1/32、1/16、1/8 分别评估：同场往返、a3/b1 与 a3/b0、首阶有效 W=4 的 a2/b0 与 a2.5/b1。Heun 8/16 子步比较数值精度，并记录带符号的 gap 投影、正交量、条件末腿抵消与强末腿的变化。

对三腿组合比较有效强度和分支调用数配平的普通 CFG。若只满足内部往返恒等而不随细网格收敛，不能称连续 ODE 反演正确。若 GPU 有非本任务进程，计时标注可能受争用；不停止其他任务。

## 候选的进入条件

暂保留一个需要真实监督检验的假设：精细 conditional 逆流的运输成分，可能构成主模型预测误差的一部分基。把已有 gap、APG 和便宜割线能够表达的部分去除，再用真实训练图像的 FM 目标 `X-epsilon` 检查剩余方向 q。

拟合与验证使用不相交的真实训练图像 ID，FID 验证参考不参与拟合。最多拟合3个时间桶系数，主网络冻结。理想 conditional oracle 下，确定性 q 与监督残差的总体相关应为零；不把合法 mixed loop 强制压为零。若一阶逆流与已有便宜割线完全等价，则直接判为没有新增基，不因换名称继续采样。

只有留出图像上的误差变化超过抽样不确定性、方向对 inverse 精度稳定，才进入固定生成候选。监督误差下降仍不是 FID 保证：teacher states 与 guided 轨迹存在分布差异，生成阶段必须独立检验。稀疏五次重新评估与逐步完整更新是不同算法，不默认为持有旧方向仍等价。

后续若证据否定当前候选，将记录失败原因，并从新的可证伪机制继续研究；不将任务困难、基线较强或一次筛查失败视为目标完成。

## 第二阶段：控制器作用分解与经验互补

上述监督候选未过留出门槛，结果见[当前结果](CFG_TRANSPORT_SEARCH_RESULTS_20260913_ZH.md)。在读取第二阶段任何 FID 前固定以下配置，继续使用 seed2026091397 的相同1K输入、Heun64、cutoff.75、224次单分支求值：

- 独立历史场插值：`v=(1-eta)*v_APG+eta*v_CTRL`，eta=.25/.5/.75，APG alpha2/beta−.5，CTRL alpha2.75/lambda5/K.2。每个控制器只更新自己的历史，共享当前c/u预测；每个 Heun 步的两阶段使用相同旧历史，接受后同时提交各自左阶段提案。eta0/1在8张真实SiT完整轨迹与原基线逐位一致。
- eta=.5 的带符号方向对照：p=v_APG−v_c，D=v_CTRL−v_APG，`v=v_APG+.5*proj_p(D)`；p为零时投影为零。它保留沿当前APG方向的有效强度变化，去除新增方向。若eta=.25或.75胜出，必须补对应eta的该对照，再讨论方向作用。
- 基线局部补充：APG alpha2.25，CTRL alpha2.5/3；其余不变。已有CTRL alpha2.75尚未被两个近邻括住，不能先宣称充分调优。
- CTRL两步分解：同一块起点g上虚拟做两次CTRL，拆成冻结的平均修正与±交替修正，rho=0/+1/−1；每个真实RHS仍在自身状态与时间查询c/u。不额外查询。详细公式、阈值反例和限制见[调制研究](research/cfg_transport_search_20260913/control_modulation_debate.md)。该构造改变时变gap下的历史，不能称为原CTRL严格等价消融。

两类构造分开筛查，不将CTRL输出直接喂入APG动量：beta=−.5在线性未clip情形对DC增益2/3，对交替分量增益2，这会混入额外的相对放大。场插值仅作为经验互补问题，不宣称是尚无前人的新方法。当前1K仅用于选择，候选胜出后才冻结进入独立5K；同时报告空间FID、IS、类别代理、饱和度与成本，不能只比较新造的弱控制。

## 冻结的独立5K确认

第二阶段全部10组完成。最佳新增点是本来作为对照的 `parallel_e.5`，FID1K43.014364；完整混合最佳43.288636。补充APG alpha2.25为43.842474；CTRL alpha2.5/3为44.137442/43.699980。因此1K最佳APG仍为alpha2的43.464164，CTRL仍为alpha2.75的43.481451。CTRL均值/正相/反相三臂为43.322551/43.331168/43.654275，没有支持必须保留交替分量的强证据。

在产生独立确认结果前固定：seed2026091337，balanced5000图，每类50张，batch16，同ADM验证参考、同模型、同Heun64及.75截止。五臂为 parallel_e.5、APG alpha2、CTRL alpha2.75、CFG alpha1.25，以及下述time-only控制。全部224次单分支求值，已有候选与基线公式不改；不在此bank重新挑eta或alpha。

令p=v_APG−vc，r=v_CTRL−vc，parallel候选等价于 `vc+s*p`，其中 `s=1+.5*<r-p,p>/||p||²`（小范数按实现EPS处理）。time-only控制使用**另一套**seed2026091321、每类1张的100个独立噪声，沿该候选精确轨迹记录所有48个活跃步×两个Heun stage的s，仅在图像轴等权平均，得到[48,2]冻结表。它不依赖FID，不截断/重加权，不混合左右stage；正式推理用普通APG的自身历史与此时间表。校准需要额外100条模型轨迹，计入离线成本；推理不查询CTRL且仍与APG共享原两分支预算。

判定首先看parallel相对新5K APG及CTRL的FID差、同输入配对不确定性与辅助指标。若time-only不劣于parallel，不声称逐样本状态反馈必要；若只胜普通CFG，不声称超过本轮强基线；若未稳定胜出，不把1K搜索结果写成已确认收益。固定参考的bootstrap只度量这套有限样本评估中的生成随机性，不消除FID有限N偏差，也不包含验证参考总体的不确定性。

## 已知降条件 guidance 的小规模迁移对照

另保留一个与新5K选择独立的经验基线探索：负分支改查 `e_null+.5*(e_class-e_null)`，输出 `vc+alpha*(vc-v_half)`，恰好两查询。它属于已知 [CDG](https://arxiv.org/abs/2603.10780) 框架的均匀类embedding变体，不认领新方法，也不同于旧三查询的half→null割线。近线性时其gap为原gap的一半；非线性时，两个半割线相对于原gap的正交分量符号相反，旧三查询的收益不能为它背书。详见[文献及仓库审计](research/cfg_transport_search_20260913/degraded_condition_prior.md)。

真实8图scale0逐位退回CFG/APG、scale1退回conditional，半条件轨迹有限，仍224次求值。同状态四时间点half残差范数约为原gap的一半，据此在读取任何该组FID前固定4个1K臂：plain alpha2.5；APG alpha3/4/5，beta−.5；scale均为.5，使用已有1K配对输入、Heun64、cutoff.75。与有效强度约为其一半的既有基线比较。此组在GPU0运行，已观察到非本研究进程，因此耗时可能受争用，只保留原始计时，不据此声称同卡速度胜负；不停止其他任务。
