# RAEv2 跨原图原型的线性终点 observable

**固定检验发现：IG 相比 Full 增加了与独立源图类别原型的线性对齐，但仍低于原图和重构。** 两个交换训练／评估 bank 的方向都成立。这比单个类间 trace 多给出一个明确的特征坐标方向；仍然不是 FID 因果证据、完整语义质量保证或新 guidance 的训练授权。

本次只读取两套历史 `raev2_ig_scale_response/n5000_seed20260801_scales7_v1`、`seed20260802` 的 source、real、scale_s1p000000、scale_s1p780000 四臂 Inception 特征。`real` 指重构。每臂 FP32 `[5000,2048]`，按 `global_id=rank+4×local_row` 还原，计算转 FP64。没有读取现场新 5K bank，没有 GPU、生成、解码、Inception 或 FID 调用。历史来源边界沿用[解码后类矩审计](RAEV2_DECODED_CLASS_MOMENT_AUDIT_20260906_ZH.md)与[FID 来源审计](RAEV2_FID_FINITE_SAMPLE_READING_20260906_ZH.md)。

**先冻结，再计算。** [request.json](/home/zhoushunyu/data/eqvae/experiments/raev2_guidance_restart_20260906/endpoint_crossprototype_witness_v1/request.json) 在加载特征数值、计算原型前写入并 fsync，SHA256 为 `65fc7ebac7eaec85bcbfbfdd6b4df3c73c54f1443438c61836502ba82d0f96fe`。其中固定原型、两折、全部三项比较、排除 ID、32 个特征文件 SHA 及源图映射。

令 A 为原型 bank，B 为评估 bank。用 A 中全部五张同类原图定义

\[
m_c^A=\tfrac15\sum_{i:y_i=c}f_i^A,\quad
m^A=\tfrac1{5000}\sum_i f_i^A,\qquad
\psi_A(f,c)=\frac{\langle m_c^A-m^A, f-m^A\rangle}{2048}.
\]

根据源图行号交集，从 B 删除 21 个 ID 及四臂对应观测，A 保留全部原图。每折剩 4979 张：21 类各四张、979 类各五张，全部 1000 类使用。先求每类剩余观测均值，再对类别等权平均；不按 4979 张直接平均。交换 A/B 再做一次，无原型数搜索、方向搜索、额外归一化或有利类别筛选。**两折复用相同 banks，不能当作两次独立实验。**

| 20260802 → 20260801 | −0.00194275 (0.00023496) | −0.00156507 (0.00023175) | +0.00135793 (0.00014039) |

两折主要差值的 `mean ± 1.96 SEM` 分别为 `[−0.00230310, −0.00131635]`、`[−0.00240328, −0.00148222]`，符合计算前固定的“两折上端都小于零”的描述性规则。负差类别为 622/1000 与 613/1000，不是每个类别都缺少对齐。SEM 描述固定类别的异质性，不是条件于这些类别和原型的精确抽样区间；未据此给出总体显著性、两独立种子确认或多重检验保证。

**机制入口及边界。** 在特征坐标中，方向明确且固定：

\[
\nabla_f\psi_A(f,c)=(m_c^A-m^A)/2048.
\]

若使用可微终点映射 `f=φ(D(z))`，其 pullback 是 `J_{φ∘D}(z)^T(m_c^A−m^A)/2048`；再传播到较早采样状态需要真实采样动力学的 adjoint 或明确近似。历史图像管线有 clamp 和 uint8 量化，不能声称这个可微表达就是其精确原生梯度。仅沿此方向增加 observable 可能增加特征范数、产生特征攻击或损害别的类别结构；理论没有把“增加线性对齐”与“降低 FID”画等号。当前检验只为终点设计提供一个数据支持的误差方向，未计算轨迹响应，也未设计增益或启动控制器。

类别等权还有一个精确的解释：`Σ_c(m_c^A−m^A)=0`，所以给评估四臂中任意一臂的所有特征加同一平移向量，不会改变该臂的总体 observable。当前缺口因此不是单纯全局特征均值偏移；它衡量沿固定类原型方向的类条件中心对齐，也不直接测量类内多样性。

**可复核文件及成本。** [CPU runner](../experiments/audit_raev2_endpoint_crossprototype.py) 有独立的 `prepare`、`compute` 两阶段；[完整结果](/home/zhoushunyu/data/eqvae/experiments/raev2_guidance_restart_20260906/endpoint_crossprototype_witness_v1/summary.json) 和 `class_observables.npz` 保留所有 1000 类差值、4979 张逐观测数值以及两个完整原型。`source_maps.npz` 保留全部原图行号、ID 和排除映射。

准备与计算分别耗 **0.5000 / 1.2864 秒 wall**、**0.8063 / 1.5967 秒 CPU**。另一条不导入 producer 的逐类原始 shard 点积计算，完成 **70 项核对、4,193,968 个数值比较、41 项来源／产物 SHA 检查**，最大绝对误差 **8.88×10⁻¹⁶**；另耗 **1.6125 秒 wall、1.9232 秒 CPU**，记录于结果目录的 `verify_cpu.py`、`verification.json`。它是另一数值实现的自复核，未冒称独立人员评审。三阶段均没有 GPU／模型／FID 调用；计时从导入 `time` 后开始，不含最终 JSON 写入、解释器退出和父 shell 启动。
