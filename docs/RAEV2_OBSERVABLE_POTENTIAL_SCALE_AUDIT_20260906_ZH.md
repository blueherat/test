# 固定势函数：纠正筛查规模后的配对 5K 评估

日期：2026-09-06。**这次只改变评估规模，不重新拟合方法。** [有限样本论文与本地复核](RAEV2_FID_FINITE_SAMPLE_READING_20260906_ZH.md)表明，最终 FID 相对降低至少 5%，不推出 1K 估计也必须降低至少 5%。同一历史协议的 IG 在两套 5K 改善 8.4659% / 5.0949%，十个完整类别均衡的 1K 子集却全部不足 5%。此前将 1K≥5% 设为后续评估的必要条件过强；这里明确修正这个操作性门槛。

旧 1K 的结果 **37.562703724300 → 37.531664406887（0.08263334%）**、当时的预注册规则及停止记录全部保留。它没有稳定收益证据，也不证明更大规模必然失败或成功。本次是已知旧阴性结果之后重新注册的规模审计，不能称为从未见过候选结果的首次检验。最终至少 5% 的质量目标及公平成本要求不变，不扣除所谓 FID floor，不从 1K 拟合 50K 收益。

## 解释与后续成本

5K 是改善估计尺度的一次固定评估，不把 `5K≥5%` 再包装成 50K≥5% 的数学必要条件。报告三组点估计、绝对差和相对差；不能由五个相关 1K 子集产生虚假的独立置信区间，也不能把旧 1K 与新 5K 混合作为独立训练重复。根据结果决定是否值得做更大规模，但不改变方法、对照或最终阈值。若继续独立噪声确认，seed 固定为 **202609102**；不轮换 seed 寻找成功。

理论仍只保证理想完整连续性修正的分布性质；本有限势的 proxy 改善和未消除 witness 不能保证终点 FID。[机制](RAEV2_OBSERVABLE_ERROR_GUIDANCE_20260906_ZH.md)、[求解器](RAEV2_OBSERVABLE_POTENTIAL_SOLVER_20260906_ZH.md)和[旧筛查](RAEV2_OBSERVABLE_POTENTIAL_SCREEN_20260906_ZH.md)共同限定结论。

本轮三组只能完成基础与推理成本比较。得到方法必需的训练与 5K 编码，已记录窗口合计 **660.5193496611901 秒**，仍有未计时边界 `U≥0`。使用[原成本公式](RAEV2_OBSERVABLE_POTENTIAL_COST_PROTOCOL_20260906_ZH.md)，N=5000 时 `K_total≥126`；**126 只是 U=0 的下界，不是完整总成本匹配**。读取完整成本对照的 FID 前，必须闭合必要准备的实际端到端时间并冻结唯一 `K_total`；不能按质量选邻近步数。所有研究审计、重放、数据准备、模型调用、CPU、显存与 GPU worker 时间分别披露。

只有后续独立确认、足够规模评估和完整公平成本比较均支持至少 5% 相对降低时，才可宣布达到当前目标。本次重新评估本身不构成成功。
