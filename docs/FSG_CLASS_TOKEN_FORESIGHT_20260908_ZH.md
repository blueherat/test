## 候选与理论含义

以当前Full条件预测F_c(z,t)构造短程未来状态 `q=z−H(z−F_c)/t`、`r=t−H`。固定H=.125，查询t为1/.9/.75/.55，不涉及分母截断区域。令第14层8个类别位置的条件差为 `d(z,t)=h_c,class−h_null,class`，写入

`h'_c,class = h_c,class + [d(q,r)−d(z,t)]`。

保留当前条件序列的所有图像和时间位置，用当前z及当前时间嵌入读取后半网络。它试图用未来计算更新当前条件载体；不是过去缓存，不是修改z的FSG复现，也不是已经定义了收敛目标的固定点算法。未使用PFR/Base时间修正。

若相关映射可微，H趋零时修正为 `−H J_class (∂t+v_c·∇z)d + O(H²)`。这是条件激活差的沿轨迹变化经当前读出传播；其与真实去噪残差的内积符号未知。因此前瞻本身不提供误差下降保证，需真实数据检查。

## 冻结数据和实现

使用既有clean bank的validation部分，32个类别 `floor(arange(32)*999/31)` 各取唯一图像；它们与该bank的5000个辅助训练样本无交集，不声称与原RAE预训练数据无交集，也不是此前从未使用过的全新确认集。`load_banks`核对全部bank及metadata哈希。每图一个固定噪声seed202609441，四时刻共享噪声，构造 `z=(1−t)x+tε`。

FP32关闭TF32，B1，固定14/28层。128组原生Full与手工拆分Full逐位一致；128组零差修正亦逐位一致。零差检查验证写入算术及读取接口，不独立重跑H=0的全部未来查询。没有调参、训练或图像生成。

脚本 `experiments/probe_raev2_class_token_foresight.py`；审计 `experiments/analyze_raev2_class_token_foresight.py`。原始保存每查询两个向量e=F_c−x、a=F'_c−F_c；CPU独立重算所有Gram及 `mean((e+a)²)`，核对 `MSE_new=MSE_old+2<e,a>+||a||²`，并核对源码及向量SHA。

本轮阅读 [GAG原文](https://arxiv.org/html/2603.02531v1) 摘要、Introduction、§§2.3–3.2，未读完全部实验和实现。它已明确讨论attention空间外推与Hopfield固定点、Anderson类比，且共享固定点是显式假设；改变正负条件时也可能不共享吸引子。因此“把fixed point放进attention”不是足够的新颖性描述，不能把一般独立Q/K/V网络自动视为有共同语义固定点。仓库已有ERG阅读对该理论适用条件的检查，不重复作为新发现。

本候选同时缺少正向误差证据和明确新颖性，停止，不追加H、增益或层数扫描。前几轮诊断保留的实质观察是：类别激活可被干预、同轨迹条件差可短期保留；尚未证明这些观察能产生优于输出缓存或原生生成的算法。研究目标未完成。
