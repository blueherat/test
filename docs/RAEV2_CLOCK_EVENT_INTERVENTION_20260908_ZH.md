# RAEv2 时钟事件的固定因果拆分

在全部原五组1K和32样本双模型分解之后冻结。原async48.9723、time_only49.9319，
原生100步38.2642。目的是定位失败，非新增h/H或guidance超参搜索。

两组1K：early_only只保留索引0处两次校准，late_only只保留54与83处2+1次。
仍然执行所有原查询，但对被排除事件在整个事件之后恢复事件之前的z；模型eval
无随机副作用，完整调用仍每样本110次。h=.025,H=.125、IG1.78、原模型/decoder/
shift8/BF16、B4、seed202609413与原组一致。每组同原async输入hash。

技术控制：先在8张上运行none，必须与原ordinary100像素精确一致；运行all，
必须与原async像素精确一致。两者同时检查110次每样本前向。技术检查未通过
不得进入质量运行。early/late各8张后才1K，官方同一FID评价器。
预估两组质量采样0.49 GPU小时，加载和评价另计。保存命令、代码和全部结果。

解释：early差/late接近baseline支持初始事件为主要退化来源；反之支持后期；
二者都差支持多阶段失配；二者都不差而all差说明交互。比较不假设FID可加，
不以事后最佳分组作为独立验证的改进方法。绝对FID不能跨1K/5K对比。

新两组采样来源一致，已复制源码的hash逐一核对，实际调用和预定事件通过。

汇总`experiments/results/terminal_defect_20260908/raev2_clock_event_intervention.csv`。

结论：此固定协议中初始事件是主要退化来源。仅初始保留了几乎全部FID退化及
IS上升；仅后期接近原生。0.1200的后期改善不能作为新方法的独立质量证据。
该定位不等于找到初始事件失败的机制，也不自动解释PFR所有历史跨模型结果。
