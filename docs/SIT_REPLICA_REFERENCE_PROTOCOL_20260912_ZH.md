# 重复加噪的配对结构与 IG 弱参考：冻结协议

本轮只推进IG候选；纯CFG保留独立研究主线。蒸馏、独立弱前缀及旧宽队列继续停止。训练仅用真实数据及人工Gaussian噪声，strong输出不是监督。

固定时间t，z=tX+(1-t)ε，读出W对应clean预测d(z)=z+(1-t)W(z)。同一张真实latent X在同一t下加两份独立噪声，得到z1,z2。残差ri=Wi-(X-εi)=(di-X)/(1-t)。所有损失先对坐标取均值。

四个头的定义在质量采样前固定：

|头|训练目标|角色|
|---|---|---|
|ig_pair_mse|(E r1²+E r2²)/4|相同输入、相同训练查询量的普通FM对照|
|ig_pair_consistent|(E r1²+E r2²+E(r1-r2)²)/4|唯一主要候选：同图重复加噪预测一致性|
|ig_pair_average|E((r1+r2)/2)²/2|方向相反的风险对照：先平均预测，再平方|
|ig_pair_shuffled|同上一行，但X1、X2是同一类别的独立真实图像|配对结构与梯度尺度对照；每项残差有各自真实target|

理论在固定t、给定类别、无限函数容量下成立。定义m(z)=E[X|z]及T f(z)=E[E[f(z')|X]|z]。T为在p_t下自伴、半正定、收缩的后验重采样算子。同图一致性最优解为(2I-T)^(-1)m；平均预测损失最优解为2(I+T)^(-1)m。独立同类图像的平均残差目标仍以m为总体最优解。后者不是Noise2Noise中直接替换监督目标的构造。

可失败预测：同图一致性收缩由T定义的非恒定函数变化；平均预测损失方向相反。Gaussian数据N(μ,C)下，两者分别对应先验协方差C/2与2C的Bayes denoiser。对于对称二点先验，前者在同一后验权重下收缩预测幅度，后者放大。因此“平均预测损失得到更宽Gaussian参考”并不推出它能消除双峰之间的混合；该候选在推导阶段降为反向对照。不能据Gaussian情形把一般结果称为密度Gaussian平滑。

T平滑的是预测函数。其不变测度仍是p_t；一般向量解不保证可积为score，也没有共同clean参考分布或终点质量定理。图像强模型不一定沿相同正则化路径欠拟合；如果这种差值不对应需要修复的错误，候选会失败。整体风险最优解也不保证有限第四层读出能实现它。所有反例及失败结果保留，不按结果更换主要候选。

四头共享原301840参数第四层IG读出结构、同一原IG初始化，strong全部冻结。每头3000更新，16图对/更新、32个主干训练输入；AdamW lr1e-4，betas(.9,.999)，wd0，clip1，EMA.995。固定种子2026121236。训练池25600图，验证池互斥3200图；每次从VAE后验采样latent。同图配对共享同一次真实latent，不为第二份噪声另采VAE后验。时间均匀(.01,.99)。最终EMA，不按验证选checkpoint。

每个方法均抽取相同候选X1、同类独立X2、ε1、ε2、t和labels，记录共同随机流指纹；前三头实际使用X1两次，shuffled使用X1和X2。800个固定验证输入报告普通MSE、同图预测分歧、平均预测MSE，不据此判定生成有效。

新配对1K七组：四个新头、原IG、既有IG自身数据参考、ADG。噪声种子2026121235、标签种子+1，每类10图。Heun64，额外IG强度.8，t<.25乘6/7，截止.5。所有方法128 full、0 prefix；训练用图对，推理每次RHS只用当前一个状态，无额外噪声副本或模型前向。实际采样与解码时间另报。

仅ig_pair_consistent相对全部六对照至少降低.5 FID才晋级。通过则同一最终参数、种子2026121237、全七组新5K；相对全部对照至少降低1%才称本轮确认。同步报告sFID、IS、数值失败与推理成本。未通过则停止这个固定构造，不扫一致性系数、噪声副本数或训练步数。即使通过，单训练seed与单模型仍不足以宣布新机制或跨模型成功。

正式质量采样前核对源文件、模型/输入SHA、初始化及随机流、strong无更新、单状态推理与速度通道、所有零引导逐元素恢复strong、hook移除、四个旧基准逐元素复现。数学检查包括直接枚举有限噪声通道的风险驻点、详细平衡及谱范围、Gaussian协方差关系和平均损失恒等式。原始batch覆盖与缓存特征FP64 FID/sFID算术审计沿用冻结流水线。
