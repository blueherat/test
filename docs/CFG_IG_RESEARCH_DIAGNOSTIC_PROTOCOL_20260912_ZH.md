# CFG 与 IG 双主线的补充诊断

本轮区分纯 CFG（同一条件模型的类别 / null 分支）与 IG（同条件的深浅预测）。以下仅定义 CPU 机制诊断，不新增图像质量队列。

**IG 的替代解释。** 复用已有高斯平滑诊断的全部 32 个 teacher 输入、五个时间与五个弱参考，沿用前 16 拟合、后 16 评价。用一个全局标量拟合 strong score，用另一个全局标量拟合径向状态，另测两者的二元组合。每个时间和弱参考分别拟合；不逐图拟合。比较 held-out gap 残差与已经冻结的有限热平移结果。该控制在热平移结果可见之后增加，属于探索性再分析，不是独立确认。固定拟合后的配对 bootstrap 只刻画 16 个评价输入的变动，不包含重新拟合或候选选择的不确定性。

**CFG 的必要概率关系。** 对完整 100 类、同一状态与时刻，若类别场和 null 场来自同一联合分布，则 null 场须处于全部类别场的凸包内。固定已有输入位置 `[0,1,16,17]`、时间 `[.15,.50,.90]`，查询全部 100 类与合法 null 标签 100。只使用强模型 step 800000 EMA；FP32、CPU、4 个 Torch 线程，模型元数据严格核对。

先报告无约束仿射包残差，再报告约束凸包残差。仿射包由全部类别预测减去类别算术均值形成，SVD 相对奇异值截断 `1e-5`；额外记录 `1e-6` 和 `1e-4` 的敏感性。凸包由非负且和为 1 的权重二次规划求解，记录可行性、优化状态与 Frank–Wolfe 对偶间隙。凸包残差是条件 / null 不相容的局部见证，不能判定哪一支更准确；零残差也不证明存在全局一致的概率模型。

仿射正交残差对该状态的所有类别相同，可以将原 CFG gap 精确分成类别差异张成空间内的分量与其正交分量。名称仅描述局部几何；正交分量可能包含有益质量修正，不能直接命名为应删除的错误。保留全部 12 个状态，不按最终结果选择子集。teacher 输入范围不能代表实际 rollout。

**解析核对。** 完整精确 Gaussian 类混合必须通过凸包检查；人为给 null 场加入不在类别差异空间内的偏差后应被检出。一个有限类别子集即使面对精确模型也可能假报不相容，因此不能用随机负类别代替完整集合声称严格违反混合恒等式。

这些诊断没有生成新 FID、没有训练新模型，不自动启动采样。其作用是让后续建议建立在可复核的实际读出上。
