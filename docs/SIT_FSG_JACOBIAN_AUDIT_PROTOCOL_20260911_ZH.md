# Jacobian 实现独立复核

针对系数与Jacobian正确性的追问，原实验及请求保持冻结，新增以下可独立复算的审计。

1. 在含时间项的二维仿射系统中，将同一8步Heun映射的中心差分JVP与解析离散Jacobian比较，同时记录对精确连续矩阵指数的误差。
2. 对恒定条件和NULL向量场验证前向vc+a(vc-vu)再反演vu的短程位移是H(1+a)g。a与w=1+a分开记，不将两者混用。
3. 使用小模型固定编号0、3，在两档CFG轨迹的t=0.375状态，H=1/32和0.125。用自动微分JVP验证中心差分的Jδ，ε仍为0.001max(||x||,64)，另有2ε。
4. AD与FD统一使用可微的math attention后端；以同一fp32网络和同一离散NULL映射比较。
5. 区分高精度引导流的未来目标，以及当前Euler适配器自己前向得到的目标。原Euler反演、同长度CFG、H(1+a)g、精细逆流及实际裁剪位移同时测量。
6. 逐条记录实际位移长度及除以H||g||后的系数，直接排查“CFG额外放大而FSG未匹配”的可能。

审计时暂停小模型控制进程并等待正在采样的批次完成，使用空闲GPU复核，随后恢复。既有1K采样计时、数据和代码不变。
