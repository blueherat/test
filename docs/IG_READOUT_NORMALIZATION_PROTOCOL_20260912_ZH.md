# 弱读出的归一化统计：一个固定生成对照

冻结时点：旧Context读出在SiT的400图筛选与独立1K出现收益，RAEv2未出现收益；SiT新5K仍未完成。本协议是看到该差异后提出的解释候选，不追溯声称为最初预测。

原假设仍是最优分布加共享污染、结构mismatch和加性误差。这里检验一个可能的参考特有加性预测误差来源：浅层特征尚需保留的信息是否被读出归一化削弱。强模型不动，始终同一depth4特征，同一固定IG强度和窗口。

代码事实：实际加载的`/home/zhoushunyu/data/research_repos/SiT/models.py`中FinalLayer对token做`LayerNorm(eps=1e-6)`，再由只依赖时间/类别的条件调制并线性读出。加上任意token内通道常量不会改变理想精度下的LayerNorm输出。正比例缩放在epsilon可忽略时近似不变；epsilon非零时，不能严格声称尺度信息完全丢失，也不能从全空间的不变性推断训练特征流形上必然有信息碰撞。

RAEv2原弱读出在depth8取特征，先做SiLU，再用这个未归一化的逐token向量调制RMSNorm后的读出。因此其幅度有另一条输入路径。模型之间还存在很多差别，不能将两模型结果直接当成该机制证据。

三个真实数据训练的参考，除输入表示外完全沿用旧Context的width384、位置/条件项、损失、batch32、3000步AdamW(lr3e-4,wd1e-4)、EMA0.995、固定最终EMA、种子2026121301和32批训练统计估计。

1. Raw：完全复做旧Context，输入原depth4特征。
2. LN：相同MLP，输入token内LayerNorm后的特征，epsilon1e-6。
3. LN+stats：与LN相同，另把该token的均值mu和r=sqrt(mean((H-mu)^2)+epsilon)经一个零初始化、无bias的2到384线性层加到隐藏层。只增加768个权重，无推理系数、门控或额外主干查询。理论上H=mu+r*LN(H)，但本模型不强制重构，有限容量与优化也可能影响差异。

三者共有权重完全相同初始化；LN与LN+stats在训练前预测相同。每步真实clean、类别、噪声和时间完全共享；各输入表示用同一32批数据估计固定逐通道mean/std，stats也如此。Raw与旧Context的最终EMA逐tensor比较，若有数值差异如实记录，不能假称精确复现。监督只有真实数据velocity，无strong输出、合成样本、蒸馏或重训强模型。

冻结生成：新种子2026121341，每臂1000图、每类10图，五臂Raw、LN、LN+stats、原IG、ADG。统一64步Heun/128次full、零prefix、一次共享主干每RHS。完整保存首个噪声、标签、图像和实际调用；第二噪声文件不用于采样。前四张固定展示，FID/IS沿用同一ADM参考；不按验证MSE筛选。

可失败预测：Raw若仍有效，而LN的FID比Raw高至少1，LN+stats再比LN低至少1且距Raw不差超过0.5，IS不低于Raw的90%，则结果支持归一化统计是这次差异的一个贡献因素。若LN不变或更好，就否定“归一化统计解释当前收益”这一具体解释；若补回统计仍差，则不能把失败全部归因于统计丢失。单训练种子与单1K生成不建立普遍因果结论，也不因此开启归一化/MLP宽度/深度/强度搜索。

每臂在同GPU上轮换测量完整采样和解码三次，计入LayerNorm、stats线性层与hook。训练MSE只记录用于确认训练有效，不作为采样收益。

先例边界：[LayerNorm原论文](https://arxiv.org/abs/1607.06450)定义该归一化；[RevIN官方实现](https://github.com/ts-kim/RevIN)已经研究移除再恢复实例统计的原则，故不能把“补回均值和方差”本身当成新贡献。[SSG](https://arxiv.org/html/2607.29122v1)也已有冻结中间读出。只有生成结果与进一步可检验的误差解释成立后，才值得讨论IG场景中的具体研究价值。
