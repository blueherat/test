# RAEv2 完整终点伴随响应：8 图机制检验协议

日期：2026-09-06。本协议写于新实验的 GPU 调用之前。它检验完整后续采样能否传递一个明确的终点修正，不训练新模型，不计算 8 图 FID，不构成 ≥5% 性能结果。

## 从机制到干预

已有两个历史 5K bank 的交叉原型分析显示：IG 终点的类中心对齐量低于独立原图，高于 Full。定义来自 seed 20260801 原图的类中心差 `a_c=m_c−m`，固定

`ψ(f,c) = <a_c, f−m>/2048`。

这个量对所有类共同的全局特征平移不敏感；它只识别一个类条件终点误差。原型和历史结果见[交叉原型分析](RAEV2_ENDPOINT_CROSSPROTOTYPE_WITNESS_20260906_ZH.md)。固定扰动尺度为该分析 A→B 的 source−IG 均值 **δ=0.0018097258402418833**，不以本次图像拟合目标。历史 bank 与当前原生 IG 混合和量化协议有差异，因此 δ 在本实验只是独立冻结的扰动尺度，不能声称已知当前原生总体或 8 图恰有这一缺口。

对实际 100 步 Euler 映射 `z[k+1]=T_k(z[k])`，在每次更新后施加 `h_k u_k`。完整终点导数 `b_k=∇_{z[k+1]} ψ(z[100])` 包含所有后续映射的转置 Jacobian，**不含当前 T_k 的 Jacobian**。线性化下，若

`G = mean_i sum_k h_k ||b_ik||² > 0`，

则满足平均终点位移 δ 的最小积分平方范数控制为 `u_ik=(δ/G)b_ik`。时间变化完全来自实际后续动力学，无手设时间窗口或增益曲线。推导与边界见[终点控制阅读 §6](RAEV2_GUIDANCE_READING_ENDPOINT_CONTROL_20260906_ZH.md)。这只是线性约束的最小能量保证；有限非线性效果、真实量化后的响应和质量收益仍须分别验证。

## 冻结设置

- 8 个噪声，seed **202609111**；类别/全局 ID 为 `[0,142,285,428,570,713,856,999]`，即 `np.linspace(0,999,8,dtype=int64)`。一个 CUDA FP32 完整形状 `[8,1024,16,16]` 随机抽取后按 ID 分片，每图 batch 1；四卡各两图。所有进程验证全局与逐图噪声 SHA。
- 相同 RAEv2 dinov3l-k7 checkpoint、decoder 和统计；官方 100 步 shift 8 网格、`t_eps=.05`、同类 Full/Base、`G=B+1.78(F−B)` 在原生区间 `[.1,1]` 内启用，其余用 Full。使用现有官方算术顺序，不把额外速度 `u` 错当 clean correction。
- 可微替代模型使用 FP32 主干、decoder 和与正式评价同坐标的 Inception-2048；禁用 TF32。保存 101 个基准状态和 100 个后继状态终点伴随，逐图流式 VJP，不截断后续轨迹。
- 原生有限响应使用 BF16 主干/decoder、FP32 状态、正式 BF16 `clamp * 255 → uint8` 导出和原生 Inception。FP32 连续导数不是 BF16 舍入或 uint8 的真实 Jacobian。
- 首张 collect 图额外核对同一 uint8 图分别经原生特征提取器、连续包装器输入 `uint8/255` 的坐标一致性。单独记录调用及误差，避免以不同 Inception 作为同一个量。

## 两阶段执行与记录

1. **collect：** 每图一个 FP32 基准 rollout。终点对 decoder 和 Inception 求输入梯度；倒序对 `T_99,…,T_1` 做 99 次 VJP。保存全部 `b_k`、状态、特征、ψ、每步积分 Gram 贡献与文件 SHA。
2. **CPU finalize：** 只有全部 8 图 collect 完整且身份一致才计算全队列平均 G，并冻结唯一 `λ=δ/G`。G 为零/非有限时报告不可用，不加 ridge，不改 δ。
3. **replay：** 固定已保存的基准控制 `u_k=λb_k`，每图执行 FP32 controlled、native baseline、native controlled。控制是沿基准轨迹生成的完整开环干预；不得称为可直接部署的零成本在线控制器。所有图保留，不选择图像、不拒绝样本。

主要结果是两种精度下逐图和平均 `Δψ`、`Δψ/δ`、有限变化与线性预测的偏差，以及原生与连续结果差异。线性预测在 collect 队列为 δ；这项恒等式自身不是实验成功。有限响应若方向相反或不稳定，保留失败，不通过 λ 搜索、裁剪或时间窗口挽救。即使方向正确，8 图也只支持进一步判断机制，不能直接准入大规模训练或声明 FID 因果改善。

每图基准 collect 100 主干 forward 加 99 VJP 重算 forward，三次 replay 共 300 forward：总计 **499 主干 forward、99 主干输入 VJP/图**，另有四次终点 decoder/Inception forward、一次终点反向和坐标核对开销。保存实际调用计数、模型加载、各阶段墙钟/CPU 时间、GPU 显存峰值及外层进程时间。它显著贵于普通 100 步；未来若摊销，标签、训练及验证成本必须完整核算。
