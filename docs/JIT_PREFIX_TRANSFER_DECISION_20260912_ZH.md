# 独立弱前缀的含义、成本与停止决定

独立弱前缀方案停止推进。它需要额外执行一个浅层模型，不满足保持原生 IG 共享前向的研究要求。SiT 上的质量结果保留为有额外推理成本的工程对照，不能作为同计算预算下的 IG 改进。JiT 的完整生成比较未启动，没有跨模型质量结论。

原生 IG 在同一次主干前向中取得浅层特征 $h_4$ 和最终预测 $v_S$，一个较小的读出头把 $h_4$ 变成弱预测 $v_W$。本轮 SiT 正结果则复制了输入、时间、类别嵌入、前四层以及原弱读出，独立更新这些参数。训练后的弱前缀与强模型前四层已经不同，因此相同输入必须再经过这份副本。

两者使用相同的外推公式

$$v_G(x,t,c)=v_S(x,t,c)+a(t)\bigl[v_S(x,t,c)-v_W(x,t,c)\bigr].$$

改变的是弱预测函数及其求值成本。强模型没有变，公式没有变，也没有通过新的密度平滑算子得到弱模型。初始化时复制了大量已训练知识，1500 步是续训预算，不能描述为从零训练一个弱模型的全部成本。

|形式|弱预测的来源|是否复用强模型前缀|新增推理计算|
|---|---|---|---|
|原生 IG|共享浅层特征的读出|是|小读出头|
|只续训读出头|同一共享特征上的新读出|是|仍为小读出头|
|独立弱前缀|参数已单独更新的四层副本|否|前缀、嵌入和读出再次执行|

SiT 的既有 5K 结果是原 IG FID 40.4318、局部 IG 39.1767、融合 IG 39.3305、独立弱前缀 36.1732。该组原 IG 的实现为了统一比较布局也重算了前缀，因此其 545.19 GPU 秒不能代表最高效共享前向原 IG 的成本。候选的 548.81 GPU 秒与这一重算版本接近，不能推出候选与原生 IG 同成本。相对已经有额外计算的局部 IG 更快，也不足以满足原生 IG 的预算要求。[既有结果与成本注释](GUIDANCE_RESEARCH_CYCLES_20260912_ZH.md)

若完整模型有 12 层、独立弱模型有 4 层、只在前半程启用，按层数估算增加 $\tfrac12\times\tfrac4{12}=16.7\%$ 的 Transformer 计算。嵌入、读出、token 数、并发和硬件利用率使这个估算不等于实际延迟。JiT 预定配置每张从原 IG 的 100 次完整前向变为 100 次完整前向加 50 次独立前缀；没有执行正式生成，因而没有本轮实测延迟。参数显存也会增加，不能以弱模型层数少为由忽略它。

质量改善说明，在已有 SiT 固定配置下，这份独立训练的弱参考能改善生成。它并未说明为什么改善，更未证明弱模型密度是强模型密度的高斯或其他平滑版本。“原强模型的前四层服务于后八层，独立训练后更适合浅层直接预测”是一个可能解释，但缺少能排除其他解释的生成干预证据；弱模型去噪误差降低也不自动保证 guidance 更好。

JiT 本次仅完成了只续训读出头的 1500 步对照：1772544 个可训练参数，1000 张既有留出图的预测误差从 0.0950361 到 0.0950265。强模型状态和梯度隔离检查通过。此数值不是 FID，不能称作生成质量收益。

独立前缀训练在第一个优化步骤之前被初始化数值检查拦下：相同权重在 BF16 下，参数允许梯度的前缀与冻结前缀有最大 0.0078125 的输出差；冻结 EMA 副本与原读出逐元素相等。这是实现检查问题，尚未定位具体底层算子原因，不能当作方法失败的质量证据。随后因计算预算要求停止该路线，不再修复并续跑这一候选。失败日志、冻结请求和只训头对照权重均保留。

今后的 IG 候选以一次共享主干前向为预算边界；纯 CFG 候选以已有条件和无条件前向为预算边界。小读出或输出端运算仍须报告实际成本。额外主干/独立前缀查询不能计入这个预算，新方案首先应有能解释具体生成偏差的假设，而不是仅以增加模型和算力换质量。
