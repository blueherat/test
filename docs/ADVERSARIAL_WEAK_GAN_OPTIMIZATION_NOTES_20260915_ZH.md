# 二分类端点GAN的优化笔记

2026-09-15。当前真实RGB实验照原计划运行；本页只是后续判断依据，不代表已排入新实验，也不改变判别器只有P/R两个来源的要求。

## 成熟GAN训练文献提供的边界

R1、R2的局部收敛分析需要可实现的均衡、局部正则性及足够小的步长，不能因为代码有R1就宣称冻结强模型、有限弱头一定收敛。[Mescheder等，ICML 2018](https://proceedings.mlr.press/v80/mescheder18a.html)

R3GAN采用真假样本的相对评分并在真实/生成两侧使用零中心梯度惩罚。其分析和实验区分了局部收敛条件与离均衡较远时的稳定性；对真实侧施加R1，不会自动约束生成侧的所有梯度。若当前方法继续失败，这是可参考的成熟训练准则，不能直接照搬其对完整图像GAN的效果或收敛保证到本弱头。[R3GAN原论文](https://arxiv.org/html/2501.05441v1)

## 一个无需新loss的随机梯度细节

当前标准交替实现先用一批P/R更新D，再让同一批R欺骗更新后的D。这是常见实现，但更新后的D已依赖该批样本；因此G-step不宜被描述成“对独立固定D的无偏新样本梯度”。

可以在未来对照中用同一批样本分别计算D与弱头在更新前参数处的梯度，待两者反传完成后再执行各自optimizer.step。若模型没有依赖当前样本的状态更新，各自的小批量梯度相对于更新前历史有正确的条件期望，两个梯度彼此相关不妨碍这一点。固定Inception的BN为eval；本D谱归一化的幂迭代依赖权重而非输入批次。这个安排不需要额外采样、额外模型或新的分布分类。

这只是可能的优化对照，不意味着它必然比交替更新更稳定；同时更新与交替更新的博弈动力学不同。其效果仍需完整采样验证，不能靠一次梯度或局部指标决定。当前首先完成真实RGB版本的既定训练及1K/5K评估。
