# 独立5K确认：原分布弱前缀的对照收益

2026-09-12。第四轮四组1K结果和审计完成后、任何新5K输入生成之前冻结。

原IG、局部IG、native弱前缀、clt弱前缀的FID依次为65.402327、63.205382、61.819696、66.300268。预定粗化候选失败，当前C_4路线结束。native原本是训练量对照；现将其提升为一个**事后发现、需要独立确认的工程候选**，不把它作为粗化理论的证据，也不称为新的AG原理。

本轮不训练，不选checkpoint，不调整深度、强度、区间、求解器。使用第四轮完全相同的original、local、native三个配置以及最终native EMA权重；唯一改变为独立5000噪声和配对标签。CUDA噪声种子2026091205，标签种子2026091206，每类50图、100类，B8；三个配置共用新输入。新噪声文件和前8项均须与1K筛选bank不同。输入不按指标挑选。

原IG与native每图128 full+64 prefix；局部IG同样128 full+64 prefix。original额外重算前缀是沿用筛选的计算布局，不把它称为最高效的原IG实现；历史共享前向原IG只需128 full。真实采样与解码GPU时间逐批记录。native训练成本为固定1500步、11,233,552可训练参数，训练主循环68.27 GPU秒，另有数据加载、验证和预检成本。

**首要判定**：native在本轮配对5K中FID低于original及local，才称为这套配置的独立质量确认。若不同时超过两者，停止这个短训弱前缀版本，不开展强度或训练预算搜索。同步披露sFID和IS；不能把单项FID改善扩展成所有质量、覆盖与模型上的改善。一次新bank不构成跨种子显著性结论。5K与1K估计偏差不同，只在同一5K表内作数值比较。

复用第四轮8条轨迹、四个原生基线、零强度及强模型完整性的已通过预检，逐项校验所有旧源码与checkpoint哈希，再冻结新包装器与协议。实际worker仍逐卡重放原局部IG基线；所有三组进行原始分片/覆盖/成本及缓存特征FP64 FID/sFID独立算术核验。没有重新提取另一套Inception特征。

最近邻是[AG](https://arxiv.org/html/2406.02507v1)的外部弱模型；本地native配置将原IG浅层前缀复制并短训，属于弱参考构造的工程变化。[SSG](https://arxiv.org/html/2607.29122v1)已经提出冻结主干、训练中间adapter，故不能把中间分支或短训本身作为新意。即使5K成功，论文核心仍未建立；其价值是提供更强的对照，避免今后的方法只战胜较弱的原IG。
