原因：原协议每类一图的总协方差无法识别类内宽度。记每个模型、每类的两份独立噪声生成结果为X_c1,X_c2。对于任意固定线性映射L，

    E[ ||L X_c1 − L X_c2||² / 2 | c ] = tr Cov(L X | c).

因此1000类等权的两份独立噪声差，提供平均类内协方差迹的无偏估计。每类只有一对，不声称单类协方差准确；Base与Full共享两套噪声，模型间比较配对。固定pooling与64维投影沿用原协议；另保存全latent对应迹。使用1000类为单位的配对bootstrap（seed202609493、2000次）描述该类别集合内的重采样波动；不将其宣称为独立训练seed或所有类别总体的置信保证。

对矩阵也有 E[(LX_c1−LX_c2)(LX_c1−LX_c2)^T/2 | c] = Cov(LX|c)。只在预定64维投影中报告全谱，并明确高维有限样本限制，不选择特征方向或新guidance参数。
