# 独立浅层弱模型在 JiT 上的固定配置迁移

在查看本轮生成质量之前冻结以下方案。候选来自 SiT-S 上原分布弱前缀续训的独立 5K 正结果；本轮检验它能否迁移到像素空间 JiT-B/16，不新增平滑机制或调参网格。

模型使用官方 JiT-B/16 的 model_ema1，原弱读出使用仓库已完成的 depth4、50K EMA。强模型完全冻结。候选复制强模型的输入、时间、类别嵌入及前四个 Transformer block，复制旧弱读出；固定位置编码不训练。该深度尚未加入 in-context tokens，相关位置参数不训练。候选训练独立副本，不修改强模型。

训练固定 1500 步、batch 32、AdamW lr=1e-4、betas=(.9,.999)、weight_decay=0、梯度裁剪 1、EMA=.995，取最后 EMA。训练种子 2026120913，FP32 参数、BF16 autocast、TF32，与 SiT 的优化预算一致。采用 JiT 原生 logit-normal 时间 sigmoid(N(-.8,.8²))、分母下限 .05、标签丢弃 .1、随机水平翻转 .5。训练目标为真实图像的原生 clean-output velocity loss，即 mean(((x_hat-x)/max(1-t,.05))²)。这是原分布监督，不是强模型蒸馏。

从既有 ImageNet-1K packed train 中按类选 48 个样本，共 48000 个；排除旧读出预留的每类一个验证样本。类内无放回抽样后统一打乱。两种训练使用完全相同的样本顺序、噪声、时间及增强随机数。验证沿用这 1000 个预留样本，仅做实现和预测误差检查，不用于选 checkpoint 或超参数；它们曾用于历史诊断，因此不称为新的独立验证集。

训练两组：native_prefix 允许整个弱前缀和读出更新；head_only 只续训原读出，其余副本冻结。head_only 在生成时继续共享强模型前缀，因此不会强加不必要的额外计算。两组的差异检验的是可训练范围，不能把参数量和优化难度视为已经单独控制。

直接进行一次新的、配对的 5000 张确认，不经本轮 1K 筛选。每类 5 张，标签顺序以 seed=2026091218 打乱；像素初始噪声以 CUDA seed=2026091217、batch 4 生成并固化。四卡按 batch 交错分片。原 IG、head_only IG、native_prefix guidance 三组均使用历史 JiT 的 Euler100、额外引导系数 alpha=.3、前 50 步引导、后 50 步关闭。该系数来自旧实验，不看本轮结果重选。三组共享全部噪声、标签、量化与评价参考。

额外计算官方配置 CFG=3、Heun50、时间区间 (.1,1) 的参考组，同一输入 bank。它用于显示已有更强实用基准，不用于将不同求解器的差异归因于弱模型训练。原 IG 与 head_only 每图 100 次完整前向；native_prefix 每图 100 次完整前向加 50 次独立四层前缀；原样 CFG 实现每图 198 次完整前向。记录真实耗时与次数，训练耗时另列。

生成前检查：复制弱前缀与旧读出数值相等；强模型单独与共享特征完整输出相等；只训头时前缀权重不变；训练强模型无梯度且 state hash 不变；zero guidance 回到完整模型；旧 IG 和官方 CFG 的首批完整轨迹/像素对齐。使用旧模型的官方像素量化。

使用现有 nanogen evaluator、imagenet_256_fid_stats 评价 FID 和 IS；记录参考统计、特征提取器权重、源码、输入、权重、全部输出的 SHA256。独立从缓存 Inception 特征重算 FP64 FID，并验证完整样本覆盖。不能把一次 5K 当成多随机种子统计显著性，也不能把不同模型、类别数、参考统计的 FID 作横向绝对比较。

无论结果正负均报告三组主对照及 CFG 参考。固定预算结束后停止，不自动扩展训练时长、深度、学习率、guidance 系数，不恢复旧大队列。正结果也不证明弱模型分布是强模型分布的高斯平滑，更不证明原生 IG 已被改进：独立权重使它在计算形态上更接近小型 AG。
