# JiT读出在官方CFG设置中的固定应用检验

目的：MLP读出在JiT独立1K中优于原IG及等训练原结构；独立5K正在确认。单独IG的改进未必在官方CFG配置中仍有价值。本实验只在独立5K通过IG门槛后启动，检验已有MLP收益在更强实用设置中是否保留，不作为新的组合引导原理。

不新增训练。保留同一3000步MLP最终EMA、同一旧50K原弱头、depth4。四臂各1000张，每类1张，NumPy seed2026121401，batch4，初始噪声和标签完全配对：

|臂|场|完整前向/图|额外前缀/图|小头调用/图|
|---|---|---:|---:|---:|
|官方CFG|既有官方CFG场|198|0|0|
|增强CFG控制|CFG场加.3*(strong−unconditional)|198|0|0|
|CFG+原IG|CFG场加.3*(strong−原弱头)|198|0|50|
|CFG+MLP IG|CFG场加.3*(strong−MLP弱头)|198|0|50|

四臂统一为官方Heun50、末步Euler、基础CFG=3、区间(.1,1)、t_eps=.05。附加项在前25个完整Heun步启用，同一步两个RHS保持开启，后25步关闭；这是原Euler100前50步窗口向Heun网格的明确离散约定。增强CFG控制只把该附加项中的weak换成已计算的unconditional：与两个组合的strong总系数在每个RHS相同，包括基础CFG关闭的早期也加.3。它不是另一个待选候选，不扫强度。条件/无条件每个RHS各一次，弱读出只在已执行的条件主干第4层hook中计算。没有额外弱前缀，也不重复运行条件主干。强度.3沿用已有JiT IG，不根据本轮结果更改。四臂共享求解器，因此相互比较不混入求解器变化。

固定晋级门槛：MLP组合的FID须比其余三臂都低至少1，IS至少为单独CFG的90%。未通过则停止该固定组合，不扫系数、层数、窗口、训练步数；通过后也只记为待独立5K确认的应用信号。所有结果均报告。这里不是纯CFG新方法，也不能用组合胜出填补纯CFG路线尚无核心改进的缺口。

正式采样前要求：官方CFG完整轨迹与旧冻结函数逐项相同；两个组合及增强CFG在附加项强度为0时逐项退回原CFG；共享读出的strong/weak输出与原函数一致；三条非零修改轨迹与独立书写、组合调用原features接口的参考实现一致。每个采样批保存1000类标签、输入噪声SHA、最终状态及像素、full与各12层block实际计数、头计数。

沿用相同nanogen ImageNet256参考统计和特征提取器，缓存特征FP64复算FID；独立测量四臂真实采样及量化时间，不能以完整调用次数相同代替延迟结论。单独CFG没有弱头，组合MLP相对它增加整个1,777,152参数读出；仅相对CFG+原IG是净增4,608参数。比较进程加载多个小头用于切换，但每个条件前向只计算选中者。

组合本身已有先例：[IG官方实现](https://github.com/CVL-UESTC/Internal-Guidance)提供IG及与CFG配合的既有背景；[SGG](https://arxiv.org/html/2603.20584v1)也研究条件与弱模型引导。该应用测试不认领这些原则，不改变前轮请求或5K晋级规则。
