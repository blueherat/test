# RAEv2 Context MLP：延长至总计20K步

用户明确要求“训到20k再试一次”。仅延长此前Context弱读出的训练；冻结原RAEv2 EMA主干、强输出、stage1解码器、读出结构、真实数据bank、损失、优化器参数和IG设置。旧实验与停止标记保持原样。本轮不是新的机制或结构主张。

旧checkpoint仅保存3000步EMA，没有在线参数、AdamW动量或随机数状态。因此先按原种子2026121301、原初始化顺序、32批统计估计和Local/Context联合训练重放前3000步；必须逐tensor精确复现旧EMA和31个已记录训练loss，才能将重建出的Context在线参数、优化器和数据随机流接续到总计20000步。3000步以后仅更新Context。若未精确复现，先调查实现差异，不能默默从EMA重置优化器后声称精确续训。

固定batch8、AdamW(lr=3e-4, weight_decay=1e-4)、EMA=.995、时间U(.01,.99)、clean latent MSE，沿用5000个真实训练latent与1000个互斥验证latent。隐层1440、输出1024、深度8。保持学习率恒定，不以FID或验证loss挑选中间checkpoint。最终20K EMA进入采样。记录每步训练loss及100步真实平均；保留在线参数、EMA、优化器、RNG与训练历史以便继续恢复。

从3000步开始，每1000步评估固定的1000个验证latent（每类1个）以及固定的1000个训练latent（每类选第1个bank样本），分别固定噪声与时间，种子2026091401/2026091402。记录每个样本的EMA MSE及整体平均。评估使用独立随机流并核对未改变训练RNG。固定特征可缓存，以免重复前8层推理；训练不使用验证数据。另复现旧256次抽样验证值。固定验证误差下降仅说明预测拟合情况，不替代生成FID。

生成首先复用旧input_local_completion_20260912/raev2/screen_400的初始噪声和类别（400个不同类别）。只新生成20K Context原强度和半强度各400图；原生IG与旧3K Context的两档结果复用。每档先对前4张重放旧3K并核对latent和像素逐位一致。采样仍为Euler100、shift8，额外系数alpha=.78/.39，活动区间[.1,1]；官方scale=1+alpha。每图100次full、0额外prefix。原有弱头仍会计算，新增Context读出仅替换guidance中的弱预测。

在400图筛选中，20K某一档需要比两档原生IG和两档旧3K Context全部至少低2 FID，并保持IS>=原生原强度的90%，才进入新噪声1000图、覆盖全部1000类的确认。若两档均通过，优先原强度；不搜索新的系数。确认固定为原生原/半强度、3K和20K获选同强度四臂。新1K种子2026091411，同噪声同标签；FID仍用原nanogen-evals与imagenet_256_fid_stats。1K只作本轮确认，不自动扩展5K。

GPU1训练，GPU1–3协同采样；GPU0不使用。保存模型、数据、代码、旧产物和新bank身份。评价、样本覆盖、重复/丢失、head调用和full/prefix计数必须核对。生成结果与固定验证曲线均报告，包括负结果。此固定训练预算不证明已到总体最优，整个研究目标不因此自动完成。
