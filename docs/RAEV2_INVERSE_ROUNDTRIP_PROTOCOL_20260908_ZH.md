# 原生100步离散反演：已知噪声的完整往返

上一轮单步检查已通过原生像素前的latent接口核验，但最后一步有小残差
与前像误差的明显差距。本轮固定8条历史原生FP32/noTF32、B1轨迹，
从各自保存的最终latent反向求解整个100步shift8 Euler，再正向100步。

每步固定32次Picard更新，从当前反演目标本身初始化。已知原始轨迹仅
用于校验与诊断，绝不作为反演初始化、步间重置或停止条件。反演过程中
全部100个已恢复状态保存，便于独立重算噪声/轨迹误差；保存再次生成的
最终latent。比较局部残差、全程状态恢复误差、初始噪声恢复及最终往返误差。
没有解码或FID，不能将重构成功当成新样本生成成功。

每条轨迹100次原生一步parity、3300次反演调用（3200更新+100残差）、
100次正向往返，共3500次B1 Full。4张GPU各两条，合计28000次。
预计总GPU计算约.18–.22小时，墙钟约3分钟，加载/文件哈希另计。
保持固定32，不因结果逐样本调迭代次数；若失败，先明确误差来源再判断
是否值得改求解器。论文暂停，没有新增真实数据逆噪声、训练或FID任务。

脚本experiments/audit_raev2_inverse_roundtrip.py。结果大文件保存在
/home/zhoushunyu/data/eqvae/experiments/raev2_inverse_roundtrip_20260908/。
