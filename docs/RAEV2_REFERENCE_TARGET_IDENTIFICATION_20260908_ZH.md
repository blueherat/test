# 参考标签干预的识别边界

以下是标准平方损失投影与极化恒等式，用来避免错误判断实验，不作为创新点。

令Y=(z,t,c)，H是Y的确定函数，m(Y)=E[X|Y]，w(t)=1/max(t,.05)^2。
即使H不能反推出时间，条件期望的塔式法则仍给出

    E[w(F-X)|H] = E[w(F-m(Y))|H].

因此Full若等于Bayes最优m，则无限读出函数类中的两个加权最优参考相同；
同一有限线性类的总体风险最优解也相同（可识别的预测函数意义下）。
教师/真实标签之差隔离的是可由弱特征预测的Full模型误差，而非不可约标签噪声。
有限样本估计仍含标签噪声，且冻结Full并非已知Bayes最优。十组噪声控制不能
单独估计全部泛化误差，亦不能凭正内积声称已恢复真实的总体误差投影。

定义 E=(F-X)/max(t,.05)，任意两个clean读出U,V，令
R_X(U)=mean[((U-X)/max(t,.05))²]，R_F(U)类似。
逐样本、逐坐标平均有

    <(U-V)/max(t,.05), E>
      = [R_X(U)-R_X(V)-R_F(U)+R_F(V)]/2.

因此仅凭已存的配对验证风险，可检查目标切换产生的方向是否与Full误差对齐，
不需重新跑模型。该内积不是余弦，缺少U-V的范数，不能称作解释误差的比例。
CSV风险计算为FP32，此恒等式用于浮点结果时存在舍入误差。

单噪声线性拟合、1000个不同heldout图像的结果：

| U−V | 对Full误差平均内积 | 描述性配对SE |
|---|---:|---:|
| data−original | .00000549 | .000022 |
| teacher−original | .00010170 | .000010 |
| teacher−data | .00009620 | .000019 |

1000个样本为每类1张，SE仅描述样本间变异，不是多次独立训练的不确定性。
两个头各自风险退化，但相减仍存在小的标签相关信号。因此“自身MSE不改善”
不能作为否定参考差、PFR或生成质量的逻辑定理。反过来，这个正内积也不证明
参考时间响应正确、生成分布更好，或新方法已成立。

十噪声实验固定增加同图的噪声/时间覆盖，并不增加独立图像数量。它只能检验
当前固定图像集上Monte Carlo覆盖是否明显影响拟合退化；不能排除有限图像
过拟合、特征类限制及原模型训练分布差异。不得在看完结果后选轮数。
