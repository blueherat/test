# PFR 与原 IG 方向的分解检查

官方 SiT 固定独立 5K 已确认收益，RAEv2 仍无收益。
下一步检查一个替代解释：PFR 是否主要改变已有 IG 的有效强度。
此诊断不提出新方法、不根据结果选择质量参数，也不宣称局部方向决定 FID。

固定 `seed=202609431`，每模型 32 个新噪声、B4，标签均匀取 0 到 999 的
32 个整数点。运行原始 IG 轨迹 100 步；SiT scale 1.35、均匀时间网格，
RAEv2 scale 1.78、shift8 网格和原引导区间。模型使用 FP32/no TF32；
SiT 状态 FP64，RAE 状态 FP32。RAE 是精度明确的诊断，不冒充 BF16
生产采样的逐位复现。两个 latent 空间维度不同，不声称噪声逐坐标配对。

在 noise-time > .5 时，查询同一状态的未来 Base，固定 h=1/32、下限 .5。
记原 IG 强弱差为 Q=F-B，PFR 修正为 D=scale*(B-B_future)。
计算 D 对 Q 的正交分解，保存每条轨迹每个实际网格点的二阶矩。
检查精确分解和正交性；额外在 0/25/50/75 步验证廉价 prefix 与
联合 Full/Base 前向的 Base 完全一致。所有探针不写回状态。

分别汇总以下最小二乘能量解释比例：常数 scale 增量；每个时间点共享
一个增量；每样本每时间点均可不同的增量。第三项是沿 Q 做任何标量
调制在此局部欧氏度量下的上限。它不是端点质量的解释比例。
同时报告 dt 加权（连续时间场能量）和 dt² 加权（离散更新能量），
避免将不同网格密度隐含混入唯一结论。

每模型 800 个 B4 Full 调用；SiT 432、RAE 744 个 prefix 调用，
各包含 32 次 prefix 一致性检查。无训练、decoder 或 Inception，
成本预计在数分钟 GPU 计算内，加载/权重哈希另计。
源码及模型/配置源码快照保存在
`/home/zhoushunyu/data/eqvae/experiments/pfr_ig_direction_20260908`，
结果位于 `experiments/results/terminal_defect_20260908/pfr_ig_direction_{sit,raev2}.json`。

## 结果

两组均完成，SiT 会话 39553、RAE 会话 99713 正常退出。
全部 prefix 逐位一致性、FP64 正交分解检查通过。计算耗时分别
33.016 秒、65.618 秒，合计约 .02740 GPU 小时，加载/哈希另计。

| 模型与权重 | 常数增量 | 常数解释比例 | 时间函数解释比例 | 样本及时间函数解释比例 |
|---|---:|---:|---:|---:|
| SiT，dt | .00063226 | .0000382% | .15505% | 2.76623% |
| SiT，dt² | .00063226 | .0000382% | .15505% | 2.76623% |
| RAE，dt | .01538684 | .0311248% | .23294% | 1.08632% |
| RAE，dt² | .00530250 | .0118918% | .11296% | .47216% |

SiT 网格等间距，所以两种权重的比例相同。RAE 网格不同，两种
权重分别反映连续时间积分和离散更新尺度。

两模型的 PFR 修正都主要不沿原 IG 差向量。简单“强度增加”不能
重构其局部向量场；RAE 的失败也不能简单归因为它更像沿 IG 加强。
但是能量占比不等于端点质量贡献，小能量分量可能受后续动力学放大。
因此此结果不证明收益的因果方向，不足以排除调强度取得类似 FID，
更不支持“取正交分量就能修复 RAE”的方法结论。

CPU 独立检查逐行数、唯一 sample/step、调用数、捕获源码哈希和
常数回归的显式残差平方，解释比例的嵌套关系均通过。
该诊断完成，不自动扩大为 1K/5K；核心方法仍未解决。
