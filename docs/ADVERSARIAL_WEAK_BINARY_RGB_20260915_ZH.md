# 用真实RGB与外推终图直接训练二分类判别器

2026-09-15。用户要求的训练对象是实际真实图片分布P与强弱外推的最终图片分布R。最初`endpoint_binary_gan_v1`沿用了此前latent实验的VAE重建真实图作为P；它实际优化的是与重建图分布的匹配。这是一个需要明确修正的目标差别，不能将它的结果直接等同于真实RGB目标的结果。

当前`train_binary.py`已改为以下实现。上一轮完整评估结束后，已于2026-09-15 22:27（北京时间）在独立run `endpoint_binary_gan_rgb_v1`启动；没有中途修改上一轮参数或评价图片。

1. 真实侧直接读取原始训练JPEG的RGB，按现有ADM风格中心裁剪到256，再除以255；不经过VAE。
2. 数据使用同样100个ImageNet类别及全部126,689张训练图像。已按审计过的原ImageNet类别编号筛选packed训练集，逐类数量与原latent数据一致。packed顺序和latent缓存顺序不同，未将两个顺序的行号混用。
3. 假侧从新高斯噪声经过实际64步Heun强弱外推，VAE解码后采用导出中的`clamp(127.5*decode+128,0,255)/255`，保留连续值供反传。最终保存图片仍按原流程uint8截断；采样评价协议不变。
4. 判别器仍是固定Inception表征后的单输出条件二分类网络。D只学真实/外推终图，弱头只用非饱和`-log D(fake)`。不采独立强/弱端点，不增加分类或分布矩损失。

从旧最佳50K guided-weak EMA重新开始，使用相同结构、系数1.05、D/弱头学习率1e-4/1e-6，256步D预热后400步弱头更新（总656步）。后续照常完整系数扫描和前两名各5K。真实RGB版训练随机流单独可复现；由于不再抽真实VAE后验，其训练初始噪声流不与上一版逐位相同。评估始终使用同一份固定输入。

`validation/binary_real_rgb/data_check.json`记录了全量类别数量及12张真实图的读取、标签、尺寸、数值范围和随机状态恢复检查。`rendering_gradient_check.json`在两张保存latent上检查连续RGB再转uint8与原导出一致，并验证二分类弱头损失通过固定图像特征、裁剪和VAE传回latent的梯度有限且非零。这些只验证实现，不证明FID改善。

源代码快照和checkpoint中以`real_rgb_official_continuous_v2`标记本数据协议，避免与先前VAE重建真实图的版本混淆。推理仍只有原强模型与现有浅头，D和Inception仅用于训练。

判别器预热从16延长到256：上一轮短预热后立即更新弱头，完整1K及首组5K均未改善。因此本轮先让新D接触6,144对真假训练图片，再开始弱头更新，减少新D启动阶段的反馈干扰。它与真实RGB目标修正在同一轮执行，属于实际方案改进，不把结果归因于其中单独一项；没有做预热长度网格扫描。
