# RAEv2：有限势函数补空间的可观测残差检验

**状态：以下冻结协议已完成全部 100 时刻 × 1000 图的诊断；结果见文末。** 径向 witness 检出冻结子空间遗漏，但两个测试方向的同库拟合能量很小，不足以批准扩宽网络。没有新训练或 FID。上一固定势函数的配对 1K 改善仅 0.082633%，已停止。

现有 scalar potential 没有读取原始 z 的旁路：`Φ(z,t,y)=Ψ((W z_p)_p,t,y)`，`W` 为固定 checkpoint 中的 `128×1024` 输入投影。故每个 token 的 `c_p=∇_{z_p}Φ` 都属于 `row(W)`。定义正交投影 `P` 到该行空间，`Q=I−P`，则 `Qc_p=0`。本轮 CPU FP64 SVD 保留全部 128 行空间，不搜索 rank 或截断点；必须确认数值满行秩及投影精度。

这只限定当前冻结模型。训练时 W 可以转动，补空间维数不是遗漏误差比例，也不能据此宣称整个 rank128 函数族不足。旧 common adapter 的固定输出子空间也很小，但它的 checkpoint、目标和输入不同；不能把两个失败实验当成相同训练的重复。

**恰好两个事先固定的测试势。** 每类 `μ_y` 只由已用的 5K training bank 中该类全部五张原图 encoder latent 求均值，保留完整 `1024×16×16` 形状。它不是验证集残差拟合出的方向。

```text
Φ₁(z)   = ½ Σ_p z_pᵀQz_p       ; g₁ = Qz
Φ₂(z,y) = Σ_p μ_y,pᵀQz_p       ; g₂ = Qμ_y
```

两者均为合法的、可直接获得的保守方向，且逐点与旧 c 正交。记 `R=X−G_official`，实际记录逐图的维度平均 `R·g₁`、`R·g₂`、`g₁²`、`g₁·g₂`、`g₂²` 和 `R²`。不会把 `||QR||²` 的大小当作可预测误差证据。两个测试函数也共同确定围绕桥均值 `(1−t)μ_y` 的径向方向，无须再加入第三个测试或选择中心。

**单位与保证对象。** g 是 clean-correction 单位；在 dataward velocity 中，测试梯度为 `g/t`，对应显含时间的测试势 `ψ_i=Φ_i/t`。因此本轮使用原训练/验证同一个积分权重 `w_k=h_k/t_k²`，不改变时间目标。固定系数 θ 的测试场为 `Σ_i θ_i g_i/t`，其总体弱残差与能量由

```text
b_i  = Σ_k w_k E[mean_dimensions(R·g_i)]
H_ij = Σ_k w_k E[mean_dimensions(g_i·g_j)]
```

给出。由于 `c·g_i=0`，这些也是加入旧 c 后的剩余弱残差。总体上，若 H 正定，`bᵀH⁻¹b` 是完整剩余可观测误差能量的一个下界；它仅是两个固定势所张成空间中的变分值。样本 plug-in 值存在选择/估计乐观偏差，不能把其正值直接称为可靠总体下界，更不能用它宣称 FID 改善。本轮不从该值拟合或部署 guidance 系数。

非零 b 支持“当前冻结子空间遗漏可预测保守误差”。接近零只能否定这两个测试，不能排除 Q 内的各向异性、位置相关或非线性误差。现有势自身的 stationarity witness 同时保留：`Σ_k w_k E[(R−c)·c] = −0.000218965868`，描述性 SEM `0.000024626210`。已有可表示方向尚未驻点，是结构解释的竞争原因。它的统计可检出性与实际优化余量大小也需分开，不能只展示显著性。

**冻结数据与执行协议。** 复用 `potential_clean_bank_fp32_v1` 的 train5000、validation1000；均值估计与验证来源行无重叠。验证全部 `100 个查询时刻 × 1000 张图`，原 seed `202609094`，同一图像跨时刻复用同一噪声，B32、原 native BF16 `B+1.78(F−B)` 与官方区间、FP32 state、关闭 TF32，和旧验证完全一致。旧验证已看过，属于配对机制复核，不是新方法的独立确认。

CPU prepare 单独计时、校验数据及最终 potential 来源，并保存完整均值和行空间基。四个 GPU worker 只按 time index mod4 划分；每个 worker 首个 batch 重算一次旧 c 验证 Qc 数值正交，之后只调用冻结 backbone。每图旧 FP32 residual MSE 与先前验证逐项对照，新 inner product 与 Gram 用 FP64 计算。记录所有模型调用、这四次额外势梯度、数据准备、GPU 峰值、wall/CPU 时间及来源哈希，不生成或选择图像。

整体统计先在每张图内按全部时刻加权，再汇总 1000 个图像/类别；保留两 witness 的协方差及其 Gram。SEM 描述固定类别样本异质性，不把 100000 个时刻条目、通道或像素当作独立重复。逐时曲线只作描述，不用它选择时间窗口或调度。结论与后续动作待真实数据决定，至少 5% 的公平成本 FID 目标不变。

**完成结果。** 上文保留查询前冻结的设计。`W` 数值秩为 128，最小/最大奇异值为 0.103757/0.905300；FP64 行空间重建及正交误差约 `2e−15`。四个首 batch 中 `||Qc||/||c|| ≤ 1.872e−7`，逐图维度平均 `|c·g₁| ≤ 1.18e−11`、`|c·g₂| ≤ 7.26e−12`。全部 100000 项旧 FP32 residual MSE 逐位一致。

Gram 为 `[[14.9545937372, 3.4325336950], [3.4325336950, 7.0934500510]]`，特征值为 5.8056234251、16.2424203631。保留的逐图积分协方差为 `[[0.0188558260, 0.0047384494], [0.0047384494, 0.0016436862]]`。

`b₁` 约为其 SEM 的 4.85 倍；`b₂` 没有明确的非零证据。二方向同库 plug-in `bᵀH⁻¹b = 0.0000336113503`，仅为旧 coupling velocity 能量的 **0.004389%**，以及旧已获得 proxy 改善的 **0.400218%**。这是这两个测试构成的有限空间估计，**小下界不是完整补空间误差的上界**，同库估计也不是可靠的总体证书。

竞争解释同样量化：旧自身 witness 虽约为 SEM 的 −8.89 倍，但若仅在同库事后求一个全局缩放，其理论额外能量为 `0.00000542609625`，仅为旧已获得 proxy 改善的 **0.064610%**。该值只用于判断沿旧场幅度继续优化的余量；没有应用拟合系数，也没有排除其他优化误差。

**设计裁决。** 当前冻结势确实没有消除所有可预测保守误差；但这不是其 FID 失败的因果解释，也不支持直接开展 rank/宽度/时间权重搜索。纯 `ψ(Qz,t,y)` 支路会遗漏依赖 `Pz` 的补空间反馈及混合势项；`Q` 也不与密度加权梯度投影交换，不能把它称为完整剩余 Poisson 解。暂不启动该支路训练。结合[强弱模型原文阅读](RAEV2_GUIDANCE_READING_STRONG_WEAK_20260906_ZH.md)，下一步首先厘清应保留的 guidance 偏置与应消除的模型误差。
