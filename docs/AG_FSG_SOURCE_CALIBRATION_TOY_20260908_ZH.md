# 来源条件校准的首个精确密度检验

本轮保留全部后续 AG。检验的是在高噪状态先做强模型正向去噪、参考模型反向回到原噪声层的校准；不是撤除 guidance，也不是完整 FSG 复现。来源条件的 Bayes 解释见 `AG_FSG_SOURCE_CONDITION_BRIDGE_20260908_ZH.md`。

## 固定协议与结果

强密度为等权双峰 N(±2,.35²)，弱密度为同峰 N(±2,1.2²)。8192 个确定性分位点从强模型 σ=3 的精确边缘开始（不是纯高斯）。校准区间 3→2→3，重复两次。参考分别为弱密度、等权强弱混合密度；另用 (1−ρ) 松弛弱参考校准作为幅度对照。随后四组均用 γ=.78 的普通 AG，RK4 从 σ=3 积分到 0。

校准使用精确 CDF/分位数流。强流往返误差 7.11e−13；100/200 步末态差小于 6.82e−5，报告 200 步结果。W2² 为8192分位点数值积分。运行 CPU 约13.26秒，无训练或 GPU 生成。

预先固定的真实分布分量标准差 .25 下，普通 AG、弱参考、混合参考、松弛弱参考的 W2² 分别为 .0111388、.0133520、.0123339、.0122959；强模型本身为 .0099968。混合校准提高了平均强来源后验（.500643→.501609），但真实分布误差变差。普通 AG 在此目标上也无收益，故这不是充分覆盖 AG 有效情形的方法否定实验。

真实分布等于强模型时，校准也变差。真实左峰质量为 .8 而两个模型均为 .5 时，所有采样方法仍给 .5，未纠正共同模态质量错误。

## 明确标记为事后的目标族检查

保持全部已保存采样末态不变，真实分量标准差取 .05 到 .5、间隔 .025，完整报告19组，未重新采样或选择算法参数。混合校准只在 .05/.075/.1/.125 四个更窄目标上优于普通 AG；其余15组更差。更强的原始弱参考校准在这四组上又优于混合校准。混合参考与松弛弱参考在全族中接近。

这些结果与进一步收窄分布的解释相容，尚无证据证明来源混合构造带来独立于校准幅度的新作用。不能从四个有利目标选择一个宣称成功。提高来源后验不是提高真实质量的充分条件。下一方法的有效性需要区分纠正弱模型额外错误与单纯加强已有 AG；该玩具结果不授权实际模型质量提升结论。

AG 原文式(5)后的文字已经明确给出假想来源分类器解释，因此来源条件本身也不能算新贡献： https://arxiv.org/html/2406.02507v3 。与 FSG 的联系目前是研究解释和待验证校准假设，尚非成熟方法。

实现：`experiments/audit_ag_source_calibration_toy.py`。
数据：`experiments/results/terminal_defect_20260908/ag_source_calibration_toy.json`、同名 `.npz`、`ag_source_calibration_target_family.json`。研究继续，论文写作暂停。

## 后续强度对照：是否超出已有 AG 的作用

新增 `experiments/audit_ag_calibration_strength_control.py`，CPU 执行15483退出0。每8个分位点取1个拟合单个标量 δ，其他7168点检验；目标为复现已保存的校准后采样末态，不使用真实分布或质量。比较全程 γ=.78+δ，以及仅 σ∈[2,3] 增加 δ 的普通 AG。优化范围 [0,3]，六组均非边界解；这是事后机制拟合，不是提出新的调参方法。分位点留出不是独立随机样本统计确认。

| 校准组 | 全程增益解释末态改变量 | 高噪增益解释末态改变量 | 高噪 δ |
|---|---:|---:|---:|
| 弱参考 | 61.0647% | 99.9935% | 2.010682 |
| 混合参考 | 58.9163% | 99.3670% | 1.099777 |
| 松弛弱参考 | 59.5250% | 99.6564% | 1.060974 |

解释比例定义为 `1−MSE(control,calibrated)/MSE(ordinary,calibrated)`，在留出分位点计算。积分在 σ=2 精确拆段，避免强度跳变的 RK 歧义；200/400步最大末态差均小于4.84e−6。结果为 `ag_calibration_strength_control.json`。

裁决：此一维分布族中，当前校准几乎可由高噪增强 AG 复现，证据不支持将其推进为具有独立机制的新候选。不据此否定所有 FSG→IG 联系或高维可能性；也不把该事后拟合推广为 RAEv2 的经验参数。下一候选必须说明额外承载的信息是什么、为什么超出现有瞬时强弱差，以及如何区分这种作用和单纯加强 guidance。当前不启动该混合参考算子的 GPU 扩展。
