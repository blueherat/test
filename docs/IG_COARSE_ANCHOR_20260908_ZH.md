# 粗空间内容写入弱参考查询：冻结 1K 方案

全局均值版本在相同噪声的探索性 1K 上 FID 38.145579，原 IG 为 38.264239。改善仅 0.31%，尚无独立确认。本版本只扩展信息载体的空间分辨率。

同一当前状态计算 F、B；P2 是 2×2 adaptive average pooling 后按 bilinear、align_corners=False 上采样至原空间分辨率。

    zW = z + (1-t) * P2(F-B)
    W = Base(zW,t,c)
    guided_clean = F + .78*(F-W)

实际沿用 native 的 velocity 外推算术，F 与 W 均相对原 z 转速度。只改变弱查询；强模型和实际状态不提前移动。空间插值给弱参考提供粗布局差异，是否改善质量由完整采样裁决，不将其称为已证实的语义信息。
