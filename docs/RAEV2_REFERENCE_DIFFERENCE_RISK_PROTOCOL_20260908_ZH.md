# 参考差的单位系数泛化检验

冻结已完成的单噪声、十噪声读出，不增加训练。验证相同1000独立图像、
seed202609420、B16、官方shift8时间、条件标签不drop，原Full/Base不改。
令 e=(F-X)/max(t,.05)，d=(W_teacher-W_data)/max(t,.05)。
此前内积 <e,d> 为正，但缺少 ||d||²，不能说明去除d能减少预测风险。
本轮记录逐样本 mean(e*d)、mean(d²)、mean(e²)及

    risk(e-d)-risk(e) = mean(d²)-2 mean(e*d).

系数固定1，不搜索缩放、时间段、checkpoint。若总体线性投影已恢复，训练
分布上应满足 <e,d>=||d||²；独立验证可以不满足。这个检验只判断参考差能否
作为可泛化的单位系数误差估计，不证明PFR质量；更不启动旧X-F适配器路线。
检查原Base和四个已存读出的逐样本MSE重现，直接风险差与恒等式数值一致。
十噪声训练集的FP64投影恒等式另由已存充分统计量CPU计算。
预计低于 .02 GPU小时；无生成采样、无论文写作。
