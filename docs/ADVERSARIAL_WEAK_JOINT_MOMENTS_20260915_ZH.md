# 弱头的联合端点分布目标

2026-09-15，`endpoint_joint_moments_v1`。前一版边际特征矩目标完整5K失败后，检验条件信息是否需要显式进入弱头的终点目标。完整1K系数扫描及两个5K已完成，最好5K为36.81170594，仍差于历史最好36.68884780。

## 定义和动机

仍用P/G/Q/R四源训练同一个类别条件判别器，强模型冻结，弱头只通过实际引导终点R接收梯度。前一版G-step只比较D的256维图像表征h。D的分类logit虽然依赖类别，G-step中的h本身没有保留明确的类别身份；混合后的图像矩相同并不要求图像与给定类别对应。

在每次当前D的真实校准后，定义联合特征

\[
u(x,c)=\left[\bar h_D(x),\ \operatorname{diag}(\hat\pi)^{-1/2}(e_c-\hat\pi)\right].
\]

hat_pi来自当前缓存的类别频率。P/R每行具有相同类别，所以两侧类别边际完全相同。缺失类别的分母下限为1/M，它在两侧对应恒为零的坐标。弱头最小化P和R在u空间的Fréchet矩距离；没有增加可扫描的类别权重。256维图像坐标沿用原真实校准，类别坐标保留固定语义，不再对整个拼接向量做额外旋转白化。

对原始one-hot有 Cov(h,e_c)=pi_c(mu_c-mu)。因此共同类别先验下，联合一、二阶矩相等还约束每类特征均值，而单纯边际图像矩没有这个性质。它仍不能识别任意高阶分布差异，也不等于对每一类分别计算完整Fréchet距离。有限的标签尺度不构成严格禁止跨类的最优传输代价。

当前5K失败是否真的来自类别偏差未被证明。这是一个明确排除目标退化的实验，而不是根据IS下降宣称已经诊断了类别坍缩。继续保留原FID评估，不用新定义的训练距离替代质量成绩。

## 与已有工作的关系

[On the Evaluation of Conditional GANs](https://arxiv.org/abs/1907.08175) 已提出拼接图像和条件表征的Fréchet Joint Distance用于评价。当前联合矩思想不是新发现；其用途在这里是让冻结强模型的浅弱头通过实际引导终点学习。

[Image Generation Via Minimizing Fréchet Distance in Discriminator Feature Space](https://arxiv.org/abs/2003.11774) 已采用分类训练D、生成器最小化D特征中的Fréchet距离。上一版与它更直接相关，不能仅援引2026年的AdvFD来暗示这种损失组合此前不存在。当前变化包括冻结扩散主干、共享浅头、完整原采样器反传、四源辅助D和在线缓存；这些组合是否足以构成研究贡献，首先取决于真实效果。

小样本FID的偏差可能因生成模型而异，见[Chong与Forsyth，CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Chong_Effectively_Unbiased_FID_and_Inception_Score_and_Where_to_Find_CVPR_2020_paper.html)。因此1K改善不保证5K排序相同；该已知现象不是对这次失败原因的唯一解释。仍按用户要求保留0.4→0.2→0.1→0.025连通搜索、最佳两个系数扩至5K。

## 实现、检查和范围

实现为 `joint_moment_objective.py` 的 `JointMomentFeedback`，复用原训练器的完整离散反传。缓存增加P/R共同的类别标签；模型、判别器、优化器、两组特征缓存和标签一起保存，各rank检查一致性。

独立实现检查中，只在类别间置换一批特征，边际距离约0而联合距离3.16282738；它验证损失能够辨别条件错配，不是图像质量实验。方向有限差分在归一化扰动0.03和0.01下分别与自动梯度相差6.9e-9和5.7e-11。更小扰动出现差分消减误差，全部数值另存，未将其解释成训练改善。

训练从边际目标600步完整状态开始，目标总步数1000，其中新增联合目标400步。GPU0/1/2/3均参与，全局batch24。学习率W=1e-6、D=1e-4、EMA=.99、训练引导系数1.0、64步Heun和半程窗保持原设定。从三卡变成四卡只恢复已有rank的保存RNG，新rank使用独立种子，明确记录数据流变化。此续训同时增加了训练时间，若获得改善，不能单凭它精确归因于条件项。

训练后先同系数1K比较EMA和当前权重，较低者进入完整扫描；这轮不会因同系数未改善而跳过扫描。最终仍以同噪声、同推理预算的5K和实际图像判断能否超过历史最好36.68884780。

## 完整质量结果

EMA被固定同系数规则选中。0.4→0.2→0.1→0.025连通扫描后，a=1.125/1.175的1K分别63.81468561/63.84312592；对应5K分别36.81170594/37.04713663。最好比标准diffusion头的36.90945189低0.09774596，但比历史guided-weak最好高0.12285814。当前没有超过全部历史结果，也不由这点差距声称统计显著。

两个5K由已核对数值精度的原ADM CUDA FP32路径完成。`search_step001000_ema_full/comparison_audit.json`核对相同输入、参考统计、128次强模型调用、64次浅头调用和原1K前缀复用。5K包含选择所用1K，不是独立留出集。
