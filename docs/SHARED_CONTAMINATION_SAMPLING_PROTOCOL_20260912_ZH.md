# 共同污染假设：直接采样检验

用户已明确要求保留“理想分布＋同一个误差分布”作为主线。输入局部读出训练产物保留，生成实验暂缓。本协议直接检验共同污染推导，分别用于 CFG 和 IG。

## 从假设到可执行系数

$q_S=(1-\kappa)q_\star+\kappa q_R$ 给出弱参考来源责任度 $\rho=\kappa q_R/q_S$ 和精确流系数 $\gamma=\rho/(1-\rho)$。$R$ 对 IG 为窗口内弱场、对 CFG 为窗口内 null 场；窗口外两者回到 Strong。$\kappa$ 是预先冻结的端点特征矩拟合值，不能依据生成 FID 调整；每个模型、每条主线只估计一个全局比例。

密度比由真实两源采样状态上的、来源平衡的二分类器估计。它读共享浅层特征，只增加小 head。特征不充分、分类误差、离散求解器，以及混合关系不准确，都会使其偏离真实比值；不把这个实现称为精确密度采样。第一求解器查询强制 log ratio=0，因为两源初始噪声完全相同。

为避免估计比值跨过正性边界，唯一候选使用 $\tilde\rho=\min(\hat\rho,2/3)$、$\gamma=\tilde\rho/(1-\tilde\rho)$，因此最大附加强度固定为2。**上限2是数值保护，不是混合定理；不扫描这个数，也不隐瞒触发频率。** 未触发上限处采用原公式。逐查询保存预测概率、正性边界越界标记与保护触发标记。成功最多先说明“有保护的去污染实现有效”，不能反推严格共同污染成立。

## 来源头与固定对照

IG 复用上一轮真实 S/W 轨迹训练并经过独立温度校准的冻结来源头，不重新训练或按结果挑 head。其比例在本轮新端点数据首500样本上拟合，和旧来源头无样本重合。时间均值控制使用旧来源数据 audit 的100条 Strong 路径，不读取新生成 FID。

CFG 新收集800对 S/null 路径：前600对训练，接着100对温度校准，最后100对来源审计／固定时间均值控制。种子2026121321；来源头结构、2000步 AdamW lr=.001、batch512、无 weight decay 沿用已有 IG 头。所有来源都在**条件前缀特征**上分类：null 路径的条件前缀仅在离线收集时另算，部署时从原 CFG 已有条件前向取得。因此部署 CFG 保留原条件／无条件两次完整调用；IG 保留一次完整共享主干。来源头与原 denoiser 均无 teacher 拟合。

固定6臂：inverse（上述候选）、time_mean（在来源审计 Strong 路径上的候选逐时间均值）、moment_constant（初始同噪声下的候选系数，窗口内不变）、native_base、native_half、constant_cap2（窗口内恒为2）。只有 inverse 是本轮方法候选，其余都是必需的幅度／时间对照。不进行额外 gain 或 schedule 搜索。

每个模型、每条主线、每臂400个独立样本；使用种子2026121331（IG）与2026121341（CFG），同臂间匹配噪声与类别。只生成一条路径，不额外生成配对分支。SiT Heun64，RAE Euler100 shift8，原 CFG／IG 窗口不变。两个模型从起点纳入。RAE 的400类覆盖问题与小样本 FID 偏差明确保留。

候选须比同组全部5个控制至少好2 FID，且 IS 不低于 native_base 的90%，才能用全新1000样本确认；否则不自动升5K。实际 wall time 与每样本 full/prefix 调用单独记录。若头／比例／数据检查失败，先修正实现并留存失败版本，不把失败运行产生的数字当质量证据。

## 对假设的独立检验

除端点矩留出检验外，来源审计直接统计事件 $A_t=\{\hat q_S/\hat q_R<\kappa\}$ 的两源频率。如果真实共同混合成立，任意事件应满足 $Q_S(A_t)-\kappa Q_R(A_t)\geq0$，这条频率关系不要求分类器给出精确密度比。沿完整同一 seed 聚合和重采样，不能把多个时间点冒充独立样本。所得证据仍受100个来源 seed、小样本和类别覆盖限制。
