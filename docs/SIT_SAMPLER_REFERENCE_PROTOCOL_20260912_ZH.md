# 参考训练数据的生成器来源交叉实验

前一轮直接最小化最终 guided velocity 的真实数据 MSE，没有胜过同预算原目标续训。该失败不自动归因于 target variance，也不通过增加训练步数修补。本轮改动唯一核心对象：参考分支学习的数据分布。

弱参考若拟合当前生成器实际产生的分布 q，强预测若近似真实分布 p 的 score，则二者之差近似 ∇log(p/q)。在固定噪声层、精确正密度、合适边界条件下，以这个场输运 q，会得到 d KL(q||p)/dτ = −E_q||∇log(q/p)||²。这是已有 KL 梯度流恒等式，不是本轮新定理。它说明选择 q 为“实际输出分布”的解释价值：它针对生成器过度产生的模式。任意较差或更平滑的参考并不具备同一关系。

实际算法仍为 S+a(S−W)，不会添加 KL 梯度或任何探针。噪声时间在变化、strong 不是精确 score、浅层 W 也不是精确 q score，所以恒等式不保证真实采样改善。CFG 的 null 只拟合类别混合 q，而不是各类 q_c；因此更不能把上述条件 KL 保证直接用于 CFG。两条线各自检验质量。

“用自己生成的样本训练负参考”已有 SIMS；“冻结主干，用合成样本训练内部参考”已有 SSG。SSG 主要采用像素模型及额外 transformer adapter，本轮 latent SiT 的原尺寸读出不构成其完整复现。本轮不是把这些配方认领为新方法，而是交叉训练数据来源，检验收益是否需要匹配当前采样器的偏差，而非笼统归于弱模型更差或合成样本更好。[SSG 原文及最近邻](https://arxiv.org/html/2607.29122v1#S2.SS3)。

冻结 SiT-S/2 800K EMA 及原 depth4_v 读出初始化。分别由原始 IG 和原始 CFG、相同新噪声 seed=2026121014 生成各 2000 个 class-balanced clean latents，直接保留连续 latent，不解码再编码，不按质量或置信度筛选。每类 20 个；2K 规模仅是限定成本下的筛查，不能据阴性结果否定大数据 SSG。第三份 real 数据从已有互斥 train pool 每类取固定 20 个原图，并固定抽取一次 VAE posterior，避免 real 组拥有更多样本或额外增强。记录所有原图位置、随机种子和文件哈希。生成训练集的噪声独立于正式 FID 输入。

两种读出各训练三组：real、IG 生成数据、CFG 生成数据，共六个训练。全部使用原始 flow-matching 目标 X−ε，1500 steps、batch32、AdamW lr=1e−4、betas=(.9,.999)、weight_decay=0、clip1、EMA .995、最终 EMA；不选 checkpoint。IG 仅原 depth4 readout，CFG 仅原尺寸 null final readout，strong 全部冻结。IG 时间范围(.01,.5)，CFG(.01,.75)，IG .1 label dropout。每条线三组共享完全相同的样本索引、噪声、时间与标签随机流；clean 数据不同，因而 z 和目标必然不同。验证仍用独立真实 validation pool，仅报告不选权重。

正式质量十组各 1K：IG 原始/real/IG-data/CFG-data，CFG 原始/real/IG-data/CFG-data，既有 ADG 和 APG。沿用原探索 bank 202610100；不得称为独立确认。原强度和区间不变，Heun64；IG 为128 full/0 prefix，CFG为224 full/0 prefix，另报实测采样时间与一次性合成数据、训练成本。禁止独立弱前缀、额外主干查询、强度网格及旧队列恢复。

主要问题是每条线的合成组是否同时优于原始、相同数据规模 real 续训及已有 ADG/APG 至少 .5 FID。满足才冻结现有配置进入独立5K；否则本构造停止。每条线两种合成来源是预先指定的对照，若都满足则选择本线 FID 更低者进入确认，并明确探索选择。来源交叉若呈现“各用自己的数据更好”，只作为与偏差匹配假设一致的证据；该交互不等于质量成功，也不排除容量、优化和训练集覆盖的解释。

运行前继承原路径、零引导和 strong 不变检查，验证新数据类别、索引覆盖及完整哈希。正式结果逐组检查原始输出哈希、coverage、FP64缓存FID/sFID复算。没有阈值外的后续自动调参。
