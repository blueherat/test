# CFG-FSG 查询一致性：固定 1K 结果

查询位置与时间对齐减少了原候选的退化，但没有超过普通 CFG。
本结果不支持扩大到 5K，也不构成新的核心方法。

|方法|FID ↓|独立 FP64 FID|IS ↑|采样秒|
|---|---:|---:|---:|---:|
|普通 CFG Euler110|40.55116805|40.55118727|68.85013|1744.1751|
|原异步查询|54.34304792|54.34306461|69.72189|1738.8834|
|状态/时间一致查询|44.28301166|44.28302752|72.99749|1752.6447|

三组均为同一 EMA、CFG2、seed202609413、batch4、1000 类各一张，
每张 220 次 Full 分支前向。新增候选采样耗时 0.48685 GPU 小时，
模型加载、8 张检查与评估另计，无训练。

候选只把 q=z−hG 改成 q=z−HG，与未来时间 t−H 配对；
写回仍为 z+h[U(q,t−H)−G(z,t)]，h=.025、H=.125。
它降低局部查询误差，也降低了原异步候选的 FID，但 FID 仍比
同预算普通 CFG 高 3.73184。IS 升高不能替代 FID 的退化。
这只否定当前固定配置的净质量收益，不能据此否定原论文的完整
DDIM/CFG++ 算法，也不能把剩余差距归因于 RAE 表征本身。

采样驱动会话 60150 正常退出；独立核验会话 65403 正常退出。
核验包括：原生 Full-only 8 张像素一致；方法 smoke 与 1K 前 8 张
像素一致；噪声、标签、模型、实际调用数、评估版本和样本哈希一致；
冻结源码仅包含预定两行变更，依赖源码逐字节一致。
从保存的 Inception 特征独立 FP64 Gram 复算三组 FID，最大差异
1.93e-5。结果见 `experiments/results/terminal_defect_20260908/raev2_cfg_fsg_consistent.csv`。

阶段决策：结束这组查询一致性质量控制，不进行 H/h、事件位置搜索，
不自动扩大到 5K。后续核心问题仍是条件写入目标为什么改善最终分布，
而不只是如何更准确地完成局部往返。论文写作保持暂停。

使用同一批保存特征分解 FP64 FID，没有再调用生成模型：

|方法|均值项|协方差项|生成特征协方差 trace|

一致查询相对普通 CFG 的剩余 FID 差距中，均值项增加 2.784712，
协方差项增加 .947128；约 74.6% 来自均值项。因此不能只用
“类内多样性压缩”解释当前失败。反过来，pooled Inception trace
也不等于类内多样性或语义正确率，1K 每类一张尤其不能识别类内方差。
不使用评估参考均值直接修正样本或调参。
