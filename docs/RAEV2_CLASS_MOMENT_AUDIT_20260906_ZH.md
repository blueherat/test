# RAEv2 raw latent 类内／类间矩审计

**两个完整 5K bank 均显示：IG 的总体方差修复同时包含类内扩张和类间中心散布下降。** 这一区分在原训练类和留出类中保持同方向，但不支持把完整变化解释成一个简单缩放，也没有导出新的 guidance 或 FID 结果。

本次只读旧 `raev2_ig_scale_response/n5000_seed20260801_scales7_v1` 与 `n5000_seed20260802_scales7_v1`，每类恰好 5 张，保留原 800 个训练类／200 个留出类。三个分支为 `latents/real_rank*.npy`、`scale_s1p000000_rank*.npy` 和 `scale_s1p780000_rank*.npy`，按 `global_id = rank + 4 × local_row` 配对。这里 **real 是原图的归一化 encoder latent `E(x)`**；它不是 `decoded/real` 的重构图 `D(E(x))`，也不是 roundtrip 的 `E(D(E(x)))`。没有新特征、解码、聚类或大协方差矩阵。

**冻结定义与统计假设。** 每类样本数 `m=5`，所选类别数为 `C`，类别均值为 `μ_c`，全局均值为 `μ`，维度为 262144。以下都是 covariance 的 trace，没有除以 latent 维度：

- `T = Σ_ci ||x_ci−μ||² / (mC−1)`：经验 pooled trace。
- `W = mean_c[Σ_i ||x_ci−μ_c||² / (m−1)]`：平均类内样本协方差 trace。
- `B = Σ_c ||μ_c−μ||² / (C−1)`：观测到的类均值散布。
- `B* = B−W/m`：扣除每类只有 5 张造成的均值估计噪声；**不裁剪负值**。对应均匀类别先验的类间 covariance trace 为 `(C−1)B*/C`。

精确 ANOVA 恒等式为 `T = W + m(C−1)B*/(mC−1)`。因此 IG−Full 的 pooled 变化可以直接拆成类内变化及修正类间项的变化，而不是把均值估计噪声误认为真实类间信号。

期望意义上的修正要求每类观测代表同一类条件总体，真实图像与生成噪声在给定类别后独立；Full/IG 则保留同噪声配对。不同类的真实均值可以不同，坐标可以相关，不要求类内 Gaussian 或各坐标独立。实际真实图像从有限 ImageNet 类别中无放回抽取；这里不把上述类条件抽样模型的修正宣称为条件于完整已实现 ImageNet 数据集的精确有限总体均值风险证书。类别覆盖固定且均匀，类别标签也不等于已识别的语义 mode。

**与旧报告的口径核对。** 旧 `scale_response_metrics.csv` 中名为 `mean_variance_ratio` 的量，源码实际计算 `mean(candidate_variance)/mean(real_variance)`，也是 trace ratio；它不是逐坐标 variance ratio 的平均。旧实现只用原 4000 张训练图，因此旧 Full 值 **0.9669650676／0.9659612804** 与本次 **train** 行逐值一致，和 **all** 行的 0.9679785885／0.9649610174 不同来自样本集合变化。IG 的旧值也与 train 行一致，四项最大差约 10⁻¹⁵。旧计算的方差分母与本次 ddof=1 分母不同，但同样本量分子／分母的公共因子在比值中抵消。源码定位为 `run_raev2_scale_response_study.py:785–820`；机器归档保存旧 CSV 的哈希和逐项对照。下述加性噪声的 PSD 必要条件针对 trace，不应以 mean of coordinate-wise ratios 替代。

这里 `Δ = IG−Full`。中心 cross-scatter 也扣除配对均值噪声：`C_FI* = C_FI−W_FI/m`，`B_Δ* = B_F*+B_I*−2C_FI*`；末列为 `(C_FI*−B_F*) / sqrt(B_F* B_Δ*)`。这些噪声修正后的比值是估计量，不强行限制在 cosine 范围内。

约 0.996 的中心 Full/IG 相关主要说明两者共享很大的类间结构，不能说明较小的 guidance 位移沿该结构方向。若所有类中心只是围绕同一中心乘一个共同收缩系数，即使允许共同平移，去掉全局均值后末列仍应为 −1；实测约 −0.63／−0.62。另一方面，围绕各类不动中心的单一正缩放要求类内 pair alignment 为 1，而实测约 0.805，且中心确实移动。当前数据支持两种矩响应同时存在，不支持这些简单模型足以描述全部变化。训练／留出类的所有派生量也保存在机器归档。

**方差靠近不等于类中心更准确。** 对 real/生成两个独立条件样本均值，类中心平方距离修正为 `mean_c ||μ_g,c−μ_real,c||²−(W_g+W_real)/m`。Full/IG 是配对样本，二者距离改用 `W_Δ/m` 扣除噪声。全局均值平方距离相应扣除 `1/C` 倍的噪声项。负修正值保持负数，不给出其虚假的实数平方根。

噪声扣除是约八万减去另一个约八万，剩余量须按有限样本估计理解；本轮没有新增置信区间或总体改善证书。

**热扩散解释的限定。** 如果 Full 相对真实 raw encoder-latent 分布只叠加独立零均值噪声，则卷积会增加非负的 covariance trace。观察到的 Full pooled 欠方差，以及更明显的类内欠方差，不支持这种“仅独立加性热扩散”的解释。这里没有测 Base-only endpoint 分布，不能把结果扩大成 Base/Full 之间所有模糊关系均被否定，也不排除其他类内模糊、状态依赖形变或温度机制。trace、均值和这些配对几何都不足以识别完整密度或 mode mass，更不是 FID。
