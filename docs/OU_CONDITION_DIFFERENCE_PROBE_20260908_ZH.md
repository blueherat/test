# 同一强模型的OU时间×条件差分：几何探针

已核对RAEV2_GUIDANCE_READING_DOUBLE_DIFFERENCE_20260906_ZH.md。双差代数本身
不是新意；本轮不使用Full/Base×条件误差作为纠偏，而测同一Full的跨时证书。
定义D_c为条件Full的degree1 OU velocity certificate，D_u为空标签Full的
相同证书，D_post=D_c-D_u。对于同一个自洽联合分布的精确score，条件减
无条件等于条件后验log概率梯度；再施加同一个跨尺度算子得到它的时间变化。
网络、离散velocity单位和近似误差不自动满足该密度解释；不声称FID定理。

冻结SiT-v800和RAE100080EMA，空标签分别100/1000（既有条件擦除研究已核对
两者有null训练）。seed202609424，每24个label ID各4个独立标准Gaussian
OU坐标；data time=.05/.1/.2，h=1/32。四组相同状态与时间查询：条件当前/
未来OU、无条件当前/未来OU；另在原raw位置查询未来条件Base得到原时间修正。
记录三种方向的能量及与raw revision的余弦，不拟合权重、不挑时间或方向。
标签ID不跨模型对应相同语义，不作为配对跨模型因果试验。SiT FP32、RAE BF16。

无新增训练、解码或质量采样；预计模型计算低于 .02 GPU小时。非零分量或
较大余弦只说明方向可区别，不能作为质量改善证据。本轮先补机制可识别性。

## 完成结果

| 模型/data time | cos(raw,D_c) | cos(raw,D_post) | cos(raw,D_u) |
|---|---:|---:|---:|
| SiT .05 | .776619 | .169136 | .679906 |
| SiT .10 | .651607 | .180218 | .581199 |
| SiT .20 | .328914 | .145991 | .284793 |
| RAE .05 | .619665 | .196773 | .433597 |
| RAE .10 | .458328 | .075945 | .388404 |
| RAE .20 | .353708 | .029918 | .326285 |

条件/无条件证书余弦SiT为.808/.855/.917，RAE为.536/.614/.742。
条件差分非零且改变方向，但与raw的平均对齐远弱于完整证书。不能把D_u
简单称为有害公共噪声，或认为删除它仅是无害净化。该probe未评价生成质量，
平均余弦低也不是质量无效的定理；不基于这些数字选择比例或启动幅值恢复。
RAE BF16结果尚未单独做该差分的FP32复验，不把细小余弦差当作高精度机制。

两模型各96样本×3时刻，模型计算SiT2.110秒、RAE11.734秒；程序正常结束、
输出有限、逐时样本数检查通过。没有对原生生成轨迹或精确联合密度做验证，
故D_post是算子名称而非已认证的真实posterior梯度。新方法仍未成立。
