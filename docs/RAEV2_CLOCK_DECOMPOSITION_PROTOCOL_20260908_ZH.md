# RAEv2 时钟校准的逐项诊断

冻结时已知四组1K：ordinary100 38.2642、ordinary110 38.3926、short 38.9395、
asynchronous 48.9723；time_only尚未完成。SiT同场控制已经完成，IG同场async
64.7713与原64.6155接近，不能认定双场身份差异是必要机制。

不新增质量候选，不调参数。固定32个新样本，seed202609414，标签0–31，B4，
原RAEv2模型/BF16/shift8 Euler100/IG1.78，仅沿ordinary100轨迹测量。
在现有事件索引0、54、83取状态。h=.025，H分别为.025和.125。
G为生成方向IG场，R=2S−G，q=z+hG。校准改变量精确分解为：

- contrast = h[G(z,t)−R(z,t)]；
- clock = h[R(z,t)−R(z,t−H)]；
- state = h[R(z,t−H)−R(q,t−H)]。

逐样本保存三项和总和的RMS、与原生一步的比值、项间余弦；核对代数残差。
测量不写回轨迹，不解码、不计算FID、不选择新h/H。最多32×约120次模型前向，
预计小于0.03 GPU小时（模型加载除外），记录实际时间。
单一模型、32类和原生轨迹的诊断只能定位数量级与方向，不能确立跨模型因果，
也不表示沿多次校准轨迹的行为相同。后续是否扩展取决于是否发现可检验机制。

## 实测结果

32样本完成，采样/测量28.515秒、896次B4模型调用；全部代数核对通过。
逐样本结果在`experiments/results/terminal_defect_20260908/raev2_clock_decomposition_per_sample.csv`。
下表是逐样本比值的平均，每次校准相对于该位置原生一步的RMS比：

| index | H | contrast | clock | state | total |
|---|---:|---:|---:|---:|---:|
| 0 | .025 | 2.533 | 7.312 | 8.372 | 5.014 |
| 0 | .125 | 2.533 | 10.261 | 2.886 | 9.370 |
| 54 | .025 | 1.479 | .370 | .396 | 1.429 |
| 54 | .125 | 1.479 | 1.704 | .673 | 1.966 |
| 83 | .025 | .499 | .061 | .062 | .507 |
| 83 | .125 | .499 | .253 | .073 | .540 |

这些是向量范数，分项不能标量相加。初始short的clock/state余弦均值−.808，
async为−.616：明显存在抵消。原生首步RMS只有.001406，因此不能将9.37倍直接
称作latent爆炸。async在三个事件的total/latent RMS分别为1.319%、1.357%、
1.742%，数量级接近，初始事件并非绝对改变量最大。

可检验的线索是初始事件对时间查询的响应及其抵消关系，而非已证明的幅度失控。
这项诊断不支持直接据此缩小h或删掉第一个事件后宣称机制成立。
