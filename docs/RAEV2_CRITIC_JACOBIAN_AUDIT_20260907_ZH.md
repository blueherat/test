# 判别器方向上的去噪器 Jacobian：固定 CPU 检查

2026-09-07。没有新采样或 FID。此前两个固定 critic 1K 和后续 two_mode 队列继续运行，没有改动其源码或设置。本检查只回答总体 MSE 的球形后验近似是否遗漏明显的局部模型响应。

相关公式来自 [On the Guidance of Flow Matching §3.3 / A.12](https://arxiv.org/html/2502.02150v3)：在独立 Gaussian 噪声路径且去噪器等于真实条件均值时，后验协方差与去噪器 Jacobian 成正比。原文将其文字写作 inverse covariance，但所列公式及证明实际对应 covariance；本处直接由条件期望微分重建，避免继承文字误称。

本地坐标为 z=aX+tε，a=1−t。对任意满足可微、可积条件的真实 posterior mean m(z)，逐坐标微分 Gaussian 条件密度得到

    ∂m_i/∂z_j = a/t² · Cov(X_i,X_j | z).

故 C=(t²/a)J_m，C 是对称半正定。若 r 是 clean 图像质量势，其局部 tilt 为 δm=C∇r(m)。对于对称的理想 J_m，可用一次反向传播计算 (t²/a)J_mᵀ∇r(m)。实际 native IG 的 Jacobian 无对称/半正定保证，直接反向传播不能凭这个恒等式变成真实 posterior covariance。

检查使用旧缓存固定 id0/class0 的全部10个时刻，重新载入同一 EMA，CPU16线程。模型、decoder、DINO 都是FP32连续近似，CLS单位化用FP64；不是当前native BF16采样的逐位导数。令G为FP32 IG，g=∇r(G)，分别计算J_Gᵀg与J_Fᵀg。每个时刻都记录，不按效果选择。

t=1不计算t²/a。此时真实条件均值不依赖z，故J_m=0；有限模型的J_Gᵀg却非零，RMS为0.00030772，不能用除零或任意clamp掩盖这一边界失配。当前缓存也没有覆盖t∈(.9,1)的其余46个时刻，不能推断这些时刻全部安全。

在t=.4972，输入方向上的中心差分为0.19291378，autograd为0.19292623，相对差约0.00645%；全部10个VJP有限。沿g的Full与IG Rayleigh量都为正，但这只检查一个方向，不能证明全Jacobian对称或PSD。主要计算26.938秒CPU墙钟，不含模型加载与来源摘要。

得到的实质信息：球形近似遗漏的可能是方向和条件几何，而不只是单一全局强度；t≈.9时两种修正几乎正交。它尚不足以推出哪个方向能改善最终图像，代理上升不是FID。此处不增加第三个critic采样臂，也不以单图结果选择窗口。若后续研究真实Jacobian版本，必须先处理纯噪声端点及近端误差放大，并计入主模型反向传播成本。
