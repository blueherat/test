# 原生轨迹上的类别与强弱来源交互

内部条件载体1K失败后，本项检查一个具体混杂解释：同类别Full/Base差值是否大量来自类别偏好差异。已有 `RAEV2_GUIDANCE_READING_DOUBLE_DIFFERENCE_20260906_ZH.md` 给出四路理论及先例，本轮不重复宣称新恒等式，而补实际模型测量。没有新采样算法、训练或质量指标。

固定同一z,t，记Fc/Bc为类别c的Full/Base预测，Fu/Bu为训练过的null=1000分支。定义

    dc=Fc−Bc，du=Fu−Bu，I=(Fc−Fu)−(Bc−Bu)，dc=du+I。

只有在各模型条件族与边缘构成自洽联合分布、且score准确时，对应score双差才是强弱类别后验比的梯度。此处是clean预测的有限向量分解；不使用该后验解释作数值估计，特别不在t=1套用奇异换算。不把du称为已证明的纯质量信号。

## 固定观测与结果

复用8条原生FP32/noTF32/B1轨迹，类别0/142/285/428/570/713/856/999；固定步骤0/47/73/87，未按新数据挑时刻。每个状态查询有类别及null各一次Full模型，同时取得Base。32组有类别Full/Base输出与此前保存的原生head逐位相等，初始状态SHA、checkpoint及原head文件SHA绑定通过。

执行47356退出0，64次完整模型样本调用，查询及文件保存7.819秒，加载/哈希另计。保存四路原始预测，由CPU42177独立重算全部Gram与分解恒等式并核对源文件身份，退出0。

起点的类别交互很大，并与null差值部分抵消；从.90021起，条件与null强弱差值已非常接近。因此，“IG中后段主要混入强弱类别偏好差异”的解释不受这组轨迹支持。此事实与状态已承载类别选择的FSG直觉相容，但没有估计互信息，没有证明完整续生成一致，更不能推出可以撤条件或撤guidance。

## 对下一步的限制

不由起点较大的I直接推出应该删除它；它可能是有益类别选择。也不由中后段I小推出IG没有作用：剩余du几乎保留整个强弱差，生成质量机制仍待解释。当前没有足够依据启动“剔除类别交互”的完整采样，更不能以四路差分的形式宣称新意。

当前证据把后续问题收窄为：在类别选择已基本由状态体现时，强弱差究竟表达哪些与质量有关的结构缺口，什么样的编码/读取能改善它们。该问题尚未转化为有效方法，不补写质量保证或论文。
