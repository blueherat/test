# RAEv2 真正条件/无条件 FSG 固定对照

在生成结果之前固定。既有RAE FSG使用合成参考2Full−IG，不能直接解释成
无条件场。本次使用训练过的null=1000完整模型分支，G=U+2(C−U)，因此
校准参考2C−G恰为U。CFG=2沿用现有FSG代数的外推因子，不宣称是RAE最优值。

两组：普通CFG Euler110；CFG Euler100加既有异步校准。校准grid事件与旧实验
相同：noise-time1/.875/.625对应2/2/1次，h=.025，H=.125，保留当前前向与
未来反向查询。两组实际每张220次完整模型分支查询，没有免费的null分支。
普通采样全程使用CFG2，校准后也继续CFG2；这是仓库clock-transfer对照，
不是声称完整复现FSG原文的DDIM/CFG++算法。

EMA100080、官方shift8、BF16/TF32、batch4、seed202609413 continuous、
1000类各1张，配对noise/labels。每组先用CFG1的8张与native Full-only像素
比较，再本方法8张检查，最后1K与官方FID。最终独立特征Gram复核并检查
输入/模型/源码/调用数。主要比较两组等调用预算，不能把它与IG原生基线的
绝对差直接归因于表示，也不能以弱CFG基线上的相对收益称RAE突破。

无训练，预计两组采样合计约.9 GPU小时，加载/评估另计。不搜索CFG强度、
时钟或窗口，不自动扩展5K。论文保持暂停。
