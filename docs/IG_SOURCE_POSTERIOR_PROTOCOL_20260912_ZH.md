# 用户粘贴方案的真实生成验证：IG来源后验

2026-09-12。该来源后验构造由用户本次明确要求验证；先跑真实模型效果，不增加toy或复杂理论准入。模型与原弱头均冻结，SiT-S/2与RAEv2同时准备，不训练新的去噪器。

各模型从新1000个训练噪声／200个保留噪声出发，分别运行仅Strong与仅Weak的实际采样路径。保存guidance启用区间的实际数值求解器查询特征；SiT包含Heun的接受状态与预测查询，分类器额外条件化于子阶段。这是明确的离散查询分布，不能直接声称得到精确连续边缘后验。没有把终点重新加噪，没有teacher预测标签，也没有使用生成质量给来源分类器打标签。离线Weak路径可使用原共享前缀，部署仍只有原一次主干前向。

来源目标为Strong=1、Weak=0，混合先验各半。特征取原第四层／第八层的前256个空间token均值；这只是现成中间表示，未被证明是来源后验的充分统计量。读出固定为标准化特征＋时间＋求解子阶段→128维SiLU→一个logit，2000步AdamW，batch512，lr.001，wd0；只取最后权重，不选最优保留集checkpoint。训练／验证按完整初始轨迹切开，所有时间查询一起归属其轨迹，避免同轨迹数据泄漏。保留集BCE/Brier/ECE仅检查来源分类，不替代生成质量。

质量采样额外强度以既有IG为a：SiT峰值.8，t<.25乘6/7，t>=.5关闭；RAE峰值.78，原noise-time窗口[.1,1]。固定候选为a_eff=2a(1-r)，使r=.5精确回到原IG。反向为2ar。控制为原IG、半强度、双强度、时间均值后验、同时间同类别置换。除这三个固定常数，禁止新增系数扫描。

置换通过两条同条件、独立噪声路径交换当前来源后验，交换的是当下两者的r，保留相同时间、类别与求解子阶段；不跨类别置换。时间均值先在本轮原IG轨迹上汇总r，再冻结，不由FID选择。主要候选不依赖其他样本；两条路径只为配对控制与统一预算一起生成。所有方法400个独立样本对，固定第一条分支输入主FID/IS，第二条保存但不混入主统计。RAE的400类子集和小样本限制同CFG协议。

每条输出SiT128次完整前向，RAE100次，零额外独立弱前缀；每个独立主评价样本对应两条输出的成本。读出与token池化增加实际延迟，不能仅凭NFE相同说零开销。原IG基线为了构造时间均值还记录r，其时间包含这项校准开销，报告时须说明。

首先检查固定r=.5完整轨迹精确等于本轮原IG，计数正确，Strong参数无梯度，原始噪声时两种来源特征相同。所有原始数据、来源标签、配置和成本保留。

400图用于筛除明显失败。只有真实后验候选比全部六个对照的FID至少低2、IS不低于原IG超过10%，才固定配置进入新1000主样本确认；不把反向或置换对照事后更名为主要候选。1K通过后再作5K与已有强对照比较。分类器校准好但质量无改善，按生成失败处理。无需两个模型同时通过才保留单模型证据，但跨模型失败必须完整报告。

提案的精确混合连续性恒等式属于已有Flow Matching边缘化原则；相关来源反馈思想与[Feedback Guidance](https://arxiv.org/html/2506.06085v2)很近。当前工作是对用户具体候选的实验检验，不先认领新颖性。
