## 保留的假设：解码器的块相位是否留下可修复的图像误差

RAEv2 的像素 decoder 以 `decoder_pred: Linear(1152,768)` 将每个末层 token
读成 16×16×3 像素，再直接 `unpatchify`。这不同于此前修改 guidance 或在
latent 上做能量投影：此处讨论的是从表示到像素的合成结构。

令一维简写中的 token 特征为 h_j，块内位置为 a，则线性读出为

    x_(16j+a) = W_a h_j + b_a。

即使 h 在粗网格上平稳，不同相位的像素均值、协方差和差分能量也未必相同。
块内差分由 `(W_(a+1)−W_a)h_j + b_(a+1)−b_a` 决定，块边界差分则由
`W_0 h_(j+1)−W_15 h_j+b_0−b_15` 决定；后者额外依赖相邻 token 的
cross-covariance。这给出了周期性图像统计出现的一条具体结构路径。

**这不是伪影定理。** token 通道可以合法地编码块内纹理；相同 token 也可能
对应自然的重复纹理。不能把 h 当成必然带限的标量场，更不能从上述恒等式
推出所有相位差异都应被去掉。

## 固定 CPU 诊断

[诊断代码](../experiments/audit_raev2_decoder_patch_phase.py)只读取两批已完成的
历史 scale-response bank，seed 为 20260801/20260802。每批按原 sample protocol
选择每类最小 global ID，保留全部 1000 类；比较原始真实图、其 autoencoder
重建图和既有 IG1.78 生成图。没有读取正在扩展的 5K 图片。

在图像内区 `[16:240)` 测量 16 种相位的一阶、二阶 RGB 差分平方；每相位恰有
14 个位置。首差的相位 15 跨块边界，二差的相位 0、15 接触边界。下表为
“边界平均能量减去其他相位平均能量”，再除以所有相位平均能量；它是无量纲
描述统计，**不是 FID 改善或可去除误差的百分比**。

| 旧 bank | 图像分支 | 水平首差 | 竖向首差 |
|---|---|---:|---:|
| 20260801 | 原始真实图 | −0.940% | +1.504% |
| 20260801 | 重建图 | +4.164% | +15.509% |
| 20260801 | 生成图 | +3.447% | +14.624% |
| 20260802 | 原始真实图 | +1.473% | +3.002% |
| 20260802 | 重建图 | +6.958% | +16.992% |
| 20260802 | 生成图 | +3.977% | +14.812% |

两批都有与网格相关的差异，但生成图的首差边界对比均比重建图弱；这不代表
全部周期偏差较弱，完整相位曲线的 RMS 偏差反而略高。竖向二阶边界差只有约
1–2%，水平二阶边界差为负。因此，“生成产生了明显额外接缝”并不符合这份
数据，不能把首差的一个数字直接解释成断裂边缘。

运行耗时 59.28 秒，零模型/GPU/FID 调用。每张原始图的类别与 source row
均核对；旧图片是 clamped FP16，真实图为 uint8/255，不能称为完全相同的
像素精度。JPEG、resize、数据内容与旧生成设置均可能影响统计。本次未作
干预、显著性声明或跨模型确认。独立审核 26 项检查通过，其中 48 个旧图片
统计按显式相位索引复算，与原结果相同。旧链还包括 encoder、FP16 latent、
decoder 与像素 clamp/FP16 存储，当前无法将周期签名单独归因于 decoder。

## 可能设计及其尚未满足的前提

一个小训练设计是仅改最后的像素合成读出，让相邻 token 共同预测重叠区域，
以已知的 partition-of-unity 合成图像。另一种实现是对线性合成核施加明确的
相位一致性约束。两者都可冻结 prior、encoder 与 decoder 主体，不必反传整条
扩散轨迹，也不需要人工 guidance 系数或时间调度。

但当前不能据此立项：重叠读出和抗混叠本身是既有工具，也没有建立区别于已有
decoder 后训练的充分新颖性。合成窗口归一，只能在各重叠预测一致为同一常量时
保持该常量，不能保证真实纹理、语义或图像分布。强制各相位
在常量 token 下输出一致，还可能删除 token 合法携带的块内细节。训练一个
更大读出层后变好，也可能只是增加了容量。

若未来重新研究，最关键的证据应是固定 generated latent 下、有容量及训练成本
对照的图像质量因果改善，同时保留真实重建质量；不是把相位曲线压平。
本次没有执行这些训练或干预。

经典 [StyleGAN3](https://arxiv.org/abs/2106.12423)为生成器内部信号处理提供了
有价值的机制直觉，但它改造并训练了网络，主要改善连续等变性，报告的是与
StyleGAN2 相近的 FID。不能把其结论移植成当前冻结 RAEv2 的免训练质量保证。

## 收束决定

**保留一个可复查的结构假设，没有找到已足够成熟的新单图质量方法。**
上述诊断没有提供 FID 或 5% 提升保证。早期评审中的判伪候选和未来训练预案
均只作历史记录，不是本次仍待执行的实验；本次收束决定覆盖这些旧预案。
不启动新的 GPU、adapter 训练、滤波器或参数搜索。普通 actual-q decoder
后训练、小头/归一化校准等也未发现足够的新机制依据，分别保留在
[decoder 适配审查](RAEV2_SINGLE_IMAGE_DECODER_ADAPTATION_REVIEW_20260907_ZH.md)和
[小训练审查](RAEV2_SINGLE_IMAGE_SMALL_TRAINING_REVIEW_20260907_ZH.md)。
