# 固定条件端点的直接反向 Base 积分

使用上一轮同8条FP32/TF32 RAE轨迹与H=.125，固定4步IG目标。直接从目标
沿Base反向Euler积分4或16步，再前向4/16/32步检查。原始latent的16/32步
IG端点同时作为细化目标，不把固定4步目标假定为真实条件流。

以下使用16步反向、32步前向，误差平方比为8个样本的比值均值；分母均为
未校准latent用同样前向步数到相应目标的误差平方：

| 原生grid step | 到冻结4步目标 | 到32步IG目标 |
|---|---:|---:|
| 0 | .568474 | 1.502270 |
| 73 | .00015863 | .00229542 |
| 89 | .00013907 | .00121673 |

初始点4步反向加32步前向时，两列分别3.12913和3.56450，明显更差。
反向细化帮助接近冻结目标，但仍没有稳定复现细化的条件端点。不能由此声称
精确ODE不可逆或固定目标思想无效；当前Euler步数尚未构成收敛证明。

中段直接逆流有较小误差，且反向16次prefix比Anderson的36次prefix少。
这只是当前精度下的局部求解成本，不是端到端加速或质量收益：条件目标仍
需预先花4次Full求出，最终Base运输也需计费。不存在已验证的新方法突破。

脚本`experiments/audit_raev2_anchored_reverse_flow.py` exit0；144条记录、
1368次batch4 prefix及492次batch4 Full，计算37.779秒，加载与哈希另计。
与上一轮的噪声/模型哈希一致，源码哈希和调用数核验通过；完整结果
`experiments/results/terminal_defect_20260908/raev2_anchored_reverse_flow.json`。

阶段决定：不继续把朴素逆流、Anderson迭代或某个较小残差本身当成新guidance。
初始区间在两个方向均存在明显离散化敏感性；解决它最多先获得可靠条件
运输，仍需另有明确的质量或成本用途。未启动FID或训练，论文保持暂停。
