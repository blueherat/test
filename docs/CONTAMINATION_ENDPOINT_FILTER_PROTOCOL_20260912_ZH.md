# 共同污染假设：离线终点过滤诊断

目的仅是定位本轮“端点矩改善、动态引导未改善”的缺口，仍围绕共同污染假设。使用已经生成的1000对 Strong/Weak/Null 端点，不增加生成，不把拒绝采样当作可部署的新方法。

四组（两个模型×IG/CFG）均使用前400对端点的官方 Inception 特征训练一个来源平衡的线性逻辑回归头；接着100对只拟合一个逆温度；后500对用于计算过滤效果。逐通道标准化只用训练数据，目标为 mean BCE＋0.5‖w‖²，截距不正则，L-BFGS 从零启动，梯度容差1e-6，最多1000次迭代。不扫描正则、特征子集或分类器结构。该端点分类器仅用于诊断，部署不调用 Inception 或额外 decoder。

沿用已拟合的全局 $\kappa$。理想共同污染模型的拒绝概率给出接受权重 $a(z)=1-\kappa q_R(z)/q_S(z)$。使用估计比值时，把负接受权重置0，并记录频率；不把这个正部修正等同于精确去污染。与未经选择的同一批500个 Strong 样本比较固定二次核 MMD，核尺度、参考矩与此前端点矩检验相同。报告接受权重均值、有效样本量、核误差及按同一 seed 重采样的描述性范围；不把自归一重要性估计当作等样本量普通 FID，也不据此提升1K生成。

拟合比例用的是前500对，包含本诊断400训练／100校准；这两者都与后500评估样本分离。固定种子2026121361生成一次接受 mask，保留所有输入与权重，禁止手选样本。理想精确情况下期望接受率为 $1-\kappa$，因此该诊断即使成功也不满足用户对部署成本的要求。
