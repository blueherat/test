# 多噪声线性参考拟合控制

单噪声线性拟合已满秩且训练风险下降，验证仍退化。本轮只检验增加噪声/时间
Monte Carlo覆盖能否消除该拟合退化，不宣称方法创新，不进行图像质量采样。

保持上一轮同一5000训练图、1000独立验证图、原始冻结模型、BF16有效特征、
最终仿射读出、加权最小二乘、无ridge和相同数据顺序。连续CUDA seed202609421，
遍历训练集恰好10轮，每轮抽独立噪声/时间/10%空标签；第一轮与上一轮完全相同。
只在第10轮末求解和验证，不根据验证挑轮数、读出或超参数。验证seed202609420。
总50000噪声状态不等于50000独立图像；相同图像导致的有限图像泛化问题仍保留。

保存FP64 Gram、两组交叉矩和目标能量以及原始系数，以便CPU独立检查方程与风险。
报告满秩/条件数/残差、训练风险、配对验证差、墙钟成本、源文件哈希。
预计 .13 GPU小时，固定10轮；若验证仍失败，不追加轮数或学习率搜索。
即便验证改善，也只说明得到了更可信的参考目标干预，尚未说明生成质量改善。

## 完成结果

固定十轮完成，50000噪声状态、12800000 tokens，仍只有5000独立训练图。
设计矩阵1441维满秩、条件数1154.53。拟合437.69秒，含验证444.43秒，
约 .12345 GPU小时（模型加载及文件哈希除外）。CPU用Cholesky独立求解，
与GPU特征分解解一致，并由保存的充分统计量独立重构三种训练风险；审计通过。
原Base的1000个验证结果与最初实验逐行一致，所有非线性读出参数保持原值。

| 读出 | 单噪声数据验证MSE | 十噪声数据验证MSE | 十噪声教师验证MSE |
|---|---:|---:|---:|
| 原Base | .477276 | .477276 | .069141 |
| data | .484877 | .480509 | .072358 |
| teacher | .479392 | .478104 | .069771 |

更多噪声覆盖缩小了退化，但两个读出仍未达到原Base自身的目标风险。这个固定
对照支持Monte Carlo覆盖影响结果，不能证明所有残余退化都由有限图像导致。
按预定约束，不追加轮数或优化器搜索；没有启动替换读出的FID。

另按极化恒等式检查teacher−data与Full误差的配对内积：约 .000090，描述性
SE约 .000011；单噪声为 .000096/.000019。说明目标切换留下小信号，并非
“两个头都退化，所以标签机制必定无效”。尚未测出该信号的归一化强度、
跨独立训练集稳定性或PFR时间响应收益。不能宣称拟合/生成方法突破。
也不据此重新包装已有失败的X−F残差适配器为新方法。
