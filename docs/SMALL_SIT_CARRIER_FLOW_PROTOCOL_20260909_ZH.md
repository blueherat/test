# 小SiT：有限修正流的直接生成对照

用户要求有明确候选后直接在小SiT做真实生成，不再构造toy作为前置步骤。
本轮把IG承载关系落实为一个有限写入方案，比较写入时机与真实生成质量。
这是方法筛查；固定时间修正流及其与Strong的分裂属于标准算子构造，尚无新颖性或质量保证。

模型与配对：ImageNet-100 SiT-S/2 v800K EMA、depth4 v50K，FP32/TF32，B8。
直接复用宽扫准备但未用于新小SiT采样的noise.npy、labels.npy，共1000张；
其随机约定与历史每批seed=b、先randn后randint完全一致。原始噪声SHA为
ab8419c7fdfd5b15dacbf4d37a3d567158e4332f25fd94580d3df73bac87e2c2，
标签SHA为7c3ae6894e7ebab5c9b6524606f03b6a56b38dccbe472ff40edde26e48654fe6。
该bank已经用于历史探索，不称独立确认。

生成时间从0到1。保持已有最佳IG额外强度：[0,.25)为.6，[.25,.5)为.7，
[.5,1]为0。主积分边界固定为0/.125/.25/.375/.5/1。
每段主求解器均为Dopri5，rtol1e-3、atol1e-6。

记D_t(z)=S_t(z)-W_t(z)。固定原时间t，有限写入E_t^a由
dξ/du=D_t(ξ)、ξ(0)=z、u从0到a定义。实际用4个Heun子步，
每次在新的ξ上重新读两个头；a=α(s−t)。不迭代到D=0，不加反向弱流。

固定三个新1K配置，四卡协同每个配置：

- ig_restarted：每段积分S+αD，后半段仅Strong。它是新分段方式必需的普通IG对照。
- write_before：先做E_t^a，再用Strong推进t→s。
- write_after：先用Strong推进t→s，再做E_s^a。最后一个活动段在s=.5写入，此后不再写入。

两个写入方案每段均8次Full配对读取，共32次额外Full读取/图。
Strong主推进因状态不同可能有不同自适应NFE，因此只保证相同辅助预算，
实际总调用与GPU时间完整报告。alpha0时写入直接跳过，退化为相同分段Strong。
不声称本文数值E满足严格流关系或两个顺序必然相等。

对照问题：两个写入时机是否保持或改善已调优IG质量，有限写入是否只是分段
重启的效果？相同输入的图像与终点差可检查两个顺序的实际影响，但差变小不
作为质量成功。若没有质量信号，本轮不自动扩大步数、幅度或horizon扫描。

历史未分段IG FID64.851298及lifting65.286964作为背景单列，不混同新分段对照。
原未分段IG的完整像素已按历史规则删除，不能伪造逐像素复现。
真实网络入口、前缀读取和零强度退化检查只用于实现正确性，随后直接采完整1K。

评价使用原SD MSE VAE与ADM ImageNet-100 validation 5K reference，记录FID、
sFID、IS及固定样本图。保留所有完整batch、请求/模型/源码/输入/输出哈希、
每段写入RMS与NFE、采样和解码成本；数学上可能改善不替代这组实际质量结果。
控制器只运行这三个配置并正常结束，不恢复已停止的四模型宽扫。
