# Base/Full 独立终点分布：AG 解释的直接检查

2026-09-08，生成前固定。当前内部条件外推候选1K失败，不继续扫参；PFR与撤引导支线不参与。本实验是机制诊断，不是新采样方法或论文。

## 问题与会改变的下一步

AG原文将兼容的弱模型描述为放大强模型相似的欠拟合错误，并用更弥散的密度作解释；它没有证明任意浅层读出都满足此关系。[原文§3–4](https://arxiv.org/html/2406.02507v3)。旧RAEv2 class-moment检查测过Full相对真实latent，却明确未测Base独立终点。本轮补齐这个对象，避免仅从同状态F−B猜测两者生成分布。

最简可否证模型为 P_Base = P_Full * N(0,C)，C半正定。对任何固定线性映射L，它要求两组均值相同，且 Cov(L Base)−Cov(L Full)半正定。负方差差可反驳该有限cohort的矩拟合；正差不证明卷积关系。该模型只是“额外独立加性模糊”的严格特例，失败不否定AG的一般欠拟合解释。ODE的有限步误差、条件混合与网络近似均仍存在。

若Base呈现Full误差的同方向放大，后续才有理由研究这一具体误差的状态承载方式。若呈现相反的收缩或显著均值变化，就不再以简单模糊逆过程推导新guidance。单独FID更差不认证误差兼容性；不从本轮统计直接生成增益、窗口、投影或新弱头。

## 固定执行

官方EMA100080，DINOv3-L K7，100步shift8，clean-to-velocity floor .05。Full与Base均取原模型完整forward中的对应头，全部100步按该头生成，保留类标签。这两条独立源分布轨迹是诊断对照，不是建议部署时撤销IG。B4、FP32状态、BF16 autocast、TF32；seed202609413，各1000张、标签0…999，与既有Full1K逐噪声/标签配对。Full最终uint8图必须与旧完整1K逐像素一致。两卡独立执行；不改变batch和随机流。

保存所有FP32终点latent、uint8图、完整输入与源码身份。每组100000次完整模型样本调用，均计算两头；为消除新前缀实现混杂，此轮不优化Base单头成本。预计每组约14分钟、两卡重叠；记录实际时间，不把诊断时长作为优化后的Base吞吐。

## 固定分析对象

1. 所有1024通道的空间均值与每图空间中心化能量；全latent的总体二阶矩及总方差。
2. pooled 1024维均值、协方差迹与逐通道方差；固定seed202609491的1024×64 Gaussian QR正交投影中的完整协方差差谱。完整谱均报告，不挑负方向。
3. 已有真实bank-validation1000图的同一统计，用真实label核对覆盖，报告类别计数差异；不把未配对真实图作为生成图的posterior target。若各类计数不均，明确限制类别混合比较，另报告按类计数匹配的可获得统计而不挑样本。
4. 官方FID只描述两头独立生成质量，与既有原生IG1K区分；不视为新方法的收益。

每类仅一份生成样本，不能估计类内终点协方差；数据与噪声只有一个固定cohort。高维有限样本负特征值不直接认证总体符号，不使用latent维数作为IID样本量，不宣称互信息或真实density-ratio可识别。原始数组保留，便于后续跨噪声验证和独立重算。
