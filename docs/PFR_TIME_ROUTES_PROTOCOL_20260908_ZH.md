# PFR时间查询的实际计算通路

只研究PFR，不引入fixed point或信息迁移。上一轮直接条件分量干预
没有修复RAE，本轮检查原时间差分在实现中究竟改变哪些通路。

SiT弱输出写为V(a,b)=R_b(H_a(z,c),c)，a为浅层表征使用的时间，
b为末层调制使用的时间；直接输出velocity。RAE写为
V(a,b,d)=(z-R_b(H_a(z,c)))/d；a改变序列里的时间token，b改变
读出前的直接时间嵌入，d改变clean到velocity的除数。事件均t,r>.5，
不会触发除数floor。未来r=max(.5,t-1/32)，状态不变。

在全部2^n个当前/未来组合上，计算每条通路从当前到未来切换带来的
V_before-V_after，并对所有n!切换顺序平均。所得有限差分Shapley
分量之和严格等于原V(t,...,t)-V(r,...,r)。所有组合仍用原trained
head和固定类别；混合时间组合不在原训练路径上，没有概率或纠偏保证。
这只是对程序通路的归因，依赖切分方式；不能将其能量当作真误差。

复现已有32条原生IG轨迹、seed202609431、B4、FP32/noTF32，SiT
FP64状态，RAE FP32状态；四事件同PFR_HEAD_KINEMATIC_RESPONSE协议。
每事件2完整原生corner之一复用轨迹前向、另1未来Full作验证，再2次
prefix提取和4次弱读出。每模型832 Full、64 prefix、128显式弱读出。
预计约.03 GPU小时，加载和CPU核验另计。不解码、不干预轨迹、不做FID。

必须原生两corner逐bit复现Full返回的Base；原raw响应能量复现旧记录；
噪声和整个终点hash复现旧32条轨迹。分量归约FP64，保存每样本Gram矩阵，
独立核验原始响应与分量相加关系、PSD、预算、源码快照和汇总。
报告分量能量比及与raw点积/||raw||²；后者带符号且和为1，前者不必。
既有径向缩放、输出参数化分解和交叉深度读出失败继续有效；本轮不
根据某项很大就将其删除后启动质量实验。所缺仍是对真实目标有益的机制。

脚本experiments/audit_pfr_time_routes.py；会话75360/95271。

## 完成结果

两会话exit0，CPU审计16857 exit0。32条/模型原生轨迹终点hash与旧
记录完全一致，两原生corner逐bit一致，全部256条raw能量复现。
源码快照、Gram对称/PSD、分量和恒等式、汇总和预算独立核验通过。
未保存完整分量向量，CPU审计不等于独立重跑神经前向。

SiT为.056153/.099135/.096275/.062357。RAE读出通路不是这四时刻

点积接近零不等于向量为零，更不证明其终点影响小：本轮未进行
质量干预，尤其最后事件读出能量仍约为raw的10.6%。因此这只是
降低该候选解释的优先级，不能声称因果否证了任何读出时间修复。

RAE晚事件表征/换算能量比2.130685/1.471891，二者明显相消；
这和旧显式参数化检查相容。两种模型主要都经表征通路改变弱输出，
因此“表征变化存在”本身不区分成功和失败。混合时钟归因没有给出
哪部分相对真实目标正确，也不构成删除某分量的质量采样依据。
