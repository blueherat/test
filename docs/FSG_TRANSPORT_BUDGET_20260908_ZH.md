# 总强度守恒不足以分解有限搬运

继续上一轮精确高斯混合模型，T=U^{-1}C。固定m=.5/2/4、8192分位数，
K=1/2/4/8/16/64/256；不训练，不生成图像，不写论文。
比较每步重算 z←z+(T(z)−z)/K 与固定初始位移 z←z+(T(z0)−z0)/K。
两者总标量强度都是1，但前者并不是T的K次复合分解；K趋大时得到的是
自治ODE dz/ds=T(z)−z 的时间1映射，一般不等于有限映射T。

m=2重算位移的平方W2：K1数值零，K2 .334332，K8 .607408，
K64 .679537，K256 .687073。固定初始位移在所有设置保持数值零。
后者只是把已知正确位移分成K份，没有新估计能力或计算优势，不能包装成方法。
各m结果完整存于 experiments/results/terminal_defect_20260908/fsg_transport_budget.csv。
代码 experiments/audit_fsg_transport_budget.py。

形式上令T_s=(1−s)id+sT，在本例严格递增而可逆。正确的小步算子是
T_{s+ds}∘T_s^{-1}，其乘积望远镜消去得到T，而不是重新作用id+ds(T−id)。
相应速度 v_s=(T−id)∘T_s^{-1} 是标准确定性插值流构造。固定原位移只是沿
已知源粒子的拉格朗日实现；未解决在真实模型中如何廉价获得T与源粒子映射。
因此停止“迭代次数除掉总guidance就能解决重复条件偏置”的简单修补建议。

## 新颖性核对的实际阅读边界

- [Flow Matching](https://arxiv.org/abs/2210.02747)：本轮打开摘要；流与插值路径
  是已有背景，未据此宣称上述精确分解新颖。
- [PathGuide](https://arxiv.org/html/2608.29107v1)：读摘要、引言、§3及§4到4.2。
  使用当前rollout上的连续性方程弱形式匹配，标量CFG产生二次目标与闭式解；
  通过端点后验权重估计，需真实条件端点样本。理想结论要求所有测试函数；
  有限测试族不自动继承路径正确性。不能把“on-policy分布匹配而非点态误差”
  当作尚无人提出的idea。没有完成其附录或实际复现，暂不推断其RAE可行性。
- [CFG-MP](https://arxiv.org/html/2601.21892v1)：检索摘要并打开页面；其同伦/
  流形投影方向已出现，尚未逐节读完，不作方法等价判断。

现阶段构造只给出一个精确可计算的校验对象，尚无新实际采样器。
下一项有意义的问题是：在现有冻结Full/Base有限区间查询下，能否估计
与一次目标搬运一致的增量，而不需要已经知道完整T。尚无得到验证的答案。
