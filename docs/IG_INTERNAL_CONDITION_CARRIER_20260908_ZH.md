# 在 DDT 内部条件中表达深浅层 guidance

用户指定研究方向：保留 guidance，从 AG 的强弱误差解释出发，借鉴 FSG 的状态承载直觉。本文是候选方法与实验记录，不是论文或有效性声明。PFR、撤引导、Stage1 decoder/RGB 重建支线均不参与。

## 候选及可辨别机制

RAEv2 的 Full 读出为 F=R(z,cF)，cF 是深层 encoder 产生的逐空间位置 DDT 调制条件。原生 Base 使用浅层特征和另一个读出，不能直接把浅层特征送进 Full 读出；此前交叉读出审计已失败。

先用冻结模型的同状态配对特征拟合固定仿射映射 A，将浅层 a8=SiLU(t_emb+h8) 映射到深层条件空间：cW=A(a8)。训练目标只为同状态 cF，不拟合生成图质量、不更新骨干。弱读出定义为 W=R(z,cW)。两个严格共享强弱表示及读取者的候选为

    输出端对照：Gout=R(z,cF)+γ[R(z,cF)−R(z,cW)]；
    内部条件载体：Gcarrier=R(z,cF+γ(cF−cW))。

γ=.78；所有原生活动时刻继续使用 guidance，无条件撤除或仅初始写入均不采用。实际输出端对照遵循原生 velocity 外推的浮点算术。内部条件在生产 BF16 下先转为原生条件 dtype，再做外推和 DDT 读取；训练与独立读取检查为 FP32/noTF32。

机制假说：深层相对浅层的计算修正先改变 decoder 的空间调制，允许后续读取以非线性方式协调输出。输出端外推则在读取完成后直接组合预测。这里的“信息”指可读取的计算结果，不声称深层确定性网络凭空增加 Shannon 信息，也不把 cF−cW 直接视为真实质量标签或合法 score。

这个假说会被同弱参考的输出端对照检验：若仅新弱参考带来收益而内部条件不再改善，不能将收益归因于载体。若两者都不如原生 IG，则当前实现没有质量依据。R 对条件仿射时两者严格相等；一般非线性时差别为有限曲率项，不保证符号或质量。固定点形式本身不是本方法的保证；这是借鉴 FSG 编码/读取直觉的新候选，而非 FSG 复现或已证明的新颖方法。

## 等待采样期间核对的新颖性边界

核读 NAG arXiv v3 §3.3–4.1、§5.6（https://arxiv.org/html/2505.21179）：它已经使用正负提示对应的注意力特征做 `Z+ + φ(Z+−Z−)`，再进行逐token L1范数限制与混合回正特征。故“从输出外推改为内部特征外推”及其后续非线性读取不能作为本候选的原创贡献。其作用对象是正负提示注意力特征，本候选是经过拟合对齐的深浅层DDT调制条件；对象不同尚不足以证明实质新意。本文没有直接移植NAG的归一化、混合系数或扫描参数。

RefDrop §3.2（https://arxiv.org/html/2405.17661）更早也在注意力输出中对自身与参考图特征做可调线性组合，以控制一致性或抑制参考特征。这进一步排除了“首次把条件信息放进内部特征”的宽泛声明。此次只核读相关方法部分，没有复现实验或作全面新颖性检索完成声明。

上述阅读收窄贡献要求：即使本轮1K为正，也只能先说明一个具体深浅层载体候选有经验价值；仍需解释误差兼容性、共享读出的必要作用，以及相对既有内部引导的方法差别。当前固定的三组对照继续，不用新文献临时增添有利变体。

## 用户授权多卡后的执行调整

用户明确允许多卡后，保留GPU0上已经完成的原生1K与正在运行的输出端对照。新增GPU1独立候选worker，源码仅将arms列表限制为condition_carrier，采样公式、模型、适配器、精度、B4、随机数序列均不变；四张卡型号均为RTX4090。独立监督器89981记录执行信息到 `parallel_execution.json`，仅在输出端对照的1000张归档及完成summary确认后终止旧顺序采样进程388368，避免其重复生成候选。原顺序控制器45767预计随子进程SIGTERM退出，这属于执行迁移，不是方法数值失败。

候选完成后保留 `parallel/request.json` 的独立源码身份，合并样本位置并重新核对全部输入及smoke像素，再统一评价。审计明确允许仅arms列表不同的并行worker，不忽略源码差异；基线与对照样本不重跑。并行会影响墙钟时长比较，因此当前实测速度是执行成本记录，若有正面质量结论，正式同成本比较仍需在同负载下核验。
