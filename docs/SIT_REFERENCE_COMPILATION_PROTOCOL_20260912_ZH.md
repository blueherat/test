# 共享参考蒸馏与候选概率 CFG：冻结实验协议

两条主线独立判定。IG 检验已经有效但需要额外前缀的参考函数能否被编译到共享主干的廉价读出中；CFG 检验真实干净 latent 候选上的概率更新是否优于同一候选读出的均值外推。冻结 strong，不恢复旧宽队列，不在部署采样中调用独立弱模型。

## IG：固定有用参考，检验其可计算性

教师为已完成独立5K的 native 四层弱前缀，旧5K FID36.1732具有额外计算成本，不能作为本轮同预算成果。教师仅用于离线监督。固定强场 S 与旧参考 W_T，目标引导是 S+a(S-W_T)。学生读出 W_phi 替换该参考，瞬时场误差恰为 -a(W_phi-W_T)。Lipschitz 条件下配对轨迹误差由沿教师轨迹的加权参考误差通过 Gronwall 界控制；这是标准稳定性结论，不是新质量定理。

离线产生1000条教师 guided 轨迹，各类10条；前800条、每类8条训练，后200条、每类2条验证。噪声独立于质量样本。只走到 t=.5，后续 strong 不提供训练信号。每条轨迹在32个有效引导步的四个等长时间段内各选一个步，收集 predictor 状态；步选择由轨迹索引固定，覆盖每个 k=0,...,31。缓存真实当前状态、教师弱输出、强输出、第4/12层特征、时间与条件。教师输出来源是该状态处的弱网络，不是终点重新加噪的 FM target。

两个固定学生：原尺寸 depth4 读出、原尺寸 depth12 读出；分别由原IG头、strong末头的正确4个速度通道初始化，均301840参数。不搜索中间层、不加adapter。它们在完全相同的缓存样本索引上用 MSE 拟合同一教师弱输出；训练3000步，B32，AdamW1e-4，betas(.9,.999)，wd0，clip1，EMA.995，最终EMA，无验证择优。保存训练和验证误差、强弱gap误差比例，实际生成质量独立决定成败。

## CFG：有监督候选概率，避免用attention冒充后验

从已有互斥训练池的真实干净 latent 取131072个2×2×4 patch，用256中心、固定30次Lloyd更新构造codebook。初始化与抽样使用固定种子。codebook不使用生成质量样本；不按FID选K、温度或训练步数。

冻结 SiT 全主干，在末层特征上用一个共享分类读出预测干净patch最近中心的类别，交叉熵目标。每个输入独立以.5概率去掉条件，读出不额外接收被去掉的类别。与IG一样3000步、B32及相同优化器/EMA；数据为既有25600图训练池，3200图验证池，噪声时间(.01,.75)。验证报告NLL、准确率、候选均值重建误差，不将这些当作生成质量结论。

固定候选c_k、条件/null logits l_c,l_u，定义 m_c=E_softmax(l_c)c_k、m_u=E_softmax(l_u)c_k、m_a=E_softmax((1+a)l_c-a l_u)c_k。

- 主候选：v=S+(m_a-m_c)/(1-t)。
- 运算对照：v=S+a(m_c-m_u)/(1-t)。

均以原strong为锚，零强度严格恢复strong，避免把分类头的重建误差混进无引导基线。m_a本身在codebook凸包内；带strong锚后的总预测没有完整凸包保证，不能声称始终位于真实图像流形。概率组合是离散CFG的已有操作；这里测试冻结连续模型上的干净候选读出。patch边际组合不是完整图像联合后验的组合，也不保证ODE终点为乘幂分布。

## 配对生成与推进

共10组新1K：IG shallow/deep两个学生、原IG、旧IG自身数据参考、ADG；CFG概率/均值两个操作、原CFG、旧CFG自身数据参考、APG。使用新噪声种子2026121220、类别种子+1，每类10图；与此前反复使用的202610100探索bank不同。Heun64固定，IG额外强度.8（前.25乘6/7）与截止.5，CFG额外强度1.25、截止.75。每图IG128次full/0prefix、CFG224次full/0prefix。训练teacher成本、head参数、实际采样与解码耗时分开记录。

候选必须在完整新1K中比本主线全部指定质量对照至少低.5 FID，才进入固定权重、种子2026121222的新5K。每线最多推进一个。CFG还须超过同一分类头的均值外推对照。sFID、IS、失败率及实际耗时同时保留，不宣称全面改善。5K需至少比最佳可比强对照降低1% FID才称本轮确认；只有单训练seed，不能推断训练方差或跨模型结论。

正式生成前检查：训练输入/源码/权重指纹，strong不更新；速度/方差通道及patch顺序；概率零强度/共同logit平移；全部新采样轨迹有限且零强度逐元素回到原strong；旧strong/IG/CFG/APG基准首批逐元素复现；hooks恢复；查询计数。完整质量batch、覆盖率和缓存FP64 FID/sFID复算沿用既有流水线。数值失败保留；不根据1K结果更改候选或开启参数网格。
