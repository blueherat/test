# 多步固定目标逆映射检查

沿用8条FP32/TF32原生RAE轨迹、seed202609425、三个noise-time点、H=.125。
本轮固定目标为4步原生IG1.78 Euler运输的端点Y；Base也使用同区间4步映射U4。
求根更新为x←x+Y−U4(x)，分别直接Picard及固定history4/relative ridge1e-4
Anderson，均8次更新，目标不随迭代改变。原生轨迹与诊断分支独立推进。

之后用Base 4/8/16步从解出的latent运输，并比较两种误差：到冻结的Y，以及
到原始latent用同样8/16步IG得到的更细目标。后者同时检查条件目标侧的离散化，
不能只把Base细化而假定4步目标已经精确。各比值的分母是未校准latent用
相同Base步数到相应目标的误差平方；报告逐样本比值平均，不是总体能量比。

这不是FID实验，也不是新逆解算法。若它只能昂贵地复现已算出的IG端点，仍未
提供生成质量或效率收益。记录完整Full/prefix batch调用与计算时间，不以
prefix免费或一次模型调用与一次整条路径等价来估计成本。论文保持暂停。

脚本：experiments/audit_raev2_anchored_inverse_multistep.py。

## 结果

运行exit0，432条求解记录、144条运输检查。输入与checkpoint哈希和上一轮
一致，源码哈希、1128次batch4 prefix及348次batch4 Full调用已核验；
计算31.158秒，加载及哈希另计。完整结果位于
`experiments/results/terminal_defect_20260908/raev2_anchored_inverse_multistep.json`。

Anderson的4步逆映射残差平方比，在原生grid step0/73/89分别为
.05738374 / .000002657 / .000003718。初始点8样本最大为.247621，
因此不能将均值的下降解读为每个样本都已精确求解。Picard初始点仍为22.9001。

对Anderson解，以下两端同时细化：Base从校准latent运行n步，IG从原latent
运行n步，比较端点误差；分母是未校准latent的Base/IG端点误差平方。

| 原生grid step | 4步 | 8步 | 16步 |
|---|---:|---:|---:|
| 0 | .057384 | .320941 | .551204 |
| 73 | .000002657 | .000736 | .001654 |
| 89 | .000003718 | .000501 | .001116 |

初始区间仍对映射离散化高度敏感；当Base与IG都细化时，误差回升比仅固定
4步IG目标的检查更大。中段结果稳定得多，但没有评估生成质量或多种seed，
不能由此挑晚期窗口宣称方法有效。不同目标/分母下的结果不能与上一轮的
86.7%直接相减作因果归因。

成本也必须明确：仅一个候选的4步目标加8次更新及末次残差评估，就需要
4次Full和36次prefix/样本，之后才是Base运输。这不是免费的条件编码。
目前得到的是数值可行性和初始区间的离散化障碍，而非质量或效率突破。
后续需有比“复现已算出的条件端点”更有价值的用途才值得进入完整采样。
