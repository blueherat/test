# 第4轮：有限密度差的Moser校正准入检查

本轮检验一个与配对位移回归不同的入口：直接规定原生一步分布q⁻至真实下一时刻p_s的**密度混合路径**，以连续性方程导出引导场。它不要求逐样本teacher残差具有零条件均值，也不把posterior covariance全部当成IG尚缺的方差。理论参考为NeurIPS2021 *Moser Flow: Divergence-based Generative Modeling on Manifolds*，不是fixed-point论文。

本协议在数值执行前写入；解析推导已经决定以下例子，数值只是复核，不称盲测或RAEv2质量实验。本轮是本次授权的第4轮；完成后若仍无闭合的候选，则结束研究并Git归档，不启动第5轮凑数。

## 机制及待检验的实现桥梁

令ρ_τ=(1−τ)q⁻+τp_s。连续性要求 `−div(ρ_τ v_τ)=p_s−q⁻`。若有满足边界条件的flux j，`div j=q⁻−p_s`，则 `v_τ=j/ρ_τ` 精确运输。在紧致连通可定向无边界流形、正光滑密度等Moser条件下有存在性；当前native BF16离散状态和未知高维q⁻不能直接视为这些密度。

本地可由两样本估计的替代是势函数目标

`J_τ(u)=.5 E_{ρ_τ}||∇u||²−(E_{p_s}u−E_{q⁻}u)`。

其全函数空间一阶条件正是弱连续性，约束适当时给最小动能梯度场。它是本地推导，不是Moser原论文的显式密度似然loss。关键检验：有限场空间或有限经验梯度Gram是否足以继承精确密度路径；若不行，现有数据有没有自然决定的、区别于旧Sobolev势函数的闭合方式。

## 固定CPU裁决

只用S¹角坐标x∈[0,2π)，q=1/(2π)、p=(1+0.5 cosx)/(2π)，均严格正且满足紧致流形条件。

1. 解析Moser速度 `v_τ=−0.5 sinx/(1+0.5τ cosx)`；不变量 `x+0.5τ sinx=x_initial`。固定1024个均匀中点，用DOP853(rtol1e−10,atol1e−12)积分至τ1，对比不变量和前两Fourier矩。保留实际rhs调用和CPU/wall；不搜索solver设置。
2. 同一路径上仅保留自然最低阶势 `u=k cosx`。ρ_τ下的梯度Gram恒为1/2，source为1/4，故Galerkin最优k=1/2且弱残差在这个特征上为零。积分实际速度−0.5sinx；解析终点矩为 `E cosx=tanh(.25)`、`E cos2x=tanh(.25)²`，而目标为1/4和0。它检验“有限源弱解=准确路径”这一具体桥梁，不否定全空间Moser定理。
3. 有限经验源δ0、目标δπ，仍用同一个cos基函数。两个端点梯度均为零，经验Gram0而source−2，故J(k)=2k没有下界。固定k=0,−1,−10,−100数值核对。此例的经验测度不是满足Moser定理的光滑总体；正是不能把总体定理迁移到任意经验loss的理由。

准入决定结合三项结果、原文假设和当前RAEv2可获得量。若必须新增密度估计、全局平滑/范数约束或重新选择有限基，须明确新假设与成本；不以临时正则、扩基或gain扫描补救。不采样RAEv2图片、不训练模型、不用toy矩代替FID。
