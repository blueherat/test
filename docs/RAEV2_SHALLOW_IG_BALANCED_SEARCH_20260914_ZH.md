# RAEv2外推系数搜索：均衡1K补充协议

三个后训练头已完成50K。原生第8层IG与第4层同结构头、第4层MLP、第8层MLP分别扫描外推系数w，定义weak+w×(strong−weak)。其他训练与采样设置保持已有冻结协议。

原计划400图扫描只覆盖400类，原生IG结果最低位于w=1。为避免部分类别筛选影响选参，在5K前将所有粗网格候选统一扩展到类别均衡1000图，每类1图。保留最初400图的全部噪声、标签和已完成的有效批次，按原PCG64随机流生成剩余600图；未完成400图候选补齐到相同1000图。旧400图结果与批次保留，其指标仅用于诊断，不参与最终选参。

粗网格w=[1,1.2,1.4,1.6,1.78,2,2.4,3]，w=1为共享纯strong基线。每族在1000图上选择最低FID点，并测试相邻网格中点；下边界只加1.1，上边界另加4。合并粗扫与细化后锁定各族最低FID系数，精确相同取较小w。不强行要求正外推获益。

原400图头扫描曾遇到高系数非有限轨迹，原控制器因此退出；新队列对这种情况保存系数、失败批次和异常，判定该系数无效并继续其他候选。不裁剪、不替换坏样本，不对部分成功输出报FID。5K若发生这种失败，必须停止审查，不能利用5K结果重新选系数。

最终每族在已保留的独立seed2026091421均衡5K噪声bank生成5000图，采样前锁定系数，5K不参与搜索。该bank用于已有原生默认IG／20K MLP比较，历史输出明确标记复用。所有新输出保留request、输入与批次哈希、NFE、全部像素与latent，指标按同一Nanogen batch64协议评价并复核。
