# APG机制延伸的冻结实验协议

本轮把第54–58项接在已有53个方向之后，沿用同一套1K噪声与标签，形成配对延伸。总计201个配置：五个方向各12组，共60组候选；另有141组对照。所有参数均执行，不根据机制检查或中途FID删掉配置，不自动追加5K。

**模型、输入与评价。** 使用已有SiT-S/2的800K checkpoint、原VAE、同一ImageNet-100训练划分与ADM参考。噪声seed为202610100，标签seed为202610101，每类10张；直接复制53-idea请求中的输入文件，校验文件与数组SHA256。机制研究另用32个新种子、32个不同类别，不读取本轮1K候选结果作参数选择。

FID是筛选依据。继承的评价器同时缓存sFID和IS，结果不据其重新选择配置。内部语义反馈使用已有、冻结的ConvNeXt-Tiny ImageNet-1K分类器，目标概率取完整1000类softmax中的真实类别，不对100类子集重新归一化。每个配置保存1000张图、终点latent、标签、原始批次、特征与计算账目；不增设后验语义评价队列。

**共同采样约定。** 时间从噪声0向数据1推进，基础求解器为64步Heun。额外引导量记为a，通常在t<0.75开启，之后恢复条件场；完整CFG倍数为w=1+a。候选强度a∈{0.5,1.25,2,2.75}。第54项以原生CFG为主场，第55–58项以无动量、无截断、η=0的APG投影场为主场。撤条件意味着切换到真正的null分支，与关闭额外CFG后继续条件分支有区别。

第55与58项的状态写入半径统一为r_x=(2/64)a‖v_c−v_u‖。第55项的两个基方向是raw gap相对clean条件预测的正交分量与平行分量，各自单位化。有限输入集合包含零、原始方向、投影方向，以及4档半径、64个角度，共259个候选；仅用已识别的二维响应评估该集合，不为每个系数重跑网络。最终提案另作实际未来验收。

第55项的moment输出为终点latent四个通道的均值和标准差，共8维；不把它称作真实亮度、饱和度或完整风格。响应矩阵按自身Frobenius范数归一化，使统一输出单位缩放不改变线性罚项。实际验收比较相同单位、相同未来网格下的moment变化。第56项的moment罚项相对η=0候选，除以其moment均方尺度。第58项不以不同时距的残差大小或梯度范数直接排序。

clean APG按论文顺序在clean预测空间累积历史、固定norm截断、投影，再转换为本模型velocity；Heun两阶段读同一旧历史，每个完整步只提交左阶段clean buffer。这是适配本SiT与Heun接口的参考实现，不声称复现论文模型和论文FID。机制数据中的clean gap norm中位数约3.87，取整到5作为固定norm网格中心；没有利用1K FID来选择该中心。

ERK-Guid依论文算法使用上一轮Euler状态及其场值，与本轮接受状态的场值构成响应估计。所有操作转换为本项目噪声到数据的正向时间，校正项符号随速度时间反向而转换；首次步和引导开关不连续处重置缓存，避免把时变引导量的跳变解释为状态Jacobian。尺度为0时退化为原生Heun；查询数与相同CFG相同。此处是该数值方法的SiT时间参数化适配，未假设真实神经场的Jacobian对称。

**计算成本。** 每次完整模型、prefix模型、内部VAE和ConvNeXt查询均计数。所有候选提案、被拒绝提案、末端复查、主轨迹及最终VAE解码均计入采样GPU时间；FID评价时间另列。逐样本决策在B8批次执行，混合决策可能需要整批计算两种轨迹，这部分实际计算照实计入，不能仅按最终选中路径报NFE。主模型统计沿用每图平均NFE约定，同时给出实际批次GPU秒与内部图像处理张数。

本轮没有强制每个方法总NFE相等，必须结合原生、普通更多步、嵌入误差、ERK和相同语义资产对照判断性价比。内部语义优化提高固定分类器q，不保证FID下降；所有最佳值都是201配置网格的探索性结果，没有独立确认或显著性结论。

正式控制器只在原队列同时满足以下事实后才分配GPU：根状态明确complete、709组结束且无后续采样；阶段状态为709/709 complete；最终analysis_audit通过。等待阶段只读状态，不启动采样worker。原队列失败时新控制器记录依赖失败；停在配置边界时不会越过依赖启动。每个配置以完整生成、FID与commit记录为提交边界，重启时核对既有提交和批次收据。

预检包含全部180个新增参数配置的非线性CPU轨迹和GPU轨迹，以及16个新family的B8完整采样、零控制/关闭控制限制、标签与hook恢复和三类历史latent逐元素复现。机制任务和GPU预检短暂停在原配置完整提交后，并用专属停止标记及finally恢复原tmux控制器；原始已提交结果保留。最终筛选结束时，全部配置检查覆盖、请求及评价元数据，每个family最佳配置另校验原始批次哈希、成本并以FP64复算缓存特征的FID。
