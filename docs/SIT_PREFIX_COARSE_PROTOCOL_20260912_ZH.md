# 固定深度的弱前缀适配：针对读出表达限制的一次结构检验

2026-09-12。在第三轮粗化头结果已知、第四轮任何训练和生成尚未开始时冻结。仍属于idea 59的实现边界检验，不另计为新理论或第五种粗化。

## 为什么允许这一次修改

第三轮固定原头、原分布短训头、粗化短训头的FID依次为65.402814、65.000022、65.651362；只改弱头未超过原IG。粗化头的独立验证MSE在t=.15/.5/.85仅由.724067/1.082238/1.247278降至.723086/1.068448/1.234999。不能因此说高阶粗化已成为有效引导。

这里有一个事先可推导的表达限制。对于任意均值μ、协方差Σ的数据X，令Y=tX+(1−t)ε，V=X−ε。最佳仿射预测V≈A_tY+b_t仅依赖

$$A_t=[t\Sigma-(1-t)I]\,[t^2\Sigma+(1-t)^2 I]^{-1},\qquad
b_t=\mu-A_t t\mu.$$

高阶粗化C_4保留μ与Σ，因此在这个极限中，**原分布和粗化分布的最优仿射去噪器完全相同**。单独改变仿射头的训练分布无法表达该干预。实际depth4特征是非线性的，所以此式不是对上一轮失败原因的证明；它提出一个有边界的后续假设：需要改变弱模型的非线性特征，才能实现足够有用的粗化参考。

本轮固定深度4、固定C_4、固定训练步数、固定引导强度和区间，只将弱模型自己的前缀从冻结改为可训练。强模型保持独立、冻结。这是一个结构对照，不扩大任何强度或层数网格。

## 模型与训练

弱模型复制strong的输入、时间和类别embedding及前4个block，另复制原50K depth4预测头。位置编码固定。它有独立权重；训练不改变strong的任何参数。一次弱查询只执行前4个block及其预测头。

训练native与clt两个版本，初始权重完全相同。复用原59组已冻结的数据池、抽样次序、随机种子2026120913。每组1500步、B32、AdamW学习率1e-4、betas=(.9,.999)、weight_decay=0、梯度上限1、EMA=.995；与上一轮弱头训练一致，唯一结构变化是允许弱前缀更新。bf16训练前向、FP32参数和优化器；噪声时间(.01,.99)，null概率.1。

仍采用最后一步EMA，不按验证损失选择checkpoint。验证使用固定的400图×3时刻，与前两轮同分布方法的验证抽样一致。不同目标分布的最小MSE不同，不跨分布用损失大小判断生成质量。

四组使用旧control同一1000噪声和标签。Heun64，峰值.8，t<.25用峰值6/7，.25≤t<.5用峰值，后半程关闭。无范数匹配，无分量投影，无局部质量探针。训练和采样完全顺序执行，真实GPU秒另报。

original多算一次前缀只作为相同计算布局的入口对照，不声称比单前向原IG更高效。每组都必须和已知局部IG比较；不能因训练出了一个更差的native弱模型，便把战胜它称为改进。

## 失败条件与范围

CLT必须同时超过原IG、同量native弱前缀以及局部IG，才考虑固定配置的新噪声确认。若只有目标损失改善、或只超过native，不进行更多前缀深度、训练率、训练轮数或引导强度搜索。

这个实验检验“可训练的非线性弱前缀是否足以使当前粗化构造有效”。它不证明粗化头的上一轮失败就是仿射表达限制，也不保证1500步已经收敛。若再次未转化为质量优势，结束本轮C_4构造链，不用继续变换架构来延后质量判断。

四卡预检复现旧strong、局部IG、CFG、APG；original重算前缀与上轮原IG首批latent逐位一致。零强度回到strong，原模型与hook完整性保持，训练请求和checkpoint全部哈希冻结。

[前一轮协议](SIT_INTERNAL_COARSE_PROTOCOL_20260912_ZH.md)给出C_4的矩、累积量、Gaussian不动点及加噪相容性；这些性质不单独保证质量。[AG原文](https://arxiv.org/html/2406.02507v1)和[IG原文](https://arxiv.org/html/2512.24176v1)分别是外部弱模型与内部读出的最近邻基线；本轮不把二者的结构本身称为创新。[研究循环复盘](GUIDANCE_RESEARCH_CYCLES_20260912_ZH.md)记录完整取舍。
