# 高噪状态的条件接管：完整生成结果

2026-09-08。对应 [冻结协议](FSG_CONDITION_HANDOFF_PROTOCOL_20260908_ZH.md)。用户指出FSG的关键是将外部条件搬进latent/noise，使无条件生成也能实现该条件。本轮正面检验了这个命题；此前token缓存与真实加噪MSE诊断不能替代它。

## 六组latent对照

全部同64初始高斯噪声、64类别，每类一图；FP32无TF32，B4，100步shift8。只在t=1写入，两次H=.125、gamma=2的条件CFG前向/null反向Euler。之后固定使用Full条件场或Full null场，不再做CFG++。因此这是FSG式信息写入的机制消融，不是原文完整配置、同成本质量比较或新算法声明。

### “有类别信息”和“走向同一个结局”分开测量

- 原始同一噪声的条件/null续生成终点MSE：1.395673508。
- 同一校准状态的条件/null续生成终点MSE：.265926381，前者的.190536，即降低约80.95%。两组写入状态SHA及数组逐位一致。
- 校准后null结局与原始噪声条件结局MSE：1.202198938。写入后并没有严格保留原来那一张条件图的构图，这不是上一项所检验的相同起点问题。

这里终点MSE是stage2 latent坐标距离，不是FID或感知质量。跨64类别的endpoint每坐标方差，持续条件.923882、直接null.923766、校准后null.959951、校准后条件1.008330；未观察到以全部样本收缩成同一点来降低gap的情形，但该统计不能证明类内多样性保持。

## 内部记忆的同目标检验

起点将第14层8个类别位置的条件−null差写为固定m。后续仅输入null，把m加到每步当前null类别位置，保留当前图像/时间位置。该模型内部增加了记忆注入，不能称为未经修改的原生无条件网络；原类别标签后续确实不再被查询。

|记忆分支|原类别top1|原类别top5|原类别平均概率|donor类别top1|
|---|---:|---:|---:|---:|
|正确记忆|9/64|15/64|.10101|—|
|跨64样本循环交换记忆|0/64|0/64|.000306|5/64|

交换同时改变donor类别和起始噪声，原始m逐位循环置换已核对。该对照支持记忆携带部分可用类别信息，不能证明其对初始噪声变化不敏感。它远弱于latent写入，也不优于持续条件生成。零记忆前8样本的完整latent终点及解码图像与原生null分支逐位一致。

这修正了前几轮取舍：不能因为m无法重构完整条件输出差，就说它不能承载条件；但实际撤标签生成证明，此固定记忆还不足以可靠接管。

## 实际图像与结论边界

[固定首8噪声的八组对照图](/home/zhoushunyu/data/eqvae/experiments/fsg_condition_handoff_20260908/contact_sheet.png)。已实际查看：latent校准后的null/条件分支在这些样本上共享明显主体与构图，直接null主体常完全不同；固定记忆多数仍延续直接null的主体。纯null往返出现大量纹理或不完整主体，表明数值往返本身并非无害操作。此处仅描述固定首8图，未挑选最佳样本，不能据此给出总体质量排名。

结果支持“高噪latent可在写入后承载条件，后续无条件场能读取它”的机制。不是新发现或ICLR贡献声明，也没有证明严格固定点、充分条件接管、总体多样性保持或FID提升。64图、一个seed、每类一图只构成机制pilot。

下一步将以此正确的条件接管基准考察质量和写入机制；不继续用局部MSE作为FSG搬运是否有效的唯一门槛，也不靠扫描内部记忆增益挽救当前弱接口。基础FSG式写入本身已有先例，后续仍必须找到真正的新方法贡献。
