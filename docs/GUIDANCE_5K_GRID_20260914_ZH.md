# IG 与 SG：步长0.2粗扫，前三个区间步长0.05细扫，每点5K

用户明确要求先以0.2粗扫，再在最优的几个区间以0.05细扫；同时保留此前每个外推系数直接采样5K、锁定系数后独立5K的要求。实验由tmux自动执行，先完成RAEv2后训练头，再完成SiT／JiT／RAEv2的原版SG与log-scoreSG。

## 网格和区间规则

外推系数范围按用户最新要求改为w=1至2，粗网格为[1,1.2,1.4,1.6,1.8,2]。每个粗点使用完整5000张。IG四种头共享w=1纯强模型。SG两种方法共享w_SG=1的IG-only基线；实际SG强度omega=w_SG-1，原有IG系数保持固定。所有区间选择只使用本轮5K指标，不使用1K排名。

对每个头／每种SG，计算每个相邻粗区间两端5K FID的平均值，按(平均值、较低的端点FID、左端点w)升序选前三个区间。要求两端均为完整、有效的5K结果；若不足三个有效区间则使用全部可用区间，无有效区间则停止并保留错误。每个选中宽0.2区间补齐左端点+0.05、+0.10、+0.15三个点，每点仍为5K，端点直接复用。相邻区间的共同端点不重复采样。

粗点与细点合并后按(FID,w)锁定参数。IG允许选择w=1；SG选择最佳正外推系数，并与IG-only单独比较。没有收益则如实报告。有限网格最优不声称连续全局最优；边界最优会标明搜索范围。

锁定头系数后，在全新seed2026091451上做独立5K，并重新评估默认原生w=1.78。该默认值作为额外对照，不参与0.2网格区间排序，也不混入网格选参最低点。既有同bank原生w=1.78历史结果只保留作参考。

## 保存、评价和恢复

每个扫描点保留全部原始像素、合并样本、评价特征、逐批输入身份与实际NFE。扩大网格后，为控制磁盘占用，调参阶段每批终点保存精确FP32 SHA256、形状、类型及生成时有限性检查结果，首批额外保留完整终点；其余调参终点可按冻结代码和配对输入重放，不保留完整数组。独立最终5K保留全部FP32终点。已有完整数组不删除、不降精度。像素和FID特征不压缩为有损格式、不抽样、不筛图。

头实验允许在GPU0提前评价完整5K组，使用逐组锁避免重复合并或评价；其余配置继续生成。墙钟时间不作为独占机器速度基准，成本比较使用实际主干／前缀／头调用计数。SiT评价沿用ADM ImageNet100参考，其余沿用Nanogen ImageNet256参考；FID从缓存特征以FP64复核。终点未保存的调参批次只能核对运行时检查记录和摘要，不声称对其完整终点做了事后数值复核。
