# 固定前缀头的全局概率校准：一次可证伪的检查

2026-09-07，第 2/8 轮。结论：**训练先验确实压低了原似然方向，但放大该方向没有通过独立类别检查，因此不增加采样分支。** 本检查不修改正在运行的单位强度 1K/5K，也不读取 FID 或 Inception。

## 理论问题不是“FID 不好就加大 strength”

原唯一拟合解包含 bias 的系数为 θ，目标为

    J(θ) = R_train(θ) + (λ/2)||θ||²,  λ=2881/64000。

在收敛驻点，沿已固定方向做全局尺度 α 的似然导数满足

    ∂α R_train(αθ)|α=1 = θ·∇R_train(θ) = −λ||θ||²。

因此只要 θ≠0，训练集无正则似然沿放大方向必有一阶收益。这是先验的代数后果，**并不证明泛化的 density ratio 被低估**。把该训练导数直接拿来提高 guidance 强度会忽略它本来就在训练目标中受到惩罚的原因。

将同一个已拟合 f 保持不变，只在先前验证集的偶数类别上拟合一个 α≥0，奇数类别只检查损失变化。原验证集已用于头的入口判断，不能称为全新的盲数据；两部分对这次标量拟合的用途分开记录。共享实际 native 初始噪声的每个负例对应八个真实正例，计算时先对八个正例平均，负例只计一次。

记 a=1−t，p_k=f(z_p,k)、q=f(z_q)，每个负例的目标为

    L(α) = α[q−mean_k p_k]/(4a)
           + [mean_k logcosh(aαp_k/2)+logcosh(aαq/2)]/(2a²)。

其二阶导为

    L''(α) = [mean_k p_k² sech²(aαp_k/2)+q² sech²(aαq/2)]/8 ≥ 0。

非退化时是严格凸的一维似然校准，使用导数求根，没有逐个倍率生成图像。非线性标量尺度不能凭此成为真实 log density ratio；这个有限函数族的拟合仍有近似误差。

## 固定结果和裁决

| 检查 | 实际值 |
|---|---:|
| 训练 α=1 的损失导数 | −1.0799939173 |
| 由 ridge 驻点预测的导数 | −1.0799935521 |
| 全部验证 α=1 的损失导数 | −.1063455732 |
| 全部验证 α=1 的曲率 | 2.0969910417 |
| 偶数类似然最优 α | 1.3005569601 |
| α 按类 sandwich SE | .1617787850 |
| 奇数类损失变化，相对 α=1 | **+.2103900666** |
| 该变化的按类 SE | .0909837833 |

原定条件为 `α−2SE>1` 且奇数类 `Δloss+2SE<0`，两项都未通过。没有通过另选全局倍率、换类划分、改正则或改时间权重挽救该方向。CPU 计算 7.119 秒；所有训练/验证特征 SHA 复核，原风险重构误差小于 1e−8，训练驻点恒等式在原优化残差界内成立。

这个结果区分了“先验造成训练收缩”与“实际存在可迁移的幅度不足”。它只否定本次固定的校准变体，不证明所有判别器梯度都无用，也不代替仍在进行的原头 5K。新前缀的单位强度 1K 已为 FID 38.576570，相对官方恶化 .2333%；这个结果没有进入上述求根。
