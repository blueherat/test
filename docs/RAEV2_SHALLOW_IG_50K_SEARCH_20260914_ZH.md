# RAEv2 50K后训练头：外推系数搜索与独立5K

本文件在系数搜索生成前冻结。用户明确要求先扫强弱预测外推系数，再采样5K。四个候选族为原生第8层IG、第4层同结构DDTFinalLayer50K、第4层ContextMLP50K、第8层ContextMLP20K续训至50K。所有主干、训练终点、采样器和活动窗口固定。

统一w定义为weak+w*(strong-weak)，w=1是纯strong；数值实现沿用原项目full+(w-1)*(full-weak)。搜索不改变训练学习率、层位或模型权重。

粗网格w=[1,1.2,1.4,1.6,1.78,2,2.4,3]。各族共用同一400图筛选bank，PCG64 seed2026091432、400个不重复类别。w=1只生成一次，各族共享该无外推对照。选每族FID最低点（精确相同时取较小w）；在其左右相邻粗网格中点再各测一次。若最小值在下边界1，只测上侧中点；若在上边界3，测左中点2.7和扩展点4。最后在该族全部已测点中按相同规则选取w。若最后仍落在上边界，明确报告搜索范围有限，不声称全局最优。不根据5K结果调参。

400图用于系数筛选，不作为最终质量结论。各族选定w后，使用与筛选独立的既有5K bank（seed2026091421、1000类各5图）生成全量5000张评价。该bank来自已归档原生IG与20K第8层MLP5K实验；可提供原生w1.78与20K MLP w1.39的配对历史参考，复用结果明确标记，不能作为独立新重复。新50K头的输出均新生成。

所有方法Euler100、shift8、窗口[.1,1]、FP32状态／velocity、BF16模型、TF32、batch16。新头共享主干中间特征，每图100次full、0额外prefix；新头在99个活动步调用。首16张旧原生IG要求latent与像素逐位重放。解码器、Nanogen FP32 Inception、batch64与参考统计均沿用旧5K协议。全量数据保留并核对输入、模型和源码身份、覆盖、计数及独立FP64 FID算术重算。速度单独记录，不宣称新增头零耗时。

执行顺序：先原生粗网格（可与头训练并行）；50K训练完毕后执行新头粗网格、各族中点细化、锁定选择、各族独立5K。报告“本搜索范围内最低FID系数”，并保留全部扫描点与负结果。完成本实验后再执行用户要求的SG系数扫描及5K。
