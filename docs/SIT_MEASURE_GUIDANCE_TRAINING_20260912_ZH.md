# 五个分布机制假设的训练协议

本轮遵循9月12日的新指令：暂停旧采样，先研究、实现并运行五个具有可失败机制预测的候选，再恢复之前的配置。旧优先批次已在93/100处正常停止，control为317/709，APG扩展为76/201；旧结果、请求、代码和权重保留。新实验不根据局部价值选动作，不把向量投影及分量系数搜索当新方法。

五个研究对象是：中心极限定理式高阶平滑；保区域边际的依赖消除；保总体类别先验的类别混合；条件生成流共轭的随机更新；包含原分布的弱模型及其密度比界。前三者与第五者通过改变训练分布产生可审阅的弱参照，第四者改变采样转移核。它们是研究假设，尚未证明是实际IG的机制，也未证明优于CFG/APG。

本协议只冻结负模型训练、数据干预与预算；生成配置与分析准则在首次新FID之前另行冻结。训练不使用生成FID、分类奖励、验证集选优或原1K噪声。

## 固定数据与训练

采用已有ImageNet100训练集SD-VAE posterior缓存，每类随机选256个训练图和32个互斥验证图；选择seed为2026120912。每次从相应类别池独立有放回抽取四个父样本，并独立采样其VAE posterior；不将posterior均值当作完整潜变量分布。样本池保留原始FP32精度。中心是训练池posterior均值的逐位置、逐通道类别均值。验证池的干预仍使用训练中心，不从验证集重新拟合。

八个弱模型均从同一个800K步small SiT EMA初始化，完整参数短训1500步，batch32，AdamW学习率0.00005、betas=(.9,.999)、weight_decay=.01，梯度范数上限1，EMA=.995。训练使用BF16 autocast及FP32参数，时间均匀取(.01,.99)，目标为原线性插值速度x−ε，显式10%条件丢弃。模型保持eval模式以禁用额外内部条件丢弃；eval不关闭参数梯度。噪声、类别、父样本索引、时间、丢弃随机流在各训练任务间对齐。固定最终EMA，不挑选中间checkpoint。

八个训练分布：

|名字|目标数据分布|用途|
|---|---|---|
|native|原训练池|相同训练预算对照|
|clt|μ+(X₁+X₂+X₃+X₄−4μ)/2，同类独立父样本|候选59：保均值及协方差，四阶累积量减为1/4|
|factor|四个同类独立样本各提供一个固定位置的16×16象限|候选60：保持各象限边际，移除象限之间依赖|
|local_label|.5来自本类，.5来自配对近邻类|候选61：类别概率粗化，保持总体类别边际|
|defensive|.5原分布+.5 clt分布，按整张图抽选|候选63：检验弱模型密度空洞假设|
|heat|X+σξ，ξ独立标准Gaussian|高斯平滑对照|
|plain_mix|(X₁+X₂+X₃+X₄)/4|未恢复方差的mixup对照|
|random_label|.5本类+.5固定随机配对类|类别粗化的随机拓扑对照|

local配对由原模型100个类别embedding的cosine距离做确定性最短边贪心完美匹配；不是依据FID或生成状态选竞争类。random配对由固定种子随机排列再两两分组。两种配对的P均满足P²=I，Q=(I+P)/2为双随机矩阵。是否真是视觉近邻是需要验证的假设，不把embedding距离当事实。

heat的σ²=训练池平均类内逐坐标方差，包含VAE posterior方差；因此在总体均方扰动意义上匹配m=4的clt相对于第一个父样本的改动。它不匹配完整协方差，这是区分机制所需的干预。

## 必须保留的限制

CLT变换不是逐点高斯卷积，也不保证一次平均后模态数单调减少；两个窄峰经m=2变换通常成为三个峰。理论主张是高阶累积量缩小、均值与协方差不变，不能偷换成“已经证明合峰”。factor保持的是固定象限在数据分布中的边际，不是每张图的局部纹理。

弱模型只是有限步学习这些已知目标分布。目标分布的等式不自动成为学到的score的等式；必须保留同预算native对照和互斥验证误差。训练中心在验证分布上不必等于真实均值，有限样本偏差另列。

这些完整弱模型首先是AG/IG机制的因果干预工具。它们需要第二次完整前向，不能冒充单次主干的IG，也不能只报采样成本而省略训练成本。强模型不更新。若它们有效，迁移成内部头是之后独立的研究问题。
