## 取舍

阶段性暂停 PFR 扩展，独立研究用户提出的 fixed point 路线。用户允许两路择一，要求开始不混合；转向是本轮研究判断，不是用户要求否定 PFR。此前阶段状态保留为历史。

PFR 的正结果保留：官方 SiT-XL 独立 5K 中，raw PFR FID 9.291876，对照 ordinary115 为 10.155902，采样慢约 1.56%。RAEv2 历史温和 PFR 的 5K 为 7.224213，对照 7.034546。两组协议不同，不能直接用数值差作跨模型效应比较。

后续固定条件分量、查询方式、OU 方向、移除普通 IG 等实验没有修复 RAE；官方 XL 的 OU 额外收益在固定 1K 仅为 0.010492 FID。没有把这些结果解释为所有 PFR 变体均不可能有效，但目前继续增加幅度规则缺少明确证据。详见同目录各实验结果和 RESEARCH_STATUS。

## 原文给出的启发和边界

本轮重读 [FSG 原文](https://arxiv.org/html/2510.21512v1) §§3.1–3.2、Algorithm 1：先向未来进行有条件预测，再通过无条件逆向更新把生成信息写回当前状态。其校准与去噪分解启发我们寻找可持续使用的条件状态；实际 Algorithm 1 仍在常规步执行 CFG++ 校准，不是只写一次条件后永久不再访问条件。

论文的收敛讨论需要算子与光滑性等假设；条件/无条件差距小本身不是分布质量证明。仓库已有精确高斯混合反例、RAE 真 CFG-FSG 负结果和逆流实验，重启不将这些当成未做过的工作。

本轮另读 [Adaptive Guidance](https://arxiv.org/abs/2312.12487) 摘要：LinearAG 已用历史 score 的仿射组合替代模型调用。当前仅核对摘要，不声称完成全文或实现复现。缓存输出残差本身不能作为新颖性依据。

## 单一候选：内部类别 token 是否携带图像相关条件状态

源码依据：`external/RAEv2/src/stage2/models/DDT.py` 的 `_build_sequence`、`_build_attn_mask`、`DiTwDDTHeadIG.forward`；配置 `experiments/configs/raev2_strict_lpl_dinov3l_k7.yaml`。256 个图像 token、4 个时间 token、8 个类别 token 一起进入 28 层编码器。掩码代码没有默认禁止类别 token 读取图像 token。每次调用重新构建序列，最终读出使用图像位置；中间类别位置因此是一个有待验证的信息载体，而不是已证实的充分统计量。

首个诊断只回答同一时刻、同一深度的因果承载问题，不改变采样器：

1. 固定同一 z、t，分别运行真实类别 c 与 null=1000 的前 14 层，得到两个序列。深度取编码器中点，预先固定，不扫描层数。
2. 保留 null 序列的图像和时间位置，仅换入 c 序列的 8 个类别位置，再运行剩余 Full 网络；记录相对 native c/null 输出差的方向与大小。
3. 做互补的图像位置置换，以及“仅替换初始类别 embedding”的对照。时间位置保持明确归属，不能把全部非图像位置都称作类别 token。
4. 使用相同 z 的另一类别提供 donor，检查效果是否跟随 donor 类别；使用同类别另一 z 的 donor，检查内部状态是否具有样本依赖。不能仅凭线性分类器能读出 c 宣称可用于生成。
5. 首先要求不置换的手动拆分与原生 Full 输出一致；统计所有前缀、后缀调用与实际时间。样本和时刻在执行前冻结。

这项诊断未实现、未运行。即使类别 token 置换能影响输出，也只证明网络会使用这些激活。跨时间持久状态仍需要处理层坐标、噪声水平和训练分布变化，不能直接把第 14 层 token 塞回第 0 层并称为信息搬运。若效果主要在图像 token 中，不应为保住候选而扫描更多层或增益。

后续若构造持久状态 m，应明确写入 W、读取 R 和更新 U，形式为 v=R(z,t,m)、m_next=U(m,z,t)。至少要用清空、错类置换、同类异样本置换检验承载作用，并与相同调用预算的当前条件计算及简单输出缓存比较。该形式只是研究问题，尚无新方法、质量保证或新颖性结论。
