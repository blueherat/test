# 递归再生成引导：设计审查

本文件记录本轮十项候选的设计依据与解释边界；最终算子、参数、运行顺序以主运行协议及其冻结请求为准。用户已授权每项二十组参数并在 tmux 启动，因此本文件不设额外审批步骤。

用户随后明确要求五轮完整回灌。执行范围扩展为 **259 个固定配置 × 初次生成加五次回灌 × 每轮 1,000 张，共 1,554,000 张分轮输出**。200 个候选和 59 个对照均完整保留六轮，每一轮分别运行、保存和评价；固定配置在回灌过程中不重选强度、探针时间或算法，不挑每轮最优图像。

## 完整回灌与内部探针是两个操作

记第 `r` 轮结束后的完整 latent 为 `X_r`。第 0 轮从原始噪声完整生成；第 `r=1,...,5` 轮使用同一配置自己的上一轮完整输出：

\[
Z_{r,.25}=.25X_{r-1}+.75\epsilon_r,
\qquad X_r=\Phi_{\text{config}}^{1\leftarrow .25}(Z_{r,.25};c).
\]

每轮都实际运行从 `.25` 到 `1` 的采样后缀，并将最终 latent 解码保存成这一轮的图像。它是模型原生 latent 回灌，不将 RGB 解码图像重新送入 VAE 编码器，也没有自然语言“保持完全不变”的编辑指令。第 10 项的“两轮”仍然指采样内部的两次小探针；它不能替代这里五次完整回灌，内部探针也不算作六轮输出中的额外图像。

每个样本保持固定类别和编号。所有配置在同一回灌轮使用同一份独立噪声 `ε_r`；不同回灌轮使用独立噪声。探针随机种子也应由固定 bank、轮次和批次身份或该轮共同噪声派生，不能从混入了各方法上一轮结果的 `Z_{r,.25}` 派生，否则方法间将不再共享探针噪声。每个探针内部的条件/null、strong/weak、有限差分和 `±ξ` 仍遵循原先的共同随机数规则。

采样后缀保留原全局时间网格、guide 窗口和强度表。CFG 仍在全局时间 `.75` 截止，IG 仍在 `.5` 截止；反馈轮从 `.25` 开始，因此不再经过 IG 的 `<.25` 低强度段。64/96/128 步是原完整网格名称，各自只执行该网格 `.25..1` 的后缀，不能把后缀重标成从 0 开始并再执行完整步数。新轮清空探针状态和 APG/CTRL 历史，以该轮输入和固定配置重新启动。

`.25X+.75ε` 含明显的信息损失，所以逐图保持不变不是精确模型也必须达到的性质。真实去噪器的正常收缩、重建中的随机变化、类别内实例替换，都可能产生大图像漂移而保持总体图像质量。正确模型反复作用时可以保持分布而改变具体样本；因此反馈中的偏移只能称为观测变化，不能自动称为“模型错误积累”。

## 六轮结果怎样判断

每个固定配置报告完整 `(round0,...,round5)` 轨迹，包括 FID、sFID、IS、实际调用和耗时。既观察与上一轮的成对差异，也观察与第 0 轮原始图像的累计差异；可直接使用已保存像素、latent 及已有 Inception 特征计算成对 RMS/距离和特征方差，不新增外部评估模型调用。这些距离受坐标与特征选择影响，不能称作完整的语义保真度。

FID/sFID 衡量当前轮分布与真实参考的差异，不直接衡量是否保留上一轮具体对象。IS 也不是单独的多样性指标。可结合已有特征的总体及类内方差、成对图像距离识别明显收缩，但这些仍不是真实分布覆盖率。需要区分“漂移增大而质量近似稳定”“质量恶化但仍有变化”“样本趋同导致表面稳定”三种情况；不能仅凭最后一轮看起来更像第一轮就认定方法更好。

59 个既定对照也执行六轮，已提供最小必要参照：Strong 用于查看无额外 guidance 的自然回灌变化；普通 CFG、原头 IG 和同 MLP 的普通 IG 用于分离回灌与新算子的作用；低强度、同范数原方向、反号及更多步数对照用于检查已知混杂。只探测但不修正的控制应在每轮与其同参数普通方法保持相同输出；若第 0 轮相同而后续不同，优先检查样本编号、共同噪声、历史重置与反馈来源。

零引导和禁用修正的完整后缀检查，必须在 **相同的反馈起点** 上比较对应普通采样器，不能拿不同历史配置的反馈输入与第 0 轮 Strong 结果比较。若某配置在某轮数值失败，之后没有合法上一轮输出，应保留失败及后继未运行状态，不能静默用其他配置、旧轮图像或重新抽样替代。

主比较保留全部 259 个固定配置的六轮记录，不用各轮分别挑出的不同超参数拼成一条“最佳方法”曲线。六轮共享样本祖先与随机数，不能把 1,554,000 张输出说成同一个条件下彼此独立的质量样本；每轮的 1K 仍是调参筛选，后续确认需要另立独立样本协议。

## 共同问题

研究的不是“反复复制不变即可证明质量好”，而是：在同一模型、同一回灌方式及同一随机性下，单轮偏移、局部扰动响应与多轮变化，是否能提供比普通强度调节更好的 guidance 控制信号。

对当前强预测的 clean 估计 `m=z+(1-t)S`，在指定噪声时间 `τ` 构造

\[
T_j(x;\xi)=q+(1-\tau)F_j(q,\tau),\qquad q=\tau x+(1-\tau)\xi.
\]

这里 SiT 时间从噪声 0 走向图像 1。`j` 可以是条件 Strong、null Strong 或同一次主干读取的 MLP Weak。固定图像、时间与噪声再生成得到的是有限模型的回灌响应，不是可观测的真实 score 误差。除第 9 项明确分别比较两份结果外，所有探针采用反向噪声平均 `T̄_j(x)=[T_j(x;+ξ)+T_j(x;−ξ)]/2`。这个平均是两次探针预测，不是额外输出样本，也不等于精确噪声期望。

应分开三个量：`T(m)-m` 是新增偏移；`T(m+h d)-T(m-h d)` 是在共同噪声下的局部响应；`T(T(m))-T(m)` 是进一步回灌的变化。改变随机噪声会另引入波动，因此每个有限差分和强弱比较必须共用相同探针噪声。反向噪声一致性实验则明确比较 `+ξ` 与 `-ξ`，不能与固定噪声的局部响应混称。

## 与已有实验的区别

仓库 [FSG 二十项结果](SIT_FSG_20_IDEAS_RESULTS_20260910_ZH.md) 的第 12 项已经直接优化条件预测的自重建稳定性：最佳 FID 为 45.200581，原 CFG 为 45.038604，最佳 APG 对照为 44.116467。本轮应把回灌读数当成待检验的控制信号，不再次声称“固定点残差下降必然有利”。

[五十项候选目录](SIT_GUIDANCE_50_IDEAS_CATALOG_20260910_ZH.md) 中，#19 使用已接受的跨时间 clean 二阶差分，#22 做隐式差值读取，#24–26 平均反射、网格相位及反向输入扰动后的 gap。本轮若使用同时间回灌曲率、回灌间方向一致性或反向噪声一致性，应保留这些明确区别；单纯平均两次扰动 gap 已经做过。

IG 的弱参考统一使用已验证的 MLP 读出，[直接替换入口](CONTEXT_REFERENCE_DIRECT_READOUT_20260913_ZH.md) 允许在原共享主干里运行。原生弱头和 MLP 弱头都应保留普通 IG 强度对照，以区别本轮回灌算子收益与已有读出收益。

## 最终十项与公式

令 `d=(1-t)(S-R)` 为 clean 坐标中的原 guidance 差，CFG 的 `R` 是 null Strong，IG 的 `R` 是 MLP Weak。实际速度为 `S+αd'/(1-t)`；实现利用各算子对当前 gap 的正齐次性，直接对当前 velocity gap 作用，避免显式除以 `1-t`。`r_s=T̄_s(m)−m`，`r_r=T̄_r(m)−m`，所有范数、内积、夹断均逐图计算。`P_x y` 表示投影到 `x`；`N_d(y)=y||d||/max(||y||,ε)`，`cap(y,a)` 限制范数不超过 `a`，`ε=1e-12`。有限差分

\[
J_jd\approx\frac{\bar T_j(m+hd)-\bar T_j(m-hd)}{2h}
\]

必须使用相同的 `±ξ`，其中 `h=.1` 是冻结的无量纲探针步长。公式表达读取探针时的机制；控制在接下来八个接受步内保持冻结，应用阶段使用当前 guidance 的规定投影/尺度，不能将历史 clean 单位直接当成当前速度。

|编号／键|有界算子及固定参数|被检验的机制与可失败原因|
|---|---|---|
|1 `cfg_cycle_gain`|`d'=d/[1+relu(||J_s d||/||d||−1)]`|再生成对 guidance 方向放大时减小强度；放大也可能是恢复真实细节。|
|2 `cfg_cycle_transport`|`d'=.5d+.5N_d(J_s d)`|尝试使用经过一次再生成输运后的条件方向；这是方向混合，没有证明是向量或梯度的正确几何搬运。|
|3 `cfg_cycle_antidrift`|`d'=d−.5 relu(<d,r_s>)r_s/(||r_s||²+ε)`|抑制与 strong 自身回灌偏移同向的 guidance；真实后验收缩也会表现为偏移。|
|4 `cfg_cycle_common_drift`|探针处 `a=relu(cos(r_s,r_r))`，`b̂=a cap((r_s+r_r)/2,||d_probe||)/max(||d_probe||,ε)`；应用时 `b=||d_current||b̂`，`d'=d_current−.25(I−P_d_current)b`|先对共同漂移限幅，再用连续正余弦加权；每次应用按当前 gap 缩放、正交投影。理想算术下保留 `<d',d_current>=||d_current||²`，极小分母与浮点运算会有偏差，且该局部约束不保证最终语义。|
|5 `cfg_cycle_curvature`|`k=||T̄_s(m+hd)+T̄_s(m−hd)−2T̄_s(m)||/(h||d||+ε)`；`d'=d/(1+k)`|控制同时间局部非线性响应，与 #1 的一阶增益不同；有限差分含高阶项及精度影响。|
|6 `ig_cycle_agreement`|`d_1=T̄_s(m)−T̄_w(m)`；`d'=d relu(cos(d,d_1))`|回灌前后的强弱差方向一致时保留原 IG；一致性并不能区分共同偏差与有效修正。|
|7 `ig_cycle_extrapolate`|`d'=cap(d+.5[d−N_d(d_1)],2||d||)`|对回灌中发生的方向变化作一次有界反向外推；不存在已知误差阶，故不能称严格 Richardson 消差。|
|8 `ig_cycle_weakgain`|`d'=d/[1+relu((||J_wd||−||J_sd||)/(||d||+ε))]`|仅抑制弱读出额外的回灌扰动放大；弱头需要更大响应时可能错杀。|
|9 `ig_cycle_antithetic`|`d_±=T_s(m;±ξ)−T_w(m;±ξ)`；`d'=d relu(cos(d_+,d_−))`|用两份反向噪声下的 gap 一致性控制原 gap；不同于旧 #26 直接平均扰动 gap。两份噪声不足以估计完整不确定性。|
|10 `ig_cycle_twohop`|`d_2=T̄_s(T̄_s(m))−T̄_w(T̄_w(m))`；`d'=d relu(cos(d_1,d_2))/[1+relu(||d_2||/(||d_1||+ε)−1)]`|同时看两轮 gap 的方向持续性与增长；第二轮两头读取不同状态，故 gap 包含路径分离，不能全归因于读出误差。|

极小分母采用 `clamp_min(1e-12)`；方向混合及外推在被输运方向范数不超过该阈值时保留当前方向。非有限探针或非有限/幅度越界的接受状态直接报数值失败。当前实现没有单列退化回退计数，不据此声称已测得退化概率。这十项改变的读数分别是线性增益、传输方向、strong 漂移重叠、共同漂移、曲率、单轮差值持续性、差值外推、强弱相对增益、噪声一致性及双轮变化。它们是机制筛选候选，不宣称十个论文级原创算法。

## 调参与结果解释

每项二十组固定使用五档普通 guidance 强度乘四档回灌时间：`τ_setting∈{.5,.65,.8,.9}`，实际 `τ=max(t_left,τ_setting)`。CFG 的峰值 `α∈{.75,1.25,1.75,2.25,2.75}`；IG 的峰值 `α∈{.4,.6,.8,1,1.2}`，沿用旧 IG 在 `t_left<.25` 时乘 `6/7`、之后到 `.5` 前取峰值的配置。表中的算子系数固定，不再乘出隐藏搜索维度。CFG 与 IG 相同强度数字不代表相同作用。

回灌控制从左端时间 `.125` 起每八个已接受步骤读取一次，可限制成本。CFG 在 `.75` 截止，IG 在 `.5` 截止；早于首次回灌时维持普通 guidance。两个 Heun 子阶段使用同一个已冻结控制值，且更新只能来自合法阶段；当前步尚未接受时不能把其未来状态写入历史。无 guidance、窗口外及零修正必须有明确回退。

实现记录逐图跨活跃查询平均的相对方向变化、有效额外强度、方向余弦、探针响应与漂移/gap 比，并记录每批活跃步骤第一阶段有效强度的五个分位数。没有单列夹断比例；未实际读取的响应或漂移字段使用零占位，不能把占位零解释成实测零漂移。门控方法若只靠把有效强度降到更好的固定值，不足以支持状态相关机制，因此保留低强度原生对照；方向修正另有同探针、同幅度的原方向对照和部分反号对照。

探针 full calls 与 prefix calls 进入正式成本，不能只统计主采样轨迹。本次筛选已包含 96/128 步普通 CFG（强度 1.25）及 MLP IG（强度 .8）对照，用以比较更多采样步的质量与成本；它们是离散预算锚点，不保证逐候选的墙钟耗时或 NFE 精确相同。筛选阶段只声称该固定小样本参数搜索的结果。

二十组挑出的最佳值是调参结果，十项间比较还包含额外选择效应。全新样本确认应冻结被选参数、加入原 CFG/IG 与强对照，不把同一小样本反复选择当作独立证据。

## 文献关系

[Idempotent Generative Network](https://arxiv.org/abs/2311.01462) 明确以输入重建和幂等映射训练生成网络。本轮冻结既有 SiT，仅用回灌响应改变推理引导，没有重新训练幂等生成器；“重复作用后不变”的一般目标已经有先例。

[FiRe: Fixed-points of Restoration Priors for Solving Inverse Problems](https://arxiv.org/abs/2411.18970) 将退化与恢复复合后的固定点性质构造成逆问题的图像先验。本轮使用带条件或弱读出的回灌探针，未求解 FiRe 的恢复目标，也不能从该论文迁移出 CFG/IG 的质量保证。

[Spectral Guidance for Flexible and Efficient Control of Diffusion Models](https://arxiv.org/html/2605.28900v1) 学习条件期望算子的奇异函数，以可保留特征的表示投影 guidance。本轮的单方向有限差分、漂移及一致性门控不估计这个全局谱；若未来把回灌响应拓展为稳定子空间或谱投影，必须直接与其比较。

[Consistent Diffusion Models: Mitigating Sampling Drift by Learning to be Consistent](https://arxiv.org/abs/2302.09057) 研究并训练采样过程中的一致性以减少漂移。其条件期望一致性不要求每条随机图像轨迹逐点相同；本轮不训练跨时间一致性，也不把自身回灌的不变性当作真实数据质量标签。

[CFG-Ctrl、FSG、CFG-MP 的仓库原文审查](FSG_CFG_CTRL_CFG_MP_COMPARISON_20260911_ZH.md) 已说明：分支差、固定点残差及未来一致性都不是通用质量函数。本轮研究回灌控制信号，不重复认领反馈控制或误差衰减的一般观点。

[SAG 与自引导文献审查](SPECTRAL_SELF_GUIDANCE_LITERATURE_THEORY_PLAN_ZH.md) 已核对“预测 clean、退化后重加噪、再查询模型、从差值外推”的先例。故本轮新颖性若成立，只能来自具体的回灌响应诊断、有效控制规律及严格比较，不能来自“重新加噪再去噪”本身。

[IG 原文及承载等式审查](IG_FIXED_POINT_CARRIER_RETHINK_20260909_ZH.md) 进一步指出：strong 与 weak 拟合同一条件目标，不能把它们像 CFG 那样自动解释为有条件与无条件的两个真实后验。本轮所有一致性与漂移信号因此保留代理量措辞。
