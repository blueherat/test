# 来源后验的校准修订：保留原始实验，追加一个确定的概率标定

2026-09-12。SiT原来源头已完成，分类准确率约68.8%，但概率损失和Brier均劣于始终输出.5，存在严重过度自信。原始七臂协议继续保留，不修改其权重、数据、源码或结果；不能把它称为已校准的来源后验，也不能仅凭其生成失败否定提案中的后验假设。

只追加一个标准概率校准操作：在原200个保留噪声中的前100条（seed id 1000–1099）上，以来源标签拟合非负逆温度β，最小化mean[softplus(βl)−yβl]。这是一个一维凸来源分类目标，用导数求根，不使用生成图像质量，不扫描guidance系数。将最后一层权重与bias乘β，故部署结构和参数量不变。

另100条（1100–1199）报告校准前后NLL/Brier；但此前已看过200条的汇总验证统计，因此它是探索性修订的拆分检查，不能伪装成从未使用过的全新测试集。没有重训特征、MLP或去噪模型。SiT的β约.07041，后一半的稳定logit NLL约2.035→.564，Brier约.266→.193。这里NLL用logaddexp计算，不是原脚本裁剪概率后的NLL，不能混作同一个数。

RAE完成其来源训练后，同样执行一次这一校准，不依生成结果决定是否校准。若β=0，读出退化为.5，候选也退化为原IG，应记录退化而不启动重复质量采样。

校准后沿用原400对探索噪声，仅重新生成原强度基线（记录新r的时间均值）及四个依赖r的方法：真实后验、时间均值、同类同时间置换、反向。原半／双常数控制的输出可复用。原强度基线的新主分支应与旧资产逐位相同；额外生成是为重新计算校准后的时间均值，不认作新确认。仍以所有对照的FID和IS判断，不把校准改善当生成成功。

这是本次来源头实现的一次有具体错误依据的修订。没有打开更多深度、head容量、训练步数或尺度网格。
