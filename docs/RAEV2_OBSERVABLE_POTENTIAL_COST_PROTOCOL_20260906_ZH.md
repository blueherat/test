# Observable potential：公平成本 1K 比较协议

> **后续评估更正（2026-09-06）**：下文保留首次 1K 的原规则、结果和当时停止决定。有限样本论文与历史特征复核说明，1K≥5% 不是最终目标的必要条件；现冻结原权重补做配对 5K。新执行状态以[规模审计协议](RAEV2_OBSERVABLE_POTENTIAL_SCALE_AUDIT_20260906_ZH.md)为准。旧结果未改变，尚无公平成本达标结论。

**本协议冻结比较规则；B8 速度和训练成本留作实测变量。** 候选为固定最终 checkpoint 的 100 步 Euler：每步在官方 clean prediction 上加入一次 `c=∇zΦ`，新增一次势网络 forward 和输入 backward；系数为 1，无新增时间窗口。必须同时比较官方 100 步、推理成本匹配和训练准备摊销成本匹配的官方基线，不能按 FID 挑选较弱对照。当前目标见[目标文档](RAEV2_GUIDANCE_GOAL_20260906_ZH.md)，机制及其有限实现边界见[机制文档](RAEV2_OBSERVABLE_ERROR_GUIDANCE_20260906_ZH.md)。

**共同条件。** 固定 `N=1000`、1000 类各一张，使用同一组按 sample ID 保存的初始噪声和类别；所有分支每个 ID 恰好输出一张，保留全部结果。固定同型号、同一张空闲 GPU、batch 8、相同软件与注意力实现；stage2 为同一官方 EMA，BF16 autocast，state 为 FP32，TF32 全局关闭。势网络及输入梯度用 FP32。官方 IG 在原生 BF16 heads 上按 `B+1.78*(F−B)` 计算，区间 `[.1,1]` 外用 Full，再转 FP32 进入 Euler。decoder、归一化、clamp、像素量化、FID 实现及真实 reference 完全相同；其身份、seed、噪声、源码及权重 hash 在看任何本轮 FID 前冻结。

改变官方对照的步数 `K` 时，只改变原 sampler 的 `num_steps`，仍用 shift 8 的完整网格、原 IG 区间及 `t_eps=.05`。尤其 `K≥154` 时最后正时间 `8/(K+7)<.05`，必须保留官方 denominator floor；不能把 100 步中成立的无 clamp 简式移植过去。候选始终保持 100 步。

**先测 B8 时间，再定步数。** 当前 pilot 的 B32 时间不能代替 B8 推理基准。单独冻结计时 request，用同一固定 B8 初始噪声运行完整 100 步：每个分支一次预热、三次正式计时，按官方／候选交替执行，每次重置 state，在计时边界 CUDA synchronize。取全部三次的算术平均，不选最快一次；计时期间不并行占用该 GPU，不计算 FID。计时包含实际模型调用、势输入梯度、Euler 和循环开销，不含两者相同的 decoder 与模型公共加载。预热和计时全部列入研究审计成本。

令 `τ₀` 为官方 100 步 B8 的平均秒数，`τΦ` 为候选 100 步 B8 的平均秒数。定义官方每图每步成本 `a=τ₀/(8×100)`、候选每图采样成本 `b=τΦ/8`。若存在候选独有的部署初始化成本，单独实测为 `SΦ`，分摊给本次 N 张；没有额外项时记 0，不能漏掉实际发生的项目。令 `D_N` 为共同的 N 图 decoder 等推理末端成本，两边都报告，以下定步公式中相消。

| 成本口径 | 候选成本 | 官方匹配步数 |
|---|---|---|
| 推理 | `C_inf = N b + SΦ + D_N` | `K_inf = max(100, ceil((N b + SΦ)/(N a)))` |
| N=1000 的方法总成本 | `C_total = C_inf + T_train + T_encode5K` | `K_total = max(100, ceil((N b + SΦ + T_train + T_encode5K)/(N a)))` |

`T_train` 是一次冻结的 2048 updates、batch 32 训练的实测必要成本，含 **65536 个 stage2 sample-forwards**、势输入梯度、参数反传、optimizer 及方法独有的准备／保存开销；它不能只按 stage2 forward 数估算。`T_encode5K` 是为训练准备 5000 张真实图的实际编码与必要处理成本。训练 batch 32 不必改成推理 batch 8，其实测成本直接加入分子。公共预训练 stage2／decoder 的历史训练成本不重复分配给任一分支。

以上统一采用同型号单 GPU 的实测占用秒作为时间预算；跨 GPU 并行阶段按各 GPU 占用时间求和，不拿较短的并行墙钟冒充总计算。另列 CPU 时间、端到端 wall、GPU 峰值内存、实际模型调用和磁盘／hash 开销，明确哪些已计入上述量，避免重复计费。合并进行的 5K 训练编码与 1K 验证编码要保留各自阶段时间；即使不做验证也必需的 encoder 加载／初始化计入训练准备，只有验证专用的增量归研究审计。无法从记录拆分的成本须注明估计方法，不能把按图数比例估算称为逐阶段实测。

**方法准备与研究审计分账。** 训练 5K 编码和最终 potential 的训练是得到可部署方法的必要准备，因此进入 `C_total`。验证 1K 编码、数值 pilot、完整 `100×1000` heldout 验证、B8 计时、比较分支的评估及 FID 计算属于本轮研究审计：必须完整披露，但它们没有参与参数拟合、checkpoint 或系数选择，不是复用既定算法生成 N 张图所需的部署步骤，不任意塞入部署摊销。若实际使用验证结果拟合／挑选方法，这一前提即失效，必须另行说明并重设独立确认；不能保留“仅审计”的标签。

**步数只由成本确定。** 在训练完成并取得 B8 计时后，保存实测变量、来源、`K_inf` 与总成本的计算规则。总成本的实测窗口若尚有缺项，保留 `U≥0`，不能把已知部分的 ceiling 当成完整成本匹配。最终比较集合为 `{100, K_inf, K_total}`，重复步数合并；不扫邻近步数、不按质量移动 ceiling、不选择有利 seed。ceiling 在线性成本估计下给基线至少相同预算，额外预算小于一整步；最终还要报告各分支实际 1K 时间和成本比。若计时显示线性估计失准，不能把明显不足预算的对照称为成本匹配；只允许由计时决定修订，并在读取该对照 FID 前冻结及保留原记录。

**1K 通过条件。** 对集合中每个唯一官方对照 `j`，均要求 `1−FID(candidate)/FID(j)≥0.05`，即候选 FID 不高于所有对照中最小 FID 的 `0.95` 倍。更高步数若质量下降，也不能解除官方 100 步这一要求。报告所有原始 FID、相对增益和两套成本，不仅报告最佳百分比。通过只表示本次配对 1K 筛查通过；方法冻结后仍需独立噪声确认和相应规模的标准评估，不能据此宣布 SOTA 或完成最终目标。

## 实测后的分阶段执行冻结（任何本轮 FID 之前）

完整 B8 benchmark 已完成：`τ₀=5.00635825524417 s`、`τΦ=5.245812027016655 s`、`SΦ=0.01063977787271142 s`，因此 `K_inf=105`。训练已测主程序 `564.0549605630804 s`；编码 train 相位 `90.44610579917207 s`、validation 相位 `17.39634994394146 s`，另有 `6.018283298937604 s` 共享开销。把全部共享开销分配给训练，编码的已计时准备窗口为 `96.46438909810968 s`；这不是纯初始化计时。

编码先行准备／身份检查、encode 内开始计时前的 CUDA 与 request 设置，以及训练 imports／末尾 summary 等边界没有全部单独计时。因此已知窗口只导出 `K_total≥211`，不能宣称 211 是完整匹配。CPU prepare-only 重放测得 `9.264727710047737 s`，选行和原记录完全相同；它是当前实现的补充实测，不是恢复历史总耗时，也没有独自闭合所有边界。

为避免为已经失败的候选继续投入，在任何本轮 FID 前预注册以下停止规则：先评同噪声的固定候选与官方 100 步；若未达到 5%，直接判这个候选未达标。若通过，再评已冻结的 105 步；若仍通过，再补齐有外层计时的必要准备成本，按同一公式计算唯一 `K_total`，最后评该对照。所有阶段使用同一冻结候选、噪声及评价协议，质量只决定是否继续投入，不能决定成本值或对照步数。完整公平成本的成功结论仍须全部阶段通过。

首次筛查 seed 为 `202609095`；若全部通过，独立噪声确认 seed 固定为 `202609096`。现在尚未计算任何本候选的 FID；这些规则没有依据本轮图像质量调整。
