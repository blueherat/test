# 从“重复复制应保持原图”重新定义反演研究

后续实测已落实本页构造：见[公共反演五轮复制结果](FM_COMMON_INVERSE_COPY_RESULTS_20260913_ZH.md)。包括 SiT-XL 在内，三个参考的 960 个真实图 latent 输出已完成；一维非 oracle 正向可行性实验也已完成。另完成[原图锚定反演复制修复器](INVERSE_COPY_REFINER_RESULTS_20260913_ZH.md)的两版训练、逐轮输出及 CFG/APG 1K 评估，四个设置均没有 FID 收益。本页保留最初的理论重定义，实际进度以后续结果页为准。

用户最新明确：研究起点是多模态生成系统的重复零编辑现象——输入图像，要求完全不变，输出再成为下一轮输入；较好系统较稳定，较差系统逐渐漂移或产生伪影。反演是将这个问题迁移到纯生成模型的工具。未来信息运输、有限映射外推是另一条思路，本轮不能用它们替代“不变性”主线。

后续推敲得到一个更直接的 CFG 命题：**当两个分支都保留完整原图及零编辑要求，只移除已经冗余的类别/描述时，理想 CFG 差场应为零，复制结果应与 guidance 强度无关。** 这是一项在明确条件接口下成立的要求；当前纯类别 SiT 没有该接口，不能把普通 conditional–unconditional 差值直接罚成零。反演可提供原图在各噪声层的参考轨迹，不能代替缺失的条件含义。见[精确命题及迁移缺口](research/identity_operator_20260913/cfg_copy_invariant_after_refiner.md)、[已有原图锚定反演方法](research/identity_operator_20260913/anchored_noop_literature_gap.md)。这是理论结论，不是已实现或已改善生成的新方法。

CFG/APG/CTRL 的组合、调制、CDG 和计划中的独立5K支线已停止。此前1K结果保留，但不作为本次反演想法的成果。停止时没有这些支线的活跃采样进程；已准备的CDG request未启动，5K确认尚未启动。

## 1. 对应原现象的数学对象

令 T 表示完整的“接收图片并按零编辑要求重建”的操作，逐轮执行 x_(r+1)=T(x_r)。要解释的首先是：

1. 原输入是否接近不动点：T(x)≈x。
2. 重复操作是否放大第一次的微小偏差。
3. 稳定点是否仍保留原图，而非已经漂移后停住。

这与“某个改动能否提高FID”是不同的初始问题。稳定性可能为guidance提供设计信号，但必须先定义为什么这里的T本应保留这张具体图片。

原始零编辑任务也没有要求主动修复输入中的伪影：用户给了一张有缺陷的图并要求复制，理想复制器仍应保留它。把有效数据设为不动点、把其他输入投影到数据上的生成解释，是另外需要提出和验证的迁移假设，不能说已由观察证明。

在给定原图x附近，设 b=T(x)−x、J=DT(x)，写 x_r=x+e_r。可微且扰动足够小时：

\[
e_{r+1}=b+Je_r+O(\|e_r\|^2),\qquad
e_K\approx\sum_{j=0}^{K-1}J^j b.
\]

所以一轮很接近，也可能多轮明显漂移；反之，相邻轮次越来越接近，也可能只是收敛到错误图片。这一展开解释研究该现象应同时考察复制偏差和局部误差传播。它没有预先断言模型大小与这两个量必然单调相关。

理想的图像保持算子还不能在所有方向强收缩，否则不同真实图像会被压成少数固定点。在光滑数据流形的理想化描述中，若T逐点保持该流形，则沿其切向必须满足DT(x)v=v；对偏离有效图像的扰动能否抑制，是另外的稳定性要求。该几何描述是假设下的研究语言，不把VAE latent的任意方向命名为“语义”或“伪影”。

## 2. 为什么直接同模型反演还不够

对一个固定、可逆、精确积分的FM映射G，T=G∘G⁻¹在整个定义域恒等。它对真实图、坏图甚至非图像都成立。因此这种T把“不变”写进了算法，并不能复现“模型对图片理解更好，所以复制更稳定”的区分。

同模型有限精度往返可检查实现、数值敏感性和编解码误差。它仍有用途，但不能先把它的漂移叫作生成能力差，也不能把更精确反演自动叫作更好的生成机制。

另一方面，随意改逆向模型也不成立：conditional与null一般对应不同目标；即使两者都精确，跨条件往返也可能改变一张已经属于该类的图。变化不是天然的零编辑错误。

## 3. 最接近原现象的待验证构造：固定独立逆编码，再重建

暂将复制操作写为：

\[
T_{\theta,c}(x)=G_{\theta,c}\bigl(E_{\mathrm{ref},c}(x)\bigr).
\]

E_ref把原图反演为同一噪声层的坐标，G_theta负责重新生成。每轮只传递上一轮图像，重新执行同一个E_ref；没有独立新高斯噪声。**逆编码规则对所有被测生成器保持固定，且不专门由当前被测G的精确逆定义。** 这使生成器有可能真正复制错误，而不是被代数恒等强制通过。

理论锚点可以是同一数据分布、同一类别、同一Gaussian FM训练路径对应的理想映射G*。该训练目标的理想速度是条件期望 E[X−epsilon|Z_t=z,c]；在所需正则与唯一流条件下，采用E*=(G*)⁻¹，就有G*E*(x)=x。被测模型与理想场的差异因此能表现为复制偏差。

实际没有oracle E*。用另一个网络充当E_ref会引入参考偏差，不能把参考模型自己必然闭合的结果当作其质量优势；也不能由跨模型重建漂移直接推出FID排序。当前构造是值得继续研究的任务定义，尚非已经解决参考选择的算法。需要优先确定独立参考、真实图像锚定和共同训练路径，不能把“换个逆模型”当作完整答案。

### 重建不变性怎样才与生成分布真正连接

令真实条件分布为P_c、采样prior为nu。在有限二阶矩等条件下，若共同理想逆E*满足E*#P_c=nu，那么

\[
W_2^2(G_\theta\#\nu,P_c)
\leq \mathbb E_{X\sim P_c}\|G_\theta(E^*X)-X\|^2.
\]

证明只需用Z=E*(X)构造一个输出与真实图的配对。这说明有合适共同逆时，真实图片的逐图复制误差确实能给生成分布误差的上界；不是任意cycle residual都拥有此性质。上界并不保证按重建误差给模型排序，因为同一正确分布也可有不同配对。

对实际固定编码器E，若G为L-Lipschitz，相应三角不等式给出

\[
W_2(G\#\nu,P_c)
\leq L W_2(\nu,E\#P_c)
+\bigl(\mathbb E\|G(E(X))-X\|^2\bigr)^{1/2}.
\]

这里两个条件必须一起看：**真实图片的复制保真，以及真实图片逆编码后的整体分布是否匹配生成prior**。自身精确逆能把第二项做成零，却不会自动把第一项做成零；反演自产样本则两项都容易自证，不能替代真实图像。高维prior匹配不能只用均值、方差或每个noise的norm代替。

这种重建与聚合编码分布共同约束的思想已有 [Wasserstein Auto-Encoders](https://arxiv.org/abs/1711.01558) 等前例。上式是本问题下的直接耦合界，不认领新定理；它的价值是明确后续反演guidance需要保住的理论前提。

## 4. 另一种获得真实复制能力的方式需要学习

[Idempotent Generative Network](https://arxiv.org/html/2311.01462v1)将真实数据自重建与生成输出幂等放进训练目标，并另外限制固定点集合；只要求幂等会允许退化方案。[SIGN](https://arxiv.org/html/2509.21470v1)进一步利用预训练扩散/flow轨迹学习幂等生成映射，提供直接递归使用输出的采样形式。

对当前FM可以研究一个独立重建器P：用真实原图作保留目标，用同条件反演产生仍锚定原图的邻域训练对，学习P(x)≈x及邻域向原图恢复。此时每轮执行P(x)，反演参与构造训练任务，不在推理中与自己的精确逆抵消。这条路线需要新增学习；教师轨迹误差、邻域覆盖及退化为简单复制的问题都仍需处理，不能称为现有SiT免训练已经拥有的能力。

## 5. 如何重新连接CFG/IG

接下来研究的应是：在有真实图像锚点、明确零编辑含义的T中，额外guidance改变了哪种复制偏差与跨轮放大；能否改善生成而保留已经有效的内容。不能把任意强弱往返的非零位移直接命名为“违反不变性”。

在共同逆编码下，可以比较G_strong、G_weak及guided G形成的T。原图是真实已知目标，强弱重建误差因此有可核验含义。若进一步将这个信号用于guidance，必须另做实际生成质量检验；让T停止变化本身不够。

“反演次数”也要分清：一次逆问题需要多少内部积分/求解步，是精度问题；T连续执行1–5轮，是原始现象的观测问题；新guidance部署中重复多少次，是尚待机制支持的算法选择。五轮应逐轮保存和观察，不能先假定五轮优于一轮。

当前优先事项是找到既忠实于原始零编辑现象、又不靠自反恒等作弊的复制算子。没有据此启动新的参数搜索或宣称超过baseline。
