# FSG 七个完整未来假设的实验协议

本轮检验 A1–A4、B1–B3 的明确有限实现，以及三个机制诊断。时间方向为噪声 `t=0` 到最终 latent `t=1`。研究对象是现有 ImageNet100 小 SiT 的固定 checkpoint；不训练模型、内部头或分类器。完整未来指确实续生成至 `t=1`，使用有限步数的数值近似，不表示精确 ODE 解。

## 方法与对照

七项各十组：基础 CFG 增量强度 `a∈{0.75,1.25,1.75,2.25,2.75}`，每项另有两个结构参数。基础 CFG 为 `v_c+a(v_c-v_u)`，作用至 `t<0.75`。状态校准只在第8和24步，分别是 `t=0.125,0.375`；其余步骤按基础采样器推进。所有状态更新限制在当前 C/U gap 和一个正交随机探针组成的二维子空间，用双精度带岭项的响应最小二乘求解，实际目标下降才接受。有限差分步长为 `0.001*max(||x||,sqrt(d))`，写入半径为 `4/64*a*||v_c-v_u||`。这是有意受限的试验，不是对各假设的最优求解。

|方向|测量和优化对象|两个参数值|主要限制|
|---|---|---|---|
|A1 软 Golden Tube|完整终点差，加无条件路径1/4、1/2位置重新运行条件后缀的终点差|后缀权重0.25、1|三个离散时刻的软约束，不要求严格连续不变性|
|A2 完整路径|完整终点差，加1/4、1/2、3/4时距的两条路径差|中途权重0.25、1|欧氏路径距离不是曲率或语义质量|
|A3 冻结目标逆映射|把当前条件完整终点冻结，调整起点使无条件未来到达它|半径乘数0.5、1|不是同起点FSG根；每次校准重新冻结当前目标|
|A4 随机耦合|条件和null实际SDE共享布朗噪声的完整未来差|共同路径1、2条|固定耦合上界，有限Monte Carlo，不等于核分布识别|
|B1 语义一致性|冻结ConvNeXt读取两个解码终点，匹配平方根概率特征|目标/非目标二元，或100类条件分布|额外分类器信息；一致仍可能共同错误|
|B2 竞争未来|正对距离，加目标/竞争类有界margin hinge|hinge权重0.25、1|竞争类取冻结标签embedding最相近的其他类；正margin不保证目标成功|
|B3 邻域一致性|共享正负扰动下的完整C/U未来差|扰动RMS系数0.005、0.02|噪声尺度另乘1−t；两个探针不保证全邻域语义鲁棒性|

优化未来采用16步Heun完整到1。A4采用16步Euler–Maruyama未来，从当前事件时刻到1。对应生成采样器在最初8步使用ODE，其后使用漂移 `2*v−x/t`、扩散平方 `2*(1−t)/t` 的真实SDE尾部；原生SDE CFG采用相同切换时刻和同一布朗噪声。优化探针噪声和真实生成布朗噪声使用不同的固定派生种子。候选之间按输入batch的内容哈希共享随机数，断点重跑不改变轨迹。

七十组对照包括：强条件模型1组、局部注意力IG回归锚1组、原生CFG12组、APG15组、同SDE CFG5组、完整终点根10组、已有FSG算子适配10组、单纯目标类别概率阈值10组、CFG-Ctrl作者离散SMC公式的Heun适配6组。总数140。FSG控制是现有算子适配，不称作者全部模型和采样设置的复现。SMC控制保留作者未除以时间步长的差分以及修正gap历史；Heun两次评估共享步首历史、用左端修正gap提交历史，明确属于采样器适配。

除A3外，共同的终点根对照直接优化同起点完整C/U残差。B1与相同ConvNeXt的目标概率阈值控制比较，阈值0.5、0.8；A4与同SDE CFG比较。其余候选和无额外语义分类器的ODE对照比较。不同方法并未强制同计算预算，必须同时报告实际开销。

## 语义资产与成本

优化分类器为本地固定的 torchvision ConvNeXt-Tiny ImageNet1K V1。数据集100类标签通过已有manifest的 `original_imagenet_label` 映射。目标二元读出使用完整1000类概率中的目标概率；100维读出使用所选100类logit的softmax。内部VAE连续解码后按原生图像映射裁剪到[0,1]，使用分类器官方预处理。额外VAE和分类器在工作进程准备期加载、预热，实际方法内部调用和解码全部计入采样计时，并保存额外处理张数。

独立评价为固定 torchvision ResNet18 ImageNet1K V1，使用最终原生uint8图像。它没有用于状态优化，但仍与生成模型共享ImageNet类体系，不能当作完全独立的人类语义裁判。top1与目标概率只称类别对齐，不称感知质量。独立评价在每组FID之后进行，开销另记；其资产、逐样本预测和文件哈希均保存。

## 三个真实模型诊断

64个新固定噪声，CUDA种子202610088；从100类中无放回取64类，标签种子202610089。使用原生强条件Heun64轨迹，在 `t=0.125,0.375,0.625` 取状态。每个状态作五种配对干预：不变、一次完整根、四次完整根、一次A1、一次A2。诊断固定强度2.25、结构参数1，不根据诊断结果调参。

优化未来为16步；测量未来使用原始 `h=1/64` 网格续生成至同一个终点。保存细网格终点残差、优化网格残差、完整路径梯形平均距离平方、一步和四分之一时距的条件后缀残差、匹配网格null后缀复合误差、竞争未来距离和margin、三种终点的独立类别读出。所有64×3×5=960个状态保留，不筛掉坏根或失败。

第一诊断明确分开条件残差反弹与无条件终点变化。第二诊断只在相同噪声、标签、t下，取终点RMS相差不超过5%的干预对，描述较低路径差异与类别读出的关联；这些对有依赖、经过筛选，不据此声称因果、统计显著性或感知质量。第三诊断分别统计组内低残差四分位和正margin中独立分类器判断失败的情况；低四分位不是精确根。

## 生成质量筛选

全新1K输入bank：连续CUDA B8噪声种子202610090，标签种子202610091，每类10张。全部140组严格共用该bank，不与旧20项的数值直接混比。四张GPU按全局batch索引分片，原始batch、噪声身份、配置身份、完整latent和uint8图像全部保存；每组统一ADM参考与Inception图计算FID、sFID、IS并缓存特征。完整记录负结果和数值失败，不用残差下降代替生成质量改善。

每组实际Full/prefix调用、采样与最终解码时间、内部额外解码和分类图数全部记录。只在真实执行停止后恢复旧队列，避免新预检和既有正式质量采样竞争GPU。独立类别评价和FID不计入采样秒数，但分别保留评价开销。没有自动选择后续5K；本轮只完成既定140组及审计，最佳1K结果属于筛选结果。

## 检查、冻结、恢复与串行调度

首次准备前执行CPU理论检查、全部新优化设置的真实网络有限性和接受条件检查、七项各一条B8完整生成、五种对照完整生成、ODE/SDE零guidance极限、禁止状态校准时退化到对应原生CFG，以及旧IG/CFG/APG逐元素回归。所有方法不得遗留标签覆盖或hooks。

运行前冻结实现、分析、协议、运行时依赖、模型与分类资产、输入bank和预检记录。复用已有原始分片提交及哈希审计机制。已有结果提交后直接恢复，孤立不完整文件归档。流程结束核对全部覆盖和元数据，至少每个family最佳配置逐批哈希、实际成本、缓存特征FP64 FID/sFID复算；独立类别预测也核对文件身份和汇总。

独立tmux队列仅在旧20项根状态同时满足 `phase=complete`、`no_further_sampling_queued=true`、无 `stage` 字段，并确认256/256及最终审计通过后启动。中间stage的complete不满足条件。启动前再次核对新冻结资产和源文件；新队列仅等待时不创建CUDA模型。旧流程失败时明确报错，停止标志按原有机制保留当前配置后退出。
