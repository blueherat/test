# 直接用最终图片真假反馈训练弱头

2026-09-15。用户明确简化目标：D只区分真实图片与强弱外推的最终图片；弱头只通过欺骗D训练。不继续增加独立强分布、弱分布的判别任务。代码已实现；energy候选完成完整评估后，本版本于2026-09-15 21:43（北京时间）启动，实际使用四张4090。

## 最小训练目标

冻结强模型S，保持现有浅弱头W_phi及实际64步Heun采样器。生成端点

\[
R_\phi=T_{S+a(t)(S-W_\phi)}(\epsilon,c).
\]

D_psi(x,c)=sigmoid(d_psi(x,c))只有一个真假输出。类别c只是条件，不是额外分类目标。每步独立抽完整真实训练集的P、新初始噪声epsilon，得到一批实际R_phi。判别器的主要损失为

\[
L_D=\mathbb E_P\operatorname{softplus}(-d_\psi(P,c))
    +\mathbb E_{R_\phi}\operatorname{softplus}(d_\psi(R_\phi,c)).
\]

训练D时R.detach()。随后固定D，弱头用标准非饱和GAN损失

\[
L_W=\mathbb E_\epsilon\operatorname{softplus}(-d_\psi(R_\phi,c)).
\]

梯度经由最终图片、VAE和完整真实采样器回传至W_phi；强模型不更新。没有分布矩匹配、energy score、独立G/Q分类或独立弱采样。Q_phi的生成分布仍由W_phi隐式决定，但不需要在这一训练迭代里把Q_phi单独采出来。

## 实际实现

沿用冻结Inception2048图像表征，接两层256维、spectral normalization的可学习判别网络，以及单输出投影条件头。D只读最终图片对应的表征。真实和生成图片走同一个连续VAE解码路径。保留feature-input R1，系数1；它施加在固定Inception的输入特征坐标，不称为完整像素R1。

数据来自全部126,689个训练样本；每次重新采真实VAE后验和生成初始噪声。`binary_data.py`不加载任何生成样本库。起点为旧最好全量50K guided-weak EMA，训练系数固定1.05；16步D预热后400步W更新，W/D学习率1e-6/1e-4、EMA=.99。训练后按既定完整连通系数扫描与前两名5K评估；若出现胜出5K，用同图原CPU ADM复核。

代码为 `binary_critic.py`、`binary_data.py`、`train_binary.py`。推理仍是128次强模型、64次现有浅头调用，不需要D或Inception。训练只保留P/R两批图像特征并省去独立弱生成，计算量低于之前四源版本。

## 检查与结论范围

CPU检查确认：D-step不向生成特征反传；D更新后固定其参数，G-step仍能把梯度传回生成特征；R1二阶导和全部D参数梯度有限；G输入梯度的方向有限差分误差6.81e-12；增大“真实”logit会降低弱头损失。正式启动还会核对原保存批次的像素、latent以及重算反传求解器的前向逐位一致。

这是标准GAN训练准则用于冻结强模型的共享浅弱头，不把二分类或非饱和损失本身称为新发明。不保证有限D的梯度足够准确，也不靠D损失下降宣称样本改善；以实际1K/5K质量为准。
