## 模型与可训练对象

- 强模型：ImageNet-100 SiT-S/2，v800K EMA。
- 弱模型：最初冻结强模型后训练的 depth4 velocity `FinalLayer`，50K EMA；不是后来的 MLP 或 GAN 续训头。
- 强 checkpoint：`imagenet_sit_flow/runs/sit-s-2_seed0/checkpoints/step_00800000.pt`。
- 弱 checkpoint：`imagenet_sit_flow/multiscale_guidance_study_v1/runs/depth4_v/checkpoints/step_00050000.pt`。
- 采样：沿用当前 GAN 的 64 步 Heun、FP32/TF32；时间从噪声 0 到图像 1。

训练一个含 64 个独立参数的向量 `a`，每个求解器步读取一个参数：

```text
v_i(z,t,c) = S(z,t,c) + a[i] * (S(z,t,c) - W_depth4(z,t,c))
```

同一步 Heun 的两次场查询共享该步系数。所有图像和类别共享该时间曲线；没有新增时间 MLP，也没有状态/类别自适应。
前 32 步初始化为 0.6、后 32 步为 0。这里的 0.6 是用户给出的初始化参照，不把不同历史采样协议下的扫描值当作本实验已经证实的最优值。

所有 64 步都会计算弱头并参与求导。系数用普通 `nn.Parameter`，无 exp/softplus、非负裁剪、固定关闭窗口或系数平滑惩罚。
负系数允许沿强弱差值反向修正；例如 a=-1 时场等于弱预测。这里只描述场的混合，不解释为图像分布的线性混合。

## 训练目标

沿用当前真实训练 RGB→冻结 Inception→条件真假判别头的 GAN。
先做 D 的 logistic 分类和特征 R1 更新，再固定更新后的 D，以 `softplus(-D(fake))` 更新系数。
梯度经过最终图片、解码器和完整采样轨迹。冻结强弱参数不截断它们对状态的输入导数。

当前长程配置：

| 项目 | 设置 |

| 判别器预热 | 128 步 |
| 系数更新 | 用户要求加长后累计 30,000 步，每步同时有一次 D 更新 |
| 全局 batch | 24，3 张 4090，每卡 8 |
| 系数 Adam | lr=1e-3，betas=(.9,.99) |

续训不重复 D 预热，不进行系数网格扫描。最终 raw 曲线保留为主比较；用户在 9 月 20 日追加每 3K 保存点的 5K 评测，用于比较训练过程中的质量变化。

## 数据新鲜性核查

训练从完整 ImageNet-100 训练人口 **126,689 张真实 RGB** 中抽样：每步先随机选类别，再从该类全部训练图片中抽图。
每步重新生成高斯噪声和类别条件，负例由当前系数在线完整采样；不缓存小批生成图反复训练。
随机种子只在启动时设定，之后 RNG 持续推进；续训加载各 rank 保存的随机状态。
抽样有放回，允许偶然重复真实图片；这不同于限定一个固定的小训练子集。

- 960 个 rank 局部 batch 的图索引序列全部不同。
- 每个 rank 的噪声 RNG 在 step64 与 step320 之间均发生推进。

## GAN 是否实际训练：观测与限制

step640→745 的 checkpoint 对照确认 D 的全部 7 个可训练参数张量均有变化，D Adam 步数为 745，系数 Adam 步数为 617。
强弱模型权重哈希保持一致。增加诊断的续训记录 `exact_global_stream=true`，没有重置训练数据流。

每 25 步额外观测以下实际更新，不增加网络前向、额外反传或额外训练样本：

- D 裁剪前梯度范数、实际参数更新范数与相对更新量。
- 真图/假图的 logit 和 sigmoid 概率；D 自信饱和比例（真图 >.99、假图 <.01）。
- G 非饱和损失 `softplus(-D(fake))` 对 logit 的导数幅度 `sigmoid(-D(fake))`，以及接近零的比例。
- 同一次 G 反传到 Inception 特征和生成终点 latent 的梯度范数。二者乘回局部 batch 大小，报告每图梯度的平均范数，不能把不同空间的数值直接比较为训练好坏。
- 64 个系数各自的裁剪前梯度与真实 Adam 更新；零梯度比例及裁剪频率。

例如 step800（累计 672 次系数更新）的三卡观测：D 梯度范数 0.936、D 参数更新范数 0.0741；G 的 logit 导数幅度均值 0.623、特征梯度均值 0.360、终点 latent 梯度均值 4.34；系数更新范数 8.62e-4。
该批次 64 个系数的梯度均非零，D/G 所监测的饱和比例为 0。这支持当前反馈链路有信号，不证明最终图像质量提高，也不排除长程振荡或模式丢失。

观测开关开/关分别与独立普通反传更新对照，Euler、Heun 的损失、参数和谱归一化状态均在测试容差内一致。监测不改变损失、学习率、系数参数化或优化器更新。
异常提示覆盖持续接近零的梯度、D 参数长期不变、系数长期不变、持续饱和、频繁 D 裁剪、非有限数及日志停止更新。阈值仅用于提示检查，不自动改训练策略，也不等价于收敛判据。

## 如何看待 0.5 处不连续

初始的 0.6 跳变来自人为分段初始化。现在 64 个独立参数没有连续性约束；若边界两侧的梯度方向和大小接近，它们可能一起移动，保留大部分初始差值。
累计约 670 次更新时，边界差值仍约 0.596，而两侧梯度和参数更新都存在。因此“断点还在”不能直接推出“GAN 梯度消失”，也不能保证训练 30K 后必然连续。
记录边界差值、两侧梯度随训练的相似程度，并坚持最终同协议 5K 比较；本轮不添加平滑损失来人为抹平断点。

实现入口：[`schedules.py`](../../classifier_guidance/schedules.py)、[`train_schedule.py`](../../classifier_guidance/train_schedule.py)、[`evaluate_schedule.py`](../../classifier_guidance/evaluate_schedule.py)。
启动器增加 `--task schedule` 和 `--task schedule-eval`；原弱头训练默认入口不变。

系数通过 field 内的可训练参数参与现有离散 VJP；传给采样器的固定表只是步索引，未把可训练系数当成固定 `amounts` 后 detach。
GPU 上使用 gather 查表，避免把 CUDA 标量转成 Python 索引导致同步；不改变系数的数学参数化。
