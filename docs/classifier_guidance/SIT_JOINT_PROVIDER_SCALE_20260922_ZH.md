# SiT：联合学习引导弱头与全程有符号系数

日期：2026-09-22。用户要求在一张空闲卡上，与现有 JiT 系数训练并行开始下一实验。

本轮要检验：冻结强模型，以最终生成图像的对抗反馈，同时调整弱头和各时刻的使用强度。不是先规定弱头应拟合哪个 diffusion target，再只搜索其系数。效果尚待 5K 评测，当前工程检查不能代替生成质量结论。

## 1. 实际参数化与目标

令强预测器为 S，弱头为 W_phi，初始 diffusion EMA 弱头为 W_0。

```
Delta_phi(x,t,c) = S(x,t,c) - W_phi(x,t,c)
v(x,t,c) = S(x,t,c) + a_i Delta_phi(x,t,c)
x_end = Heun_64(v, z, c)
I_fake = frozen_VAE_decode(x_end)
F_fake = frozen_Inception(I_fake)
```

64 个 a_i 是直接训练的标量，每个采样区间一个。它们不是人工预设曲线，也不是本轮引入的状态条件网络。初始化全程 a_i=.75，允许负值和经过零点。两次 Heun 场计算共享左侧区间的 a_i；时间网格和步数不训练，NFE=128。

v=(1+a_i)S-a_i W_phi，因此 a_i 确实同时改变强预测与弱预测的线性权重；它不修改强模型参数，也不等同于把求解器步长乘上 1+a_i。最终图像对这些系数及弱头参数的依赖是非线性的。

判别器依然是已有的条件 RGB 终点特征判别器：真实 RGB 与解码后的最终生成 RGB 都经过冻结 Inception2048；训练 2048→256→256→1 的带谱归一化分类器及类别投影。不是直接判断 SiT latent，也不是直接用一个端到端可训练的像素判别网络。

```
L_D = mean softplus(-D(F_real,c)) + mean softplus(D(F_fake,c))
      + (1/2) * mean ||grad_F_real D||^2
L_joint = mean softplus(-D(F_fake,c)) + 0.1 R_gap
```

保持现有 non-saturating logistic GAN 和 feature-space R1，不在这一轮同时更换 hinge loss、特征网络或求解器。弱头没有 diffusion target 回归项，也没有向 W_0 的向量输出 MSE 约束。

## 2. 多解性：应处理什么，不能声称什么

在不受限的向量场空间，任何非零 k(t) 都可以构造

```
a'(t)=k(t)a(t)
Delta'(x,t)=Delta(x,t)/k(t)
W'(x,t)=S(x,t)-Delta'(x,t)
```

使 a'Delta'=aDelta，因而同一确定性离散求解器得到完全相同的结果。只用终点分布目标不能识别其中哪个系数和哪个弱头才是“真正的解”。

但这个函数空间变换包含 S。一个受限的 depth4 浅头未必能精确表示每一个 W'，所以不能自动说当前有限网络的参数空间存在所有这些精确对称性。即使没有精确对称，也可能出现近似补偿与病态优化。

这种多解性不意味着联合 SGD 不合法，也不意味着必须换成双层优化。它提示我们需要约束/诊断参数化的尺度，并评价实际修正场及最终生成器。

在 a_i 接近零时，局部 weak 梯度包含因子 -a_i，可能变小；这不同于判别器梯度消失。系数自身的导数仍包含 Delta，零系数不能被代码跳过。初始化 .75 避免一开始把整条弱头路径关闭；本轮梯度审计也专门包括了零系数。

即使固定 residual 的范数，还存在符号对称、网络内部重参数化、未被探测到的方向以及“不同动力学生成相同终点分布”的可能。因此文中不称本轮方法为严格可辨识的 weak distribution recovery。

一个简单例子是 dx/dt=b(t)：终点只取决于 integral_0^1 b(t)dt。给 b 加上任意积分为零的函数会改变路径，但不会改变任一输入噪声的终点。这种路径多解性独立于 aDelta 的分解多解性；两者不能靠同一个 norm penalty 一并解决。

## 3. 本轮选择：软 residual 能量锚点

每次 joint 更新额外从本批新抽取真实 RGB 的前 8 张构造 probe。冻结 VAE 编码器得到后验，重新采样后验 latent、独立高斯噪声和一个全批共享的均匀随机 t：

```
x_t = (1-t) z + t x_real_latent
E_phi = mean_batch,pixels [Delta_phi(x_t,t,c)^2]
E_0   = mean_batch,pixels [Delta_0(x_t,t,c)^2]
R_gap = log((E_phi+1e-8)/(E_0+1e-8))^2
```

W_0 固定为同一个初始 50K diffusion EMA 头。两种 residual 在相同 probe 状态上计算，从而避免把状态变化误当作弱头的幅度变化。probe 状态分布独立于训练参数，所以这里对强模型/编码器使用 no_grad 不会遗漏这项目标的路径梯度；GAN 的采样轨迹绝不做这种截断。

这是一个明确的“随机 minibatch log-energy ratio 平方”的期望目标。由于 log 和平方非线性，它不是相应总体矩目标的无偏估计；不应混淆二者。

在忽略 epsilon、把 Delta 单纯乘以 k 的理想情况下，这项惩罚变为 (2 log |k|)^2。它会惩罚大幅缩放，而且不会把输出方向强制回到 W_0。有限权重仍允许优化器在幅度变化与终点收益之间做权衡，不能说已经严格分离了方向和幅度。

局限：锚点在真实后验插值分布上生效；学习后的采样轨迹可能访问其他区域，因此它不保证处处幅度受控。当前 profile PNG 也明确是 fresh real-interpolant probe，而非生成轨迹上的总体统计。后续可补充 on-policy 诊断，但不能把离策略 probe 直接写成 sampler 全分布结论。

为什么第一版不硬归一化：逐样本归一化会改变可用的幅度结构和采样函数，epsilon 还影响精确尺度不变性；即使消除了前向输出对 raw residual 大小的依赖，raw 网络参数仍存在径向冗余。它是值得后续比较的另一种方法，不是无需代价的“唯一性修复”。

## 4. 对用户粘贴分析的取舍

采用：从能工作的预训练弱头开始；以完整终点效用训练；同时观察系数、强弱差值和乘积；抑制纯尺度漂移；冻结强参数但保留强模型对中间状态的 Jacobian。

作出以下修正：

- 不用正值 sigmoid 限制系数。此前已有负系数现象，用户也明确允许小于零。
- soft norm penalty 不能证明唯一解；hard normalization 也不能让 raw head 唯一。
- 几次交替 SGD 不能直接表述成解出了 argmin 的 best response 或精确 bilevel 梯度。D 也在变化，包络定理需要额外条件。
- scale 参数量小，不意味着一次 scale 更新很便宜：它仍然需要完整生成轨迹的状态导数。额外做 K 次 scale 更新可能近似多付 K 次轨迹反传成本。
- 第一版采用一次 D 更新、一次 weak+scale 联合更新，分别设置学习率及梯度裁剪。两者共享同一次昂贵的轨迹反传。
- 不为了省显存改成 8/16 步。现有精确逐场重算已能执行 64 步。
- 不预言无锚点 joint 必然失败，也不预言 standalone weak FID 必然变差；这两项都必须实测。

关于双层分析可以保留的部分：固定D时，如果 F(phi)=min_a L_end(phi,a) 有足够光滑的内点最优解，且内层满足 grad_a L_end=0，包络定理允许用 partial_phi L_end(phi,a*) 求 grad_phi F，不一定需要显式 implicit-gradient 项。问题是有限次交替更新没有保证已达到该条件，D还会变化。因此可把 best response 作为理想化分析，却不能把当前训练过程直接等同于解出了它。本轮直接优化 L_end+lambda R 是自洽的联合目标，不依赖这种等同。

TTUR 提供了不同学习率 GAN 的相关理论，但其假设下的收敛结论不能直接套到本轮 D、弱头和时间系数的固定学习率 Adam 系统：[Heusel et al., 2017](https://arxiv.org/abs/1706.08500)。方向/尺度分开设计也有标准参数化先例，如 [Weight Normalization](https://arxiv.org/abs/1602.07868)，但它不是本轮 residual 能量锚点的现成收敛证明。

## 5. 与已有方法、一般 GAN 后训练的关系

[Adversarial Learning of Classifier-Free Guidance Schedules](https://arxiv.org/abs/2608.14038) 已研究通过判别信号学习时间、状态、条件相关的 guidance scale；因此“用 GAN 学系数”本身不能作为全新贡献。[GAS](https://arxiv.org/abs/2510.17699) 将采样器参数学习和对抗训练结合，用于改善少步求解器。这些是直接相关工作。

尤其要区分前者的训练对象：论文以时间相关的密度比/边缘一致性约束引导轨迹的各时刻分布；本轮GAN仅匹配最终RGB特征分布，probe范数项不是中间分布的对抗匹配。二者不能仅因为都使用“判别器+scale”就写成相同训练目标。

本轮具体问题是让可训练的弱 provider 与其使用系数共同适应终点目标，并研究它们的可辨识性、受限容量和优化。当前标量仅依赖时间，其条件化能力比状态网络少；不要把它宣传成更一般的 policy。

从数学上讲，这属于冻结主干、受结构限制的生成器 GAN 后训练：可训练的修正为 a(t)[S-W_phi]。不能声称与 GAN 后训练完全无关。研究价值需要由适当结构是否更高效、联合学习是否超过单独学习，以及尺度约束是否有可重复的好处来支撑。

当 W 可以任意表达、a非零时，一部分系数自由度能被 W 吸收；系数的额外价值可能主要来自受限浅头的可表达范围及优化条件。这比简单声称“系数一动就必然获得更优分布”更严谨。

此外，冻结 Inception 后的判别目标只能直接约束特征分布。后续应使用独立特征的指标、precision/recall 和样例检查来区分画质改善、覆盖率变化及对训练特征的适应；不能用训练判别器分数作为最终质量证据。
