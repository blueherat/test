# AG / IG 平滑假说：CPU 诊断预设协议，2026-09-11

本协议在读取本次模型诊断结果前固定。问题是：现有弱模型的 score 能否由同一坐标上的强模型更高噪声 score 解释？这是网络场的一致性诊断，不直接鉴定采样器的终点分布，也不测 FID。

- 设备：仅 CPU，float32，4 个 PyTorch 线程；不使用正在运行其他实验的 GPU。
- 强模型：ImageNet100 SiT-S/2，seed0，800K EMA；外部弱模型：同一训练运行 500K EMA。
- 内部弱模型：冻结同一个 800K backbone 的 depth4/6/8/10 velocity 读出，各训练 50K，使用 EMA。严格复用已有加载器校验来源及 SHA256。
- 数据：已有 validation SD-VAE posterior moments；NumPy seed 20260911 无放回抽取 32 个图像 ID，保持抽取顺序；前 16 个拟合，后 16 个检验。Torch 同 seed 抽取一次 posterior noise 和一次 flow noise；各时间复用。推断结论只适用于这批 teacher 状态。
- 时间：仓库线性流 `z_t=(1-t)eps+t*x`，`t=[0.15,0.30,0.50,0.70,0.90]`，从噪声到数据递增。
- 坐标：`y=z_t/t`，`q=((1-t)/t)^2`。比较 `s_W(y,q)` 与 `s_S(y,q')`，其中 `t'=1/(1+sqrt(q'))`、`z'=t'*y`，`s_S(y,q')=t'*(t'*v_S(z',t')-z')/(1-t')`。不能保持 z 不变而只改变网络时间。
- 有限平滑候选：`q'=q*(1+delta)`，`delta=[-0.75,-0.5,-0.25,-0.1,-0.03,-0.01,0,0.01,0.03,0.1,0.25,0.5,1,2,4]`。主检验只允许 `delta>=0`；完整带符号拟合作为反向尺度对照；不额外拟合输出幅度。
- 每个时间及弱模型用 16 个拟合 ID 的总平方误差选一个 delta，在 16 个检验 ID 上报告 `E||s_W-s_S(q')||^2 / E||s_W-s_S(q)||^2`。分母是强弱差分能量，不能换成占主导的全 score 能量。
- 导数：固定 y 的相对 q 中心差分，步长 0.002 与 0.001；报告导数收敛误差、与 `s_W-s_S` 的余弦、带符号和非负最小二乘 tau 的留出残差。有限平滑不要求差分彼此共线。
- 不确定性：按检验图像 ID 成对 bootstrap，seed 20260912，2,000 次；不把像素或跨时间的同一图像当成独立样本。给出每格区间，不把探索性多格结果当作确证显著性。
- 正对照：精确双峰 Gaussian mixture，弱分布明确由强分布 Gaussian convolution 得到；验证有限尺度恢复、score 坐标变换及“有限平滑不等于共线”。反例：同样的平滑假说并不保证最优系数在低噪声趋零。
- 输出：保留协议、代码、输入/模型来源及 hash、逐图像误差、所有候选拟合曲线、留出汇总、分析图及其 CSV/XLSX 数据。高维输入与预测保存到数据目录，不写入 Git。

解释边界：即使有限平移拟合失败，也只反对“这组弱网络场等于强网络场的单一额外 Gaussian 噪声尺度”；不能凭此排除各向异性或依赖位置的粗化，更不能断言已经鉴定其机制。若拟合成功，仍需跨样本、轨迹状态及独立终点样本验证。
