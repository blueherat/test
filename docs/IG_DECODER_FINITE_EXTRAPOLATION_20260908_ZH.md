# 像素引导直觉迁移到RAE的有限外推缺口

2026-09-08。不是新方法或质量成功；本轮为下一项AG/IG设计核对坐标与实际作用的关系。

## 新近相关工作与本轮问题

SSG（arXiv:2607.29122v1）冻结像素扩散主干，用自产样本训练中间adapter，再做中间/最终预测外推。它已覆盖“合成数据训练冻结主干弱头”；本文不能将该配方改名为新想法。阅读范围为摘要、引言、相关工作、方法中coarse-to-fine动机、数据/容量消融与附录配置及限制：https://arxiv.org/html/2607.29122v1 。其证据在像素模型上；不能从中直接推出RAE latent外推仍是相同像素方向。SGG的分段引导已有本仓库文献记录，本轮未重启该方向。

令W、F为同一状态上的原生Base/Full clean latent，G=W+1.78(F−W)，D为冻结decoder。直接比较

    A = D(G)−D(F)
    L = .78 [D(F)−D(W)]
    C = A−L。

A是原生latent外推的实际像素变化，L是从两个已解码预测作线性像素外推的增量。D仿射时C为零；一般非线性下没有此保证。若沿d=F−W的曲线φ(u)=D(W+ud)二阶可微，插值余项界为 `||C|| ≤ .6942 sup_{u∈[0,1.78]} ||φ''(u)||`。这是标准有限插值余项界，不是本轮新的质量理论，不声称向量余项可由同一个中间点的Hessian精确表达。本实验不用导数近似，直接读取三个完整decoder输出。

## 对下一步的约束

中间图更模糊、最终图更清晰，不足以把RAE IG等同于沿着这个像素细节差继续前进；在本组非零索引，真实变化方向与它差异很大。因此不能用像素SSG的细节增强解释直接论证一个RAE方法。

另一方面，C可能包含有用的decoder非线性，不能因其大就将其视为误差，也不能把L当作更好图像目标。当前不进行“抵消C”的采样、不用cycle残差替代score、不重启已失败的全局校准。需要先建立有证据的目标，再判断应让guidance作用在latent、解码特征还是其他内部载体。此前终点decoder线性化审计仍有效，本轮新增对象是同状态强弱clean预测的有限外推，不冒充此前从未发现decoder非线性。
