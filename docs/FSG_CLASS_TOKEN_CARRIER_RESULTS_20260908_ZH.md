# 类别 token 承载诊断

2026-09-08。独立 fixed point 路线，不使用 PFR 修正，不是生成方法或论文稿。

固定第14/28层、FP32关闭TF32、8个已有轨迹ID及查询类别 `[0,142,285,428,570,713,856,999]`，步 `[0,47,73,87]`。状态来自此前原生IG轨迹，本次只比较真实类别/null=1000的Full输出。缓存状态SHA核对通过，没有新rollout。

分别用条件、null、错类 `(c+1)%1000` 运行前14层。接收方采用null序列，仅置换8个类别位置、256个图像位置或4个时间位置，再运行Full后半网络。同类别异状态donor固定下一条缓存轨迹，以接收方类别重新运行前缀。“同类别”指查询标签相同；donor的历史生成类别不同，不能称作两个已知同类真实样本。

令g=F_c−F_null，a=置换后Full clean输出−F_null。投影为汇总内积除以汇总g能量，余弦为拼接8样本的余弦，不是解释方差。非线性网络各位置作用不要求可加。

类别位置是有效干预接口，但不承载完整条件作用。“类别方向”仅指冻结模型条件输出差，没有独立确认最终图像语义。

直接搬入另一状态的类别token，三个非初始时刻的作用能量约为接收方自身类别token作用的859/1166/908倍。第二轮在同一donor状态另算null前缀，改为写入：

`h_recipient,null,class + (h_donor,c,class − h_donor,null,class)`。

这是同状态的条件激活对比，不含PFR时间修正。两轮原有7组输出差逐位一致。同状态加减算术对照的相对平方误差最大1.62e−7，远小于迁移误差。

减去共有状态减少了异常幅度，却没有恢复接收方需要的条件作用。当前结果不支持将类别token视为与图像无关的可搬运语义存储器。只检查纯噪声端会漏掉该问题。跨轨迹失败不推出同一轨迹相邻时刻复用失败，后者尚未测试。

实现为 `experiments/probe_raev2_class_token_carrier.py`、`probe_raev2_class_token_contrast.py`，CPU分析为相应 `analyze_*.py`。第一轮96 Full+128前14层+256后14层及decoder；第二轮96 Full+160前14层+320后14层及decoder，均B1。所有192个不置换拆分输出与原生Full逐位一致。CPU重算64组保存向量的Gram，核对源码SHA和共同控制向量，不是独立重跑全部神经计算。

GPU执行器内计算及保存墙钟26.879526+32.525546=59.405072秒，约.01650 GPU小时；加载、checkpoint哈希和CPU分析额外，不是纯kernel时间。两GPU执行器和两分析均退出0。一次py_compile命令漏写`.py`后缀报错，更正后通过。没有训练、图像生成、FID或质量改善结论。

便携结果位于 `experiments/results/terminal_defect_20260908/raev2_class_token_carrier.json` 和 `raev2_class_token_contrast.json`，包含逐查询Gram、输入SHA、源码身份和向量文件SHA。外部向量目录为 `/home/zhoushunyu/data/eqvae/experiments/fsg_class_token_carrier_20260908/` 与 `fsg_class_token_contrast_20260908/`。
