# 用户粘贴方案的真实生成验证：共享 CFG 推动

SiT-S/2 ImageNet100与RAEv2 dinov3l-k7 ImageNet1000同时进入首轮。各模型400个独立样本对，固定每对第一分支作为主要FID/IS输入，第二分支只作配对展示。400图是筛选，不能承担小幅改善或完整质量—多样性前沿的确认。RAE标签为事先随机选定的400个不同类别；其FID对完整ImageNet参考，存在类别子集与小样本限制，只比较同标签同噪声方法。SiT为100类各4个主样本。

两个同条件状态分别运行自己的条件模型C；共享方案用两者gap的算术平均作为额外推动。2×2为独立／相反初始噪声×独立／共享gap。主要分支初始噪声在所有设置中相同。独立guidance不存在粒子通信，改变第二分支不会改变第一分支；代码先检查整段轨迹逐位相同，因此两种噪声下独立guidance的主分支质量复用同一资产，并明确只复用主分支，不伪造相反噪声的第二分支结果。

每格相同两个固定额外强度：SiT γ=1.25及.625，RAE γ=1及.5。没有连续强度拟合、重匹配gap长度、聚类或邻居路由。共8个概念格、6个实际采样臂／模型。SiT保留Heun64、t<.75启用额外CFG；RAE保留原Euler100、shift8、全程CFG，null标签分别100和1000。RAE的CFG为两次完整条件／null前向，不混入IG。

每臂实际采样800条路径，主评价400张。每条输出SiT224次完整前向，RAE200次；每个独立主评价样本的成本对应两条路径，不能称为单图免费。也记录同步后的完整采样和两分支解码时间，不用NFE替代延迟。

实现前检查：独立第一分支对第二噪声的逐位不变性；零强度退化；两个完全相同状态的共享版与独立版逐位一致；完整调用计数与零独立前缀。结果保留全部臂和指标，方法／输入／权重固定后不改源码。

优先用400图筛除明显失败。若共享方法在某个模型的两点最优FID比普通CFG两点最优改善至少2，且IS不下降超过10%，才固定该配置进入新的1000主样本确认；后续5K与更强APG比较以1K确认结果为依据。门槛仅为资源分配规则，不是显著性检验。跨模型不要求强行同号，负迁移也完整报告。小样本结果不追加强度网格。
