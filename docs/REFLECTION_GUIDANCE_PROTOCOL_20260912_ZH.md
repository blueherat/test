# 固定预算反射交替：加性预测错配的生成检验

保留理想分布与共同错误分布的主要结构，单独检验预测加性误差中不符合空间反射对称性的部分是否能在原推理预算内被抑制。该方法不拟合密度比、不增加探针、不训练teacher或独立弱前缀，不从FID选择变换或顺序。

令R为原生latent宽度轴上的水平反射，$F^R(z,t,c)=R^{-1}F(Rz,t,c)$。理想场若满足该反射等变，$F_\star^R=F_\star$；对反射不变的状态测度，Reynolds平均 $\bar F=(F+F^R)/2$ 的平方场误差不超过F。这里只对精确群平均及指定对称测度成立；有限步交替并不是精确平均，实际latent目标不保证反射不变，生成FID更没有由此获得保证。

唯一新采样候选在连续完整步上固定使用A、B、B、A循环，A为原场，B为反射场。SiT同一Heun步的两次查询使用同一视图；RAE为原Euler步。CFG两分支使用同一视图，IG两输出来自同一次共享前向。该次序在等步长光滑自治精确子流下给出对称的平均场分裂近似；真实RAE非均匀步长、有限网络和Euler误差不继承二阶保证。保留原步数、噪声时间、guidance窗口与强度。

SiT-S/2与RAEv2各使用同一全新400样本bank，种子2026121381。CFG和IG共享bank但独立判断。每模型固定11臂：Strong原样／ABBA；CFG原幅度／半幅度／固定反射／ABBA／错配视图ABBA；IG原幅度／半幅度／固定反射／ABBA。错配CFG中conditional用当前视图，null用相反视图，仍为两次前向；它只作为差异误差放大的对照。Strong对照用于区分一般采样改善与guidance本身的改善，不将FID交互差解释成严格因果效应。

每个输出只有一条轨迹。IG每输出SiT128、RAE100次full，CFG分别224、200次full；额外prefix为0。翻转和内存搬运的耗时另测，不能用NFE宣称完全零成本。无引导ABBA也会改变原Strong轨迹，故不宣称零guidance等于原采样；其明确对照就是Strong ABBA。

ABBA在各自轨道须优于原幅度、半幅度、固定反射至少2 FID，IS至少为原幅度的90%，才进入全新1K完整类别确认；CFG错配视图结果同列报告。若晋级，1K还加入预定APG强基线，随后再决定是否5K。400样本尤其RAE的类别覆盖限制不能作为最终质量结论。所有方法固定原系数，不搜索反射周期、起始相位、截止区间或混合权重。未通过则结束当前反射构造。

实现检查包括：R为精确自逆置换；原视图包装与直接CFG/IG逐位一致；固定反射采样与“反射噪声后运行原采样，再反射输出”一致；所有输出的full/prefix计数符合协议。检查不以额外真实生成对照替代，仅用小批量实现核验。记录每步视图和反射时间步权重。

已有工作边界：[Visual Anagrams](https://arxiv.org/html/2311.17919v2)研究变换后预测的融合，也包含交替方案，其多视图错觉实验中平均优于交替，且讨论latent变换的伪影。仓库[旧第24项](SIT_GUIDANCE_50_IDEAS_CATALOG_20260910_ZH.md)额外调用后只平均IG差值，结果没有超过原IG。本次对整个场在原调用预算内交替，是对最新加性错配讨论的一个具体实例；不声称群平均、交替视图或反射本身具有新颖性。只有真实收益、跨模型验证及进一步机制区分才能支持核心方法贡献。
