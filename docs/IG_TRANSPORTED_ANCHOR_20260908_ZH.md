# 全局内容弱查询的冻结平移拉回：固定 1K 方法

全局与 2×2 anchor 同一 1K 分别 FID38.145579 与38.146866，原 IG38.264239。没有布局分辨率收益，不继续分辨率搜索。本版改变读取算子，不改变载体分辨率或强度。

    a = spatial_mean(F(z,t)-B(z,t))
    T_t(z) = z + (1-t)*a
    W = B(T_t(z),t)
    B_ref = W-a
    guided_clean = F + .78*(F-B_ref)

动机：在本次查询局部冻结 a，则 DT=I，partial_t T=-a。弱速度在原坐标中是 vW(T,t)+a。当 t>=.1 大于 velocity floor .05 时，这恰好等于 (z-(W-a))/t。旧版直接以 W 作为 clean 参考，未包含此冻结平移的拉回项。t=1 时虽然 T=id，时间导数仍非零，所以本版本依然扣 a，但直接复用 B，无额外前缀。

这只严格描述局部冻结平移。真实 a(z,t) 的空间雅可比与完整时间导数被忽略，不能声称是完整非线性 pullback、密度变换定理或 FID 保证。也可能仅改变全局 gap 的有效强度，若有效仍须排除此解释。当前直接进行质量试验，不将恒等式或 gap 下降作为成功。

实际沿用原 velocity 外推，两个 clean 输出均对原 z 换算。实际状态只按 guided Euler 更新。仍持续 guidance，未永久移除强模型。100步 shift8，IG1.78，原活动区间，B4，FP32 状态/BF16+TF32，seed202609413，标签0..999均固定。每图100 Full+98 Base前缀，不训练。四卡协同生成一个方法1000张，每batch原子保存；仅评估新方法，复用已有 baseline 和 anchor 结果。不写论文。
