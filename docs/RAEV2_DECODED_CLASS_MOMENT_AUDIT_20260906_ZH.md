# RAEv2 解码后类内／类间矩审计

**两个完整 5K bank 中，IG 在 Inception 特征空间使类内散度下降、类间散布上升，方向与 raw latent 相反。两项都更接近原图统计。** 这细化了 IG 的分布响应，但没有导出可实施的 guidance，也不是新的 FID 或目标达成结果。

本轮先固定问题，再读取特征数值：解码后 pooled covariance trace 的校准，是否由类间结构增大提供，而不是类内扩张？沿用旧 seed `20260801/20260802`、全部 1000 类每类 5 张及原 800/200 类划分。没有读取其他 guidance scale，没有拟合参数、变换、白化或采样。

**原图与重构分别报告。** 数据来自 `raev2_ig_scale_response/n5000_seed{seed}_scales7_v1/inception/`，每分支四个 `(1250,2048)` FP32 shard，按 `global_id=rank+4×local_row` 交错还原。`source` 是原始图片的 Inception 特征；`real` 是 `D(E(x))` 重构特征；`scale_s1p000000` 和 `scale_s1p780000` 分别为 Full 与官方 IG 的历史终点。四个分支没有混合。重构参考用于区分特征映射与参考对象变化，原图仍是实际图像比较对象。

Full/IG 的同噪声配对依据旧 runner 和 manifest；原 cache 没有逐图 noise SHA，不能补称存在这样的原始证明。manifest、sample protocol、原图行号、类别、划分与已完成 raw latent 审计逐项一致。所有 32 个 feature 文件保存完整 SHA256。旧 decoder 路径先 `.float()` 再 clamp 与乘 255，不等于当前 native BF16 量化协议；这些历史结果不替代新方法的成本匹配基线。

**定义与去偏。** 每类样本数 `m=5`，类别数 `C`；所有原始 FP32 特征转 FP64 计算。设 `T` 为全部 `mC` 张图的 ddof=1 covariance trace，`W` 为平均类内无偏 covariance trace，`B` 为类均值的 ddof=1 covariance trace。则

```text
B* = B − W/m
T = W + m(C−1)/(mC−1) × B*
```

这是精确样本 ANOVA 恒等式。`B*` 的期望解释要求类内样本估计同一条件总体；不把无放回的 ImageNet 抽样当作完整有限数据集均值风险的精确证书。均匀固定类别混合分布的 covariance 无偏估计采用 `W+(C−1)B*/C`，与通常 pooled 样本 covariance 的系数略不同。2048 维、1000 类时，类均值 covariance 的秩最多 999；修正后的矩阵通常不是 PSD，不能直接计算所谓“去偏 FID”，本轮也没有构造该矩阵或裁负。

各划分的 pooled、类内、修正类间三个 trace 都向原图靠近。不能把“类内下降”写成多样性恢复失败：Full 在该特征空间的类内 trace 本来偏大，IG 的收缩是在修复过方差。全 5K 的加性分解为：

| seed | Δ pooled T | Δ 类内 W | Δ 修正类间贡献 |
|---|---:|---:|---:|
| 20260801 | +1.350542 | −3.547239 | +4.897780 |
| 20260802 | +2.854841 | −2.514530 | +5.369371 |

因此 **pooled trace 的正增量由类间项提供，类内收缩抵消部分增量；但类内与类间的统计误差都在减少。** 这两个陈述同时成立。矩的代数贡献不是 FID 的因果贡献。

这种反转**不能单独证明 decoder 非线性或 Jensen 偏差机制**。例如二维 covariance 变化 `ΔW=diag(2,−1)` 的 trace 为正，但在线性映射 `A=diag(1,2)` 下，`trace(A ΔW Aᵀ)=−2`。各向异性的线性特征映射就足以改变 trace 的符号；Inception、clamp 和量化也共同参与当前观测。它排除了不区分空间的统一方差扩张叙事，没有确定应修改的采样方向。

**类中心误差不是类间散布。** 真实图像与生成噪声在给定类别后独立，类中心平方误差使用

```text
M_A = mean_c ||mean(A_c) − mean(R_c)||² − (W_A+W_R)/m
```

Full/IG 的位移能量必须使用配对 `W_delta=W_IG+W_Full−2×cross_within` 去偏；误差与位移的内积也保留对应交叉项。实现逐类核对 `ΔM=2×corrected_error_shift_cross+corrected_shift_energy`，不把两臂或五张同类样本当成独立重复。

| seed | 参考 | 修正类中心误差 Full → IG | 配对 ΔM ± 描述性 class SEM |
|---|---|---:|---:|
| 20260801 | 原图 | 2.729747 → 1.472105 | −1.257643 ± 0.287772 |
| 20260801 | 重构 | 2.641457 → 1.338801 | −1.302657 ± 0.285072 |
| 20260802 | 原图 | 1.920118 → 1.376391 | −0.543727 ± 0.315068 |
| 20260802 | 重构 | 1.967405 → 1.385426 | −0.581979 ± 0.329186 |

第二个 seed 的 `mean ± 1.96 SEM` 跨零，两 seed 的 heldout 类中心误差区间也都跨零。SEM 描述固定类别间的异质性，不是条件于这 1000 个固定类别的精确抽样置信区间；不能宣称已获得总体显著改善。raw latent 中类中心误差的变化方向相反，但这些不同几何中的风险不是同一个质量指标。

更换原图／重构参考导致的配对风险变化之差，精确为 `−2 mean_c[(mean_IG−mean_Full)·(mean_source−mean_reconstruction)]`。两 seed 为 `+0.045014/+0.038252`，只减弱了原图参考下的平均收益，没有改变上述均值方向。该恒等式已逐项核对；共享原图参考与 Full/IG 配对不会被误当成独立误差。

**验证、成本与决定。** [CPU 实现](../experiments/audit_raev2_decoded_class_moments.py)核对直接 pooled 方差与 ANOVA、全部配对协方差恒等式、风险归因及参考效应、序列化和 raw/decoded 身份。读取的 feature 有效载荷为 **327,680,000 bytes**，脚本计时 **12.914 秒 wall、12.903 秒 CPU**，峰值 RSS 约 **1.071 GiB**；GPU、生成、解码、Inception 调用和参数拟合均为 **0**。计时从脚本导入 `time` 后开始，不包含之前的解释器启动与最后 summary 序列化／退出；SHA 读取与数组读取均在计时内。独立复核记录及完整来源见[机器归档](data/raev2_guidance_restart_20260906/decoded_class_moment_audit.json)。

独立审计不调用 producer 函数，从全部 32 个原始 feature shard 用逐类 pairwise／U-statistic 恒等式重算，完成 **1030 项核对、16,526,948 个数值比较**，最大绝对差 **5.68×10⁻¹³**；来源哈希与身份链也通过。独立脚本另耗 **7.930 秒 wall、7.893 秒 CPU**，GPU 调用为 0，运行源码已保存到实验目录。它复核了数值与当前缓存身份，不宣称从头重新生成历史特征。

本轮结果要求后续理论区分表示空间与类内／类间误差。它仍不能确定一个控制向量场：trace 不包含 covariance 方向、同一 trace 变化对应许多不同轨迹，终点统计也没有给出可用的轨迹因果干预。没有据此添加缩放、时间窗口、投影或 controller；最终公平成本下 FID 至少降低 5% 的目标保持 active，尚未达成。
