# RAEv2 配对桥流：固定可学习性实验

日期：2026-09-06。状态：实现与独立审查阶段，尚未训练或获得新质量结果。首次 GPU 数值 pilot 前以脚本 request 中的 SHA 固定本协议、模块、测试及 runner；结果另写，不回改已开始阶段的协议。本次为当前已授权研究中的一次机制实验，不需要新的用户批准。

## 机制与有限实现

依据[有限步缺陷与桥校正推导](RAEV2_ACTUAL_ROLLOUT_FINITE_TRANSPORT_20260906_ZH.md)，真实 teacher `Z_t=(1−t)X+tε` 经原生一步得到 `Y=T_native(Z_t)`，真实下一时刻为 `W=(1−s)X+sε`。令 `R=W−Y`、`Uτ=Y+τR`。辅助速度的总体回归目标为 `w(U,τ,t,s,c)=E[R|Uτ=U,τ,t,s,c]`。

精确桥流把 teacher 一步分布推到真实下一边缘，对任意实际输入分布给出相对 KL 非扩张；可逆时为等号，不能宣称自动收缩已有误差。有限模型的均值偏差进入起点速度；即便这个均值为零，条件残差 covariance 的散度仍产生非零的后续速度。这是本次区分普通均值回归与有限桥校正的机制。

部署网络只读取当前 `U,t,s,τ,c`，不能读取真实 X、ε、W、冻结原 Y/Z_t 或主模型中间特征。辅助函数的有限表示与数值积分不自动继承精确流的 KL 结论。本实验不要求先估计完整高维 KL 才能测试可学习性；所有有限可观测量按各自对象报告。

固定归一化为 `β=(t−s)/max(t,.05)`，网络输出 `fθ`，实际速度为 `wθ=βfθ`，训练目标为实际 FP32 差 `R/β`。β 来自原生一步尺度；它是参数化和目标单位变换，不是新增 guidance gain。各时刻归一化会改变有限函数类的优化权重，但不改变给定 `(t,s,τ,c,U)` 时的总体最优条件期望。禁止用简式 `X−G` 静默替代实际标签，尤其要保留 floor 与浮点差异。

训练和 teacher 验证统一使用 FP32 `(1−τ)*Y+τ*W` 的插值运算顺序，与实数定义 `Y+τR` 相同；不混用两种浮点算术。原生网格统一在 CPU FP32 构造后转 GPU，与现有严格采样器一致。

原生 baseline 为冻结 RAEv2 EMA100080、100 步 shift8 网格、原生 BF16 `B+1.78(F−B)` 及其已有 `[.1,1]` 区间，然后转 FP32；FP32 状态更新为 `z−(t−s)*((z−G)/max(t,.05))`。候选在全部 100 步的 successor 后校正，无新增原时间窗口。

固定辅助积分为两个查询的 explicit midpoint：

```
k1 = β fθ(Y, t, s, 0, c)
Uhalf = Y + 0.5*k1
k2 = β fθ(Uhalf, t, s, 0.5, c)
Ynext = Y + k2
```

不固定第二次查询的状态为原 Y。零初始化时两次输出为零，精确保持原生 successor。这个选择能看到起点速度为零时的辅助时间响应，但不是完整流：在独立 Gaussian 的 `b=Var(R)/Var(Y)` 例中，midpoint 伸缩为 `(4+3b)/(4+b)`，其方差相对目标还差 `−Var(Y)*b³/(4+b)²`。不据此声称有限 solver 有普遍 KL 非扩张，也不扫描辅助步数。

## 固定辅助结构与对照

两网各 3,652,224 参数，均为直接向量场。输入为 `[B,1024,16,16]`，完整状态始终保留在 residual 通路：

- 类别 embedding 为 64 维；`t,s,τ,β` 各用 32 维正余弦 embedding，输入时间乘1000，频率沿用常见指数频率构造。
- 拼接的 192 维条件经 `192→128→1024`、SiLU MLP；加到原 U 和零初始化的 `[1,1024,16,16]` 位置参数上。
- 两个 residual block：`h ← h + Conv1x1(SiLU(DepthwiseConv3x3(h)))`，输入输出均保持完整 1024 通道。
- 最后完整 `1024→1024` 的 1×1 向量 readout，权重与偏置全零初始化；无 scalar potential 输入梯度、归一化层、裁剪、dropout 或手写 τ 乘子。

辅助网的卷积有效视野为5×5，是固定局部近似偏置，不能据其失败否定所有桥校正。完整状态通路避免旧固定128维输入/梯度子空间的限制。宽度、优化器和数值预算是预先固定的工程选择，未声称由定理唯一决定。解析卷积/线性成本约 0.81018 GMAC/样本/field，不含逐元素操作、访存和检查；墙钟另测，不能拿 MAC 直接冒充部署时间。

两网在同一个 run 内以完全相同初始化、原始 teacher 批次、主模型预测与优化预算训练：

| 名称 | 训练输入 | 训练标签 | 有限积分 |
|---|---|---|---|
| candidate | `Y+τR`，独立 `τ~Uniform[0,1]` | `R/β` | 上述 midpoint，τ0与τ0.5 |
| mean-only control | Y，τ固定0 | 同一个 `R/β` | 相同两次查询，均输入τ0，但第二次状态仍为自己的 Uhalf |

对照是起点均值场的动力学对照，不是单次 Bayes 投影，也不是另一组待搜索的候选。它用于判断额外桥条件化的作用。两网各自独立 Adam，主模型 teacher 前向共享。成本记共同总账和各辅助账，绝不把候选独立使用仍需的主模型/数据成本平分掉。

## 数据、训练与冻结规则

使用已有严格 RAE latent bank `potential_clean_bank_fp32_v1`：5000 张训练图（每类5张），1000 张当前参数拟合外的验证图（每类1张），源数据行无交集。latent 为已归一化的 FP16 存盘，读取提升 FP32；该 bank 中 FP32 指源图输入处理路径，不表示存盘 dtype 为 FP32。验证图已用于此前研究，不冒称全研究历史从未见过的独立质量确认。

训练固定 `2048 updates × batch32 = 65536` 条新 teacher 配对：训练图独立有放回抽样，100 个原生 query index 均匀抽样，Gaussian noise 新生成；candidate τ 独立均匀。两网各用 Adam `lr=1e-4, betas=(.9,.999), eps=1e-8, weight_decay=0`，无 EMA、学习率调度或 clipping。损失为均匀坐标和样本平均的 `.5*f²−(R/β)*f`；省略的目标平方项不改变回归梯度。只保存最终2048次更新的两份权重，不看验证选择 checkpoint。

随机种子固定：model202609141、data/time202609142、noise202609143、τ202609144、validation202609145、actual rollout202609146。辅助权重、状态、训练均FP32；主模型BF16 autocast、原生头 dtype 混合；全局 TF32 关闭。主模型参数冻结且不接入 optimizer。

全部真实主模型调用统一为 B8：训练/验证的外层 B32 分成4个B8；每个验证时刻最后4张重复本批行补到B8，只对原4张评分，实际8张调用照计。真实 rollout 同为B8，避免将不同主模型 batch 内核视作逐位相同的 T。辅助模型训练仍为B32，验证B32或4、rollout B8，其数学函数按 batch 分离，有限浮点 batch 差异不冒称逐位消失。

训练前一次数值 pilot 用训练 bank 的前32张、8个预先固定的 query index 重复4次和τ0.5，核对原生 wrapper/零校正 parity、有限梯度，并对每网更新8次确认能执行回归。此 pilot 权重丢弃，正式训练从原始固定初始化开始；它不是 held-out 或质量证据。零 readout 导致初次 trunk 梯度为零是正常现象，仅要求总梯度有限非零，不要求每个参数初次都有非零梯度。

## 固定验证与实际轨迹检查

验证使用全部1000张当前 fit 外图：固定随机排列后划分10组，每组100张。第 k 个 query 使用组 `k % 10`，因此覆盖全部100个 query，每时刻100张、每张图10个时刻，共10000条。每张图使用一个独立新 Gaussian noise，在自己的10个时刻复用；图像和噪声因此形成相关簇。

监督验证只在真正 teacher `Uτ=Y+τR` 上，candidate 固定检查 `τ=0,.5,1`，mean-only检查τ0。报告预测能量、标签能量、内积及相对零预测的风险差。**部署 midpoint 的 Uhalf 不服从这条配对 joint，不能把原 R/β 当它的真实速度标签。** 不将端点配对 MSE `||Ŝ(Y)−W||²` 作分布改善门槛；即使正确恢复 Gaussian 方差，这个配对 MSE 也可能增大。

有限输出 official/candidate/control 分别使用各自正确的更新，目标仅为 W 的边缘统计。固定可观测 φ 为全1024通道的空间均值和空间平方均值，共2048维；不拟合投影、频段或半径。保留每时刻原始 moment sums 和配对差平方和，报告经验均值差的平方与配对残差的非对角交叉内积。固定异质类别/图像不构成 IID，这个交叉量不称总体 squared mean gap 的无偏估计，其期望也可能因异质性为负；不添加独立样本 CI。它们是固定 cohort 的可观测量，不是完整分布距离、KL 或 FID。

另以固定新噪声、类别0…31、B8做三组真实完整100步 rollout，共96条。每步记录同一 φ、末端 latent 与各臂成本；没有真实 X 作为这些状态的 denoising target，也不做解码或FID。这是一次有限模型的轨迹稳定性和分布外响应检查；32类不代表全部类别质量。逐步FP64统计与拷贝包含在计时内，所以它不是纯部署性能 benchmark。

每阶段记录真实主模型/辅助网 forward call 和 sample-forward 数、参数 backward 数、显存峰值、计时边界、数据/代码/checkpoint 身份。数值 pilot、候选训练、mean-only对照训练、验证及96条诊断 rollout 全部作为研究成本保留。

这个实验只检验一个已固定结构，结果不得选择新的宽度、τ步数、原时间gain或window。可学习性、teacher上的有限分布修复、实际轨迹响应分别判断，保留阴性结果；不因一个代理改善就称FID改善，也不将1K≥5%设为最终目标的必要筛选条件。下一阶段是否进入完整配对1K，应根据这些实际机制证据决定，并在采样前另固定公平成本协议。**当前至少5% FID提升目标仍未达到。**
