# 五个机制候选的生成与接续协议

本协议在任何本轮FID结果产生前固定。对应[五个机制假设及反例](FIVE_MECHANISM_IDEAS_20260912_ZH.md)和[训练协议](SIT_MEASURE_GUIDANCE_TRAINING_20260912_ZH.md)。新实验先完成，再恢复旧优先批次和大队列。

## 样本、方法及对照

模型为原small SiT 800K EMA、原MSE VAE、原ADM参考与Inception图。沿用control队列的配对1000噪声和标签，每类10张；noise seed=202610100，label seed=202610101。候选和对照的原始像素、latent、逐batch索引、实际调用、耗时和特征全部保留。不是新的独立确认bank。

本轮共59组：24组候选、35组对照。重跑原strong、原生IG(.8)、局部IG(.8)、此前最佳原生CFG(1.25)与APG(2.0, beta=−.5)共5组；原大队列的完整基线曲线也作为外部对照列出，不能只挑一个较差点。

八个训练弱模型各跑α=.5/1.25/2/2.75四组，共32组。其中clt、factor、local_label、defensive分别对应59、60、61、63，其余native、heat、plain_mix、random_label是消融对照。强模型冻结，速度为v_s+α(v_s−v_w)。AG机制组在t<.5应用，类别粗化组在t<.75应用；候选与对应训练对照完全同窗、同强度。它们使用完整弱模型，不能报告为单次前向IG。

62用普通CFG，α同四点，在t=.5插入一次条件生成流共轭OU更新，ρ=.9/.97，共8组。正反条件流各32步RK4，共256次额外完整前向。另有相同α的ρ=1往返对照4组、ρ=.9完整类内经验协方差Gaussian更新4组、同一近邻类别的hard-pair对照4组，以及α=0的两组OU分布保持对照。Gaussian更新使用训练数据的完整低秩协方差与VAE posterior方差，不使用逐样本探针。所有主路径为原64步Heun，两个RHS评估保持同一步guidance量，CFG在t<.75生效。

α是相对于条件强模型的额外系数，不是有些论文中以无条件模型为起点的总CFG倍数。训练弱模型组使用固定α；原生IG仍按原代码的早期6/7比例复现，其旧基线不改。对应训练对照使用与新候选相同的固定α，避免用时间形状变化解释组内胜负。

## 机制与实现校验

先在解析分布检查CLT的低阶保持/高阶缩减、加噪相容性、区域边际保持、类别总体边际保持、共轭OU的Gaussian不变性及混合weak的密度比界，并保留CLT增加峰数的反例。这些是数学与实现校验，不是实际模型已经符合假设的证据。

再在128张互斥验证图、三个噪声水平上读取strong、depth4/6/10和八个新weak。64图拟合、另64图检验，原图ID不重叠。比较各已知分布干预的score/velocity特征对实际IG gap的解释力；同预算native用于扣除共同短训变化，另设原场与输入的两参数标定对照。这些拟合仅用于离线诊断，正式算法不读取拟合系数，不用诊断值选动作或调强度。

四卡正式生成前逐项运行全轨迹、零强度原生退化、调用计数及hook恢复检查。四个已有基线需在原control输入上复现已有首批latent；正式worker还沿用旧pipeline的局部IG逐元素预检。条件流往返在独立状态检查相对误差，并保留ρ=1质量对照，不从近似反演直接宣称精确不变性。

全队列完成后审计全部请求和覆盖；每个family最佳完整配置另核对原始batch、聚合文件和计时，并从缓存特征独立FP64复算FID/sFID。训练成本另报，不能隐入或省略为零。

## 判断与停止

1K结果用于探索，不能称统计显著或独立确认。有限训练若没有学会目标分布，只能说明该干预模型不足，不能否定总体机制。学会目标但不改善生成，则收缩方法主张；FID改善但无法区分替代解释，则只保留经验结果。任何数值失败完整记录，不生成部分FID。

本轮不会自动追加新超参数、5K、模型训练或其它候选。59/63共享退化资产，不把同一结果重复计为两份独立证据。无需把CFG候选移植到IG才允许继续。
