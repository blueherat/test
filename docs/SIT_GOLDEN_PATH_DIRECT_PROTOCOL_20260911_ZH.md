# 直接验证同一状态的无条件—条件未来相等假设

针对“先验证无条件等于有条件是否更好”的追问，直接检验FSG Eq.6的同状态未来一致性，独立于现有FSG适配器。固定原机制集前16个噪声、CFG a=1.25轨迹、t=0.125/0.375/0.625，真NULL标签100。

在完整4096维latent上比较三个目标：完整未来的 U(x)-C(x)、U(x)-C(x_original)、当前速度差 vc(x)-vu(x)。所有分支对状态求导；条件未来是否冻结由目标明确决定。不会优化分类器或其他图像质量读出。

使用FP32模型、关闭矩阵TF32、可微math attention、冻结模型权重。优化器为L-BFGS，64次外层迭代、历史12、强Wolfe线搜索。损失按各样本初始MSE归一化；逐样本若目标上升即回退该次更新并重置历史。保存第0/1/4/16/32/64次。

优化时用12个剩余区间的Heun积分，正式测量使用原64网格剩余段，分别保存纯NULL、纯条件、原CFG续生成。同时记录粗/细残差、位移RMS、状态RMS、条件目标漂移、两种后验图像分类器读出及原始256px图片。预检查包括标量目标的AD/FD导数核对、可微求解器与普通12步版本逐位回放。

64次后的额外对照：把最终更新投影到原半径r=(4/64)a||g||或4r；以及与最终更新同长度的CFG方向。另有完整NULL逆流实现冻结条件目标的oracle。投影对照不是球内最优解。

先用固定前2张、t=0.375、agreement目标运行16次作可执行性与梯度检查；不据其图片质量改参数。通过后执行完整固定协议。

本实验是机制诊断，16张不计算或报告FID。原32项1K配置继续完成。若无法在细网格上达到接近相等，会如实报告“尚未充分检验严格等式”，不会把小幅残差下降当作等式成立。无约束优化也不能保证论文Eq.6中的概率流形约束；投影、位移和图像检查用于显示这一限制，不能替代严格流形验证。

主1K采样在当前配置全部分片结束后暂停，诊断结束后在finally中恢复；冻结的原实验不作修改。
