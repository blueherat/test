# FSG 前向目标匹配补充审计

针对此前以高精度连续流近似终点评价 Euler 适配器的问题，在已有独立 AD/FD 检查之外补做完整 32 样本比较。原实验代码、数据和参数保持冻结，补充实验单独记录。

- 使用原 Jacobian 实验完全相同的 32 个噪声、两档 CFG 轨迹、三个时刻及四档 H；批大小仍为 8。
- 对同一状态固定两个目标：8 子步 Heun guided flow 的终点，以及原 FSG 适配器单步 Euler 前向的终点。
- 比较未裁剪 FSG、与其实际长度相等的 CFG、裁剪 FSG、等裁剪长度 CFG、一阶 H(1+a)g，以及两个目标各自的精细 NULL 逆流。
- 所有误差直接计算实际有限位移后的 NULL 终点，不依赖任何 Jacobian 或有限差分近似。分别以目标与原 NULL 终点的距离归一化。
- 显式记录 ||δ||/(H||g||)、||δ||/[H(1+a)||g||] 和方向余弦；等长度控制在每个样本内验证。
- 手写 Euler 公式必须与冻结适配器逐位一致，已存在目标的数值结果必须与原实验重放一致。完整结果为 5376 行。
- 模型使用 FP32、关闭 TF32 矩阵乘，与原 Jacobian 实验一致。采样计时不与补充审计重叠：只在当前 1K 配置的四个采样分片全部完成后运行，并在 finally 中恢复主控制进程。
- 本补充实验检验目标定义和反演误差，不能把这些误差直接解释成生成质量。
