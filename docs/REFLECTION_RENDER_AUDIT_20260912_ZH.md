# 反射表示的解码检查

SiT固定latent反射的CFG／IG均明显退化，因此增加一个不改变原22臂的解码诊断。只复用每模型每轨道 `fixed_flip` 臂已完成的400个latent。若其终点为 $z_R=R\Phi(Rz_0)$，原输出为 $D(z_R)$；本诊断输出为像素反射 $R_{\rm pix}D(Rz_R)=R_{\rm pix}D(\Phi(Rz_0))$。两者来自同一条已有轨迹，差异只在“latent反射后解码”和“解码后像素反射”的次序。

新增采样full/prefix调用为0，不使用筛选、插值或学习变换。每模型CFG与IG各400个额外渲染视图，不能和原图一起当作独立生成样本，也不能据此挽救ABBA候选。沿用原FID/IS提取器，原始latent、类别与SHA均保存关联。若差距大，支持解码／表示不交换对固定反射结果有影响；仍不能把ABBA的全部退化归因于这一项。
