# 字体

本版全部标注使用 **Comic Sans MS**，与 AdvFD 原图的文字字体相同。拉丁字母、希腊字母、公式、上下标及图注标题均使用该字体族的常规或粗体，不再混用衬线数学字体。

- `Comic.TTF`：Comic Sans MS Regular。
- `Comicbd.TTF`：Comic Sans MS Bold。
- `comic32.exe`：未改动的 Microsoft TrueType core fonts 原始分发安装包。
- `Microsoft-corefonts-EULA.html`：随包保留的最终用户许可协议。

PPTX 已内嵌常规和粗体的完整字符集，文字可继续编辑。若编辑软件不支持内嵌字体，安装上述两个 TTF 后重新打开。SVG 已内嵌同一字体，PDF 内含导出所需字体。

原始分发来源：<https://downloads.sourceforge.net/corefonts/comic32.exe>

EULA 来源：<https://corefonts.sourceforge.net/eula.htm>
